# 実装：HeroDemo(LP)のKPIカード折り返し・高さ統一

## 背景

LPのヒーローセクション(`HeroDemo.tsx`)のKPIカード3枚(FIRE達成・資産寿命・MC破綻率)で、iPhone SE相当の狭い画面幅において以下2つの表示崩れが確認された(スクリーンショット確認済み)。

1. 「52歳で達成」の見出しが「52歳で達」/「成」のように1文字だけ孤立して折り返される
2. FIRE達成カードのみサブテキスト(「FIRE達成後最低充足率{%}」)があるため縦に伸び、他の2枚(資産寿命・MC破綻率)と高さが揃わず縦長になる

`tooltip_wrap_fix.md`で`KpiGrid.tsx`(シミュレーター本体)向けに作成した`useEqualHeight`フック(`src/hooks/useEqualHeight.ts`)を、`HeroDemo.tsx`にも適用して解消する。

## 実行内容

### 1. 見出しの折り返し修正
「52歳で達成」のような見出しテキストが、1文字だけ孤立して次行に落ちないよう、`word-break`・フォントサイズ・カラム幅のいずれか適切な手段で調整する。3列レイアウト(4列の`KpiGrid.tsx`より1枚あたりの幅が狭い)であることを踏まえ、必要であれば見出しのフォントサイズを`KpiGrid.tsx`より一段階小さくすることも検討してよい。

### 2. カード高さの統一
`useEqualHeight`フック(既存)を`HeroDemo.tsx`のKPIカード3枚に適用し、サブテキストの有無に関わらず3枚の高さが揃うようにする。

## 確認事項

- iPhone SE幅(375px)相当で、見出しの折り返し崩れがないこと
- 同幅で、3枚のカード高さが揃っていること
- 既存の「資産寿命」「MC破綻率」カードの見た目(余白・文字サイズ)が、今回の調整によって崩れていないこと(LPは第一印象・コンバージョンに関わる箇所のため、他2枚への意図しない影響がないか特に注意すること)
- PC幅でも同様に崩れがないこと
