# FIX: 改善案インパクト比較パネルをdisplayStrategyに連動させる

## 背景・問題

「改善案インパクト比較」パネル(支出10%削減・退職2年延長・余剰CF全額投資の3施策について、最終資産差・破綻率変化を示す表)が、MCモードで複数戦略選択時に`displayStrategy`(表示戦略)を切り替えても値が変わらないことを実機で確認した。

具体的には、表示戦略を「現金優先」に切り替えた状態でも、このパネルの数値が「比例取崩」単独選択時の値(固定モードで最初に確認した値)と完全に一致していた。これは、以前の一連の修正(`KpiGrid.tsx`・`MonteCarloPanel.tsx`・`AssetChart.tsx`の`displayStrategy`統合)の対象からこのパネルだけ漏れていたためと考えられる。

## あるべき仕様

このパネルは「1つの基準戦略について、施策を変えたらどうなるか」を示す単一値系の表示であり、資産寿命・最終資産などの他の単一値KPIカードと同じグループに属する。**表示戦略(`displayStrategy`)を切り替えたら、このパネルの数値も連動して変わるのが正しい仕様。**

(参考:旧版`STEP35_simulator.html`の`updateImpactTable`関数は`const st = [...activeStrategies][0]`を基準にしていた。今回`displayStrategy`という明示的な概念に統合した以上、この関数も同じ基準を参照すべき)

## 依頼事項(2段階で進めてください)

### Step 1:調査・確認(先に実施)

1. 「改善案インパクト比較」パネルを描画しているコンポーネント名を特定する
2. 現在、このパネルの計算がどの戦略を基準にしているか(`activeStrategies[0]`をそのまま使っているか、別の固定値か、あるいは他の原因か)を特定する
3. `displayStrategy`に差し替える際の影響範囲(このパネル特有の計算ロジックが、他のdisplayStrategy参照箇所と同じパターンで差し替えられるか)を確認する
4. 今回と同様の見落とし(displayStrategy統合の対象から漏れている箇所)が、他にまだ残っていないか、念のため一通り確認する(資産推移グラフ・KPIカード・モンテカルロ分析欄・改善案インパクト比較以外に、戦略を参照する表示箇所がないか)
5. ここまでの調査結果を報告してください。実装はその後の指示を待ってから着手してください。

### Step 2:実装(Step 1の報告後、GOを出してから着手)

- 上記「あるべき仕様」に基づき、このパネルの基準戦略を`displayStrategy`に差し替える
- Step 1-4で他の漏れが見つかった場合は、あわせて報告し、その場で直すべきか別途指示を待つべきか確認すること(勝手に修正範囲を広げないこと)

## 検証(6-A・6-B、完了報告前に必須)

### 6-A:動作確認

1. **単一戦略選択時**:既存の表示に変化がないこと
2. **複数戦略選択時**:表示戦略(displayStrategy)をラジオで切り替えるたびに、改善案インパクト比較パネルの数値(最終資産差・破綻率変化、3施策すべて)が連動して変わること
3. **既知の値との整合性確認**:表示戦略を「現金優先」単独にした場合の値が、以前確認済みの「現金優先」単独選択時のMC結果(支出10%削減:+2,153万円/-2.3%、退職2年延長:+4,031万円/-13.3%、余剰CF全額投資:+1,196万円/+0.7%)と一致すること
4. **通常ケースのKPI**:既存のサンプルプロファイル(山本・中村・田中・佐々木)で、単一戦略時のKPI・パネル表示に変化がないこと
