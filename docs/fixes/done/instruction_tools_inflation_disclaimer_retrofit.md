# 指示書:Tools第1弾・第2弾へのインフレ非考慮注記の追記

## 背景

Tools第3弾(積立(複利)計算機)のProduct Spec策定中に、第1弾(積立額逆算ツール
`monthly-investment`)・第2弾(目標資産到達年齢シミュレーター`fire-age`)の
既存の法務注記が「税金・NISA枠上限は考慮しない旨」のみで、**インフレ(物価上昇)を
考慮しない旨**に触れていないことが判明した。

本体シミュレーター(simulate.ts)は「実質ベース」の前提を採用しているが、これは
ユーザーがインフレ率(`inflR`)を入力することで実現される仕組みであり、自動的に
実質換算されるわけではない。Tools第1弾・第2弾はインフレ率の入力を持たないため、
「入力した利回りをそのまま複利計算するだけ」という前提を明示する必要がある。

## 対応内容

第1弾・第2弾それぞれの法務注記(固定文言が表示されている箇所)に、以下の一文を
追加する:

> 「本ツールはインフレ(物価上昇)を考慮しません。入力した利回りをそのまま
> 複利計算するだけの試算です。入力する利回りが名目か実質かによって、
> 将来の金額の意味合いが変わります。インフレ率を加味した現在価値ベースの
> 試算をご希望の場合は、本格シミュレーターをご利用ください。」

## 対象ファイル(要Claude Code確認)

- `src/app/tools/monthly-investment/`配下の法務注記表示コンポーネント
  (おそらく`MonthlyInvestmentResult.tsx`または注記専用の共通コンポーネント)
- `src/app/tools/fire-age/`配下の法務注記表示コンポーネント
  (おそらく`FireAgeResult.tsx`または同上)

もし両ツールの法務注記が共通コンポーネント(例:`ToolDisclaimer.tsx`のような
共有部品)から出力されている場合は、そちらを1箇所修正するだけで済む可能性が
高い。まず既存の法務注記の実装箇所を特定し、共通化されているか個別実装かを
確認した上で修正すること。

## 完了報告に含めるべき事項

- 修正箇所が共通コンポーネントだったか個別実装だったか
- 修正後、両ツールの実画面(またはローカルビルド)で注記が正しく表示されることの確認
- 既存の他の注記文言(税金・NISA枠上限)との重複・矛盾がないことの確認
