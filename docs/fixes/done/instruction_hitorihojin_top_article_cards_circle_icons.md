# 実装指示書: 一人法人トップページの記事カードにも円アイコン処理を適用

## 背景

`instruction_hitorihojin_blog_list_circle_icons.md` で `/hitori-hojin/blog`(記事一覧ページ)のカードは対応済みだが、`/hitori-hojin`(トップページ)内の「一人法人を知る」「一人法人を考える」セクションに表示されている記事カードには、**同じ空のグレー画像枠の問題がまだ残っている。** これは前者と別のコンポーネント(おそらく `HitoriHojinArticleCard.tsx`)で実装されているため、前回の変更が及んでいなかった。

同じ処理(画像枠削除+円アイコン+テキスト一覧化)を、こちらのコンポーネントにも適用する。

## 差し戻し安全性の方針

- 引き続き `feature/lp-visual-refresh` ブランチ上で作業する。mainには直接pushしない。
- 元のコンポーネント(`HitoriHojinArticleCard.tsx`)は直接改変せず、新規コンポーネントとして追加し、呼び出し側を差し替える形にする。

## Phase 0: 調査(必須、報告してから次へ)

1. `/hitori-hojin` トップページの「一人法人を知る」「一人法人を考える」セクションが、実際にどのコンポーネントを使って記事カードを描画しているか特定する。
2. そのコンポーネントが、他にも使われている箇所(例えば一人法人以外のページ)がないか確認する。他で使われている場合、変更の影響範囲を報告する。
3. `instruction_hitorihojin_blog_list_circle_icons.md` で作成した `HitoriHojinBlogListRows.tsx` の実装(円アイコン・単色ネイビー・罫線区切り)がそのまま流用できるか、それともこのセクション専用に調整が必要か(例えば2カラムグリッドのレイアウトを維持する必要があるか)を確認する。

## Phase 1: 実装

- Phase 0の調査結果を踏まえ、「一人法人を知る」「一人法人を考える」セクションの記事カードから、空のグレー画像枠を削除する。
- `HitoriHojinBlogListRows.tsx`と同じ視覚処理(円の輪郭線、単色ネイビー、塗りつぶしなし)のアイコンに置き換える。
- レイアウト自体(2カラムグリッドで並んでいる現状の配置)は維持してよい。画像枠をアイコンに置き換える対応を基本とする。ただし、Phase 0で「テキスト一覧形式の方が自然」と判断した場合はその形に変更してもよい(判断に迷う場合はこのチャットに確認する)。

## Phase 2: 検証(証跡必須)

- 変更後の `/hitori-hojin` トップページ全体のスクリーンショット(PC・モバイル)を報告する。「一人法人を知る」「一人法人を考える」両セクションで空のグレー枠が解消されていることを確認する。
- 先に対応済みの `/hitori-hojin/blog` の見た目に影響が出ていないことを確認する。
- 各記事へのリンクが引き続き正しく機能していることを確認する。
- Vercel Preview URLを報告する。

## やってはいけないこと

- Phase 0の報告なしにPhase 1へ進まないこと。
- 元の`HitoriHojinArticleCard.tsx`を削除すること(切り戻しのため残す)。
- mainへの直接push。
- 証跡なしの完了報告をしないこと。
