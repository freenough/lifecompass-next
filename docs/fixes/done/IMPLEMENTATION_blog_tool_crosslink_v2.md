# 実装指示:ツール→ブログ記事の相互リンク追加(修正版)

## 訂正事項

前バージョンの指示書は誤って「記事→ツール」方向(既存パターンと同じ)の追加に
なっていた。本来解決したい課題は「**ツールページに、関連するブログ記事への
リンクが一切ない**」ことなので、本指示書では**ツールページ側にブログ記事への
リンクを追加する**(逆方向)。前バージョンの指示書は破棄し、本ファイルの内容を
正としてください。

対象リポジトリ:`lifecompass-next`

---

## 追加するブロックのデザイン

### 見出し

```
あわせて読みたい
```

### 配置位置

各ツールの`{Tool}Cta.tsx`コンポーネント内、**既存のCTAボタン(資産シミュレーターへ)
→アフィリエイトリンクの下**に、新規ブロックとして追加する。既存要素は一切変更しない。

```
[CTAボタン:→ 資産シミュレーターで続きを試算する]
[PR] アフィリエイトリンク
──────────────────────
あわせて読みたい          ← 新規ブロック見出し
[カード1]
[カード2](該当する場合のみ)
```

### カードのデザイン

- サムネイル画像・日付・カテゴリタグは**付けない**(ブログ一覧ページのカードとは
  明確に区別する、CTAボタンより目立たせないため)
- 構成:アイコン + 小さいラベル「次に読む」+ 太字の記事タイトル(タイトルが
  そのままリンク)
- アイコン:Tabler Iconsの`IconBook2`を使用。サイズ・色は既存のツールカードで
  使っている`IconCalculator`・`IconHourglass`等と同じスタイル(線画・
  `#334155`系カラー)に統一する
- 枠線で囲む(白背景・薄いボーダー)。既存の`/tools`一覧ページのツールカードの
  枠線スタイルを流用する
- 複数記事が対応する場合はカードを縦または横に並べる(2枚まで想定。グリッドか
  縦積みかは既存のコンポーネント幅に合わせて実装しやすい方でよい)

## UTM・GA4について

同一サイト内の遷移であり、新規GA4イベントは追加しない(既存の`tool_calculate`等
のイベント設計を分岐させない方針を踏襲)。UTMパラメータも、サイト内の同一ドメイン
遷移のため付与不要(フッター→`/tools`一覧ページ遷移と同じ扱い)。
