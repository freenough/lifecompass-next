# 指示書: Header.tsxのモバイル幅(iPhone SE等)での折り返し修正

作成日: 2026-07-19
対象: `lifecompass-next`の`src/components/layout/Header.tsx`
種別: バグ修正

---

## 1. 発生している問題

iPhone SE(画面幅375px)で、ヘッダーの「資産シミュレーター」(ロゴ+テキスト)と、ナビゲーション(「シミュレーター」「ブログ」)が折り返してしまう。

## 2. 原因

サービス名変更(LifeCompass→資産シミュレーター)により、ロゴ横のテキストが英字11文字から**全角8文字**になった。全角文字は半角英字よりも1文字あたりの横幅が大きいため、文字数は減っても実際の描画幅はむしろ増えている。狭い画面幅(iPhone SE等)では、この増加分が原因で、ロゴ+ナビの合計幅が画面幅を超え、折り返しが発生する。

## 3. 対応内容

モバイル幅(狭い画面)でのみ、文字サイズ・余白を一段階詰める。デスクトップ幅の見た目は変更しない。

- ロゴ横テキストのフォントサイズ:モバイルでは`text-base`程度に縮小し、`sm:`以上(タブレット・デスクトップ)では現状の`text-lg`を維持する
- ナビゲーションの`gap`:モバイルでは`gap-4`程度に詰め、`sm:`以上では現状の`gap-6`を維持する
- ナビゲーションのフォントサイズ:モバイルでは`text-xs`程度に縮小し、`sm:`以上では現状の`text-sm`を維持する

修正イメージ(実際のクラス名・数値は実装時に微調整してよい):

```tsx
<Link href="/" className="flex items-center gap-2 text-base sm:text-lg font-bold text-slate-800 tracking-tight">
  ...
</Link>
<nav className="flex gap-4 sm:gap-6 text-xs sm:text-sm text-slate-600">
  ...
</nav>
```

## 4. 確認方法

- iPhone SE相当の画面幅(375px)で、ロゴ・ナビともに折り返さず1行に収まることを確認する
- 実機(ヘッドレスブラウザではなく、可能であれば実際のiPhone SEまたはSafari)でも確認できると確実
- デスクトップ幅で、文字サイズ・余白が意図せず変わっていないことも確認する

---

## 5. 受け入れ基準

- [ ] iPhone SE(375px)幅で、ヘッダーが折り返さず1行に収まる
- [ ] デスクトップ幅での見た目に変化がない
- [ ] `npm run build`が型エラーなしで通る
