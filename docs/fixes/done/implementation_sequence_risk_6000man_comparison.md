# 実装指示書:初期資産6,000万円ケースの追加実行と5,000万円ケースとの比較

## 背景

`docs/fixes/done/implementation_sequence_risk_5000man_rerun.md`(前回)で
初期資産5,000万円(取崩率4.0%)のA/B/C結果を得たが、基準シナリオ(A)の破綻率が
40〜43%と、記事の主眼(「暴落そのもの」ではなく「暴落が退職直後に来ることの
怖さ」)を語るにはやや高すぎる可能性がある。6,000万円(取崩率3.33%)のケースも
追加実行し、両者を比較した上でプランニングチャット側でどちらを採用するか
判断する。

## 対象・制約

**ロックファイル(`simulate.ts`・`analyze.ts`・`montecarlo.ts`)は変更禁止。**
`scripts/sequence-risk-orcan-model-numbers.js`の初期資産のみ6,000万円に
変更し、A/B/C(N=1,000試行×2回)を再実行する。

**重要**:5,000万円ケースの結果(前回の完了報告)を上書き・削除しないこと。
6,000万円版は同じスクリプトのパラメータを書き換えて実行する形で構わないが、
実行結果(数値)は前回分と今回分の両方を今回の完了報告に含めること。

**重要(範囲外の変更について)**:前回、指示範囲外の表示ログのハードコード値
(4,000万円表記)を自己判断で修正した経緯があった。今回は無害だったが、
今後この種の「ついでの修正」が必要だと判断した場合は、**実施せず先に
報告すること**。検証スクリプトは数値の解釈に直結するため、小さな表示側の
変更であっても、無断での実施は避けること。

## 変更内容

初期資産:5,000万円 → **6,000万円**(年間取崩200万円・その他パラメータは
前回と同じ。取崩率は約3.33%になる)

## 実行・報告内容

前回と同じ形式で、N=1,000試行・2回実行し、以下を**5,000万円ケースと
6,000万円ケースを並べた比較表**として報告してください:

| 初期資産 | 取崩率 | シナリオ | 破綻確率 | 平均枯渇年齢 | 最短枯渇年齢 | 95歳p10/p50/p90 |
|---|---|---|---|---|---|---|
| 5,000万円 | 4.0% | A/B/C | (前回結果を再掲) | | | |
| 6,000万円 | 3.33% | A/B/C | (今回結果) | | | |

あわせて、6,000万円ケースについて:
- B・CそれぞれのAとの差分(破綻確率のpt差)
- 退職1年目の実際の資産減少額・減少率(円ベース)
- 2回の実行結果の安定性

## 判断基準(プランニングチャット側で最終判断するための参考情報)

以下の4条件を踏まえた所感を報告に含めてください(採用可否の決定はプランニング
チャット側で行うので、判定は不要、材料の提示のみで構いません):
1. 基準シナリオ(A)が極端に高い破綻率になっていないか
2. B(-2σ)で明確に悪化しているか
3. C(-3σ)でさらに明確に悪化しているか
4. A→B→Cの差が、記事で「前提の限界」を弁解せずに説明できる水準か

- 上記4条件に照らした所感
