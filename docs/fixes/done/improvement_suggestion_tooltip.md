# 実装：改善案提案文言に前提条件のツールチップを追加

## 背景

KPIカードの改善案文言(「支出{X}%減または退職+{Y}年で達成」)のうち、**退職延長側の数値は「延長期間中も現在と同じペースで貯蓄を続ける」ことを前提**に計算している(`buildRetirementExtension()`、NISA/iDeCo/特定口座の合算額を特定口座に継続投資する仕組み)。

この前提が文言だけでは伝わらず、フォームで手動に退職年齢を変更しただけ(継続貯蓄の仕込みなし)で試すと、提案より遅れて達成する・達成しない、という食い違いが起きることをKENZOが実機で確認した。計算ロジック自体に誤りはなく、前提条件が伝わっていないことが原因と判明済み。

## 実行内容

`KpiGrid.tsx`の改善案文言(未達成カードの3行目)に、既存の`InfoTooltip.tsx`を使って前提条件の補足説明を追加する。

- 主提案(「支出{X}%減または退職+{Y}年で達成」)は常時表示のまま変更しない
- 退職延長を含む文言(「退職+{Y}年で達成」または「支出{X}%減または退職+{Y}年で達成」)にのみ、`ⓘ`アイコン等でツールチップを付与する
- 支出削減のみの文言(「支出{X}%減で達成」)には、この前提が関係ないため付与不要

### ツールチップ文言(案、微調整はClaude Codeの判断でよい)

> 退職延長した期間も、現在と同じペースで貯蓄を続けた場合の試算です
