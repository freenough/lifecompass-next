# 実装指示書：2本柱ブロックの図を戻し、テキスト側の余白で高さを合わせる

作成日：2026-09-30
種別：**実装指示**（対象：`freenough-main`リポジトリ、`feature/top-hero-refresh`ブランチ）
前提：左右カラム比率変更（前回分）はcommit・push済み、Preview確認済み。今回はその方針を変更する。

---

## 0. 今回の内容

前回、左右カラム比率を6:4程度に変えて画像側を縮小したが、資産シミュレーター側の図（実際のシミュレーター画面）が小さくなりすぎ、視認性が落ちた。

方針を変更し、**画像側は元の大きさ（比率変更前、ほぼ1:1）に戻し**、高さの差は**テキスト側の余白を伸ばして埋める**ことで解消する。

- 見出し（「資産シミュレーター」「一人法人」）は上端、CTAボタンは下端に固定し、その間（見出し→説明文、説明文→CTA）の余白を、画像の高さに応じて自動的に広げる。
- 図は上揃え（`align-items: start`、または画像側だけ上揃え）にする。

---

## 1. 作業上の絶対ルール（これまでと同じ）

1. `feature/top-hero-refresh`ブランチで作業する。
2. 第1段階はローカル確認・報告のみ。commit・pushはKENZOの明示的な指示があってから。
3. `tsconfig.tsbuildinfo`が書き換わった場合は元に戻す。

---

## 2. 画像側の比率を元に戻す

- 前回導入した`grid-cols-[minmax(0,1fr)_min(26.5rem,50%)]`等の比率変更を元に戻し、比率変更前の指定（ほぼ1:1、800px以上でgrid-cols-2相当）に戻す。
- これにより、資産シミュレーター側の図の文字サイズも、比率変更前の大きさに戻ることを確認する。

## 3. テキスト側を画像の高さに合わせて伸ばす

- 01・02それぞれのテキスト列（見出し・説明文・CTAボタンをまとめている要素）に、**縦方向いっぱいに広がる**指定をする（`flex flex-col h-full` 等、親の`grid`行の高さいっぱいまで伸びるようにする）。
- テキスト列の中身は、`justify-content: space-between`（または見出しの下だけ`flex-grow`させる等、同等の効果が出る方法）にして、
  - 見出しは上端に固定
  - CTAボタンは下端に固定
  - 見出しとCTAの間（説明文を含む）の余白が、画像の高さに応じて自動的に伸縮する
  ようにする。
- ただし、余白が広がりすぎて説明文と見出し・CTAが不自然に離れすぎる場合（画像が非常に高い場合など）は、上限（`max-height`相当の余白上限、または一定以上離れたら余白を打ち切って残りは空白にする）を設けてよい。実装しながら見た目で判断し、上限を設けた場合はその値と理由を完了報告に書く。
- 画像側は上揃え（`align-items: start`）にする。テキスト列の見出しの上端と、画像の上端が揃うようにする。

## 4. 検証

375, 390, 768, 799, 800, 1024, 1280, 1366, 1440, 1920の全幅で以下を確認する。

- 資産シミュレーター側の図が、比率変更前の大きさ（文字が読みやすいサイズ）に戻っている
- 01・02それぞれで、見出しの上端と画像の上端が揃っている
- テキスト列の余白が画像の高さに応じて自然に広がっており、不自然な間延びがない
- 800px未満（1カラム）の表示に影響がないこと
- 横スクロールが発生していない

3. 4.の各幅でのスクリーンショット（01・02ブロック全体）
4. `npm run build`の結果
5. 気づいた点があれば別枠で記載。修正はせず報告のみ
