# 実装指示書:教育費シミュレーター フェーズ3(CTA・UTM・GA4)

## 前提

フェーズ1(データ+計算エンジン)・フェーズ2(UI)は実装・コミット済み。本フェーズはCTA文言・アフィリエイトリンク・UTM・GA4イベントの実装のみを対象とする。既存6ツールと完全に同じパターンを踏襲する。

---

## 1. CTAボックス

既存ツール(iDeCo/DC出口戦略シミュレーター等)と同一のCTAボックスデザインを流用する。

- グレー背景角丸ボックス(既存の`bg-slate-50`、幅は`max-w-2xl`で結果カードと統一)
- 構成:シミュレーター誘導文+ボタン → 直下に`AffiliateLink`コンポーネント(松井証券NISA)
- インフレdisclaimer(既存の確認済み固定文言)を含める

### シミュレーター誘導文言(案)

「この教育費のピークが資産形成にどう影響するか、本格シミュレーターの『ライフイベント』機能で確認できます」

ボタンラベル:「資産シミュレーターで確認する」(既存ツールのボタン文言パターンに合わせて微調整可)

リンク先:資産シミュレーター本体、ライフイベント機能への導線(既存ツールが同機能に誘導している場合はそのリンク構造をそのまま参照する)

### アフィリエイトリンク

- `matsui/nisa`(教育資金づくりの文脈)をそのまま使用、`AffiliateLink`コンポーネント流用
- `rel="sponsored"`・`[PR]`表記など既存規約に従う

---

## 2. UTMパラメータ

- キャンペーンパターン:`utm_source=tools&utm_medium=referral&utm_campaign=education_cost_tool`(既存ツールのUTM命名規則`{tool_name}_tool`に準拠)
- シミュレーターへのリンク・アフィリエイトリンクそれぞれに付与(既存ツールの実装を確認し、同じ付与方法(クエリパラメータの組み立て方)に揃える)

---

## 3. GA4イベント

既存3種のイベントをそのまま実装する(新規イベントは追加しない):

- `tool_calculate`:入力変更→計算実行時に発火(既存ツールの発火タイミング・デバウンス有無を確認して合わせる)
- `tool_to_simulator_cta_click`:シミュレーター誘導ボタンクリック時
- `tool_to_nisa_cta_click`:アフィリエイトリンククリック時

本ツール特有の注意点:子供の人数・仕送りON/OFFなど複数の入力要素があるため、`tool_calculate`が入力のたびに過剰発火しないか(例:タブ切り替えのたびに毎回発火してしまう等)既存ツールの実装パターンと比較して確認すること。

---

## 4. 確認事項

- 既存6ツールと並べて見た際、CTAボックスのデザイン・文言のトーンに違和感がないか
- UTM付きリンクが正しく`?utm_source=...`形式で生成されているか(実際にクリックしてリンク先URLを確認)
- GA4のDebugViewで3イベントが正しいタイミング・パラメータで発火しているか
- 完了報告時は、変更したコンポーネント名を明記すること(行番号は使用しない)
