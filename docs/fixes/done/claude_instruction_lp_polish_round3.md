# 実装指示：お悩みカード背景色調整／フッター濃紺エリア拡大／セクションラベル区切り線の太さ調整

作成日：2026-09-21
種別：**実装（小規模な見た目調整）**
関連：`claude_instruction_lp_polish_round2.md`（完了報告への追加対応）

---

## 背景

`claude_instruction_lp_polish_round2.md`（お悩みカード修正・ラベル濃色化・ケーススタディ左固定・資産管理ダーク化実験）の完了報告をKENZOが実機確認した結果、以下3点の追加対応が決まった。

- 資産管理ツールブロックのダークゾーン化実験（`feature/lp-asset-dark-experiment`）は、見た目がしっくりこなかったため**見送り**。このブランチはmainにマージしない（別途Claude Codeに伝達済み、本指示書の対象外）
- お悩みカードは、枠線が薄く存在感が弱いため、**枠線はそのまま・カード内部の背景色を`bg-sub`に変更**して存在感を出す
- あわせて以下2点も対応する

---

## 1. お悩みカードの背景色を変更する

- 現状、お悩みカード（`ConcernCard.tsx`）は白背景＋薄いグレーの枠線になっている
- **`border`に関連するクラス・プロパティ（`border`, `border-*`, 枠線の色・太さを指定している箇所）には一切触れないこと。** 現状のコードの該当部分をそのまま残し、変更を加えないこと（「太くする」「戻す」等、どちらの方向の調整も不要）
- 変更するのは、**カードの内部の背景色のみ**。現状の白背景（`bg-white`等）を、`bg-sub`（前回1節のボタン配色変更で使用した、globals.css定義済みの薄いグレー背景トークン）に置き換える
- つまり、diffとしては背景色のクラス（`bg-white`→`bg-sub`のような1箇所）のみが変わり、`border`関連の行は差分に一切現れない、という状態が正しい
- 新しい色は追加で定義しないこと。既存の`bg-sub`トークンをそのまま再利用する
- モバイル幅・デスクトップ幅の両方で確認すること

## 2. フッターの濃紺エリアを拡大する

- 現状、ページ最下部の著作権表示バー（`© 2026 FREENOUGH` / `本サービスは情報提供を目的としており、投資助言ではありません。`）のみが濃紺背景になっている
- その直上にある、リンク一覧セクション（「FIREを考える」「一人法人を考える」の見出しと、その下の`資産シミュレーター`/`ツール`/`お悩み`/`ブログ`/`一人法人トップ`/`一人法人ブログ`等のリンク一覧、さらにその下の`シミュレーター`/`資産管理ツール`/`使い方ガイド`/`計算ロジック`/`X`/`Note`の一覧、`Freenoughについて`/`広告開示`/`プライバシーポリシー`/`免責事項`/`運営者情報`の一覧）を含めて、**フッター全体（リンク一覧〜著作権バーまで）をひと続きの濃紺エリアにする**
- 背景色は、既存の`--color-accent`（#334155）ではなく、著作権バーで既に使われている濃紺の値をそのまま使い、フッター全体で統一すること（著作権バーの色を変えるのではなく、リンク一覧部分の背景をそちらに合わせる）
- 文字色は、濃紺背景の上で十分なコントラストが取れるよう調整すること（現状の薄いグレー文字のままだと視認性が落ちる可能性が高いため、白系または明るいグレー系に変更する）。リンクのホバー色等、インタラクティブ要素の視認性も確認すること
- フルブリード（画面幅いっぱい）で背景色を敷くこと。中身のコンテナ幅（既存の`max-w-*`）自体は変更しないこと
- モバイル幅・デスクトップ幅の両方で確認すること

## 3. セクションラベルの区切り線を太くする

- 「— お悩み」「— FIREガイド」「— ケーススタディ」等、各セクション見出し上部にあるラベルの左に付いている短い横線（`h-px w-6 bg-slate-300`のような実装になっているはず）が細すぎて見えにくい
- 前回、ラベルの文字色を濃くした結果、相対的にこの線がさらに目立たなくなっているため、**線の太さを1〜2px程度太くする**こと（例：`h-px`→`h-0.5`程度。Tailwindの高さクラスの都合で近い値に調整してよい）
- 色は変更しなくてよい（前回変更していなければ`slate-300`のまま）
- LPトップの全セクションで同じパターンが使われているはずなので、該当箇所すべてに反映すること
