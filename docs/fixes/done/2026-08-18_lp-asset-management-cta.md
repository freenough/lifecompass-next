## 0. 前提・スコープ

- 本指示は資産シミュレーター本体LP（`/asset-simulator/` トップ）への変更。
- **ロックファイルには一切触れない**：`simulate.ts` / `analyze.ts` / `PortfolioPanel.tsx` / `simulatorStore.ts` / `profile.ts`
- 既存の資産管理ツール本体（`src/components/assetManagement/*`、`src/app/assets/page.tsx`）にも変更は不要。今回はLPからのリンク導線のみを追加する。
- 着手前に、LPの現在のセクション構成を管理しているファイル（トップページのコンポーネント構成）を確認し、以下の配置がどのファイルに実装されているか特定すること。指示範囲外の構造変更が必要そうな場合は、実装前に報告すること。

## 2. 新規セクション：資産管理ツール導線

### 2.1 コンポーネント方針

- 新規ファイルとして切り出す（既存セクションと同様の粒度を想定）。命名は既存パターンに合わせて決めてよいが、例：`AssetManagementPromoSection.tsx`
- 配置先ディレクトリは、他のLPセクションコンポーネント（悩み・かんたん計算ツール・あなたはどのタイプ等）が置かれているディレクトリに合わせる
- `src/lib/assetManagement/routes.ts` 等、既存の資産管理ツールのルート定義があればそれを import してリンク先URLを取得する（URLのハードコード禁止）

### 2.2 レイアウト

- デスクトップ：2カラム（左：テキスト＋CTA、右：イラスト風ミニダッシュボード）
- モバイル：1カラムに縦積み（テキスト→イラスト→CTA の順、またはテキスト＋CTA→イラストの順。既存の悩みセクション等のレスポンシブパターンに準拠）
- 外枠：角丸12px、薄いボーダー、白背景カード（既存の「悩み」カード等のトークンに準拠）

### 2.3 コピー（確定文言）

**見出し：**
```
毎月の資産を、記録する。
```

**サブテキスト：**
```
シミュレーションで描いた未来と、実際の資産を突き合わせる。目標との差分がひと目でわかります。
```

**3つの特徴（アイコン＋テキスト）：**
```
[アイコン: chart-donut系]  カテゴリ別に資産を入力するだけ
[アイコン: target系]       目標資産との差分・進捗率を表示
[アイコン: trending-up系]  前回記録との増減がひと目でわかる
```

**CTAボタン：**
```
資産管理ツールを開く →
```

**CTA下部の補足テキスト：**
```
無料・登録不要・データは端末内に保存
```
（シミュレーター本体HEROの補足文言と統一表現）

### 2.4 右側イラスト（ミニダッシュボード風・静的モック）

**重要：実データ連携ではなく、静的な「見立て」イラストとして実装する。** 資産管理ツール本体の実装内容が変わってもLP側の修正が不要になるよう、固定のモック値・固定のダミー円グラフとする。

構成：
- カード内タイトル：「資産の内訳」
- 円グラフ（CSS `conic-gradient` または軽量な自前SVGで実装。ライブラリの新規導入は不要）
- 円グラフの4分割と色（シミュレーター本体の結果グラフの配色に統一。半透明トーン）：
  - 株式・投信：`rgba(59,130,246,0.45)`（青）
  - 現金：`rgba(147,197,253,0.55)`（水色）
  - iDeCo：`rgba(148,163,184,0.4)`（グレー）
  - その他：`rgba(74,222,128,0.45)`（緑）
- 円グラフ角度配分の例：株式・投信158°／現金94°／iDeCo54°／その他54°（合計360°、見た目のバランス用の固定値でよい。実データ連動は不要）
- 凡例：色スウォッチ＋ラベルを4行
- 円グラフ下に2つのミニ統計カード（グレー背景の角丸カード）：
  - 「目標達成率」→ `68%`
  - 「前回比」→ `+3.2%`（色は本文と同じ通常テキスト色。目立たせすぎない）
- **日付表記は入れない**（「2026年8月」等の月表記は不要、モックとして不要と判断済み）

## 3. 最終CTAセクションの改修

### 3.1 方針

既存の「まず、自分の数字を入れてみる。」セクションは**そのまま維持**（見出し・サブテキスト・ボタン・補足文言はすべて変更なし）。その下に、資産管理ツールへの**従属的な**導線を追加する。

### 3.2 追加要素（既存CTAブロックの下に追加）

**区切り：**
- 横線＋中央にテキスト「すでに試算した方は」を挟む区切り（線ー線の間にテキスト、既存デザインに区切り線パターンがなければ簡易な `border-top` ＋中央配置テキストで可）

**セカンダリ導線（テキストリンク、ボタンにはしない）：**
```
資産を記録して、進捗を確認する →
```

- 見た目：下線付きテキストリンク、フォントサイズは主CTA・補足文言より小さめ（本文の`text-secondary`相当の色）
- ボタンコンポーネントは使わず、通常の `<a>` またはNext.jsの `<Link>` として実装し、視覚的な優先度を明確に主CTAより下げる
- リンク先は資産管理ツールのルート（`src/lib/assetManagement/routes.ts` 等の既存定義から取得）
