# 修正指示書:retirementTaxCalc() 退職所得控除額 80万円下限バグ

## 背景

第5弾ツール(退職金手取り計算)の投資調査(`investigation_retirement_tax_tool.md`)
の過程で、`src/lib/helpers.ts`の`retirementTaxCalc()`に、
本来のツール開発とは別の潜在バグが見つかった。

現状の実装は勤続年数20年以下の場合の退職所得控除額を
「40万円×勤続年数」で計算しているが、国税庁の規定では
この金額に**最低80万円の下限**が設けられている
(勤続年数が2年以下の場合、40万円×勤続年数が80万円を
下回るため、本来は80万円が適用されるべき)。

この下限が未実装のため、勤続年数が短いケース(例:勤続1年)で
控除額が過小になり、結果として**過大課税**になっている。

`retirementTaxCalc()`は`src/lib/helpers.ts`にあり、
`simulate.ts`/`analyze.ts`本体ロックファイルではないため、
修正対象として扱ってよい(要:実装時に念のためロックファイル
一覧を再確認し、`helpers.ts`が対象外であることを確認すること)。

## 修正してほしいこと

1. `retirementTaxCalc()`内の退職所得控除額計算部分を修正し、
   勤続20年以下の場合の控除額を`Math.max(40万円×勤続年数, 80万円)`
   とする(20年超の場合の計算式には影響しないはずだが、
   念のため既存の20年超側のロジックに意図しない影響が
   出ていないか確認すること)

2. 障害者特例(+100万円)は**今回のスコープ外**とする
   (これは「未実装機能の追加」であり「バグ修正」ではないため、
   別途ツール側で対応するか、本体側に追加するかは別途判断する。
   今回は80万円下限バグの修正のみに留めること)

## 検証してほしいこと

- 修正前後で、勤続年数が3年以上のケース(80万円下限に
  かからないケース)の結果が変わらないことを確認する
  (回帰がないことの確認)
- 勤続年数1年・2年のケースで、修正後は控除額が80万円に
  なり、課税退職所得金額・税額が正しく減少することを確認する
- 勤続年数20年ちょうど・21年(20年超の境界値)のケースが
  影響を受けていないことを確認する
- 検証スクリプトを作成し、境界値・代表値でのPASS/FAILを
  明示すること(過去の類似修正と同様の形式でよい)
- `full-verify.js`があれば実行し、既存機能全体に回帰がないことを
  確認する

## 注意事項

- `simulate.ts` / `analyze.ts`には一切触れないこと
  (今回の修正対象`helpers.ts`がこれらと異なるファイルであることを
  実装前に確認すること)
- 完了報告には、計算方法(本番関数経由か、独自検証か)を明記すること
- 完了報告には関数名を明記し、行番号は使用しないこと
- この修正は既存機能(本体シミュレーターの退職金課税計算)に対する
  ものであり、ブログ記事等の確定済みコンテンツの数値には影響しない
  想定だが、もし過去に公開したブログ記事の試算がこの関数を
  経由していた場合は、その旨を完了報告に明記すること
  (過去記事は"公開時点のスナップショット"として扱い、遡って
  修正はしない方針を踏襲する)
