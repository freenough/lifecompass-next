# 実装指示書: 背景グレー化が「画面幅いっぱいの帯」になっていない問題の修正

## 背景

`instruction_hitorihojin_gray_background.md` の実装結果をPreviewで確認したところ、最終CTA部分(「一人法人を考える前に...」〜「資産シミュレーターで試算する→」)は、**角丸・白背景に浮いた"箱"のまま、色だけがグレーに変わった状態**になっていた。

資産シミュレーター側の対応するセクション(「まず、自分の数字を入れてみる。」)は、**画面の端から端まで背景色が伸びるセクション単位の帯**になっており、左右に白い余白は残らない。この構造の違いが、「グレーになっていない」ように見える原因になっている。

## 差し戻し安全性の方針

- 引き続き `feature/lp-visual-refresh` ブランチ上で作業する。mainには直接pushしない。

## やること

1. 最終CTA部分を、**角丸・枠線付きの"箱"としてページ内に浮かせる構造から、画面幅いっぱいに広がるセクション単位の背景帯**に変更する。資産シミュレーター側の「まず、自分の数字を入れてみる。」セクションと同じ構造(背景は画面端まで、コンテンツ自体はその中で中央寄せ・幅を制限)にする。
2. **「一人法人を知る」「一人法人を考える」セクションについても、同じ構造(画面幅いっぱいの背景帯)になっているか確認する。** もし同様に角丸の箱として浮いた状態のままであれば、同じ考え方で画面幅いっぱいの帯に修正する。
3. ボタンの色・角丸・枠線など、ボタン自体の見た目は変更しない(背景セクションの構造のみが対象)。

## 検証(証跡必須)

- 修正後のスクリーンショット(PC・モバイル)を報告する。最終CTA・「一人法人を知る/考える」セクションともに、背景が画面の端から端まで伸びており、左右に白い余白(枠)が残っていないことを確認する。
- 資産シミュレーター側の対応セクションと構造が一致していることを確認する。
- Vercel Preview URLを報告する。

## やってはいけないこと

- ボタン自体の見た目(色・角丸・枠線)を変更すること。
- mainへの直接push。
- 証跡なしの完了報告をしないこと。
