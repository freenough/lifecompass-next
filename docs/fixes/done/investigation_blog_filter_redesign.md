# 調査指示書:ブログ一覧フィルタ再設計(category廃止→topics主軸+stages維持)

作成日: 2026-08-03
このチャットでの決定事項を踏まえた投資調査。**実装は行わず、調査結果の報告のみ**。

## 背景・決定事項(この指示書の前提)

- `category`(FIRE基礎知識/シミュレーター活用)をフィルタ軸から廃止し、
  記事カード単位の軽量バッジ表示に格下げする
- `topics`/`primaryTopic`(現状12種、UI非露出のクロスリンク専用フィールド)を
  ユーザー向けフィルタの主軸に格上げする。ただし12種のままでは粒度が細かすぎるため、
  意味のある親グループに統合する(下記「調査項目2」参照)
- `stages`(concerns.tsと共有するライフステージ軸)はそのまま維持する
- 新2軸構成:「主題(topics統合後)」×「ステージ(stages)」

## 調査項目

### 1. 現行フィルタUIの実装構造

- `src/components/blog/BlogListClient.tsx`が現在category×stageの2軸フィルタを
  どう実装しているか(コンポーネント構造、状態管理、URLクエリとの連携有無)
- category軸を「複数選択可能なtopicsタグ」に置き換える場合の改修コスト感
  (単一選択タブ→複数選択タグへのUI変更が必要になる想定。既存のstage軸は
  単一選択のまま維持でよいか、それとも将来的に複数選択にする可能性も
  考慮すべきか、実装上の制約があれば報告)
- categoryフィールド自体は削除するのか、データとしては残してバッジ表示にのみ
  使うのか、現状のfrontmatter・型定義への影響範囲

### 2. topics12種の親グループ統合案の精査

現在の12種:
```
nisa, ideco, pension, withdrawal, montecarlo, education_cost,
compound_interest, fire_basics, fire_age, retirement_tax,
dual_income, inflation
```

このチャット側で仮に立てた5グループ案(たたき台、精査前提):
- NISA・投資 ← nisa, compound_interest
- iDeCo・退職金 ← ideco, retirement_tax, dual_income
- 年金・リタイア後の生活 ← pension, withdrawal
- 教育費・ライフイベント ← education_cost
- シミュレーションの考え方 ← montecarlo, fire_basics, inflation, fire_age

**調査してほしいこと:**
- 全14記事の実際の本文内容と現在のtopics設定値を照らし合わせ、上記グループ分けが
  読者の探索体験として妥当か(特にdual_income、fire_basics、fire_ageのように
  複数文脈にまたがる語彙の割り当てに違和感がないか)
- 統合後、各グループに何記事が紐づくか一覧化(1記事しかないグループが残らないか)
- 別の切り方の方が自然であれば対案を提示してよい(決定はこのチャット側で行うが、
  実データを見た上での提案は歓迎)

### 4. topicsフィールドの「表示用」と「スコアリング用」の分離要否

- 現行`topics`は関連記事アルゴリズム(`getRelatedPosts`/`getRelatedPostsForTopics`)の
  スコアリングに使われている内部データ
- これを表示用フィルタにも流用する場合、以下いずれが適切か調査・提案:
  a) 同一の`topics`フィールドをそのまま両用途に使う
  b) 表示用に新しい`displayTopics`(親グループ)フィールドを追加し、
     既存`topics`(12種)はスコアリング専用として温存する
- 既存14記事全てへの影響範囲(frontmatter追加が必要な場合の作業量)を報告

### 5. 一覧ページ冒頭の見出し・リード文言の変更箇所

- 現在の見出し「ブログ」とリード文「FIREと資産形成の情報を発信しています。」が
  どのファイルのどこにハードコードされているか特定
- 変更後のリード文言(このチャットで確定済み):
  「制度の解説だけでなく、独自シミュレーターでの試算結果もあわせて紹介しています。」
- 見出し「ブログ」自体は変更しない(現状維持)。リード文のみ差し替え対象
- 実装時の変更箇所(ファイルパス・該当箇所)を報告のみ。今回はまだ実装しない
