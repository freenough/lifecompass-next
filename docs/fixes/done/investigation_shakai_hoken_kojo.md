# 調査指示:社会保険料控除・調整控除の推定方法の仕様化(フェーズ1・調査のみ、実装しない)

## 位置づけ
resident-tax-timingツールの計算精度改善の第1段階。年収600万円の手動テストで、
本ツールの試算(約39.8万円/年)が、社会保険料控除等を考慮した簡易計算機の試算
(約30.65万円/年)より約9万円過大であることが判明した。主因は社会保険料控除の欠落。
本指示は、この控除を追加するための一次情報調査であり、**実装は一切行わない**。

「15%」のような数字を先に決め打ちしないこと。以下の調査結果を踏まえて仕様を確定してから、
別途フェーズ2の実装指示を作成する。

## 調査対象

### 1. 社会保険料の構成要素の確認
給与所得者の社会保険料は、通常以下で構成される。それぞれの一次情報を確認すること:
- 厚生年金保険料率(全国一律のはず。現行の料率を確認。本人負担分=労使折半後の割合)
- 健康保険料率(協会けんぽの場合、都道府県ごとに異なる。組合健保の場合はさらに異なる。
  本ツールは都道府県入力を持たないため、全国平均または最も加入者の多い都道府県の料率を
  「標準」として採用してよいか、その根拠と共に検討すること)
- 介護保険料(40歳以上のみ加算。本ツールに年齢入力がないため、年齢を考慮しない場合の
  影響と、年齢入力を追加する場合の実装コストを比較検討すること)
- 雇用保険料率(業種により異なる。一般の事業の料率を標準としてよいか検討)

出典候補:
- 日本年金機構:厚生年金保険料率のページ
- 全国健康保険協会(協会けんぽ):都道府県ごとの保険料率表
- 厚生労働省:雇用保険料率のページ

### 2. 標準報酬月額の扱い
- 社会保険料は「実際の月給」ではなく「標準報酬月額」(一定の等級に区分された金額)を
  基準に計算される。本ツールのような年収ベースの簡易試算で、標準報酬月額表を
  正確に反映すべきか、それとも年収に対する概算料率(合算後の実効税率)で近似してよいかを検討すること
- 標準報酬月額には上限がある(高所得者ほど、実効的な社会保険料率が年収に対して逓減する)。
  800万円等の高年収パターンでこの上限の影響がどの程度出るか、試算して報告すること
- 賞与にも社会保険料がかかる(標準賞与額、年間累計に上限あり)。本ツールは賞与を
  月割り推計の中に含めている(年収を12等分)ため、賞与分の社会保険料をどう近似するかも検討すること

### 3. 調整控除の計算式
- 個人住民税の「調整控除」(所得税と住民税の人的控除の差を調整するための控除)の
  現行の計算式・金額を、総務省または国税庁の一次情報で確認すること
- 本ツールは独身・扶養なしを前提としているため、調整控除の計算はどの程度単純化できるか
  (扶養家族がいる場合との差)を確認すること

### 4. 設計方針への示唆(調査結果に基づく所見の提示のみ、実装はしない)
- 上記を踏まえ、「標準ケースでは全国平均等の概算料率で社会保険料控除を推定し、
  正確に試算したいユーザーは実額(年間社会保険料)を入力できるようにする」という
  設計方針(既存の「より正確に試算する」パターンを踏襲)が技術的に妥当かどうかを所見として述べること
- 概算料率を採用する場合の具体的な数値案(本人負担の合計目安として何%とするか、
  根拠となる一次情報とともに)を提示すること
- 標準報酬月額の上限を無視した場合、高年収帯でどの程度の誤差が生じるか、定量的に見積もること

3. 賞与分の社会保険料の扱いに関する考察
4. 調整控除の現行の計算式、出典URL
5. 設計方針への所見(概算料率の具体案、実額入力とのハイブリッド設計の妥当性、高年収帯での誤差の定量評価)
6. 参照した一次情報のURL一覧
