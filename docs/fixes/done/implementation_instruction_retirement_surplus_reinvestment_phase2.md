## 実装タスク

### 1. トグルUIコンポーネント

- 配置場所:取崩戦略選択(比例取崩・現金優先・課税優先)の近傍。既存の
  取崩戦略選択UIコンポーネントを確認し、視覚的に「黒字/赤字で挙動が
  変わる」ことが伝わる位置に配置すること
- トグル本体の文言:「退職後の収支黒字を運用する」
- 補足説明文(トグル近傍・ヘルプテキストまたはtooltip):
  「年金などの収入が支出を上回った場合、その差額を特定口座で運用します。」
- デフォルト状態:OFF
- スペース制約で文言調整が必要な場合、意味を変えない範囲で短縮してよい
  (最終文言は実装後にスクリーンショット等で確認)

### 2. State管理・`profile.ts`配線

- フォームのstate(Zustand store等、既存の取崩戦略選択と同じ管理方式)に
  `retirementSurplusReinvest`を追加
- `profile.ts`のシリアライズ/デシリアライズ関数に配線し、プロファイル保存・
  読込・URL共有時にトグル状態が正しく保持されることを確認する
- 既存の`loadInitialProfile`のマージ仕様
  (`{ ...SAMPLE_PROFILE, ...loaded, params: {...SAMPLE_PROFILE.params, ...loaded.params} }`)
  を踏まえ、古い保存済みプロファイル(このフィールドを持たない)を読み込んだ
  場合に`undefined`→falsy評価で正しくOFF扱いになることを確認する

### 3. grep確認

- 新規追加したコンポーネント・変数名に「LifeCompass」「FIRE達成」の
  文字列が含まれていないことを確認する

### 4. 実機確認

- トグルON/OFF切り替えで、KPIグリッド(総資産・破綻率等)や口座別内訳
  表示(`YearlyTable.tsx`等)の数値が期待通り変化することを、黒字が発生する
  プロファイル(例:年金額が支出を上回る設定)を作成して確認する
- トグルOFF(デフォルト)のまま、既存のサンプルプロファイル・田中/山本/
  中村/佐々木の各シナリオ表示に変化がないことを確認する
- モバイル幅での表示崩れがないことを確認する
