# 実装指示書：2本柱ブロックの図カードサイズ統一・テキスト間隔の固定化

作成日：2026-09-30
種別：**実装指示**（対象：`freenough-main`リポジトリ、`feature/top-hero-refresh`ブランチ）
前提：図を1:1に戻し、テキスト側を可変余白で伸ばす対応（前回分）はcommit・push済み、Preview確認済み。今回はその可変余白の方式をやめる。

---

## 0. 今回の内容

1. 01・02の右側の図カード（枠・背景を含む箱）の縦横サイズを統一する
2. テキスト側の「見出し→説明文」「説明文→CTA」の間隔を、両方とも同じ固定値にする（画像の高さに合わせた伸縮はやめる）

---

## 1. 作業上の絶対ルール（これまでと同じ）

1. `feature/top-hero-refresh`ブランチで作業する。
2. 第1段階はローカル確認・報告のみ。commit・pushはKENZOの明示的な指示があってから。
3. `tsconfig.tsbuildinfo`が書き換わった場合は元に戻す。

---

## 2. 図カードのサイズ統一

- 01（資産シミュレーターの実画面スクリーンショット）・02（分岐図）、それぞれを包むカード（白背景・枠線・角丸のコンテナ）の**幅・高さを共通のサイズ**にする。
- 基準は01のカードサイズ（実際のシミュレーター画面を収めるのに必要な高さ）に合わせる。02のカードもこれと同じ高さ・幅にする。
- 02側の画像は、このカードサイズの中に`object-fit: contain`等で収める（画像を無理に引き伸ばさない。カード内に余白ができるのは問題ない）。画像の配置は上寄せか中央のどちらが自然か、実装しながら確認して選んでよい（判断理由を完了報告に書く）。
- 800px以上の全幅で、01・02のカードの高さが一致していることを確認する。
- 800px未満（1カラム）では、カードは画面幅に応じて縮小されるため、縦横比は保ったまま統一サイズの考え方を維持する。

## 3. テキスト間隔の固定化

- 前回導入した「見出し→説明文」「説明文→CTA」の伸縮する余白（flex-growで画像の高さに合わせる方式）をやめる。
- 両方とも、**現在の「見出し→説明文」の間隔（上限48px）と同じ固定値**にする。01・02とも同じ値。
- CTAは画像の下端に揃える必要はない。上揃え（見出しの上端と画像の上端を揃える）は維持し、下側の余り（テキスト列が画像より短くなる分の空白）はそのままでよい。

---

## 4. 検証

375, 390, 768, 799, 800, 1024, 1280, 1366, 1440, 1920の全幅で以下を確認する。

- 01・02の図カードの高さが揃っている（800px以上）
- 02側の画像がカード内に自然に収まっている（引き伸ばされていない）
- 見出し→説明文、説明文→CTAの間隔が、01・02とも同じ固定値になっている
- 見出しの上端と図の上端が揃っている（前回どおり）
- 横スクロールが発生していない

---

## 5. 完了報告の形式

1. カードサイズ統一の値（01・02それぞれの変更前後の高さ、幅ごと）
2. テキスト間隔の固定値
3. 4.の各幅でのスクリーンショット（01・02ブロック全体）
4. `npm run build`の結果
5. 気づいた点があれば別枠で記載。修正はせず報告のみ

commit・pushは、KENZOの明示的な指示があってから行う。
