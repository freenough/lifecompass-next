# 修正：改善案文言へのツールチップアイコン追加による折り返し崩れ

## 問題

`improvement_suggestion_tooltip.md`で追加した`ⓘ`アイコンにより、長い改善案文言(例:「支出12%減または退職+18年で達成」)がアイコン分だけ余計に折り返され、カードの高さが他のKPIカードより伸びてしまっている(スクリーンショットで確認済み)。

## 修正方針(確定・2点セットで実施)

### 1. `ⓘ`アイコンを廃止し、点線下線(dotted underline)方式に変更する

改善案文言(退職延長を含むケース)自体に`text-decoration: underline dotted`(またはそれに準ずるスタイル、下線の色・太さはデザイントークンに従う)を付与し、タップ/ホバーで前提条件のツールチップが表示されるようにする。別要素としてのアイコンは追加しない(幅を消費しないため、アイコン追加による折り返し増加そのものが起きなくなる)。

- 支出削減のみの文言(前提条件が関係ないケース)には下線を付けない(既存方針通り)

### 2. KPIカード4枚の高さを揃える

`KpiGrid.tsx`の4枚(資産寿命・FIRE達成・MC破綻確率・最終資産)のレイアウトに、CSS Grid/Flexboxの`align-items: stretch`(またはそれに準ずる高さ統一手法)を適用し、**文言の長さに関わらず4枚の高さが揃う**ようにする。

背景:支出%・延長年数はプロファイルによって桁数が変わるため(例:「支出45%減または退職+27年で達成」のように、今回よりさらに長い文言になるケースも起こりうる)、「常に1行に収まる」ことをCSS側で保証するのは非現実的。折り返し自体は許容し、その代わりカード間の高さ不揃いという崩れ方を防ぐ、という設計判断に基づく対応。

## 確認事項

- 修正後、KPIカード4枚(資産寿命・FIRE達成・MC破綻確率・最終資産)の**高さが揃っていること**(1枚だけ突出して高くならないこと)
- 短い文言(「支出12%減で達成」など、退職延長を含まないケース)ではアイコンが付かないため、この確認は不要
- モバイル幅(320px程度)でも同様に確認すること
