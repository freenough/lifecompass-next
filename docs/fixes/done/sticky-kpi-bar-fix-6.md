# 指示: 「保存/読み込み」ボタンも常時固定化し、入力トグンと横並び1行で隣接配置

## 背景
「入力を閉じる/編集」トグンと同様、「保存/読み込み」ボタンもスクロール位置に
関わらずいつでも押せるべき、という判断になった。現状は通常のスクロールフロー内に
あり、スクロールすると流れて見えなくなる。

なお、本プロジェクトには「UIコンポーネントで2段レイアウトを作らない」という
既存の設計原則があるため、2つのボタンは2段ではなく横並び1行で配置する。

## やること

### 1. 「保存/読み込み」ボタンの常時固定化（トグンと横並び1行）
「保存/読み込み」ボタンを `position: fixed` にし、画面最上部（ヘッダー直下）に
常時表示する。

**2段ではなく、「入力を閉じる/編集」トグンと横並び1行で配置すること**
（本プロジェクトの「UIコンポーネントで2段レイアウトを作らない」という
既存の設計原則に従う）。

- 配置順序: ヘッダー → [「保存/読み込み」ボタン＋「入力を閉じる/編集」トグン
  を横並び1行] → 「入力パラメータ」ボックス（隙間なく隣接、余分な余白を作らない）
- 横幅の配分: トグンが主要な操作のため広めに、「保存/読み込み」は最小限の幅で
  よい（例: トグン側を `flex-1`、保存/読み込みは内容に応じた固定幅）。
- 両ボタンの `top` 値は同じ（1行のため段差なし）。
- 表示範囲は「入力を閉じる/編集」トグンと同じブレークポイント（`lg:hidden`、
  縦積みレイアウトの間のみ）に揃える。PC幅（横並びレイアウト）では
  「保存/読み込み」ボタンは元々の通常配置のままでよい（固定にする必要はない）。

### 3. 余分な余白を作らないこと（重要・従来の既知の問題を含む）
以前のセッションで、「入力を閉じる/編集」トグンと「入力パラメータ」ボックスの
間に意図しない余白が生まれ、「保存/読み込み」ボタンが隠れる、という
リグレッションが発生していた（原因はスクロールアンカー用要素が
レイアウト上の高さ・余白を持ってしまっていたこと）。

今回、「保存/読み込み」ボタンをトグンと同じ行に統合することで、この行自体を
作り直す形になる。実装にあたっては、以下を満たすこと。

- 固定行（保存/読み込み＋トグン）の直下に、「入力パラメータ」ボックスが
  余分な余白なく密着して表示されること（本番機の見た目を基準にする）。
- `tabAnchorRef`・`formTopAnchorRef` 等のスクロール位置合わせ用の要素は、
  レイアウト上の高さ・余白を一切持たない形（例: 高さ0の要素、または
  既存要素に直接 `ref` を付与する形）で実装し、見た目に影響を与えないこと。
- 実装後、固定行の高さ・「入力パラメータ」ボックスとの間隔を実際に計測し、
  余白が生まれていないことを報告すること。

### 4. スクロールアンカーのオフセット再計算
前回追加した `tabAnchorRef`（閉じる時）・`formTopAnchorRef`（開く時）の
`scroll-mt-28` は、固定要素の合計高さ（ヘッダー＋入力トグン、約94px想定）を
基準に設定されていた。今回「保存/読み込み」ボタン分の高さが追加されるため、
両アンカーの `scroll-mt` 値を、新しい固定要素の合計高さに合わせて再計算すること。
（マジックナンバーの決め打ちではなく、実際に固定要素の高さを計測した上で
値を設定し、その根拠を報告すること）

### 5. 前回のリグレッション修正の指示との関係
これは以前単独で出した「トグンとフォームの間の余白除去」指示（別ファイルとして
渡していたもの）を、本指示の3番に統合したものである。**別ファイルの指示は
本指示に統合済みのため、別途参照・実施する必要はない。**

## 制約・確認事項
- `simulate.ts` / `analyze.ts` は変更禁止。
- StickyKpiBar・入力トグンの開閉方向それぞれのスクロール機能は変更しない。
- 完了後、`full-verify.js` がPASSすることを確認。

## 動作確認観点
1. 縦積みレイアウトの範囲（`lg:` 未満）で、スクロールしても「保存/読み込み」
   ボタンと「入力を閉じる/編集」トグンの両方が常に画面上部に見え続けるか
2. 2つのボタンが重ならず、横並び1行で意図した幅配分（保存/読み込みが最小限、
   トグンが広め）で並んでいるか
3. トグンと「入力パラメータ」ボックスの間に余分な余白が生まれていないか
4. 「開く」「閉じる」双方向のスクロールアンカーが、新しい固定要素の高さを
   踏まえて正しい位置（入力パラメータ最上部／固定モード・MCモードタブ直上）に
   着地するか
5. `lg:` 以上（PC幅）で、「保存/読み込み」ボタンが通常の配置に戻り、
   固定表示されていないか（回帰確認）
