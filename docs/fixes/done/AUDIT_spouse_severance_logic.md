# 調査依頼：配偶者の退職金(severance)ロジックの実装確認

## 背景

中村夫婦シリーズ(翔太58歳退職・美咲56歳退職)のブログ記事化を検討する中で、以下の疑問が出た。

- 配偶者側の勤続年数(退職所得控除の算定基準)が、退職金の課税計算に反映されているか
- KPIグリッドの「退職金」表示項目に、配偶者の退職金が正しく反映されているか

旧HTML版(STEP29〜35、確認できる範囲すべて)のコードを確認したところ、以下の点が判明している(参考情報。Next.js版が同じ実装とは限らない)。

2. 配偶者の退職金額は、本人の退職金と合算されて課税処理されるか。合算される場合、退職所得控除の計算に使われる「勤続年数」はどの値が使われているか(本人の勤続年数のみが使われ、配偶者の勤続年数は考慮されていない、という状態になっていないか)
