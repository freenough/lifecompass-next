# HeroDemo.tsx:LPのKPIデモ表示を「FIRE安全度」の新デザインに追従させる

## 背景

`kpi_grid_redesign.md`の実装で、実際のシミュレーター画面のKPIカードは「FIRE達成」→「FIRE安全度」に名称・デザインが変更され、以下の内容になった。

- 達成時:メイン「{年齢}歳で達成」、サブ「FIRE達成後最低充足率 {%}」
- 未達成時:メイン「未達成」、サブ「退職後最低充足率 {%}」
- 3段階色分け(緑/黄/赤、`minRatio`ベース)

LP(ランディングページ)の`HeroDemo.tsx`は固定デモデータを表示するコンポーネントだが、旧デザイン(「FIRE達成」というタイトル・旧2段階ロジック)のまま残っている。実際の製品画面とLPのデモ表示で見た目が異なっており、LPを見てシミュレーターに進んだユーザーが違和感を覚える可能性がある。

## 実装したい変更

`HeroDemo.tsx`内のKPIカード表示を、`KpiGrid.tsx`の新しいデザインに合わせて更新する。

- カードタイトルを「FIRE達成」から「**FIRE安全度**」に変更する
- デモ用の固定データが「達成」を示す想定であれば、メイン表示を「{デモ用の年齢}歳で達成」、サブに「FIRE達成後最低充足率 {デモ用の%}」を表示する形にする(逆に「未達成」を示す想定であれば、未達成時の表示形式に合わせる。どちらのシナリオを見せるデモかは既存の`HeroDemo.tsx`のデータ・意図を確認した上で判断してよい)
- 色(背景・文字色)も、新しい3段階ロジック(緑/黄/赤)の配色に合わせる。ただしHeroDemoは固定デモなので、実際に`minRatio`を計算する必要はなく、見せたいデモの状態(達成/未達成)に応じた固定の色を設定すればよい
- 他のKPIカード(資産寿命・MC破綻確率・最終資産)についても、`HeroDemo.tsx`内で古いデザイン・古い色分けロジックのまま残っている箇所がないか確認し、あれば同様に現在の`KpiGrid.tsx`のデザイン・配色に合わせて更新する

## 確認してほしいこと

- `HeroDemo.tsx`が実際のシミュレーターと全く同じレイアウト構造(トップ4枚+必要なら詳細アコーディオン風の見せ方)を再現する必要があるか、それとも簡略化されたデモ表示のままで良いかは、既存のLPのデザイン意図を踏まえて判断してよい(全面的なレイアウト再現は今回のスコープではなく、あくまで「タイトル名称」「色分けロジックの世代」を最新に揃えることが目的)

## 動作確認したいポイント

- LPを開いた際、HeroDemoのKPIカードタイトルが「FIRE安全度」になっていること
- 色・表示形式が、実際のシミュレーター画面(`KpiGrid.tsx`)の新デザインと一致した印象になっていること
- LPの他の箇所(説明文など)で「FIRE達成」という旧名称を前提にした文言が残っていないか、軽く確認する(見つかった場合は報告のみでよく、今回の修正対象に含めるかはKENZOの判断を仰ぐ)
