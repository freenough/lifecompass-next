# 指示書：広告開示ページ（/disclosure）差分更新

**目的**：ASP各社（A8.net・もしもアフィリエイト・アクセストレード）への申請前に、
「アフィリエイトについて」セクションのみを実態（申請準備中・未掲載）に合わせて更新する。
他のセクション（広告について／情報提供について）は変更しない。

**対象ファイル**：`src/app/disclosure/page.tsx`

**方針**：全面書き換えはしない。既存の見出し構成・文体・スタイルをそのまま維持し、
対象セクションの見出しと本文のみを差し替える。制定日の下に更新日を1行追加する。

---

## 差分①：「アフィリエイトについて」セクション（見出し・本文とも差し替え）

### 変更前（現状）

```
アフィリエイトについて
現時点でアフィリエイトプログラムへの参加はありません。
将来参加した場合は、本ページに追記します。
```

### 変更後

```
アフィリエイト広告について
本サイトでは、第三者配信のアフィリエイトサービス（A8.net、もしもアフィリエイト、アクセストレード等）を利用し、提携事業者の商品・サービスを紹介する場合があります。
アフィリエイト広告を掲載する記事・ページには、広告であることが分かるよう「[PR]」「広告」等の表記を行います。
本サイトで紹介する商品・サービスは、独自の調査・比較・検証に基づき、利用者の皆さまへの情報提供を目的として掲載しています。掲載内容は特定の商品・サービスへの申込みや契約を断定的に推奨するものではなく、最終的なご判断はご自身の責任においてお願いいたします。
なお、現時点ではアフィリエイト広告の掲載は開始しておりません。提携ASPおよび広告主との提携が承認され、広告掲載を開始した際には、本ページの内容を適宜更新いたします。
```

**注意**：見出しを「アフィリエイトについて」から「アフィリエイト広告について」に変更する
（本文内容と一致させるための意図的な変更。他の見出しは一切変更しないこと）。
