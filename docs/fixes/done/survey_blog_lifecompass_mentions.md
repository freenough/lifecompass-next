作成日: 2026-07-19
対象: `lifecompass-next`の`src/content/blog/*.md`(全6記事)
種別: 調査のみ(この時点では一切編集しない)

---

## 目的

サービス名変更(LifeCompass → FREENOUGH 資産シミュレーター)に伴い、ブログ記事本文中の「LifeCompass」という言及箇所を修正したい。ただし機械的な文字列置換だと、「資産シミュレーターでシミュレーションし」のような重複・不自然な表現が生まれるリスクがあるため、まず全箇所を洗い出し、前後の文脈込みで報告してもらう。**この指示ではファイルの編集は行わないこと。**

## 調査内容

- `src/content/blog/`配下の全6記事(md ファイル)を対象に、「LifeCompass」という文字列が出現する箇所をすべて検索する
- 各出現箇所について、以下を報告する:
  - ファイル名(記事のslug)
  - 出現箇所の前後を含む1〜2文程度の抜粋(文脈が分かる範囲)
  - 記事タイトル中の言及か、本文中の言及か

## 報告フォーマット

```
## 調査報告: ブログ記事中のLifeCompass言及箇所

### (記事slug名、例: fire-checklist.md)
1. [タイトル/本文] 「〜〜〜LifeCompassで〜〜〜」(前後の文脈込み抜粋)
2. ...

### (次の記事slug名)
...

### 出現件数の合計
- 全◯箇所(◯記事)
```
