# 修正指示: tooltip-close-on-scroll

## 症状

InfoTooltip(Portal化・position:fixed実装)を開いた状態でページをスクロールすると、吹き出しの位置が「?」ボタンに追従せず、その場に取り残されて位置がずれる。

## 原因

Portal化した際、吹き出しはクリック時点のビューポート座標(px)で一度だけ位置計算されており、その後のスクロールに対して再計算する仕組みがない。

## 修正方針

スクロールが発生したら、吹き出しを自動的に閉じる。

- 既存の「吹き出し以外の場所をクリック/タップすると閉じる」挙動はそのまま維持する
- 加えて、ツールチップが開いている間にスクロールイベント(該当ページ内の各スクロールコンテナ、および window のスクロール)を検知したら、吹き出しを閉じる
- スクロール量の閾値は設けず、スクロールが発生した時点で即座に閉じてよい
- 位置を追従させ続ける(再計算し続ける)実装は今回は採用しない

## 確認事項

- MC設定・利回り設定・KPIカード等、InfoTooltipを使っている全箇所で、吹き出しを開いた状態でスクロールすると閉じることを確認
- 通常のクリック外し(既存の閉じる動作)に回帰がないことを確認
- モバイル(タッチスクロール)・PC(マウスホイール)両方で確認
- 6-A/6-B再検証結果
