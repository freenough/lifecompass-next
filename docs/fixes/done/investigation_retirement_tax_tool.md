# 投資調査指示書: retirement-taxツールの実装確認

作成日: 2026-08-03
種別: investigation-only(実装・ファイル変更は一切行わないこと)
目的: ブログ記事「退職金の手取りはいくら?」の数値算出のため、
`/asset-simulator/tools/retirement-tax`の実装詳細を確認する。

---

## 調査してほしいこと

### 1. 計算ロジックの所在

- retirement-taxツールが使っている計算関数はどこにあるか(`financeCore.ts`内か、
  専用ファイルか)、関数名は何か
- 退職所得控除・課税退職所得・税額の計算式が、本体シミュレーター(ロック済み
  `simulate.ts`/`analyze.ts`)内の`retirementTaxCalc()`ロジックと同一か、
  独自実装かを確認(同一の場合はそのまま流用、異なる場合はどちらの数値を
  記事に使うべきか報告してほしい)

### 2. 入力項目とデフォルト値

- ツールのUI入力項目一覧(例: 退職金額・勤続年数、iDeCo関連の入力があるか等)
- 各項目のデフォルト値・入力レンジ(min/max/step)
- ページを開いた直後の初期表示結果(デフォルト値での計算結果)があれば、
  その数値も報告してほしい

### 3. 出力項目

- ツールが表示する結果項目一覧(手取り額・税額・控除額など)
- 感度テーブルのようなものがあれば、その内容(他ツールのパターンに準拠しているか)

### 4. 既存記事での言及有無

- 過去13記事の中で、retirement-taxツールの数値や退職所得控除について
  すでに言及している記事があるか確認(あれば記事名・内容の要約)

---

## 報告してほしい形式

- 計算関数の所在(ファイルパス・関数名)
- 本体シミュレーターの`retirementTaxCalc()`との同一性(同一/差異ありなら差異点)
- 入力項目・デフォルト値の一覧表
- デフォルト値での計算結果(手取り額・税額など)
- 勤続年数を変えた場合(例: 15年・20年・25年・35年)の計算結果も、
  可能であれば本番関数を直接importして算出し、あわせて報告してほしい
  (記事で「勤続年数による差」を見せるため)

---

## 注意事項

- **この指示書は調査専用。ファイルの作成・変更は一切行わないこと**
- 数値算出が必要な場合も、必ず本番の`financeCore.ts`(または該当関数)を
  直接importして算出すること。独自の再計算スクリプトは作らない
  (プロジェクト共通ルール:コンテンツ用の確定数値は本番関数経由が必須)
- 完了報告には、算出方法(実機/本番関数経由/独自再現)を明記すること
- 完了後、この指示書は`docs/fixes/active/`から`docs/fixes/done/`へ移動してよい
