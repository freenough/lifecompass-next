# 投資調査指示:ブログ↔ツールの相互リンク

## 背景

現状、ブログ記事→ツールへのリンクは一部の記事(9本目「新NISAは毎月いくら積み立
てればいい?」など)で実装済みだが、**ツール→ブログ記事へのリンクは一切実装されて
いない**(一方通行)。6ツール・10記事まで増えた今、関連性の高い組み合わせに限って
相互リンクを追加し、回遊(記事⇄ツール⇄本格シミュレーター)を強化したい。

**このファイルは投資調査のみを依頼するもの。実装はしないこと。**
調査結果をもとに対応表を提示し、KENZOの承認を得てから別途実装指示を出す。

対象リポジトリ:`lifecompass-next`

---

## 調査してほしいこと

### 1. 現在の全ブログ記事の棚卸し

`src/content/blog/`配下の全記事(frontmatter含む)を一覧化し、以下を整理する:

- ファイル名(スラッグ)
- タイトル
- 記事の主題(1行程度)
- 現在、本文中または末尾にツールへのリンクが既に存在するか(あれば、どのツールへの
  リンクか)

### 2. 現在の全ツールの棚卸し

`src/app/tools/`配下の全ツール個別ページを一覧化し、以下を整理する:

- スラッグ(URL)
- ツール名
- 現在、ツールページ内にブログ記事へのリンクが存在するか(あれば、どの記事への
  リンクか)
- CTAセクション(シミュレーターへの誘導)のコンポーネント構造
  (どこに1行追加する形になりそうか、実装イメージが湧く程度の把握でよい)

### 3. 対応表の提案(調査時点での仮説でよい)

上記1・2の棚卸しをもとに、**「この記事にはこのツールへのリンクを足すと自然」**
という組み合わせを、関連性が高い順に提案する。すべての記事・全ツールを無理に
組み合わせる必要はない(関連性が薄い場合は「対応する記事なし」でよい)。

判断基準の目安:
- 記事の題材になった数値・ロジックが、そのままそのツールで再現できるか
  (例:9本目記事は積立額逆算ツールの数値をそのまま使っている、という前例)
- 記事のテーマとツールの計算内容が直接一致するか
  (例:iDeCo/NISA比較記事 ↔ iDeCo/DC出口戦略シミュレーター、のような明確な一致)
- 単に「同じ制度(NISA/iDeCo等)に言及している」程度の緩い関連は除外し、
  「この記事を読んだ人が次にこのツールを使いたくなる」という導線として
  意味があるものに絞る

理由 の4列)を作成し、報告してください。この表をもとに、次のセッションで
KENZOと最終確認した上で実装指示を作成する。

**繰り返しになるが、このファイルでは調査・提案のみ行い、コードの変更は一切
行わないこと。**
