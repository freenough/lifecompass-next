# 実装指示書: タイポグラフィ全体適用 + Hero再設計(LP再設計 Phase 1)

## 位置づけ

LP再設計プロジェクトの最初のPhase。今後複数Phaseにわたる作業を、単一のブランチ `feature/lp-visual-refresh` 上で進める。本Phaseはその最初のコミット群となる。

## 差し戻し安全性の方針(最重要・今後のPhase全てに適用する共通ルール)

- 新規ブランチ `feature/lp-visual-refresh` を作成し、その上で作業する。**mainには直接pushしない。**
- pushしたブランチのVercel Preview URLをこのチャットに報告し、確認・GO判断が出るまでmainにマージしない。
- 今後のPhaseもこの同じブランチに積み重ねていく想定。Phaseごとにコミットを分け、後から特定のPhaseだけ`git revert`等で戻せるようにする。
- 既存コンポーネントは直接改変せず、可能な限り新規コンポーネント追加+呼び出し側の差し替えとする。

## 対象範囲

- lifecompass-next側の資産シミュレーターLP(`/asset-simulator`)が対象。他ページ(一人法人・freenough-main)への適用は今回のスコープ外(後続のPhaseまたは別指示で判断)。

## Phase 1-A: タイポグラフィの全体適用

### 採用フォント

- 見出し用:**Zen Kaku Gothic New**(weight 700を基本、必要に応じて500も)
- 数字用:**Space Grotesk**(weight 700を基本)。年齢・パーセント・件数など、数値が主役になる箇所に適用。
- 本文用:既存のフォント設定を維持(変更しない)。

### やること

1. Google Fonts(`Zen Kaku Gothic New`, `Space Grotesk`)を、既存のフォント読み込み方式(next/fontまたは同等の仕組み)に合わせて追加する。パフォーマンスへの配慮として、必要なウェイトのみ読み込む(700中心、必要なら500)。
2. 見出しタグ(h1, h2など、LP内で見出しとして使われている要素)に `Zen Kaku Gothic New` を適用するCSS変数またはクラスを定義する。
3. 数値表示箇所(FIRE達成年齢、資産寿命、破綻確率、チャート軸ラベルの数字部分など)に `Space Grotesk` を適用する。単位(「歳」「%」等)は本文フォントのまま、数字部分だけ切り替える実装とする(先に見せた比較サンプルと同じ考え方)。
4. LP全体(Hero・お悩み・ガイド・ツール・資産管理・ケーススタディ・使い方・CTA、全セクション)に適用する。今回はHero以外のセクションレイアウトは変更しないが、フォントだけは全体に反映する。

## Phase 1-B: Hero再設計

### 変更内容

1. **コピーを主役にする。** 「あなたのFIREは、何歳?」の文字サイズを現状より一段階大きくする。コピーとチャートの比率を、現状の50:50に近い状態から、コピーがより優勢な比率に変更する(具体的な数値バランスは実装しながら調整してよいが、狙いは"文字が先に目に入る"状態)。
2. **チャートは残す。** 現状のチャート自体(実際に動くシミュレーション結果)は削除・作り替えしない。
3. **チャートの周囲に、放射状に広がる薄い線のパターンをSVGで追加する。** 「1,000通りの未来がそこから分岐している」ことを示す装飾。既存のチャートを隠さない程度の薄さ・控えめさにする(実装しながら濃さは調整可)。
4. 3つの特徴カード(モンテカルロ対応/日本制度対応/データ保護)は、**今回のPhaseでは変更しない**(これはPhase 3の思想セクション統合で扱う)。

## Phase 検証(証跡必須)

- タイポグラフィ適用後のLP全体を、PC幅・モバイル幅でスクリーンショット。見出し・数字それぞれが指定フォントで表示されていることを確認。
- Hero部分の変更前後を並べたスクリーンショットを報告する。
- 既存のチャート機能(実際の計算・表示)が壊れていないことを確認する。
- ページの表示速度に明らかな劣化がないか(フォント追加による影響)を確認する。
- Vercel Preview URLを報告する。
- ロックファイルへの変更が発生していないことを確認する。

## やってはいけないこと

- mainへの直接push。
- ロックファイルの直接改変。
- 3つの特徴カードなど、本Phase範囲外のセクションを変更すること。
- 証跡なしの完了報告をしないこと。
