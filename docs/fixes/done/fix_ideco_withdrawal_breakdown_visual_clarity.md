# 指示書: ideco-withdrawalツール — 内訳表示の視認性改善

作成日: 2026-08-03
このチャットの役割: 企画・意思決定 / 実行: Claude Code
関連: `fix_ideco_withdrawal_breakdown_consistency.md`(直前の修正・docs/fixes/done/)。
     今回は計算ロジック変更なし、表示・UIの調整のみ。

## 背景

前回の修正で内訳最終行の数値はカードと一致したが、レビュー中に2つの視認性の
問題が見つかった。

1. **一時金パターン選択時、無関係な「年金分」の内訳ブロックが表示されている**
   一時金パターン(iDeCo全額を一時金で受取)では、iDeCo年金分は常に0円になる。
   このとき表示される「年金分(総合課税、10年間・1年あたり)」ブロックの
   公的年金等控除・雑所得・基礎控除・税額×2の5行は、実質「公的年金だけ」の
   課税計算であり、iDeCoの情報を一切含まない。最後の行が「iDeCo年金分の手取り
   (1年あたり)0万円」になることを示すためだけに、無関係な計算過程を丸ごと
   見せてしまっている。

2. **年金・併用パターンで、「合算の計算過程」と「按分後の結果」が同じ見た目で
   並んでおり、区別がつきにくい**
   公的年金等控除〜税額までの5行は、公的年金+iDeCo年金を合算した1本の計算。
   最後の「iDeCo年金分の手取り(1年あたり)」だけは、そこからiDeCo分を
   グロス比で按分して抜き出した別種の数値。同じインデント・同じ見た目のため、
   最後の行も同じ計算の延長のように見えてしまう。

## 修正内容

### 対象ファイル
`src/components/tools/ideco-withdrawal/IdecoWithdrawalResult.tsx`

### 1. 一時金パターン選択時、「年金分」内訳ブロックを非表示にする
- 一時金パターン(`ratio=100%`相当)を選択している場合、「年金分(総合課税、
  ◯年間・1年あたり)」ブロック全体(公的年金等控除〜iDeCo年金分の手取りまでの
  6行)を表示しない
- 「一時金分(退職所得課税、一括受給)」ブロックのみを表示する

### 2. 年金・併用パターンの内訳を、計算過程と結果で視覚的にグループ分けする
- 公的年金等控除〜住民税までの5行に「年金分(総合課税:公的年金+iDeCo年金を
  合算して計算)」という見出しを付け、これが合算計算であることを明示する
- 5行目(住民税)と「iDeCo年金分の手取り(1年あたり)」行の間に区切り線を入れ、
  区切り線の直後に一言添える(例:「↓ 上記の合算税額を、iDeCoと公的年金の
  グロス金額比で按分」)
- 文言はドラフトなので、実装時に自然な日本語に調整してよい

### 3. 「結果」行に背景ハイライトを追加する
以下の行(すべて「iDeCo単体の最終手取り」を表す行)に、既存のKPIカード
(「併用 最大」等でハイライトされているカード)と同じ薄い青グレーの背景色を
適用する。**新しい色を追加せず、既存のCSS変数・クラスをそのまま流用すること**
(色の判断基準を複数箇所に分散させないため。該当の色が定義されている場所を
先に特定してから使う)。

- 「一時金分の手取り」行
- 「iDeCo年金分の手取り(1年あたり)」行
- 「◯◯パターンの手取り総額(iDeCo単体・◯年間)」行(最終行)

計算過程の行(控除・雑所得・税額など)にはこの背景色を付けない。

## 検証方法

- 一時金パターン選択時、内訳に「年金分」ブロックが一切表示されないことを
  目視確認する
- 年金・併用パターンで、5行(計算過程)と結果行(背景ハイライトあり)が
  視覚的に区別できることを確認する
- 併用パターンでは「一時金分の手取り」「iDeCo年金分の手取り(1年あたり)」
  「手取り総額」の3行すべてにハイライトが付くことを確認する
- 計算ロジック自体は変更していないため、`full-verify.js`・
  `verify-ideco-withdrawal-tool.js`の数値系チェックには影響しないはずだが、
  念のため実行してPASSを確認する
- 実機ブラウザで一時金・年金・併用の3パターンをスクショ確認する
  (前回ブラウザ操作が不安定だったため、可能なら別環境・別セッションで
  再試行すること)

## やらないこと(スコープ外)

- 計算ロジック(`src/lib/tax/ideco.ts`)の変更
- 色そのものの新規定義(既存トークンの流用のみ)
