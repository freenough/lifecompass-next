# 実装指示書:退職直後の暴落シナリオ検証スクリプト(shockZOverrides使用)

## 背景

ブログ記事(仮:退職直後の暴落=シークエンスオブリターンズリスクの検証)用に、
田中さんプロファイルで「退職1年目に狙った規模の下落が来た場合」を
モンテカルロで再現し、通常のランダム試行と比較する検証スクリプトを作成する。

以前の調査(`docs/fixes/done/`配下、シークエンスリスク関連)で技術的な実現方法は
確認済み:`simulate()`の`shockZOverrides`引数(既存の拡張ポイント、ロックファイル
変更不要)に、1年目だけ固定Zスコア・2年目以降はランダムなZスコア配列を渡すことで
実現する。乱数生成は`montecarlo.ts`内の`randNorm()`の実装と寸分違わず同じものを
再利用すること(独自に書き直さない)。

**ロックファイル(`simulate.ts`・`analyze.ts`・`montecarlo.ts`)は変更禁止。**
これらはimport元として読むだけ。スクリプトは記事用の一時的な検証スクリプトとして
新規作成する(既存記事のCSV出力スクリプトと同じ置き場所・命名慣習に従うこと)。

## シナリオ設計(プランニングチャットで確定済み)

田中さんプロファイル(既存記事で使用しているものと同一のものを使用)で、
以下3シナリオをN=1,000試行ずつ比較する:

| シナリオ | 退職1年目のZスコア | 2年目以降 |
|---|---|---|
| A. 基準(通常のモンテカルロ) | ランダム(固定しない) | ランダム |
| B. 中程度の下落 | -2σに固定 | ランダム(以降は通常のmontecarlo.tsと同じ乱数生成ロジック) |
| C. 深刻な下落 | -3σに固定 | ランダム(同上) |

「退職1年目」の定義:田中さんプロファイルの退職年齢(既存記事の値を踏襲)に到達した
最初のシミュレーション年。積立期ではなく取崩期の1年目であることに注意すること。

## 出力してほしい数値

各シナリオ(A/B/C)について:
- 破綻確率(bankruptcyRate)
- 資産寿命の分布(depletionMean・depletionMin、破綻したケースがあれば)
- p10/p50/p90(生涯の各年、特に最終年齢時点)
- **退職1年目時点での実際の資産減少額・減少率**(円ベース。Zスコアではなく、
  動的σ(残高加重)適用後の実際のドル換算下落幅。これが記事の「◯%資産が
  減った」という具体的な数値の根拠になるため、必ず算出すること)

B・Cそれぞれについて、Aとの差分(破綻確率が何ポイント上がったか等)も算出すること。

## 数値ルールの遵守

- 使用する`simulate()`・`montecarlo.ts`の乱数生成は本番のものをそのまま呼ぶこと。
  独自の再実装・簡略化は行わないこと(既存の「本番関数経由」ルールに従う)
- 手計算・推測値は禁止。全て実行結果から取得すること
- 田中さんプロファイルの他のパラメータ(退職金・年金額等)は、既存記事から
  変更しないこと(比較対象を変えないため)

## 完了報告に含めるべき内容

- 実行結果(A/B/C各シナリオの上記数値一覧)
- 退職1年目の実際の資産減少率(B/Cそれぞれ)
- スクリプトの配置場所
- 実行に使った乱数シード(あれば)、または非シードである旨
- この検証結果が記事に使える水準か(数値が極端すぎない/小さすぎない等)の
  所感があれば併記してもらって構わない
