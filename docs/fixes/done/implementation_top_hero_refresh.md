### 3.3 Hero

**構成順序**：タグライン → 見出し → リード文 → CTA（2ボタン横並び、狭幅で縦積み）

**タグライン**

```
FREE + ENOUGH.
```

- 等幅フォント風の小さい文字（現状のGeist/Arial系のまま、`tracking-widest`程度の字間で可）。色は`--sub`相当のグレー。
- **「FREE」の2つ目のE**と、**「ENOUGH」の1つ目のE**の2文字だけを、2.で確認したロゴの緑色（正確な値を使用。仮に不明な場合のみ`#1d9e75`）にする。他の文字は変更しない。
  - 例：`FRE`＋緑`E`＋` + `＋緑`E`＋`NOUGH.`

**見出し**

```
あなたにとっての「足りる」を、
数字で描く。
```

- 「あなたにとっての「足りる」を、」の後で改行し、「数字で描く。」を2行目にする（この改行は`<br>`などで常に固定する）。
- 1行目「あなたにとっての「足りる」を、」自体は、**固定ブレークポイントを使わず**、次の実装で幅に応じて自動的にもう一段折り返す：「あなたにとっての」と「「足りる」を、」をそれぞれ`white-space: nowrap`の別要素で囲む（間に空白文字を挟まない）。
  - 横幅が十分あれば、ブラウザはこの2つの塊を自然に同じ行へ収める→結果として見出し全体が2行になる。
  - 横幅が足りない場合は、この2つの塊の間だけで折り返しが起こる→結果として見出し全体が3行（「あなたにとっての」／「「足りる」を、」／「数字で描く。」）になる。
  - **768pxを含め、どの幅がどちらになるかは実装しない（メディアクエリで固定しない）。実際に描画してみて、収まる幅では2行に、収まらない幅では3行に、自動的に切り替わる状態にする。** 768px幅で3行になった場合、それは仕様どおりの正しい挙動であり、無理に2行へ寄せる調整（テキストブロックのさらなる拡幅、フォントサイズの縮小など）は行わないこと。
  - 守るべき条件は次の2点のみ：「足り」と「る」が別の行に分かれないこと、「あなたにとって」と「の」が別の行に分かれないこと。この2つが守られていれば、2行か3行かは幅によって変わってよい。
- 下線・強調装飾はつけない（プレーンなテキスト）。
- 現状の`text-balance`等の自動改行調整は、上記のnowrap保護と両立するなら残してよい（両立しない場合は外してよい）。
- 下線・強調装飾はつけない（プレーンなテキスト）。
- 現状の`text-balance`等の自動改行調整は、上記の強制改行・nowrap保護と両立するなら残してよい。

**リード文**

```
将来のお金と働き方を、シミュレーションで確かめる場所。
```

- 見出しの下に1行。サイズは本文サイズ（理念ブロックの本文と同程度でよい）。

**CTA（2ボタン）**

| ボタン | 文言 | href | 見た目 |
|---|---|---|---|
| 主 | 資産シミュレーターを見る → | `/asset-simulator` | 塗り。色は2.で確認した既存の2本柱ブロックのボタンと同じ色を使う（新しい色を作らない） |
| 従 | 一人法人という選択肢を見る → | `HITORI_HOJIN_URL` | アウトライン。ボーダーと文字色は主ボタンと同じ色、背景は透明 |

**背景**

- 装飾的な背景（グラフ線・写真など）は**つけない**。プレーンな白背景のまま。

**Heroブロックの横幅**

- 見出しが、より広い幅（目安1024px以上）で2行に収まるようにするため、Hero内のテキストブロック（見出し・リード文・CTAを含む中央寄せの列）の最大幅を、現状より広げる必要がある可能性が高い。どこまで広げるかの正確な値は、上記の見出し折り返しルール（nowrapの2塊方式）を実装した上で、実際の描画を見ながら調整する。

### 3.4 理念ブロック

**文言は一切変更しない**（現状の5行のまま）。

- 上下のpaddingを現状よりやや詰める（現状の1.5倍程度あるゆとりを、目安2〜3割減らす）。具体的な値は既存のTailwindスケールに沿って一段階詰める程度でよい。
- 本文の最大幅（読みやすさのための`max-w-2xl`相当）はそのまま維持する。今回のコンテナ幅変更（3.1）は、この内側の本文最大幅には適用しない。

**iPhone SE幅（375px）での改行対応**

現状、各文がデスクトップ幅を前提にした`<br>`で改行されており、375px幅ではその1行が収まらず二段目で自動改行が発生し、単語の途中（例：「人それぞれです。」の「人そ」／「れぞれです。」）で割れて見た目が崩れる。

対応：
1. 既存の`<br>`に印（クラス名等）をつけ、640px未満ではその`<br>`を無効化する（`display:none`）。狭い画面では改行を強制せず、自然な折り返しに任せる。
2. 「それぞれ」「足りる(Enough)」など、途中で割れると読みにくい短い語のまとまりは、`white-space: nowrap`で保護する。
3. 可能であれば、段落全体に`word-break: keep-all;`を付与し、英数字部分（`Enough`等）が不自然な位置で割れるのを防ぐ。

375px幅で実機（またはブラウザのビューポート指定）で確認し、単語の途中で割れる箇所がないことをスクリーンショットで確認すること。

### 3.5 検証する幅

375, 390, 768, 1024, 1280, 1366, 1440, 1920（前回の調査と同じセット）。各幅で以下を確認する。

- Heroの見出しの改行ルールが守られている（「足り」と「る」が分かれていない、「あなたにとって」と「の」が分かれていない）。2行になるか3行になるかは幅によって変わってよく、各幅での実際の行数を完了報告に記載する。
- 理念ブロックの本文が、単語の途中で割れていない
- ヘッダーのリンクが2つだけになっている
- 横スクロールが発生していない
- ヘッダー・Hero・理念ブロックのコンテナ幅が72remになっている

### 3.6 フォントについて（今回は変更しない）

デザイン検討時のモックでは見出し用に別のGoogleフォント（Zen Kaku Gothic New等）を試したが、これは本番採用が未確定。**今回の実装では、見出し・本文とも既存のフォント指定（現状のGeist/Arial系）をそのまま使う。** フォント変更は別タスクとして扱う。
