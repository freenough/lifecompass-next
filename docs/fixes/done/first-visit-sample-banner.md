# 新規実装指示: first-visit-sample-banner

## 目的

note.com経由の初回訪問者が、入力パネルに最初から入っている数字を「サンプルデータ」だと認識できるようにする。すでに全項目に数値が入っている状態で表示されるため、これが自分の入力ではないと気づかず戸惑う可能性があるための対応。

## 表示内容

入力パラメータパネルの一番上に、初回訪問時のみ薄い案内バーを表示する。

**文言:**
> この画面はサンプルデータです。ご自身の数字に置き換えると、結果がリアルタイムで更新されます。いつでも「サンプル」で元に戻せます。

## 表示仕様

- 表示位置: 入力パラメータパネルの最上部(「入力パラメータ」見出しの上、または直下)
- 表示条件: 初回訪問時のみ。`localStorage`に表示済みフラグ(例: `lifecompass_sample_banner_seen`)を保存し、2回目以降は表示しない
- 挙動の前提: ブラウザ単位の管理のため、別端末・別ブラウザ・シークレットモードでは再度表示される(想定通りの挙動として許容)
- 閉じ方: バー自体に閉じるボタン(×等)を用意し、明示的に閉じた場合もフラグを立てて以降表示しない。閉じるボタンを押さず離脱した場合の扱い(表示済み扱いにするか)は実装時に決めて報告してよい
- スタイル: 控えめな見た目(薄い背景色、小さめの文字)。既存のUIトーン(slate系の配色)に合わせる。目立ちすぎて他の要素を圧迫しないこと

## 確認事項

- 初回アクセス(localStorageクリア状態)でバーが表示されることを確認
- 一度閉じる、またはページを再読み込みした後、2回目以降は表示されないことを確認
- モバイル375px・PC幅それぞれでレイアウト崩れがないことをスクリーンショットで確認
- 前回までの入力パネル関連の修正(単位列・トグル位置・ブレークポイント統一)に回帰がないことを確認
- 6-A/6-B再検証結果
