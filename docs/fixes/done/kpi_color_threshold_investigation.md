# 【調査のみ】KPIカード(FIRE達成・MC破綻確率・初年度取崩率)の色分けロジック調査

## 目的

KPIカードの色(緑/黄など)がどのような条件・閾値で切り替わっているか、実装を変更する前に現状を正確に把握したい。**このファイルでは実装は行わず、調査結果のレポートのみをお願いします。**

## 背景

スクリーンショットで確認した限り、以下の挙動が見られた。

- FIRE達成カード:未達成(達成率68%)→黄色背景+オレンジ系文字、達成(達成率100%)→緑背景
- MC破綻確率カード:2.7%〜3.9%程度→緑、4.4%〜6.4%程度→黄
- 初年度取崩率カード:確認したケースでは常に3.7%で値が変わっていないため、条件付きで色が変わるのか、常に固定色なのか判別できなかった

これらの色分けについて、緑/黄の2段階にとどまっているのか、あるいは今後「本当に危険な水準」を示す赤(3段階目)を追加する余地があるのかを判断したい。

## 調査してほしいこと

1. **FIRE達成カード**
   - 色(背景色・文字色)を決定している条件分岐のコード箇所を特定する
   - 達成率が何%以上で「達成」扱い(緑)になるか、閾値を確認する
   - 「未達成」の中でも、たとえば達成率が極端に低い場合(30%未満など)とギリギリ未達成(90%台)で色に差はあるか、それとも未達成なら一律同じ黄色か

2. **MC破綻確率カード**
   - 色を決定している条件分岐のコード箇所を特定する
   - 緑/黄の閾値(何%を境に切り替わるか)を確認する
   - 黄色より上の段階(赤など)が実装されているか、されていない場合は上限なく黄色のままなのか確認する(例:破綻確率30%でも黄色のままか)

3. **初年度取崩率カード**
   - 色が条件付きで変わる実装になっているか、常に固定色(黄系)なのかを確認する
   - もし条件付きであれば、その閾値(一般的な「4%ルール」を意識した基準になっているか等)を確認する

4. **その他のKPIカード(資産寿命・最終資産・年金開始時資産)**
   - これらも条件付きで色が変わる実装になっているか、簡単に確認する(詳細調査は不要、色分けの有無だけで良い)

## 期待するレポート形式

各カードについて、以下を表形式でまとめてください。

| カード名 | 色分けの有無 | 閾値(具体的な数値) | 色の段階数(2段階/3段階など) | 該当コード(関数名/コンポーネント名) |
|---|---|---|---|---|

コード変更は不要です。レポートのみお願いします。
