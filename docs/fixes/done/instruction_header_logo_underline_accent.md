# 実装指示書: ヘッダーロゴの「FREENOUGH」に緑の下線アクセントを追加

## 背景

`instruction_header_logo_text_lockup.md` で資産シミュレーター側・一人法人側のヘッダーを「FREENOUGH ｜ セクション名」というテキストロックアップに変更したが、FREENOUGH TOPページのロゴにある**「FREENOUGH」の2つ目の"E"の下にある緑の下線アクセント**が再現されていない。

## 差し戻し安全性の方針

- 引き続き `feature/lp-visual-refresh` ブランチ上で作業する。mainには直接pushしない。

## やること

1. FREENOUGH TOPページ(freenough-main)のロゴ実装を確認し、「2つ目のE」の下にある緑の下線アクセントがどのように実装されているか(疑似要素、SVG、個別のspanタグ等)を特定する。
2. 資産シミュレーター側・一人法人側のヘッダー(lifecompass-next、`Header.tsx`)の「FREENOUGH」表記にも、同じ緑の下線アクセントを同じ見た目(位置・色・太さ)で追加する。
3. TOPページ側の実装をそのまま複製せず、可能であれば共通化(同じロゴ表記コンポーネントとして両リポジトリで一貫した見た目になるよう)を検討してもよいが、無理に共通化せず、見た目が一致していればページごとに個別実装でもよい。

## 検証(証跡必須)

- 修正後の資産シミュレーター側・一人法人側それぞれのヘッダーロゴのスクリーンショットを報告する。TOPページのロゴと並べて、緑の下線アクセントの位置・見た目が一致していることを確認する。
- Vercel Preview URLを報告する。

## やってはいけないこと

- FREENOUGH TOPページ側のロゴ実装を変更すること(参照元として維持する)。
- mainへの直接push。
- 証跡なしの完了報告をしないこと。
