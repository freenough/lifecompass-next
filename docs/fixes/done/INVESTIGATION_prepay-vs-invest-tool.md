# 調査専用指示書: 繰上返済 vs 投資比較ツール(第8弾)

## 位置づけ

このファイルは**調査のみ**を目的とした指示書です。実装は行わず、以下の項目を調査してKENZOに報告してください。設計判断が必要な箇所は独自に決定せず、選択肢を提示して停止してください。

実装指示書はこの調査結果をもとに、別途プランニングチャットで作成します。

---

## 背景

前セッションで住宅ローンイベントに「繰上返済(単発)」機能を実装済み(`helpers.ts`の`calcMortgageBalance`/`calcMortgageTermFromPayment`、`simulate.ts`のmortgageブロックに`prepayAge`/`prepayAmount`/`prepayType`を追加)。これを土台に、新規ツール「繰上返済 vs 投資比較」を第8弾ツールとして追加する。

入出力仕様は確定済み(下記「確定済み仕様」参照)。今回はツール実装前の土台調査。

---

## 調査項目

### 1. 既存の計算関数のシグネチャ確認

以下の関数の現在の正確なシグネチャ・戻り値の型・実装内容を`helpers.ts`から引用して報告してください:

- `calcMortgageBalance`
- `calcMortgageTermFromPayment`
- `calcMortgage`
- `calcMortgageMonthly`

これらを**そのまま**新ツールから呼び出せるか、あるいはツール専用の薄いラッパーが必要か、所見を添えてください。

### 2. 新ツールに必要な計算ロジックのギャップ確認

新ツールの出力に必要な計算のうち、既存関数で賄えないものを洗い出してください。具体的には:

- 「繰上返済による利息削減額」の算出に、既存の`calcMortgageBalance`/`calcMortgageTermFromPayment`をどう組み合わせれば求まるか(疑似コードレベルでよい)
- 投資側の複利試算(利回り5%/7%/9%プルダウン、NISA非課税前提)は、既存コードに流用できる関数があるか、それとも新規実装が必要か
- 「期間短縮型」と「返済額軽減型」で、削減額の算出方法・出力する副次情報(新完済年齢 or 新返済額)がどう変わるか

**設計判断は行わず**、既存コードで対応できる範囲とできない範囲を分けて報告してください。

### 3. 既存ツールのディレクトリ構成・実装パターン確認

既存7ツール(`monthly-investment`/`fire-age`/`compound`/`pension-timing`/`retirement-tax`/`ideco-withdrawal`/`education-cost`)のうち、入力フォーム→比較表出力という構成に最も近いもの(候補: `retirement-tax`または`pension-timing`)を1つ選び、以下を報告してください:

- ディレクトリ構成(`src/app/asset-simulator/tools/{tool}/`配下のファイル一覧)
- 入力フォームの状態管理パターン(useState / 専用hook等)
- 計算結果の表示コンポーネント構成
- GA4イベント発火箇所(`tool_calculate`のdebounce実装含む)
- メタデータ登録方法(`toolMetadata.ts`の`TOOLS`配列にどう追加されているか、既存1件の実例を引用)

### 4. 住宅ローンモーダルの按分処理後の表示確認

前セッションで`mortgageブロック`内に`boundaryAge`/`fraction`による按分処理を局所実装した。`LifeEventTimeline.tsx`のモーダル内試算表示部分が、この按分処理の結果を**矛盾なく**表示できているか、コードを読んで確認してください(実機操作ではなくコードレビューでよい)。

具体的には:
- モーダル内の試算表示(繰上返済後の利息削減額等)が、按分処理導入前の古いロジックを参照していないか
- 表示側で`Math.ceil`等の丸め処理が残っており、按分処理の結果と二重に矛盾を生んでいないか

問題があれば報告のみ(このタイミングでは修正しない)。

### 5. インフレ・σ・Monte Carloの扱い確認

確定済み仕様では「Monte Carlo/σ/インフレ率の詳細設定は非表示」としている。既存ツール(特に`retirement-tax`等の単純計算系ツール)がMonte Carloを使わず単発計算のみで完結しているパターンを確認し、新ツールが同様の設計で問題ないか所見を報告してください。

## 確定済み仕様(参考・変更しないこと)

**入力(基本モード):**
- ローン残高(万円)
- 金利(%、step0.1)
- 残年数(年)
- 比較する金額(万円、可変・初期値100)
- 繰上返済タイプ(期間短縮型/返済額軽減型)
- 投資利回り(5%/7%/9%プルダウン、NISA枠内・非課税前提固定)

**出力(比較表形式・勝敗判定なし):**
- 確実な効果(繰上返済の利息削減額) vs 期待値(投資の複利試算額)
- リスク・流動性・完済年齢or返済額への影響
- 締め文言:「どちらが適しているかは、金利・リスク許容度・投資期間によって異なります。」

**固定条件(スコープ外・実装しないこと):**
- 投資は常にNISA枠内前提(課税口座非対応)
- Monte Carlo/σ/インフレ率の詳細設定は非表示
- 繰上返済は単発のみ(継続的な毎月繰上返済は非対応)
- 変動金利のブレ・借り換えシナリオは非対応

**設計思想:** 「確認」でなく「意思決定」を支援するツール。結果は「勝敗判定」ではなく「判断材料の比較表」に徹する。
