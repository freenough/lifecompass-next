# 指示書: ブログ記事用 期間別セミリタイア感度分析の計算

作成日: 2026-07-22
対象: `lifecompass-next`
種別: 計算のみ

---

## 背景

ブログ記事(佐々木さんのセミリタイア戦略検証記事)のため、以下3パターンの90歳時点資産を比較したい。56〜65歳のケースはすでに正確な値(`profileToSimParams()`経由)が確定済みだが、56〜60歳・56〜63歳のケースはまだ計算していない。**必ず前回確立した正確な計算方法(プロファイルJSON`佐々木_55歳`をベースに、`profileToSimParams()`経由で`simulate()`/`analyze()`を実行する方法)を使うこと**。以前の簡易スクリプトでの計算方法は使わないこと。

## 計算する3パターン

いずれも佐々木誠一の基本プロフィール(55歳退職、プロファイルJSON`佐々木_55歳`と同一設定)をベースに、56歳以降の副業収入(sidejobサブタイプ、年120万円)の**期間だけ**を変えて計算する。

1. **56〜60歳(4年間)**、年120万円収入
2. **56〜63歳(7年間)**、年120万円収入
3. **56〜65歳(10年間)**、年120万円収入 ※既に確定済み:90歳時点資産11,680万円。この値を、今回と同じ方法で再現できるか検算も兼ねて実行すること

比較対象として、55歳完全退職(収入なし)の90歳時点資産(確定済み:8,761万円)も念のため報告に含めること。
