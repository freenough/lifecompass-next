# 修正指示: input-panel-closed-spacing

## 症状

「入力を編集」ボタン(入力パラメータパネルが閉じている状態)の下に、次のセクション(固定モード/MCモード)との間に大きな空白がある。

パネルが開いている状態(「入力を閉じる」ボタン→入力パラメータが直下に続く)では余白がなく詰まっているのに対し、閉じている状態だけ余白が残っている。

## 期待する見た目

パネルの開閉状態にかかわらず、ボタン直下の余白は同じ(現在の「開いている状態」と同じ詰まり具合)にする。

## 原因の見立て

パネルの開閉をheight:auto⇔0やdisplay:none等で切り替えている場合、外側のコンテナ(ボタンと固定モード/MCモードセクションを含む親要素)側のmargin/gap/paddingが、パネルの開閉状態と無関係に固定値で設定されている可能性が高い。あるいは、パネルの折りたたみに transition 用の min-height や padding が残っていて、閉時にもその分の高さが確保されている可能性もある。決め打ちせずDevToolsで実際に余白を作っている要素を特定すること。

## 修正方針

1. パネル開閉ボタンを含むコンテナと、次のセクション(固定モード/MCモード)との間の余白(margin/gap/padding)を確認する
2. 閉じている状態で余白を作っている要素を特定し、開いている状態と同じ余白量になるよう修正する(閉時だけ大きい余白を持たせている固定値があれば削除、もしくは開時の値に統一)
3. 開閉アニメーション(transitionを使っている場合)がある場合、余白修正後もアニメーションが不自然にガクつかないか確認する

## 確認事項

- デスクトップ・モバイル両方で、パネルを開いた状態・閉じた状態それぞれのスクリーンショットを撮り、次セクションとの間隔が同じであることを確認する
- 開閉の切り替えアニメーションが崩れていないことを確認する
- 6-A/6-B再検証結果
