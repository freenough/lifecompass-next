# 修正指示: pf-warning-and-hscroll-regression

## 症状1: PF資産配分の警告メッセージが実際の計算結果と矛盾している

「③取崩期」のPF(NISA・iDeCo・特定口座)にファンドの行が追加されていない状態で、以下の警告が表示される:

> NISA(取崩期)、iDeCo(取崩期)、特定口座(取崩期)の資産配分が未設定です(利回り0%として計算されています)。ポートフォリオに1行追加するか、利回り設定で直接利回りを入力してください。

しかし実際には、「利回り設定」で「取崩期は積立期と同じ利回りを使う」にチェックが入っており、この場合は取崩期の利回りとして積立期と同じ値(例: 7%)が使われる。実際のシミュレーション結果(資産寿命「枯渇なし」、最終資産9.4億円等)も、0%運用ではあり得ない良好な数値になっており、計算自体は正しく7%を使っている様子。

**つまり、警告メッセージの内容(0%として計算)と、実際の計算結果が矛盾している。**

**調査手順:**
1. 警告メッセージを表示する判定ロジックの箇所を特定する
2. この判定が、「取崩期は積立期と同じ利回りを使う」チェックボックスの状態を考慮しているか確認する
3. 考慮していない場合、なぜ矛盾したメッセージが出るのか(チェックボックスがONの場合はPFが未設定でも実際は0%にならないため、本来は警告を出すべきでないケース)を確認する

**修正方針:**
- 「同じ利回りを使う」チェックがONの場合、そのアカウント種別についてはこの警告を出さない(実際に0%になるのはPF未設定かつチェックもOFF、直接利回り入力もされていない場合のみ)
- チェックがOFFで、かつPFもファンド未設定・利回り直接入力もない場合のみ、警告を表示する
