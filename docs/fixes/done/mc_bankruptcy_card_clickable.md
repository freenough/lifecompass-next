# 実装：MC破綻確率カードの「MCモードで実行」をクリック可能にする

## 背景

トップKPIカードの「MC破綻確率」は、固定モードでは`—`表示に「MCモードで実行」という説明が添えられているが、これは静的テキストでクリックできない。一方、「改善案インパクト比較」カード(`ImpactTable.tsx`)の同じ文言「MCモードで実行」は既にクリック可能なリンクになっており、押すとMCモードに切り替わる。同じ文言なのに片方だけ操作できない、というアプリ内の一貫性のなさがある。

## 実行内容

`KpiGrid.tsx`のMC破綻確率カード内「MCモードで実行」を、`ImpactTable.tsx`で既に使われているモード切替処理と同じものを呼び出す、クリック可能なリンク/ボタンに変更する。

- 見た目は`ImpactTable.tsx`側の「MCモードで実行」リンクに準じること(青字等、既存のスタイルを踏襲)
- クリックすると固定モード→MCモードに切り替わり、必要であれば(既存のMC実行フローに準じて)1,000試行の実行が開始されること
- 新規の計算ロジックは追加しない。既存のモード切替処理をそのまま呼び出すだけでよい

## 確認事項

- クリックで実際にMCモードに切り替わること
- モバイル幅でもタップ領域が適切に確保されていること(誤タップ・タップしづらさがないか)
- 他のKPIカード(資産寿命・FIRE達成・最終資産)のレイアウトに影響がないこと
