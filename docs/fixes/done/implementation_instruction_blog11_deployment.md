## 3. UTM命名規則の新設(重要・テンプレート更新)

今回、ブログ記事からツール・シミュレーターへのリンクに以下の命名規則を
新設した:

```
utm_source=blog&utm_medium=referral&utm_campaign={topic}_blog
```

これはToolsページの`{tool_name}_tool`パターンと対称的な命名であり、
今後のブログ記事にも適用する。**`blog_article_template.md`のUTM関連箇所
(共通チェックリストの「文中にUTMパラメータ付きのシミュレーターリンクを
使っているか」の項目付近)に、この命名規則を明記する形で追記すること。**
