# 調査: 戦略比較関連の表示箇所、displayStrategy統合漏れの全体監査

## 背景

ここまでのセッションで、以下の箇所が「単一値系の表示なのに`activeStrategies[0]`のまま(displayStrategy未対応)」というパターンで、3回連続で見つかった。

1. モンテカルロ分析欄(当初`MonteCarloPanel.tsx`が対象外だった)
2. 改善案インパクト比較(`ImpactTable.tsx`)・感度分析(`SensitivityPanel.tsx`)・AI分析(`AiPanel.tsx`)
3. グラフの帯(`bandStrategy`という別概念になっていた)

同じ見落としがまだ他に残っていないか、個別に指摘する形ではなく、**今回は横断的に一度すべて洗い出す**形で調査してほしい。今回は調査のみ。実装はしない。

## 調査内容

### 1. 機械的な検索

以下のようなパターンで、リポジトリ全体を検索し、該当箇所をすべてリストアップする。

- `activeStrategies[0]`
- `activeStrategies\[0\]`
- `strategies\[0\]`
- その他、複数戦略の中から1つを取り出して単一値として使っている箇所(配列の`[0]`アクセスに限らず、`.find()`や`.at(0)`など別の書き方をしている場合も含む)

見つかった箇所それぞれについて、以下を判定する。

- **displayStrategyを使うべき箇所か**(単一値表示・単一戦略を基準にした計算):該当すればdisplayStrategy未対応の漏れとして報告
- **意図的にactiveStrategies[0]のままでよい箇所か**(例:フォールバック値の算出、配列が空でないことの型ガードなど):該当すればその理由を添えて報告

### 2. 個別に確認してほしい機能(思いつく範囲)

以下は今回のセッションでまだ明示的に確認していない、思いつく限りの機能。それぞれ、複数戦略選択時にdisplayStrategyに正しく連動するか確認する。

- **年次資産テーブル**(年齢ごとの総資産・NISA・iDeCo・特定・現金・収入・支出・CFなどを一覧表示する機能):複数戦略選択時、どの戦略のデータを表示しているか。displayStrategyに連動しているか
- **年次資産テーブルのCSVエクスポート**:同上。エクスポートされるデータがdisplayStrategyのものになっているか
- **資産推移グラフの「口座内訳」タブ**(「総資産」「口座内訳」の切り替えがあった。口座内訳表示時、どの戦略のデータを表示しているか)
- **シナリオ比較モード**(比較モードのもう一方の選択肢。戦略比較とは別軸だが、両方を同時に使った場合に矛盾が起きないか)
- **プロファイルの保存/読み込み機能**:displayStrategy・activeStrategiesの状態が正しく保存・復元されるか

### 3. モバイル表示の確認

チェックボックス+表示ラジオの行が、狭い画面幅(360px程度)で崩れていないか、念のため確認する(過去にモンテカルロ分析欄・グラフ凡例で同種の問題があったため)。
