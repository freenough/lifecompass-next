# 調査依頼：iDeCo年金受取額が退職金の勤続年数(sevYrs)によって変化する件

## 背景

田中さんのプロファイルで、iDeCo受取方式を「年金・15年」に固定したまま、退職金の勤続年数(sevYrs)だけを5年→13年に変更したところ、以下のようにiDeCo側の数値が変化した。

| 項目 | sevYrs=5 | sevYrs=13 |
|---|---|---|
| 退職金(手取り) | 739万円 | 772万円 |
| iDeCo手取り(年金15年) | 1,536万円 | **1,540万円** |
| iDeCo累計課税額 | 391万円 | **391万円**(同じ) |

iDeCo側の累計課税額は同じなのに、手取り額(≒税引き前受取額)が4万円異なっている。

`AUDIT_ideco_pension_tax_attribution.md`の調査結果では、iDeCo年金の税額計算(`calcPensionTaxDiff`)は本人の公的年金額(`currentPenAmt`)とiDeCo年金額(`idecoAnnualPension`)のみを引数に取り、退職金・sevYrsは一切関与しないはずだった。今回の結果は、この調査結果と矛盾する。

なお、2回のテストとも「比例取崩」戦略で統一されており、戦略選択の違いによる単純な設定ミスではないことは確認済み。

## 調査してほしいこと

0. **(最有力の仮説)** 「比例取崩」戦略が、iDeCoの年間引出額(またはiDeCoから生活費に充当する割合)を、他の口座(NISA・特定口座・現金)との相対的な残高構成に応じて決定する設計になっていないか。もしそうなら、退職金の33万円の差が口座全体の構成比をわずかに変え、それが比例取崩の計算を通じてiDeCoの年間引出額自体を変化させている可能性がある(単純な「iDeCo残高÷15年」の固定スケジュールではなく、他の戦略や口座残高に連動する設計になっていないか確認)
1. sevYrsを変更した場合に、iDeCoの年金受取額(税引き前の元本相当額)自体が変化する経路が存在するか
2. 公的年金等控除の計算(`deduction()`関数、`AUDIT_ideco_pension_tax_attribution.md`で確認済みの控除テーブル)に、退職所得(退職金の課税所得や`taxableRetirementIncome`相当の値)を「公的年金等以外の合計所得金額」として参照している箇所がないか
3. 退職金の手取り額(cash相当)が、NISA・特定口座以外の経路でiDeCoの残高・運用シミュレーションに影響を与えていないか(本来iDeCoは独立口座のはずだが、念のため)
4. 上記0〜3のいずれにも該当しない場合、他にどのような経路でこの4万円の差が生じうるか

## 依頼の範囲

**調査のみ。実装・修正は行わないこと。**
