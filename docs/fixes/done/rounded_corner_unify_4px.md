## 1. 方針（KENZOが決めたこと）

- LP以外も、LPと同じく**四角い部品は一律4px**にする。
- 丸が意図された部品は、**全丸のまま**にする。
- 共有部品とLP側に残っている12px／8pxも、4pxにする（LPの見た目が変わる。5節）。
- 角丸だけを変える。**色・サイズ・影・余白は変えない。**（CTAの色・寸法の統一は別作業）

## 2. 範囲

対象：lifecompass-nextの`src`配下。freenough-mainは対象外（対応済み）。

### 2-1. 4pxにする（`rounded-lg`・`rounded-xl`・`rounded-md`、および`prose-pre:rounded-lg`を、`rounded`・`prose-pre:rounded`に）

| 役割 | 今の値 |
|---|---|
| ボタン（塗り・枠線・破線・2択・選択式・owner切替・子供タブ） | 4／8px |
| 「資産管理ツールからインポート」「①の比率をコピー」「↺リセット」など、**動作を起こす小さい全丸ボタン** | 全丸 |
| 入力欄・セレクト（ツール10本、プロファイル名、計画名ほか） | 4／8px |
| セグメント切替の外枠 | 8px |
| カード・パネル・CTAの箱・結果ボックス・アコーディオン・表の枠・補足ボックス | 4／6／8／12px |
| 注意書き・バナー・警告（黄色・青・琥珀・警告箱を含む） | 4／6／8／12px |
| モーダル・ポップオーバー・トースト（検索モーダル本体と行、InfoTooltipのポップアップ、トースト） | 8／12px |
| 画像（ブログ記事のヒーロー。一覧のサムネイルは既に4px） | 12px |
| コード（ブログの`pre`。インラインの`code`は既に4px） | 8px |

## 3. やること

1. 作業ブランチを切る：`fix/rounded-corners-4px`（`main`から）。
2. **変更の単位**ごとに順に直す。**1行は1つの単位にだけ属させる**（後でcommitを分けるため）。
   1. ボタン（2-1のボタン行。「小さい全丸の動作ボタン」を含む）
   2. 入力欄・セレクト
   3. カード・パネル・モーダル・ポップオーバー・トースト
   4. 注意書き・画像・コード
   5. 共有部品とLP側（5節）
3. 一括置換（`sed`など）で全部を変えない。**役割を1か所ずつ確かめてから**変える。同じ`rounded-lg`でも、役割によって対象かどうかが違う。
4. 各単位が終わるごとに、変更した`ファイル:行`を控える（報告に載せる）。
5. **重なりの確認**：親が`overflow-hidden`で、中の子が角を持つ場合、親を4pxにしたあと、子の角が親からはみ出したり、枠線が欠けたりしないか確かめる。セグメント切替（外枠と中のボタン）、KPIカード、画像つきカードで特に。
6. `tsc`とビルドを通す（この環境ではGoogle Fontsが取れないなどで通らない場合は、その旨を報告）。

## 4. 検証

通常と「動きを減らす」の両方は不要（角丸のみの変更）。

1. **棚卸しと同じ実測を再実行**：幅375・768・1280、30ルート（ブログ記事は2本ずつ）、棚卸しと同じ操作（検索モーダル、ドロワー、折りたたみ、イベント追加フォーム、MCモード、/assetsのプロファイル管理）。役割ごとに、`getComputedStyle(el).borderRadius`が、2節の方針どおりか確かめる。
2. **残りの確認**：`src`で`rounded-lg`・`rounded-xl`・`rounded-md`・`prose-pre:rounded-lg`を検索し、**残っているものが、2-2の例外か、「迷ったもの」だけ**になっていること。残りの一覧を報告する。
3. **直接測れなかったもの**（InfoTooltipのポップアップ、トースト、/assetsの法人タブ、法人モードの各パネルなど）：棚卸しではクラス表から換算した。今回、**測れるものは測り、測れなければ「換算」と明記する。**
4. **LPの見た目**：
   - 単位1〜4では、LP2つ（`/`、`/hitori-hojin`）の見た目は**変わらないはず**。変わったら、共有部品を触っている。報告する。
   - 単位5では、**角のピクセルだけが変わる**ことを確かめる。スクリーンショットの比較方法は、いつもの手順（資産シミュレーターLPのHeroチャートは乱数のため、乱数を固定し、変更前を2回撮って差0を確かめてから比較。ビューポートをページの高さまで広げ、アニメーションが終わってから撮る）。
5. 幅375・768・1280で、横あふれ（`document.documentElement.scrollWidth > window.innerWidth`）が、変更前と同じであること。
6. ヘッダーの検索ボタンと検索モーダル（全ページに出る）を、LPでも開いて見た目を確かめる。
