# MCモード:p10/p90ラインと「現金優先」戦略ラインの色相衝突を解消する

## 背景・問題

先日実装した「基準戦略のハイライト表示」(`STRATEGY_STYLE`による色+線種の固定、太さ/不透明度での基準強調)は正常に機能している。

その確認の過程で別の問題が見つかった。MCモード(モンテカルロ)のチャートでは、戦略比較の3線に加えて `p10` / `p90` の中央値線が表示されるが、これらが「現金優先」戦略の水色破線と近い色相になっており、3戦略+p10/p90を同時表示した際に、どちらの線か瞬間的に判別しにくい。

これは今回のバグ(基準判定ロジックの不具合)とは別の問題であり、既存のカラーパレット設計の話。優先度は低〜中で、緊急対応は不要。

## 調査してほしいこと

1. `src/components/simulator/AssetChart.tsx` 内で、MCモードのp10/p90ラインに使われている色・線種の定義箇所を特定する(前回追加した `STRATEGY_STYLE` とは別の定義になっているはず)
2. p10/p90ラインと「現金優先」(`STRATEGY_STYLE`の水色破線)の実際のカラーコード・dasharrayを比較し、どの程度近いか(色相・明度・線種)を確認する
3. p10/p90ラインが他のUI(凡例、KPIカードのツールチップなど)でも同じ色定義を参照している箇所がないか確認する(変更の影響範囲把握のため)

## 実装したい変更(方向性)

p10/p90ラインと「現金優先」ラインが同時に画面上に出てもひと目で区別できるように、以下のいずれか、または組み合わせで調整する。

- **色相を離す**: p10/p90を現在の水色系から、戦略ライン(青・水色・グレー)と被らない色相(例:紫系、オレンジ系など、既存のブランドカラーと衝突しないもの)に変更する
- **線種を変える**: 現金優先が破線(8 4)なので、p10/p90は別の点線パターン(例:細かいドット "1 3" など)にして、色が近くても線種で判別できるようにする
- **太さ/不透明度で背景に下げる**: p10/p90はあくまで「幅を示す補助線」という位置づけなので、戦略ラインより明確に細く・薄くして、視覚的に手前に出ないようにする(前回の「基準/非基準」と同じ考え方を応用できる)

上記のうち、どれが最も実装コストが低く効果的か判断した上で進めてほしい。個人的には「太さ/不透明度で背景に下げる」+「線種をドットにする」の組み合わせが、色覚多様性への配慮も含めて堅実だと考えている。

## 注意点

- 前回追加した `STRATEGY_STYLE`(比例取崩=青実線、現金優先=水色破線"8 4"、課税優先=グレー点線"2 3")の色・線種は変更しないこと。今回はp10/p90側だけを調整する
- 凡例の表示も、変更後の色・線種と一致させること(`legendType="plainline"`のパターンを踏襲)
- 固定モードのチャートにはp10/p90は表示されないため、影響範囲はMCモードのみのはず。念のため固定モードに意図しない影響が出ていないか確認すること

## 動作確認したいポイント

- MCモードで3戦略すべて表示+p10/p90表示の状態で、5本の線(比例取崩・現金優先・課税優先・p10・p90)が色/線種の組み合わせだけで判別できること
- 基準戦略を切り替えた際も、p10/p90の見た目が意図せず変化しないこと
- モバイル幅でも判別可能なこと

## 完了報告時にお願いしたいこと

- 3戦略+p10/p90を同時表示したスクリーンショット(Before/After)
- KPIスナップショット比較・回帰確認(6-A/6-B)で数値に変化がないことの確認(見た目のみの変更のはずだが念のため)
