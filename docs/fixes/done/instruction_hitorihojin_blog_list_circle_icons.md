# 実装指示書: 一人法人ブログ一覧を円アイコン付きテキスト形式に変更

## 位置づけ

直前に渡した `instruction_hitorihojin_blog_list_textify.md`(画像枠を消してテキストのみにする指示)を置き換える。**まだ着手していなければこちらを使う。着手済みであれば、その延長として以下を追加で反映する。**

これは試験的な変更として扱う。気に入らなければすぐ元(現状の画像枠付きカード)に戻せるようにすること。

## 差し戻し安全性の方針

- `feature/lp-visual-refresh` ブランチ(既存)上で作業する。mainには直接pushしない。
- Vercel Preview URLを報告し、確認・GO判断が出るまでmainにマージしない。
- 既存のカードコンポーネントは直接改変せず、新規コンポーネントとして追加し、呼び出し側を差し替える形にする(元のコンポーネントは残す)。こうすることで、気に入らない場合は呼び出し箇所を元に戻すだけで済む。

## 変更内容

対象:`/hitori-hojin/blog` の記事一覧カード。

1. 左側の画像枠(現状グレーの矩形)を削除する。
2. 画像枠があった位置に、**円の輪郭線(塗りつぶしなし、単色ネイビー、3特徴セクションで使ったのと同じ色)で囲んだ小さめのアイコン**を配置する。アイコンはカテゴリ(「一人法人を知る」「一人法人を考える」等の既存の記事カテゴリ分類)ごとに1種類でよく、記事ごとに個別の画像・アイコンを用意する必要はない。**色はカテゴリで変えず、全て同じネイビーで統一する**(今回は色分けはしない)。
3. カード自体の枠線・背景・シャドウは撤去し、行が薄い罫線で区切られる一覧形式にする。
4. タイトルを太字で強調し、右端に遷移を示す矢印(→)を置く。
5. 記事タイトル・説明文の文言、日付表示は変更しない。

## 検証(証跡必須)

- 変更後の `/hitori-hojin/blog` のスクリーンショット(PC・モバイル)を報告する。
- アイコンが全て同じネイビー(色分けなし)で表示されていることを確認する。
- 各記事へのリンク(クリーンURL)が引き続き正しく機能していることを確認する。
- 元の実装(画像枠付きカード)がコンポーネントとして残っており、切り戻しが呼び出し箇所の差し替えだけで完結することを確認する。
- Vercel Preview URLを報告する。

## やってはいけないこと

- アイコンをカテゴリごとに色分けすること(今回は単色ネイビーで統一)。
- 記事ごとに個別の画像・イラストを新規作成すること。
- 元のカードコンポーネントを削除すること(切り戻しのため残す)。
- mainへの直接push。
- 証跡なしの完了報告をしないこと。
