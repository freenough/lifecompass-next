# 調査のみ：KPI色閾値検証用データ収集(minRatio・資産寿命)

## 背景

`docs/fixes/done/`のKPI再設計で、FIRE達成カードの3段階色分け閾値(`minRatio>=100`緑/`80-100`黄/`80未満`赤)と資産寿命の黄閾値(`lifeEx-5`)を仮置きした。これを山本・中村・田中・佐々木の実際の`minRatio`分布で検証する。

**このタスクは調査のみ。コードの実装・変更は一切行わないこと。**

## 実行内容

以下の4プロファイル(既存の各キャラクター確定パラメータ・`reference/`配下のfixtureまたは各シリーズ確定値を使用)について、3つの取崩戦略(比例取崩・現金優先・課税優先)それぞれで`simulate()`→`analyze()`を実行し、以下の値を出力せよ。

### 対象プロファイル
- 山本恒一(基本シナリオ・第1話相当のパラメータ)
- 中村夫婦(確定設定・第3シリーズ)
- 田中誠(勤続13年版・現行確定パラメータ)
- 佐々木誠一(既存の確定パラメータ。退職前FIRE達成のケースを含むため特に重要)

### 出力してほしい値(プロファイル×戦略の全12パターン)

| 項目 | 説明 |
|---|---|
| `fA` | FIRE達成年齢(null可) |
| `retAge` | 退職年齢(入力値) |
| `minRatio` | 新指標。未達成時=retAge以降〜lifeExの最小充足率、達成時=fA以降〜lifeExの最小充足率 |
| `minRatioAge` | `minRatio`が発生した年齢 |
| `dA` | 資産寿命(枯渇年齢、枯渇しない場合はnull) |
| `lifeEx` | 想定寿命(入力値) |
| `dA - lifeEx` | 資産寿命が終端年齢からどれだけ余裕/不足か(nullの場合は「枯渇なし」と記載) |

### 出力形式

Markdownの表形式で、プロファイル×戦略の12行×上記7列を1つの表にまとめて出力すること。CSVエクスポート機能がある場合はCSVも添付可。

### 確認してほしい追加観点(数値を出す際に一緒にメモしてほしい)

1. 現在の閾値(`minRatio>=100`緑/`80-100`黄/`80未満`赤)で分類した場合、12パターンがそれぞれどの色になるか
2. 佐々木誠一のケースで、`fA`が`retAge`より前に成立する場合の`minRatio`計算範囲が意図通り(fA以降〜lifeEx)になっているか、実際の値から確認できるか
3. 資産寿命の黄閾値(`lifeEx-5`)について、12パターン中に「黄」に該当するケースがあるかどうか
