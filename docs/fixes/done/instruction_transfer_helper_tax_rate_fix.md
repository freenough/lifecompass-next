# 実装指示：資産移転ヘルパー「適用税率」の計算式修正・デフォルト値変更・ツールチップ追加

作成日：2026-09-05
種別：**実装**
関連：`investigation_transfer_helper_tax_rate_wording.md`（本件の調査指示書。結果が届いている場合はその内容を前提に、届いていない場合は本指示書内の1節をまず確認してから進めること）

---

## 0. 背景・確定した方針

資産移転ヘルパー（法人→個人）の「適用税率」欄について、KENZOとの協議で以下が確定した：

- **文言通りの計算式に統一する**：入力値は「移転額のうち税金として差し引かれる割合」として扱う。すなわち `個人側受取額 = 移転額 ×（1 − 適用税率）`
- **デフォルト値を70%から35%に変更する**
- **既存の「実効税率」欄と同様の「？」アイコン付きツールチップを追加し、35%という数字の根拠・使い分けを説明する**（詳細は2節）

背景にある考え方（ツールチップに反映するため、実装者も理解しておくこと）：

- この欄は、法人から個人へ実際に資産を移す際に、最終的に税金として失われる割合の見積もりを入力するもの
- 移転する残高が「まだ法人税が確定していない今期の利益」を含む場合（＝積立期、役員報酬より利益の方が大きく、内部留保が積み上がっている状況）は、法人税と個人側の税金（所得税・住民税・社会保険料）の両方がかかるため、合算負担率は40〜50%程度になりうる
- 逆に、移転する残高が「過去にすでに法人税を払い終えた内部留保」である場合（＝取崩期、役員報酬が今期の利益を上回り、過去の蓄積を取り崩している状況）は、個人側の税金（20〜30%程度）のみで済む
- どちらに該当するかは、その時々の状況（積立期か取崩期か、今回の引き出しが今期の利益の範囲内かどうか）によって変わるため、単一の「正しいデフォルト値」は存在しない。35%はその中間的な初期値であり、**KENZOが都度の状況に応じて自分で調整することを前提とした値**である

---

## 1. 計算式の修正（未確認の場合はまずここを確認）

- `investigation_transfer_helper_tax_rate_wording.md`の調査で、現在の計算式が`個人側受取額 = 移転額 × 適用税率`（文言と逆の動き）であることが確認済みの場合、`個人側受取額 = 移転額 ×（1 − 適用税率）`に修正する
- 調査がまだ行われていない、または結果が不明な場合は、実装前に実際のコードを確認し、現在の計算式がどちらの向きかを完了報告に明記した上で、最終的に上記の正しい向き（`移転額 ×（1 − 適用税率）`）になるよう修正する

## 2. デフォルト値の変更

- 「適用税率」のデフォルト値を70%から**35%**に変更する

## 3. ツールチップの追加

- 既存の「実効税率」欄で使われている「？」アイコン＋ツールチップのUIパターン（`CorporateSettingsSection.tsx`内、実効税率の説明文表示に使われているコンポーネント）を、そのまま「適用税率」欄にも適用する
- ツールチップの説明文は以下の内容とする（文言は日本語として自然な範囲で実装者側で微調整してよいが、意味は変えないこと）：

> 目安：この移転額のうち、最終的に税金として失われる割合の見積もりです。今回の引き出しが今期の利益の範囲内（法人税がまだ確定していない利益を取り崩す想定）なら、法人税と個人側の所得税・住民税・社会保険料を合わせた負担率（目安40〜50%程度）。役員報酬が今期の利益を上回る場合（過去に法人税を払い終えた内部留保を取り崩す想定）は、個人側の税金のみ（目安20〜30%程度）で構いません。精緻な税務計算ではなく、ご自身の見積もりとして入力してください。

---

## 4. 遵守事項

- ロックファイル（`types.ts`/`profile.ts`/`PortfolioPanel.tsx`/`simulate.ts`/`analyze.ts`/`montecarlo.ts`/`blog.ts`/`blogTopics.ts`/`concerns.ts`）は変更しないこと
- 既存テスト（`scripts/verify-*.js`、`full-verify.js`）が全てPASSすることを維持する。計算式の向きが変わることに対する回帰テスト（例：移転額100万円・適用税率35%で個人側受取額が65万円になること）を追加すること
- 検証は本番相当の実データ環境を使わないこと
- 完了報告には、修正前後の計算式の差分（該当コード抜粋）、デフォルト値変更箇所、ツールチップ実装箇所（コード抜粋）、テスト結果、実機ブラウザでの動作確認（100万円・適用税率35%→個人側65万円になることのスクリーンショット、ツールチップの表示確認）を必ず添付すること
