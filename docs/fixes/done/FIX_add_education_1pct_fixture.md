# 実装依頼：「教育費込み・支出300万円・インフレ1%」シナリオのfixture追加

## 背景

田中誠プロファイル(sevYrs=13変更後)には、以下3シナリオがfixture化されている。

- 完全FIRE(教育費なし・支出480万円維持)
- セミリタイア(教育費なし・支出300万円)
- インフレ2%(教育費込み・支出300万円・インフレ2%)

しかし、**「教育費込み・支出300万円・インフレ1%」というシナリオ(55歳7,367万円〜、note第4話結果④相当)がfixtureに存在しない**。このシナリオは、以下の複数のブログ記事が数値の根拠として使っている、最も重要なシナリオの一つ。

- 4%ルール記事
- モンテカルロ解説記事
- FIREチェックリスト記事

## 依頼内容

1. 田中誠プロファイル(sevYrs=13、教育費込み・支出300万円・インフレ1%)を実機で実行し、以下のチェックポイント年齢の総資産を報告すること
   - 55歳・60歳・65歳・70歳・80歳・90歳
2. このシナリオを新しいfixtureエントリとして`reference/simulation_fixtures.md`・`scripts/full-verify.js`に追加すること(名称は「教育費込み・インフレ1%」など分かりやすいものでよい)。今後、同様の「使っているのにfixture化されていない」という抜け漏れを防ぐため

## 依頼の範囲

実行+fixture追加。
