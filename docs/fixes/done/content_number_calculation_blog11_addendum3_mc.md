# 数値算出指示書 追記3:モンテカルロ試算(リスクの可視化)

対象:`content_number_calculation_blog11.md`のH2-5、A・B・Cプロファイルの
モンテカルロ(MC)試算追加

---

## 背景

これまでのH2-5数値は、想定利回り年4%を毎年きっちり得られる前提の
決定論的パス(MCオフ)によるものだった。これは「期待値ベースでは黒字運用が
有利」という結論の根拠にはなるが、市場変動(暴落を含む)のリスクを一切
反映していない。記事で「運用すれば得」という単純な結論に読者を誘導しない
ため、同じA・B・Cのプロファイルをモンテカルロ(1,000試行)で実行し、
リスク面の数値を追加で取得する。

## 対象プロファイル

- A(65歳受給・トグルOFF)
- B(60歳受給・トグルON)
- C(65歳受給・トグルON)

いずれも、これまでの決定論的パスと同一の基礎条件(単身・退職年齢60歳・
生活費120万円/年・特定口座初期残高3,000万円のみ・想定利回り年4%
[NISA・iDeCo・特定口座すべて、積立期・取崩期共通])を維持する。

## MC設定

- 試行回数:1,000試行(既存の`simulate()`/`analyze()`の標準仕様)
- 標準偏差(σ):シミュレーターの標準設定値をそのまま使用する
  (記事独自のσは設定しない。使用したσの値[積立期・取崩期]を報告に明記すること)
- ショック(`shockZOverrides`)は指定しない(通常のランダム試行とする)

## 算出・報告する項目(A・B・Cそれぞれについて)

1. 90歳時点総資産額の分布:
   - 10パーセンタイル値(悪いケース)
   - 中央値(50パーセンタイル)
   - 90パーセンタイル値(良いケース)
2. 破綻率(生涯を通じて資産がマイナスにならず、`analyze.ts`の既存指標
   [`bankruptcyRate`等]で算出される値をそのまま使用。独自の破綻判定基準は
   設けない)
3. 決定論的パス(前回報告済みの90歳時点総資産:A=8,880万円・B=9,753万円・
   C=9,689万円)と、MC中央値との乖離があるかどうか

## 記事での使い方(確認のみ・作業不要)

これらの数値により、「期待値で見れば黒字運用が有利(C・B)だが、リスクで
見ると分布のばらつきが運用ありの方が大きい」というトレードオフを、
記事本文で誠実に示す。特に、Aの分布幅(現金滞留のため市場変動の影響を
受けにくい)と、B・Cの分布幅(市場変動の影響を受ける)の違いを比較できる
形で報告すること。

## 算出方法

`analyze()`を直接importして算出すること。独自の再実装・手計算は一切
行わないこと。`scripts/blog11-pension-timing-numbers.js`にMC実行部分を
追加する形で対応してよい。

実装は行わない。数値算出・報告のみ。
