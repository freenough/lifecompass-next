# 指示書：広告開示ページ（/disclosure）差分更新（Amazonアソシエイト文言追加）

## 背景

Amazonアソシエイト・プログラムの提携基準により、メディア側のポリシーページ等に
Amazonとの関係を明記した定型文言が必要（例：「Amazonのアソシエイトとして、
当メディアは適格販売により収入を得ています。」）。審査時点でこの記載がないと
提携否認となるため、申請前に追記が必須。

**対象ファイル**：`src/app/disclosure/page.tsx`

**方針**：既存の「アフィリエイト広告について」セクション本文の末尾に、
Amazon規約準拠の一文を追加する。見出しやその他のセクションは変更しない。
