# 数値算出指示書 追記4:インフレ率0%への変更・再計算

対象:`content_number_calculation_blog11.md`のH2-5(比較グラフ)・
モンテカルロ試算、インフレ率設定の変更に伴う再計算

---

## 背景

これまでのH2-5算出は、インフレ率2%(既定値)で行われていた。シミュレーターの
設計上「収入は現在価格で固定、支出はインフレ率で上昇する」という仕様のため、
年金額(名目固定)に対して生活費だけがインフレで上昇し、結果として黒字が
途中で赤字に転じるという挙動になっていた。

この「年金は名目固定・生活費だけ上昇」という組み合わせは、記事の主題
(繰り上げ・繰り下げ+運用の効果分解)とは別の効果を持ち込んでしまうため、
**インフレ率を0%に変更し、生活費・年金額とも実質的に一定という前提で
再計算する。**

## 変更点(確定)

- **インフレ率(`inflR`):0%**(既定値2%から変更)
- その他の条件はすべて変更なし:単身・退職年齢60歳・生活費120万円/年・
  特定口座初期残高3,000万円のみ・想定利回り年4%(NISA・iDeCo・特定口座
  すべて、積立期・取崩期共通)
- プロファイルA(65歳受給・198万円・トグルOFF)・B(60歳受給・150万円・
  トグルON)・C(65歳受給・198万円・トグルON)の構成も変更なし

## 再計算・報告する項目

### 1. 決定論的パス(MCオフ)

- A・B・Cそれぞれの60〜90歳の年次総資産推移(グラフ用CSV形式、
  年齢,A,B,Cの4列)
- 90歳時点総資産額
- 要因分解:C−A(黒字運用のみの効果)、B−C(繰り上げタイミングのみの効果)、
  単純合計と実際のA→B差額が一致するか(非線形性の有無)
- **Bの黒字発生年齢範囲**(前回:60〜71歳だったが、インフレ0%では
  生涯続く可能性が高い。実際の範囲を確認して報告)
- **Cの黒字発生年齢範囲**(前回:65〜85歳だったが、同様に確認)
- プロファイルAの60〜64歳(年金未受給期間)の取り崩し発生有無(参考情報。
  この期間はインフレの有無に関わらず変化しないはずだが、念のため確認)

### 2. モンテカルロ試算(1,000試行)

- A・B・Cそれぞれの90歳時点総資産分布(10パーセンタイル・中央値・
  90パーセンタイル)
- 破綻率
- 決定論的パスとMC中央値の乖離
- σ設定(積立期・取崩期)は前回と同一の値を使用し、報告に明記すること

## 算出方法

`simulate()`/`analyze()`/`runMC()`を直接importして算出すること。独自の
再実装・手計算は一切行わないこと。`scripts/blog11-pension-timing-numbers.js`
の`inflR`パラメータを0に変更する形で対応してよい(既存のプロファイル
定義・出力形式は変更しない)。

## 記事への反映方針(確認のみ・作業不要)

再計算後の結果次第で、記事本文のH2-4(「今回の試算で分かったこと」)の
記述を一部修正する必要がある(「黒字がいずれ赤字に転じる」という説明が
成立しなくなる可能性が高いため)。これは数値到着後、この記事の担当者
(このチャット)側で対応する。Claude Codeは数値算出・報告のみでよい。

実装は行わない。数値算出・報告のみ。
