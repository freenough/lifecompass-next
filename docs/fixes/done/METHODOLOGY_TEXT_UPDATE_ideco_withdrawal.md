# 文言更新指示:iDeCo/DC出口戦略シミュレーター Methodology最終版

対象:Claude Code
性質:UI文言の差し替えのみ。計算ロジックの変更は一切不要。

---

## 背景

第6弾ツール(iDeCo/DC出口戦略シミュレーター)の実装・検証は完了済み。本体資産シミュレーターMethodologyページの⑦、およびツール自体の開示セクションの文言を、以下の最終版に差し替える。

「長期の資産シミュレーションを高速に実行するため」という表現は、`calcPensionTaxDiff()`の実装コメント(`// 所得税+住民税（簡略化・一律）`)を確認したところ、「高速化」を理由とする記述が存在しないため不正確と判断し、下記の通り修正する。同じ表現を使っている退職金側(methodologyページ①)についても、次回別途修正を検討する(今回のスコープ外)。

---

## 1. 本体資産シミュレーター Methodologyページ「⑦ iDeCo年金受取の税計算」の差し替え

**現行**(差し替え対象):
```
本シミュレーターでは、長期の資産シミュレーションを高速に実行するため、iDeCo年金の受取に伴う税額を「公的年金のみの場合との差分」として近似的に計算しています。 一時金・年金・併用のどの受取方法が手取り最大になるかを、公的年金等控除・所得税（累進課税）・住民税を一次情報に基づいて正確に計算・比較したい場合は、[iDeCo/DC出口戦略シミュレーター](/asset-simulator/tools/ideco-withdrawal)をご利用ください。 特に年金・併用パターンでは、税負担に加えて社会保険料の増加も別途考慮する必要があります。
```

**差し替え後**:
```
本シミュレーターでは、長期にわたる資産推移を継続的に試算する都合上、iDeCo年金の受取に伴う税額を「公的年金のみの場合との差分」として、一律20.315%の簡易モデルで近似的に計算しています。実際の税額と差が生じる場合があります。一時金・年金・併用のどの受取方法が手取り最大になるかを比較検討したい場合は、[iDeCo/DC出口戦略シミュレーター](/asset-simulator/tools/ideco-withdrawal)をご利用ください。
```

変更点:「高速に実行するため」→「長期にわたる資産推移を継続的に試算する都合上」に修正。「正確に計算・比較したい場合」という絶対表現を「比較検討したい場合」に弱め、社会保険料の注記はツール側の開示に譲り本体側からは削除(重複解消)。

## 2. ツール自体の開示セクション(「計算根拠を見る」等)の差し替え

**現行**の記載内容(Methodology文言としてこのチャットで作成した案がまだ未反映の場合、以下を新規掲載。既に類似の文言が掲載されている場合は下記で全文差し替え):

```
本ツールは、所得税(累進課税)・復興特別所得税・住民税・公的年金等控除を中心に、現行の税制に基づいて計算しています。本体シミュレーターは長期にわたる資産推移を継続的に試算する都合上、税額を一律20.315%とする簡易モデルを採用していますが、本ツールは特定の受け取り方を比較検討するための単発計算のため、より精緻な計算を行っています。また、差分方式による経路依存性を避け、各受取方法(一時金・年金・併用)について、指定いただいた受給期間全体で受け取れる手取り総額を直接計算しています。

ただし、以下は反映していません:
- 国民健康保険料・後期高齢者医療保険料・介護保険料(特に年金・併用パターンでは、公的年金等に係る雑所得の増加に伴いこれらの保険料負担も増える場合があり、本ツールの試算はその分だけ有利に見える可能性があります)
- 退職所得控除の重複調整(19年・9年ルール)
- 基礎控除以外の各種所得控除
- 年金受取中の運用
- 税制年度ごとの基礎控除差
- 比較期間中に65歳をまたぐ場合の区分切り替え

退職後も給与・事業所得等がある方は「年金以外の所得」欄への入力を推奨します。実際の受取可否・税額は金融機関・企業年金規約・税務署にご確認ください。
```

配置は第5弾ツール(退職金手取り計算ツール)の「計算根拠を見る」開閉式セクションと同じ構成・スタイルに合わせること。箇条書き部分はリスト表示にすること。

## 4. 【追加】退職金手取り計算ツール側の同種文言も同様に修正

第5弾ツール(退職金手取り計算ツール)にも、iDeCoツールと全く同じ2つの問題(「高速に実行するため」という技術的根拠のない理由付け、「正確な計算のため」という絶対表現)を含む文言がある。表現を統一するため、こちらも合わせて修正する。

**現行**(ツール側の本体との対比説明。差し替え対象):
```
本体の資産シミュレーターでは、長期シミュレーションを高速に実行するため、退職所得税について簡易モデルを採用しています。このツールは国税庁の一次情報に基づく正確な計算のため、本体シミュレーターの結果とは金額が異なる場合があります。
```

**差し替え後**:
```
本体の資産シミュレーターでは、長期にわたる資産推移を継続的に試算する都合上、退職所得税について一律20.315%の簡易モデルを採用しています。本ツールは、特定の受け取り方を確認するための単発計算のため、国税庁の一次情報に基づいてより精緻な計算を行っています。ただし、退職所得控除の重複調整(19年・9年ルール)は反映していません。実際の税額と本体シミュレーターの結果とは異なる場合があります。
```

変更点:
- 「高速に実行するため」→「長期にわたる資産推移を継続的に試算する都合上」(iDeCoツールと表現統一)
- 「正確な計算のため」(絶対表現)→「より精緻な計算を行っています」(本体との相対比較に限定)
- 既存のmethodologyページ②で開示されている「19年・9年ルールの重複調整未実装」を、この文中にも一言明記し、「正確」と言いながら非反映事項がある、という矛盾を解消

**併せて修正**:本体資産シミュレーターMethodologyページ①(退職金側)も、⑦(iDeCo側)と同じ2つの問題(「高速に実行するため」「正確な税額を確認したい場合は」)を含んでいるため、全文を差し替える。

**現行**(差し替え対象):
```
実際の退職所得は、退職所得控除・1/2課税適用後、所得税（累進課税）・住民税・復興特別所得税により税額が決まります。 本シミュレーターでは、長期の資産シミュレーションを高速に実行するため、課税退職所得（控除・1/2適用後）に一律20.315%を適用する簡易計算モデルを採用しています。 そのため、実際の税額と差が生じる場合があります。 正確な税額を確認したい場合は、[退職金手取り計算ツール](/asset-simulator/tools/retirement-tax)をご利用ください。
```

**差し替え後**:
```
実際の退職所得は、退職所得控除・1/2課税適用後、所得税（累進課税）・住民税・復興特別所得税により税額が決まります。 本シミュレーターでは、長期にわたる資産推移を継続的に試算する都合上、課税退職所得（控除・1/2適用後）に一律20.315%を適用する簡易計算モデルを採用しています。 そのため、実際の税額と差が生じる場合があります。 特定の受け取り方について具体的な手取り額を確認したい場合は、[退職金手取り計算ツール](/asset-simulator/tools/retirement-tax)をご利用ください。
```

変更点:
- 「高速に実行するため」→「長期にわたる資産推移を継続的に試算する都合上」
- 「正確な税額を確認したい場合は」→「特定の受け取り方について具体的な手取り額を確認したい場合は」(⑦の「比較検討したい場合」と同系統の、絶対評価を避けた誘導表現に統一)

## 6. 【追加】インフレ注記の実装漏れ対応(第5弾・第6弾両方)

Tools共通仕様チェックリストの確認により、インフレ注記(全Toolsページ共通の必須要件)が第5弾(退職金手取り計算ツール)・第6弾(本ツール)の両方で未実装だったことが判明した。既存の共通文言(複利計算・利回り前提)は税金計算系ツールにはそのまま転用できないため、以下の専用文言を新規作成し、両ツールに追加する。

**退職金手取り計算ツール(`/tools/retirement-tax`)に追加**:
```
本ツールは、入力いただいた退職金額をそのまま名目金額(実際に受け取る時点の金額)として計算しています。物価上昇(インフレ)による調整は行っていません。
```

**iDeCo/DC出口戦略シミュレーター(`/tools/ideco-withdrawal`)に追加**:
```
本ツールは、受給期間中の物価上昇(インフレ)を考慮せず、入力いただいた年金額やその他所得等を、期間を通じて毎年同額の名目値として計算しています。実際の受取額は物価変動により変わる可能性があります。
```

配置は既存4ツール(積立複利計算機・目標資産到達年齢・積立額逆算・年金繰上げ繰下げ)と同じ位置・スタイルに合わせること(インフレ注記の掲載箇所の慣例を踏襲)。
