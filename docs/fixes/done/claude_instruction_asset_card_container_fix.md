# 実装指示：「毎月の資産を、記録する。」ブロック コンテナ幅の誤変更を修正

作成日：2026-09-21
種別：**実装（前回変更の一部差し戻し＋修正）**
関連：`claude_instruction_asset_card_width_fix.md`（完了報告への追加対応）

---

## 背景

前回の対応（カード幅を広げてKPIの値が段落ちしないようにする）で、意図せず**セクション全体を囲っているコンテナの最大幅**（`max-w-5xl`→`max-w-6xl`）まで変更されていた。

KENZOが本番相当の画面で確認したところ、「毎月の資産を、記録する。」ブロックだけ左右の外側余白が、ページ内の他のセクション（例：直前の「かんたん計算ツール」セクション）より狭くなっており、ページ全体の中でこのブロックだけ横に広がって見える不整合が発生している。

**意図していたのは「右側のグラフ・KPIカードの箱の幅」だけを広げることであり、セクション全体の外枠（左右の余白）は変更対象ではなかった。**

---

## 1. コンテナの最大幅を元に戻す

- `AssetManagementPromoSection.tsx`内の、`max-w-5xl`→`max-w-6xl`に変更した箇所を**`max-w-5xl`に差し戻す**
- これにより、このセクションの左右の外側余白が、ページ内の他のセクションと再び揃うことを確認すること

## 2. 右側カードの幅は、左側とのバランスの中で確保する

- 前回`lg:w-[340px]`→`lg:w-[420px]`に広げた右カードの幅は維持してよいが、**コンテナ全体は広げない**ため、右カードを広げた分は左側（見出し・説明文・箇条書き・CTAボタン）の幅から確保することになる
- KENZOの確認によれば「左側の文章との間の余白は十分ある」とのことなので、その余白分を右カードの幅に回す形で調整すること
- 左側のテキスト・CTAボタンが極端に窮屈にならないか（特にモバイル幅で確認しやすいよう、まずデスクトップ幅で目視確認すること）
- 調整後も、KPI（目標資産・前回比）の値が段落ちしないことを維持すること（前回対応の目的を後退させないこと）
