# 退職金・iDeCo課税ロジック 一次情報リファレンス(国税庁ベース)

このドキュメントは、LifeCompassの実装を検証するための「あるべきロジック」の一次情報まとめです。Claude Codeへの現状調査の比較対象として使用します。

---

## 1. 退職所得控除額(国税庁 No.1420)

```
勤続年数20年以下: 40万円 × 勤続年数 (最低80万円)
勤続年数20年超  : 800万円 + 70万円 × (勤続年数 - 20年)
```

- 勤続年数の1年未満の端数は切り上げ(例:10年2か月→11年)
- 障害者になったことが直接の原因で退職した場合:+100万円

## 2. 退職所得の金額(1/2課税)

```
退職所得の金額 = (収入金額 - 退職所得控除額) × 1/2
```

**例外(通常のFIREシミュレーションでは考慮不要と思われるが念のため記載)**:
- 特定役員退職手当等(役員等勤続年数5年以下)は1/2を適用しない
- 短期退職手当等(役員等以外で勤続年数5年以下)は、控除後300万円を超える部分に1/2を適用しない

課税退職所得金額に対し、通常の所得税(超過累進税率)+復興特別所得税+住民税10%(分離課税)を適用。

## 3. 退職金とiDeCo一時金の重複排除ルール(19年ルール・9年ルール)

**方向A:退職金が先、iDeCo一時金が後**
- 退職金受給の**前年以前19年以内**にiDeCo一時金を受給していた場合、重複排除の対象(この期間は2026年の改正でも変更なし)

**方向B:iDeCo一時金が先、退職金が後**
- 退職金受給の**前年以前9年以内**にiDeCo一時金を受給していた場合、重複排除の対象
- **2026年1月に改正**:改正前は「前年以前4年以内」(=5年以上間隔を空ければセーフ)だったが、改正後は「前年以前9年以内」(=10年以上間隔を空ける必要)に延長された

**重複排除の考え方**:後から受け取る側の勤続年数(または加入年数)から、重複する期間を差し引いた「みなし勤続年数」を用いて控除額を再計算する(具体的な按分計算は複雑なため、LifeCompassでは実装せず、独立計算の簡略化としてmethodologyページに明記済み)。

**LifeCompassの現状の設計方針(確定済み)**:
- 同一年に受け取る場合のみ、両者の年数の大きい方(`max(dcYears, sevYears)`)で一本化(これは正しい税制上の扱い)
- 異なる年に受け取る場合は、重複調整をせず、それぞれ自分自身の年数のみで独立計算(簡略化。実際より税負担が軽く出る可能性がある近似)

## 4. 公的年金等控除(雑所得、2020年改正後の速算表)

**65歳以上**
| 収入金額 | 控除額 |
|---|---|
| 330万円以下 | 定額110万円 |
| 330万円超410万円以下 | 収入×25%+27.5万円 |
| 410万円超770万円以下 | 収入×15%+68.5万円 |
| 770万円超 | 収入×5%+145.5万円 |

**65歳未満**
| 収入金額 | 控除額 |
|---|---|
| 130万円以下 | 定額60万円 |
| 130万円超410万円以下 | 収入×25%+27.5万円 |
| 410万円超770万円以下 | 収入×15%+68.5万円 |
| 770万円超 | 収入×5%+145.5万円 |

- 公的年金等以外の合計所得金額が1,000万円を超える場合はさらに控除額が縮小される区分があるが、LifeCompassでは未実装(旧HTML版からの継続的な簡略化。FIRE計画用途では通常想定しにくい高所得帯のため許容)
- iDeCo年金は、本人の公的年金と合算した上でこの控除を適用(個人単位課税のため、配偶者の年金とは合算しない)

## 5. iDeCo受給ルール(実務上の制約)

- 受給開始年齢:60〜75歳の間で選択。ただし60歳時点で通算加入者等期間が10年に満たない場合は段階的に遅くなる(8年以上10年未満→61歳、6年以上8年未満→62歳...1月以上2年未満→65歳)
- **年金受取は5年以上20年以下の期間で指定し、受給開始後は年数・受取回数を変更できない**(唯一の例外:受給開始から5年経過後に残額を「繰上一時金」として一括受取に切り替え可能。LifeCompassはこの機能を扱っていない)
- 一時金と年金の併給も可能(10%単位で按分。LifeCompassでは扱っていない可能性が高い→要確認)
- 60歳(または受給開始年齢)前の任意引き出しは原則不可(脱退一時金等の極めて限定的な例外のみ)

## 6. 特定口座(譲渡益課税)

- 譲渡益に対して20.315%(所得税15%+復興特別所得税0.315%+住民税5%)
- 取得原価(コストベース)に応じて按分計算(LifeCompassでは`costBasis`を簡略化して管理)
