# 戦略比較チャート:基準戦略のハイライト表示 + 線スタイルの識別性向上

## 背景・問題

「総資産推移」チャート(戦略比較モード)で、以下の不整合がある。

- 情報バナーには「単一値のKPI・グラフの帯は『(選択中の戦略)』基準」と表示される
- しかし実際の線の見た目(実線/点線、太さ、濃淡)は、どの戦略が「基準」として選択されているかに関わらず固定になっている
- 結果として、UI上のテキスト説明と視覚的な優先順位が一致しておらず、ユーザーがKPIカードの数値がどの線に対応するのか直感的に把握しにくい

加えて、現状は戦略ごとの色分けのみで線種(dasharray)の差が乏しく、特に「現金優先」と「課税優先」のような近い色味の線が判別しにくい。

## 調査してほしいこと(実装前に確認)

1. 「総資産推移」の戦略比較モードを描画しているコンポーネントを特定する(Next.js/Recharts想定。旧HTMLプロトタイプ内の `STRAT_COLOR` / `STRAT_LABEL` 相当の定義がNext.js版でどこにあるか確認)
2. 「比較モード」パネルで戦略の基準(ラジオボタン「表示」)を選択している状態を保持しているstate/propの名前を特定する(例:`baseStrategy` 的なもの。UIの「表示」ラジオボタンがどのstateを更新しているか)
3. 上記2つの接続点(どのコンポーネントが両方にアクセスできるか)を確認してから実装に入ること

## 実装したい変更

### 1. 役割を分離する

- **識別性(この線がどの戦略か)** → 色 + 線種(dasharray)の組み合わせで固定。基準がどれであっても、同じ戦略は常に同じ見た目にする(学習コストを下げるため、基準切り替えで色/線種そのものを変えない)
- **重要度(これが今の基準戦略か)** → 線の太さ + 不透明度で動的に切り替える

### 2. 具体的なスタイル定義(案)

| 戦略 | 色(既存踏襲) | 線種 |
|---|---|---|
| 比例取崩 | 青 | 実線 |
| 現金優先 | 水色 | 破線(長め、例: dasharray "8 4") |
| 課税優先 | グレー | 点線(短め、例: dasharray "2 3") |

基準/非基準による動的スタイル:

| 状態 | 線幅 | 不透明度 |
|---|---|---|
| 基準戦略(ラジオボタンで選択中) | 3px | 100% |
| 非基準戦略(チェックボックスで表示のみ) | 1.5px | 60〜70% |

- FIREラインなど既存の補助線のスタイルは変更しない
- 凡例(レジェンド)の線見本も、上記のdasharrayを反映させ、実際のチャートと一致させる

### 3. 動作確認したいポイント

- 「戦略比較」で比例取崩を基準にした場合と現金優先を基準にした場合の両方で、太い実線側が正しく切り替わること
- 3戦略すべて表示した状態(比例取崩・現金優先・課税優先)で、3本の線が色だけでなく線種でも判別できること
- モバイル幅で表示した際も、破線・点線のピッチが潰れて見えないこと(必要ならモバイル時はdasharrayをやや大きめにするなどの調整を検討)

## 影響範囲の確認

- KPIカード側(資産寿命・FIRE達成・MC破綻確率など)が参照する「基準戦略」のロジックとは別物なので、KPIカードの数値自体に変更は不要。あくまでチャートの見た目のみの変更
- シナリオ比較モード(戦略比較ではなくシナリオ比較)側に同様の実線/点線ロジックがあれば、同じ考え方を適用できないか併せて確認(必須ではない)
