# 調査のみ：FIRE達成カード黄閾値の意味づけ検証(挽回可能性レバーとの対応関係)

## 背景

前回調査(`kpi_threshold_investigation.md`)で、4プロファイル×3戦略のうち「未達成」に該当したのは田中誠の3戦略のみで、いずれも資産が実際に枯渇する(`minRatio`=0.0%)最悪ケースだった。緑(達成済み)と赤(枯渇)の間の「黄」ゾーン(`minRatio` 80-100%未満)に該当する実例がまだない。

黄ゾーンの実質的な意味を「支出10%削減・退職2年延長という標準的な2つの改善レバーのどちらかで、FIRE達成に転じるかどうか」と定義し、この境界がだいたい何%の`minRatio`に対応するかを検証したい。

**このタスクは調査のみ。`kpi-thresholds.ts`・`analyze.ts`・KpiGrid.tsx等、プロダクトコードは一切変更しないこと。** 一時的なスクリプト・使い捨ての計算実行のみで完結させる。

## 実行内容(0. 前提調査 → 1. 本調査)

### 0. 前提調査:改善案(improvements)機能の実装状況確認

旧HTML版(`DESIGN_AI_ANALYSIS.md`参照)には、AIパネル向けに「支出-10%」「退職+2年」「余剰CF全額投資」の3パターンを`simulate()`→`analyze()`で再計算し、`finalAssetDelta`・`assetLifeDelta`・`effectHint`等を生成する`improvements`ロジックが既に設計・実装されていた。

Next.js版の`AiPanel.tsx`(またはその周辺ファイル)に、このロジックが**既に移植済みかどうか**を先に確認せよ。具体的には:

- `improvements`相当の配列生成ロジックが存在するか(`type:'expense'`・`type:'retirement'`等)
- 存在する場合、`finalAssetDelta`・`assetLifeDelta`・`effectHint`に加えて、**改善後にFIRE達成(`fA`)状態が変わったかどうか**を扱っているか(現状はおそらく最終資産・資産寿命の変化のみで、FIRE達成有無の変化は扱っていない可能性が高い)
- 存在しない場合、その旨を報告するのみでよい(このタスクでは実装しない)

**もし既に同等のsimulate()呼び出し(支出-10%・退職+2年)が実装されている場合、1.本調査ではそのロジック(関数)をそのまま呼び出して結果を取得すること。新規に同じ計算を書き直さないこと。**

この前提調査の結果(実装状況・参照した関数名)は完了報告に含めること。

### 1. 本調査

田中誠の現行確定パラメータ(勤続13年版)をベースに、3戦略(比例取崩・現金優先・課税優先)それぞれについて、以下のバリエーションで`simulate()`→`analyze()`を実行せよ。

### バリエーション

1. **ベースライン**(現行確定値、前回調査と同じ):`fA`・`minRatio`を再掲(比較用)
2. **支出10%削減**:`baseExp * 0.9`
3. **退職2年延長**:`retAge + 2`
4. 2・3のどちらでも達成(`fA≠null`)に転じない場合、段階的に緩めて達成に転じる境界を探る:
   - 支出15%削減、支出20%削減 …
   - 退職3年延長、退職4年延長 …
   - (達成に転じた時点で打ち切ってよい。全戦略で網羅的に振る必要はなく、傾向が掴めれば十分)

### 出力してほしい値(各バリエーション×3戦略)

| 項目 | 説明 |
|---|---|
| バリエーション名 | ベースライン/支出10%減/退職2年延長/(段階的緩和した場合はその内容) |
| `fA` | FIRE達成年齢(達成に転じたか否かが最重要) |
| `minRatio` | 達成に転じた場合の値。転じない場合は「未達成のまま」と明記(ベースラインのように枯渇して0.0%になるか、枯渇しないが未達成か、両方あり得るので区別して記載) |
| `dA` | 資産寿命(枯渇年齢)。枯渇しなくなった場合はnull |

### 特に見たいポイント

- 支出10%減・退職2年延長のどちらか(または両方)で、田中誠が実際にFIRE達成(`fA≠null`)に転じるか
- 転じる場合、その時点の`minRatio`はどのくらいの値になるか(80%前後なのか、もっと高い/低いのか)
- 転じない場合、どこまで緩めれば達成に転じるか、その時のminRatioはどうか
- 「枯渇して未達成」(minRatio=0%)から「枯渇しないが未達成」(minRatioが正の値)に変わる境界がどのあたりにあるか、もし観測できれば併記
