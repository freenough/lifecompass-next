## 背景

KENZOがPreviewを確認し、次の5点を調整することになった。

---

## 1. Heroの説明文の幅

現状、Heroの説明文に最大幅がなく、広い画面では左右いっぱいに広がっている。見出しに比べて説明文の横幅だけが突出していて、左右の余白のバランスが崩れている。

- 説明文に `max-w-3xl`（768px）程度の最大幅を付け、中央に置く（`mx-auto`）。中央寄せのテキスト配置は現状のまま
- 1文目「これから法人化を考える人にも、すでに一人法人を運営している人にも。」の直後にある**半角スペースを削除**し、md以上でだけ改行する（`<br className="hidden md:inline" />` 等）。md未満は自然に折り返す
- `[line-break:strict]` を付ける
- **これ以外のHeroの要素（h1・背景色・余白・文字サイズ・色）は変更しない**

## 2. 導入文の配置

導入文を `max-w-2xl` で左寄せにした結果、広い画面で右側に大きな空白ができている。Heroの見出し・説明文が中央寄せなので、それに合わせる。

- 導入文のブロックを中央に置く（`mx-auto`）。**ブロック内のテキストは左寄せのまま**
- 導入文にも、記事の行と同じ `text-pretty` を付ける（375pxで1段落目の最終行が「す。」だけになる件の対策）

## 3. 記事一覧セクションの見出し

h2を「一人法人を、知る・考える」から**「一人法人を知る・考える」**（読点なし）に変える。375pxで「る」だけが次の行に落ちる件の対策。

- ラベル・説明文・リンクは変えない
- 375pxで1行に収まることを確認する

## 4. 法人資産ブロックの見出しの大きさ

h2「法人の資産も、FIREの進捗に。」を、本体LPの `AssetManagementPromoSection` の h2「毎月の資産を、記録する。」と**同じ大きさ・太さ・行間**にする（現状は24px。本体側は32px、sm以上48px）。

- 本体側のh2のクラスをそのまま使う。色は一人法人側の現状のまま
- 大きくなることで折り返しが変わるので、**375・768・1440px**で改行位置を確認する
  - 折り返す場合は「法人の資産も、／FIREの進捗に。」の位置で切れるようにする（本体側で固定の改行を入れているなら、同じ方法に合わせる）
  - 「に。」「。」のような短い行が出ないこと
- 見出しの下の説明文・特徴リスト・ボタン・右側のプレビューは変えない

## 5. 下部CTAの説明文の改行

1文目の「…確認してみてください。」の直後で改行し、「一人法人はFIREを実現するための選択肢の一つです。」を次の行に置く。

- `<br />` で改行する（全幅で有効）
- 1文目が1440・768pxで1行に収まるよう、最大幅を調整する（`max-w-xl` のままで収まらなければ `max-w-2xl` にする）
- 375pxでは各文が自然に折り返してよい。ただし1〜2文字だけの行が出ないこと（出る場合は `text-pretty` を付ける）
- 文言は変えない

---

## 確認

**GA4・AdSenseへの通信を遮断したうえで**、開発サーバーで確認する。

1. 1440・768・375pxのスクリーンショット（今回の変更前と並べる）。**1920px**でもHeroと導入文を撮ること（KENZOの画面幅に近い）
2. 各節の改行位置を、スクリーンショットの該当箇所で示す
3. 横スクロールが発生しないこと（3幅）
4. `npx tsc --noEmit` がエラーなく終わること
5. `tsconfig.tsbuildinfo`・`next-env.d.ts` が書き換わっていたら `git restore` で戻す
