## 追加調査: PC版で入力パラメータ左パネルに横スクロールバーが出現

**症状:** 今回の一連の変更以降、PC版の入力パラメータパネル(左側カラム)に横スクロールバーが出るようになった。以前は出ていなかった。

**注意:** スクロールバーの表示位置をずらしても直りません。パネル内の何らかの要素が親コンテナの実際の幅より広くなっている(scrollWidth > clientWidth)ことが原因なので、**幅がオーバーしている要素そのものを特定して修正**してください。

**調査手順:**
1. DevToolsで該当パネルの`scrollWidth`と`clientWidth`を比較し、差分を確認
2. 差分が出ている状態で、パネル内の要素を一つずつ調べ、コンテナ幅を超えている要素を特定する(候補: InfoTooltip関連の絶対配置要素が閉じた状態でも幅を計算に含めている、Section見出しのflex-1配置変更に伴う余白、RateFieldのラベル幅縮小に伴う周辺要素の再配置 等。決め打ちせず実測で特定すること)
3. 特定した要素について、コンテナ幅を超えないよう修正する(絶対配置要素であればコンテナのoverflow基準に影響しないようposition:fixedやportal化を検討、通常要素であればmax-width/flex-shrink等で調整)

**確認事項:**
