# 実装指示:CTAボックスの幅・背景色修正 + 全ツールへの展開

## 背景

前回実装した「あわせて読みたい」ブロック(3ツール:ideco-withdrawal・
retirement-tax・pension-timing)で、CTAボックスに2点の問題が見つかった。
修正とあわせて、CTAボックスの見た目を残り3ツールにも展開し、6ツール全体で
統一する。

対象リポジトリ:`lifecompass-next`

---

## 1. 幅の不一致を修正

`/tools/ideco-withdrawal`等で、CTAボックス・「あわせて読みたい」ボックスが、
上部の計算結果ボックスより狭く表示されている。

- 上部の計算結果ボックスが依拠しているコンテナ要素(max-width指定・親要素の
  paddingなど)を確認し、CTAボックス・関連記事ボックスも同じ幅になるよう
  そろえること
- 具体的にどの要素にmax-width/width指定が漏れていたか、原因箇所を完了報告に
  含めること

## 2. 背景色を既存のグレーに統一

前回追加した`src/app/globals.css`の`--color-cta-bg: #eef2f6`は削除し、
サイト内で既に使われている既存のグレー(フッター・LPの交互背景セクションで
使用している色)を流用する。

- grepで既存のグレー背景色(フッターの背景色クラス・値)を確認し、
  同じ値をCTAボックスの背景色として使うこと
- 新しい色変数は追加しないこと

## 3. CTAボックスのスタイルを残り3ツールにも展開

ideco-withdrawal・retirement-tax・pension-timingの3ツールで作った
「グレー背景・角丸ボックス」のCTAデザインを、以下の残り3ツールにも適用する:

- `/tools/monthly-investment`(`MonthlyInvestmentCta.tsx`)
- `/tools/fire-age`(`FireAgeCta.tsx`)
- `/tools/compound`(実ファイル名は要確認)

### 要件

- 上記3ツールのCTAエリア(注記文・シミュレーターボタン・`[PR]`アフィリエイト
  リンク)を、他3ツールと同じグレー背景の角丸ボックスで囲む(上記2で統一した
  既存グレー色を使う。新しい色は追加しない)
- これら3ツールには「あわせて読みたい」ブロックは追加しない(対応する記事が
  ないため、CTAボックスのみでよい)
- ボックスの幅も、上部の計算結果ボックスと揃える(1と同じ問題が起きないよう
  確認すること)

---

## 確認事項

- 6ツール全てで、CTAボックスの背景色・角丸・幅が統一されていること
  (実機スクリーンショットで横並び比較できると理想的)
- ideco-withdrawal・retirement-tax・pension-timingの3ツールでは、
  「あわせて読みたい」ボックスとの幅・分離感も維持されていること
- full-verify.jsがPASSすること(計算ロジック無変更のため件数増減なし)
