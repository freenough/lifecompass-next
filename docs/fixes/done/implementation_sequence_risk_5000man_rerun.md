# 実装指示書:検証用モデルの初期資産を5,000万円に変更して再実行

## 背景

`docs/fixes/done/implementation_sequence_risk_verification_v2.md`(前回実装)の
検証用モデルは、初期資産4,000万円・年間取崩200万円(取崩率5.0%)で、基準
シナリオの破綻率が59.5%と高く出た。調査の結果、実装バグではなく「実効成長率
(μ−σ²/2≈5.05%)と取崩率がほぼ拮抗する際どいパラメータ設定」が原因と判明した
(`docs/fixes/done/investigation_mc_bankruptcy_rate_check.md`参照)。

これを受け、プランニングチャット側で初期資産を5,000万円に変更することにした
(年間取崩額200万円は変更しない。結果として取崩率が5.0%→4.0%になり、
「4%ルール」という読者に馴染みのある基準に合わせる狙い)。

## 対象・制約

**ロックファイル(`simulate.ts`・`analyze.ts`・`montecarlo.ts`)は変更禁止。**
`scripts/sequence-risk-orcan-model-numbers.js`(前回作成したスクリプト)の
初期資産パラメータのみを変更し、再実行する。他のパラメータ(年間取崩200万円・
退職年齢60歳・95歳まで・μ=6.83%・σ=18.89%・インフレ率・シナリオ設計A/B/C)は
一切変更しないこと。新規スクリプトの作成は不要、既存スクリプトの初期資産の
数値を書き換えるだけでよい。

## 変更内容

初期資産:4,000万円 → **5,000万円**(それ以外のパラメータは前回のまま)

## 実行・報告内容

前回と同じ形式で、N=1,000試行・2回実行し、以下を報告してください:

- 各シナリオ(A/B/C)の破綻確率・平均枯渇年齢・最短枯渇年齢・95歳p10/p50/p90
- B・Cについて、Aとの差分(破綻確率のpt差等)
- 退職1年目の実際の資産減少額・減少率(B・Cそれぞれ)
- 2回の実行結果の安定性(方向性・規模が再現するか)

前回同様、`simulate()`・`montecarlo.ts`の乱数生成は本番のものをそのまま
呼ぶこと。手計算・推測値は禁止、全て実行結果から取得すること。

## 完了報告に含めるべき内容

- 変更箇所のdiff(1行程度のはず)
- 上記の実行結果一覧
- 基準シナリオ(A)の破綻率が、前回(59.5%)と比べてどの程度改善したか
- この設定(初期資産5,000万円・取崩率4.0%)が記事に使える水準か
  (基準シナリオが極端すぎず、B・Cとの対比が明確に出ているか)の所感

commit・pushは行わず、報告のみでお願いします。
