## 背景

`sequence-of-returns-risk`の悩み(「退職直後に暴落が来たらどうなる?」)は、
シミュレーターのUI上では自己解決できない(暴落タイミングを固定する機能が
露出していないため)。文言を工夫しても「試算する」ボタンを押した先で
期待とのズレが生じる構造的な問題があり、プランニングチャット側で「お悩み
一覧には含めない」方針とした。

## 変更内容

`src/data/concerns.ts`から`sequence-of-returns-risk`エントリを削除して
ください(先日追加した1件のみ、他のエントリは変更しないこと)。

記事自体(`src/content/blog/sequence-of-returns-risk.md`)・画像ファイルは
そのまま残し、削除しないこと。記事は通常のブログ一覧・既存記事からの
内部リンク等を通じて到達可能な状態を維持する。

## 影響範囲の確認

1. `full-verify.js`を実行し、全PASSを確認すること
2. `tsc --noEmit`がクリーンであることを確認すること

   件数表示、関連する集計処理等)にエラーが出ないか確認すること

   到達可能であることを確認すること
