## 3. MESSAGEラベル（理念ブロック）

- 理念ブロックの本文（「人生に必要なお金も、理想の働き方も、人それぞれです。」〜）の上に、「MESSAGE」というラベルを追加する。
- 配置は**中央揃え**（本文が中央揃えのため、ラベルもブロック内で完結させる。LPの左揃えパターンとは別物として扱う）。
- 書式は2.1で確認したLPのラベル書式（フォントサイズ・字間・線のスタイル）をベースにしつつ、以下の色分けにする。
  - **線（ー）**：緑（ブランドグリーン、Header.tsxのロゴ下線と同じ値）、太さはbold
  - **テキスト（MESSAGE）**：黒（2.2で確認する見出し色、または既存の本文色に準ずる。緑にはしない）

---

## 4. SERVICESラベル（2本柱ブロック）

- 2本柱ブロックの上に、「SERVICES」というラベルを追加する。
- 配置は**左揃え**。2.1で確認したLPの「FIREガイド」等と同じ書式（線＋テキストの構造、サイズ、間隔）をそのまま使う。
- 色は3.と同様の分け方にする。
  - **線（ー）**：緑（ブランドグリーン）、太さはbold
  - **テキスト（SERVICES）**：黒（LP側は別の色の可能性があるが、今回はMESSAGEラベルと合わせてテキストは黒で統一する）

## 8. 2本柱ブロックの「一人法人」CTAをHeroと同じ見た目にする

現状、以下のようにボタンの見た目が場所によって食い違っている。

| ボタン | Hero | 2本柱ブロック |
|---|---|---|
| 資産シミュレーターを見る → | 紺（プライマリ） | 紺（プライマリ） |
| 一人法人という選択肢を見る → | 白抜き（セカンダリ） | 紺（プライマリと同じ見た目） |

2本柱ブロックの「一人法人という選択肢を見る →」を、**Heroの「一人法人という選択肢を見る →」と同じ白抜き（セカンダリ）スタイル**に変更する。hover挙動（-translate-y-0.5・shadow-lg等、既存実装済みのもの）はそのまま維持する。

資産シミュレーター側のCTA（紺・プライマリ）は、Hero・2本柱ブロックとも現状のまま変更しない。
