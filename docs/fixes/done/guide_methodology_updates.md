# 実装：ガイドページ・methodologyページの更新(3件)

## 背景

今回のKPIカード再設計セッションで、以下3件のドキュメント更新が積み残しになっていた。`docs/fixes/active/`が空になった際、これらを反映し忘れていたことが判明したため、まとめて対応する。

## ①黄ゾーンの意味づけ文言修正(ガイドページ・ツールチップ)

セッション序盤で、FIRE達成カードの黄ゾーン(`minRatio` 80-100%未満)の意味づけを「挽回容易」から「改善途中の状態」に修正することで合意済みだったが、指示ファイル化されないまま漏れていた。

- ガイドページ(`/guide`)のFIRE達成指標の説明で、黄色の意味を「小さな改善で挽回できる状態」のようなニュアンスで書いている箇所があれば、「まだ達成には届いていないが、赤(大幅な不足)ほど深刻ではない状態」という表現に修正すること
- 同様の説明がツールチップ(`InfoTooltip`経由)にもあれば、同じ修正を行うこと
- 資産寿命の黄色説明(`lifeEx-5`)は既に前回のセッションで対応済みのため、対象外

## ②改善案自動提示機能のガイドページ説明を新規追加

「支出{X}%減または退職+{Y}年で達成」という新機能について、ガイドページに説明がない。FIRE達成カードの説明箇所に、以下を含む説明を追加すること。

- 未達成の場合に、達成に必要な支出削減%または退職延長年数の目安が表示されること
- **退職延長側の数値は「延長期間中も現在と同じペースで貯蓄を続けた場合」の試算であること**(アプリ内ツールチップで補足している内容と同じ趣旨。ツールチップは気づかれないことがあるため、ガイドページにも明記する)
- 両方とも上限(支出50%・退職は余命年齢の1年前)まで試して届かない場合は「大幅な見直しが必要」と表示されること

## ③methodologyページへの近似の追記(任意・優先度低)

退職延長シナリオの計算で、「NISA・iDeCo分の積立額も合算して特定口座に継続投資する」という近似を採用していることを、他の近似(ρ=1の単一ショックモデル、iDeCo受給開始後の即時破綻扱い等)と同様に、methodologyページに追記すること。

- 追記内容の例:「改善案提案機能で退職延長を試算する際、延長期間中の新規積立はNISA・iDeCo分も含めて特定口座に計上しています。口座別利率の有利・不利を考慮した最適配分ではなく、簡略化した近似です」
- 既存の近似の説明トーン(簡潔・事実ベース)に合わせること
