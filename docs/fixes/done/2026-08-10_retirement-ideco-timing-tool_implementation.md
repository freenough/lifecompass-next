### D-3. 計算ロジック仕様

`src/lib/tax/retirementIdecoTiming.ts` に以下を実装。関数名は例示であり、既存コードの命名規則に合わせて調整してよい。

#### (1) 重複期間・合算勤続年数の算出

**投資フェーズ後のレビューで発見した重要な訂正点。** 単純な「期間の外周(最も古い開始〜最も新しい終了)」ではなく、**区間の和集合の長さ**として計算すること。

```
退職金開始年齢 = 退職金受給年齢 - 勤続年数
iDeCo開始年齢 = iDeCo受給年齢 - iDeCo加入期間

重複期間 = max(0, min(退職金受給年齢, iDeCo受給年齢) - max(退職金開始年齢, iDeCo開始年齢))

合算勤続年数 = 勤続年数 + iDeCo加入期間 - 重複期間
```

**この計算式は必ず以下4パターンのテストで検証すること(特に「完全分離」が今回の修正ポイント):**

| ケース | 勤続年数 | iDeCo加入期間 | 受給年齢の関係例 | 期待される重複期間 | 期待される合算勤続年数 |
|---|---|---|---|---|---|
| 完全重複 | 35年(25-60歳) | 20年(40-60歳) | 退職金60歳・iDeCo60歳 | 20年 | 35年 |
| 一部重複 | 35年(25-60歳) | 20年(45-65歳) | 退職金60歳・iDeCo65歳 | 15年 | 40年 |
| 隣接(重複なし) | 35年(25-60歳) | 5年(60-65歳) | 退職金60歳・iDeCo65歳 | 0年 | 40年 |
| 完全分離 | 35年(25-60歳) | 5年(65-70歳) | 退職金60歳・iDeCo70歳 | 0年 | 40年 |

#### (2) 適用ルールの判定

```
受給間隔 = |退職金受給年齢 - iDeCo受給年齢|

if 退職金受給年齢 <= iDeCo受給年齢:
    退職金が先 → 「19年ルール」を適用
    調整対象か: 受給間隔 <= 19
else:
    iDeCoが先 → 「10年ルール」を適用
    調整対象か: 受給間隔 <= 9   # ← 「10年ルール」だが判定は9以下である点をコード上に必ずコメントで明記すること
                                 #   (前年以前10年内=受給間隔が9年以下なら調整対象、10年以上空けば対象外)
```

同一年齢(受給間隔0)は「退職金が先」側(19年ルール)の判定に含める。

境界値のテストケースを1つ以上入れること(例:iDeCoが先で受給間隔ちょうど9年・10年の両方で調整対象/対象外が切り替わることを確認)。

#### (3) 税額計算

調整対象の場合、国税庁タックスアンサーNo.2735の「合算→2回目は差額」という構造に従う。

```
combinedTax = calcRetirementIncomeTax(退職金額 + iDeCo額, 合算勤続年数, false, false)
firstTax    = calcRetirementIncomeTax(1回目の受給額, 1回目の受給に対応する年数, false, false)
secondWithholdingTax = max(0, combinedTax - firstTax)   # マイナスにならないようフロア処理
```

- 関数名は `calculateSecondWithholdingTax()` のように「源泉徴収税額」であることが分かる命名にすること(「2回目の納税額」という曖昧な命名は避ける)
- UIの表示ラベルは「2回目の源泉徴収税額」とし、注記で「実際にこの額を下回る場合は還付を受けるには確定申告が必要」である旨を明記すること
- 調整対象外の場合は、`calcRetirementIncomeTax` にそれぞれの受給額・年数をそのまま渡して独立計算する
- `isExecutive`・`hasDisabilityException`は常に`false`固定(役員退職金等の特殊ケースは対象外とする設計判断のため)
- `calcRetirementIncomeTax()`の退職所得控除計算(20年以下:40万円×年数、ただし80万円未満なら80万円/20年超:800万円+70万円×(年数-20))が仕様通り実装されていることを、新ツールのテストケースの中で最低1件確認すること(既存ロジックの再確認が目的で、新規実装は不要)

### D-4. 手取り額の範囲

所得税・復興特別所得税・住民税(市民税6%+県民税4%の標準税率)をすべて含めて「手取り額」とする。既存の`retirement-tax`・`ideco-withdrawal`ツールと同じ前提で統一すること。

### D-5. UI上の必須注記

- 「本ツールは一般的な退職金・iDeCo一時金の受け取りを対象としています。役員退職金等(特定役員退職手当等・短期退職手当等)は対象外です」
- 「本ツールは現行制度(令和8年1月1日以降の税制)を前提としています」
- 「国税庁の例外規定(所得税法施行令第70条、先行受給額が自身の退職所得控除額に満たない場合の特殊計算)には対応していません」
- 「2回目の源泉徴収税額がマイナスとなる場合、還付を受けるには確定申告が必要です」
- 端数処理:年未満の端数(月単位等)は非対応で、年単位の整数入力のみに対応している旨
