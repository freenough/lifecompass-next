# 指示書: ideco-withdrawalツール — 内訳表示をカードと整合させる修正

作成日: 2026-08-03
このチャットの役割: 企画・意思決定 / 実行: Claude Code
関連: `spec_ideco_withdrawal_redesign_planA.md`(実装済み・docs/fixes/done/)、
     今回の実装レビュー中に発見された、本Specの記載漏れに対する追加修正

## 背景

先の実装(案A・比例配分)で主比較カードはiDeCo単体の手取り額に変更済みだが、
その下に展開される「◯◯パターンの内訳」は、公的年金込みの合算値のまま変更されて
いなかった。結果、同一カード内に「年金カード:1,847万円(iDeCo単体)」と
「内訳の年金パターンの手取り総額(10年間):3,233万円(公的年金込み)」という
2つの異なる"総額"が並んでしまっている。これは今回の再設計がそもそも解消しようと
していた「同じ画面内に複数の"総額"が並び、読者がどちらを見ればいいか迷う」問題を
再生産している。

検討の結果、「公的年金込みの総額を(参考)として残す」という案は不採用とした。
理由:これは以前ツール再設計時に検討し「GA4データで需要が明確になってから」と
保留にした「老後全体の総受取額」表示(案C)を、決定を経ずに内訳側から実質的に
復活させることになるため。老後全体の総額を知りたい読者は「iDeCo単体の手取り」+
「参考:公的年金 年間◯◯万円×受給年数」を自分で足し算すれば足りる。

## 修正内容

### 対象ファイル
`src/components/tools/ideco-withdrawal/IdecoWithdrawalResult.tsx`
(「年金パターンの内訳」「併用パターンの内訳」の展開表示部分)

### 1. 内訳の計算過程行はそのまま維持
- 公的年金等控除・雑所得(公的年金+DC年金)・所得税の基礎控除・所得税+復興特別所得税・
  住民税、という各行は変更しない(実際の課税が合算で行われている実態を正しく
  示しているため)

### 2. 内訳の最終行を差し替え
- 現状:「年金分の手取り(1年あたり)」→「年金パターンの手取り総額(10年間)」
  (いずれも公的年金込みの合算値)
- 変更後:上記の代わりに以下の2行を表示する
  1. 「iDeCo年金分の手取り(1年あたり)」= 3.2で算出した`idecoNetPerYear`(按分後)
  2. 「年金パターンの手取り総額(iDeCo単体・◯年間)」= カードと同じ`idecoAnnuityNetTotal`
- **公的年金込みの合算総額(現状の3,233万円のような数字)は、参考表示も含め
  一切表示しない**(案C相当の機能を内訳経由で復活させないため)

### 3. 併用パターンの内訳も同様に修正
- 「一時金分の手取り」行(985万円相当)はiDeCo単体のままなので変更不要
- 「年金分の手取り(1年あたり)」「併用パターンの手取り総額(10年間)」の2行を、
  上記2と同じ考え方でiDeCo単体の値(`mixedIdecoNetTotal`)に差し替える

### 4. 一時金パターンの内訳
- 元々iDeCo単体のみで構成されているため変更不要

## 検証方法

- 同一カード内で、カードの手取り額表示と内訳最終行の手取り総額が**完全に一致する**
  ことを確認する(年金・併用の両パターンで)
- 公的年金込みの合算値が、内訳のどこにも数値として表示されていないことを目視確認する
- `full-verify.js`・`verify-ideco-withdrawal-tool.js`が引き続きPASSすることを確認する
  (内訳の表示ロジックのみの変更であり、計算ロジック自体`idecoOnly*`フィールドは
  前回実装済みのため、新規の計算ロジック追加は不要なはず。表示コンポーネントの
  参照先を差し替えるだけで済むかを確認する)

## やらないこと(スコープ外)

- 計算ロジック(`src/lib/tax/ideco.ts`)自体の変更(前回実装済みの`idecoOnly*`系
  フィールドをそのまま表示に使うだけのはず)
- 公的年金込みの総額表示機能の新規実装(案C自体は今回も見送り)
