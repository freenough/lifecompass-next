# 実装指示書:sitemap.xml のツール一覧を TOOLS 配列駆動の動的生成に変更する

## 背景(調査結果の要約)

先の調査で以下が判明した:

- `src/app/sitemap.ts`はNext.js App Routerのネイティブ`sitemap.ts`規約で、
  ビルド時にNode.jsランタイムで実行される(fs等の制約なし)。
- `STATIC_PATHS`(`src/app/sitemap.ts:9-31`、全21件)のうち、ツール由来が
  10件、固定ページが10件(残り1件は`/tools`一覧ページ自体)。
- `tools/page.tsx`(一覧ページ)と`search-index.json/route.tsx`は、
  どちらも既に`toolMetadata.ts`の`TOOLS`配列を直接参照して動的生成して
  おり、**ディレクトリ走査ではなくTOOLS配列を単一データソースにする方式が
  既存コードベースと一貫性が高い**。
- ファイルシステム走査(ディレクトリ一覧)方式は不採用。理由:
  メタデータに未登録のツール(開発中の空フォルダ等)まで拾ってしまう
  リスクがあり、`tools/page.tsx`・`search-index.json`との一貫性も崩れる。
- `/disclosure/old`が`STATIC_PATHS`から除外されているのは意図的な仕様と
  KENZO確認済み。**本タスクの対象外。変更しないこと。**

## 今回の変更方針

1. `toolMetadata.ts`の`Tool`型(または該当する型定義)に、
   任意フィールド`draft?: boolean`を追加する。
   - 既存の10ツールのエントリには**何も追加しない**(`draft`未指定
     = 公開扱い、という後方互換のデフォルト動作にする)。
   - `draft: true`が設定されたツールは「一覧ページ・検索インデックス・
     サイトマップの3箇所すべてから除外」される、という意味で統一する。
2. `toolMetadata.ts`に、`draft`でフィルタ済みのツール一覧を返す
   エクスポート(例:`PUBLISHED_TOOLS`、命名はコードベースの既存規則に
   合わせて調整してよい)を追加する。
3. `src/app/sitemap.ts`を変更する:
   - `STATIC_PATHS`からツール由来の10エントリを削除する
     (`/tools`一覧ページ自体のエントリは固定ページ側に残す。
     これはツールではなく一覧ページなので`STATIC_PATHS`に残置でよい)
   - `toolMetadata.ts`から公開済みツール一覧をimportし、
     `/tools/${slug}`形式でサイトマップエントリを動的生成する処理を追加する
   - 既存の`postEntries`(ブログ記事の動的生成)と同様のパターン・
     同様のコードスタイルに合わせること
4. `src/app/tools/page.tsx`(一覧ページ)と
   `src/app/search-index.json/route.tsx`(検索インデックス)についても、
   `TOOLS`配列を参照している箇所を、上記2で追加した「公開済みツール一覧」
   (`draft`フィルタ後)を参照するように変更する。
   - 現時点では`draft: true`のツールは存在しないため、この変更による
     見た目・動作の変化は本番上は発生しないはず。念のため
     `full-verify.js`等で確認すること。

## 変更してはいけないもの(明示的に列挙)

- `calcResidentTax()`・`simulate()`・`analyze()`など、計算ロジック関連の
  ファイルには一切触れないこと(本タスクと無関係)。
- `/disclosure/old`の扱い(サイトマップからの除外)は変更しないこと。
- `toolMetadata.ts`内の既存10ツールのメタデータ(名称・説明・URL等)の
  内容そのものは変更しないこと。型定義への`draft?`フィールド追加のみ。
- `docs/fixes/active/`フォルダ自体を`rmdir`しないこと(空になっても)。
- コミット・プッシュは行わないこと(KENZOの明示的な承認後に別途実施)。

## 検証してほしいこと

- `full-verify.js`が全PASS・`tsc`がクリーンであることを確認
- ビルド後、実際に生成された`sitemap.xml`を確認し、以下を満たすことを確認:
  - ツール由来のURLが10件、`/tools/${slug}`形式で含まれている
    (現行の10ツールすべて)
  - `/disclosure/old`が引き続き含まれていないこと
  - 固定ページ(トップ、`/app`、`/blog`、`/guide`等)が引き続き
    すべて含まれていること
- `tools/page.tsx`(一覧ページ)・`search-index.json`が、変更前と
  見た目上・件数上変わらず10ツールを表示・返却していることを確認
- 完了後、この指示書を`docs/fixes/done/`に移動すること
