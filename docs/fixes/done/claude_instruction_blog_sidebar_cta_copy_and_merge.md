# 指示書: ブログ一覧サイドバーの導線カード文言修正と、mainへのマージ

## 種別

実装指示（小規模）。`feature/blog-list-redesign` ブランチで作業すること。KENZOはPreview URLでの確認を完了済み（問題なし）。

## 1. 導線カードの文言修正

`SimulatorCtaCard` の中身を、次の3要素に変更する。

```
あなたのFIREは、何歳？          ← 見出し（現状のまま）
無料・登録不要で試算できます    ← 新規に追加する補足（1行）
[シミュレーターで試算]          ← ボタン（現状のまま）
```

- 補足の文字は `text-sm text-slate-500` 程度とし、見出しとボタンの間に置くこと。余白は既存のバランスに合わせて調整してよい
- 補足の文言は、記事末尾のCTA（「無料・登録不要・データは端末内に保存」）の定義元があれば、それとの関係を確認して報告すること。今回は定数の共通化はせず、`SimulatorCtaCard` 内に書いてよい

### 止める条件

次のどちらかに当てはまった場合は、**コミットせずに止めて**、スクリーンショットと実測値を添えて報告すること。

- 1440px（サイドバー）・375px（ページ最下部）のどちらかで、見出しまたは補足が2行に折り返す
- サイドバー全体の高さが560pxを超える

## 2. 検証

- 1440pxのサイドバー部分と、375pxのページ最下部のスクリーンショットを撮ること
- サイドバー全体の高さを実測すること
- `npm run build` と `tsc --noEmit` がエラーなしで通ること。書き換わった `tsconfig.tsbuildinfo` は元に戻すこと
- 検証中は、Playwright等でGA4・AdSenseへの通信を遮断すること（`googletagmanager.com`・`google-analytics.com`・`googlesyndication.com`・`doubleclick.net` 等）

## 3. コミット・push・マージ（KENZOの指示済み）

上記「止める条件」に当てはまらなければ、以下を行ってよい。

1. `SimulatorCtaCard` のファイル**だけ**を個別に指定してcommitし、`feature/blog-list-redesign` をpushする
2. 前回までと同じ手順（PR作成 → mainへマージ）で、`feature/blog-list-redesign` をmainにマージする
3. この指示書を `done/` へ移動し、docs整理分だけを個別に指定してmainにcommitし、pushする。`active/` フォルダは削除しないこと

## 安全ルール（必ず守ること）

- `localStorage.clear()` などの破壊的操作は行わないこと
- devサーバーを停止するときは、ポートからPIDを特定し、そのPIDだけを個別に停止すること。`taskkill /F /IM node.exe` は**使用禁止**
- `git add -A`・`git add .` は使わないこと

## 完了報告のフォーマット

- スクリーンショット2枚（1440pxサイドバー・375pxページ最下部）と、サイドバーの高さの実測値
- 全commitのハッシュとブランチ名、マージしたPRの番号
- 本番デプロイの完了状況
- **完了報告にローカルファイルパスは一切含めないこと。** スクリーンショットは、チャットにインライン表示するか、Artifact機能で共有すること
