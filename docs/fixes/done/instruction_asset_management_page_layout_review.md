# 実装指示：資産管理ツールトップページのレイアウト整理

作成日：2026-09-05
種別：**実装**
関連：`instruction_remove_transfer_helper_and_update_personalization_ratio.md`（直前に実装・クローズ済み。本指示書はその実装結果をKENZOと一緒にレビューして見つかった、ページ全体の構成・表示の課題に対応するもの）

## 0. 背景・確定した方針

資産管理ツールのトップページ（`AssetManagementPage.tsx`、`/asset-simulator/assets`）を、KENZOとこのチャットで実際の画面を見ながらレビューした結果、以下の課題が見つかった。このページの目的は既存の見出し文言通り「保有資産を記録して、毎月のFIRE進捗を確認する」ことであるという前提に立ち、構成・表示を整理する。

### 0.1 セクションの並び順を変更する

現状、各セクションの並び順に一貫した理由がなく、「今の事実」と「まだ起きていない仮定（法人資産を個人化した場合）」の話が途中で入り混じっている。以下の順番に並び替える：

1. **FIRE進捗**（目標資産額／目標までの進捗／前回記録比の3カード）
2. **資産推移＋「記録する」ボタン**（グラフ・記録日一覧）
3. **予実比較**
4. **今の資産構成**（個人資産＋法人保有資産の内訳バー／資産クラス内訳の円グラフ／資産配分の変化の表。この3つは隣接させ、まとめて1つの塊として配置する）
5. **法人資産を個人化した場合**（旧「適用税率」カード。タイトルを「法人資産を個人化した場合」に変更する）

理由：FIRE進捗（このページの目的そのもの）を最上部に置き、その数字の直接の裏付けとなる資産推移（記録ログ）をすぐ下に続ける。予実比較は、資産推移で記録した実績を計画と照らし合わせる位置に置く。今の資産構成（中身の分析）はその後。最後に、「今の事実」とは性質が異なる「将来の仮定の見積もり」である法人資産の個人化シミュレーションを、明確に区切られた最後のセクションとして独立させる。

（検討の経緯：予実比較を資産推移より先に置く案も検討したが、現状の予実比較グラフは「計画に対して今どれだけ差があるか」を示す明示的な単一の数値を持たず、ホバー操作で任意の地点の値を読み取る形式のため、今回は見送った。また、FIRE進捗カードの数値（前回記録比等）自体が資産推移の記録ログから直接生成されているため、資産推移を先に続ける方が数字の裏付けとして自然という判断もある。将来、予実比較に「現在時点の計画比：+◯◯万円」のような明示的な数値表示が追加された場合は、順序の再検討の余地がある）

### 0.2 「法人資産を個人化した場合」のツールチップ圧縮

現在、スライダー直下に長い説明文が2本べた書きされている。次の形に圧縮する：

- スライダー直下には、1行の短いキャプションのみを残す：
  > 将来、法人資産を個人へ移す際の実質的な負担率の見積もりです。
- 「？」アイコン（`InfoTooltip`）を新設し、そこに、既存の2本の説明文（「まだ引き出していない法人保有資産のうち...」＋「目安：この比率は、法人保有資産が将来個人の手取りになるまでにかかる...」）を1つにまとめた詳細説明を格納する。内容は変えず、まとめる際に重複する言い回しがあれば整理してよい

### 0.3 「個人資産＋法人保有資産」カード内の重複表示を解消

- 現在、このカードの内訳行に「法人保有資産（個人化想定額：◯◯万円）：◯◯万円」という形で個人化想定額が括弧書きで表示されているが、この数字は本指示書の並び替え後は5番目に来る「法人資産を個人化した場合」カードで初めて説明される数字であり、説明より先に結論の数字だけが出てきてしまっている
- この括弧書き（個人化想定額の表示）を削除し、「法人保有資産：◯◯万円」という表示のみに単純化する

### 0.4 「個人資産＋法人保有資産」カードの内訳バーを、進捗バーに見えないようにする

- 現在、このカード内の横棒（個人資産／法人保有資産の内訳を示すバー）が、目標資産額（例：10,000万円）に対する比率で幅を決めているように見え、結果として「合算での目標達成度」を暗に示す進捗バーのように見えてしまっている。FIRE進捗カードは「個人資産のみ」を基準にすると明記しているため、この見た目は矛盾している
- この横棒は、目標資産額に対する比率ではなく、**個人資産＋法人保有資産の合計（例：885万円）を100%として、その中で個人資産と法人保有資産がそれぞれ何割かを示すだけの内訳バー**に変更する（バー全体は常に満幅になる）

### 0.5 「資産クラス内訳」に、個人＋法人合算である旨を明記する

- 円グラフ・見出し部分に、この内訳が個人資産と法人保有資産を合算したものである旨を明記する（例：見出し横に「（個人＋法人合算）」という一言を添える、または「？」アイコンで補足する）
- FIRE進捗カードが「個人資産のみ」と明記しているのに対し、このセクションでスコープが黙って合算に変わっている状態を解消するための対応

### 0.6 「前回記録比」に、"前回"の意味を補足する

- 「前回記録比」の"前回"が「前月」ではなく「直前に記録した回」であることを、軽い注記または「？」アイコンで補足する（記録をスキップした月があると「前月」とは一致しないため）
