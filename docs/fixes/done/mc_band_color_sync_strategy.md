# MCモード:p10〜p90の帯(バンド)の色を基準戦略の色に連動させる

## 背景・問題

MCモードのチャートでは、p10〜p90の幅を示す帯(塗りつぶし範囲)が表示される。グラフ下部のキャプション(例:「中央値2本+比例取崩のバンド」「中央値3本+現金優先のバンド」)を見ると、帯が示すデータの中身(幅)は基準戦略(`baseStrategy`)に応じて正しく切り替わっている。

しかし、帯の色(塗りつぶしの色)は基準戦略に関わらず常に同じ汎用的な薄い青色のままになっており、「データは切り替わっているのに、見た目からはどの戦略の幅を表しているか分からない」という状態になっている。

`STRATEGY_STYLE`(前回実装済み:比例取崩=青、現金優先=水色、課税優先=グレー)の色と、帯の色を連動させることで、テキストのキャプションを読まなくても直感的に「これは今どの戦略の幅か」が伝わるようにしたい。

## 調査してほしいこと

1. `src/components/simulator/AssetChart.tsx` 内で、p10〜p90の帯を描画している `<Area>` コンポーネント(fill/fillOpacity)の定義箇所を特定する
2. 現在の帯の色(fillカラーコード)が、`STRATEGY_STYLE`の色定義と別管理になっているか確認する
3. 帯の色を`baseStrategy`(または`STRATEGY_STYLE[baseStrategy]`)から動的に参照できる構造にできるか確認する(基準戦略が切り替わるたびに帯の色も再計算される必要があるため)

## 実装したい変更

- 帯の`fill`カラーを、固定値ではなく`STRATEGY_STYLE[baseStrategy]`の色(またはそれに準ずる色)から動的に生成するようにする
- 塗りつぶしなので、線の色そのまま(不透明度100%)を使うと濃すぎる可能性が高い。`fillOpacity`は現状程度の薄さ(帯として背景に馴染む濃度)を維持しつつ、色相だけ基準戦略に合わせて変える
- 課税優先(グレー)を基準にした場合、帯が地味になりすぎて視認性が下がらないか確認する。必要であれば課税優先の帯だけ`fillOpacity`をやや上げるなどの調整を検討する

## 確認してほしい懸念点

- 前回、p10/p90の**境界線**(細い線)は「薄く・細く・ドット状」にして目立たなくする対応をしたばかり。今回帯の色を基準戦略の色に寄せることで、帯(面)とp10/p90境界線(線)の色相が再び近づき、新たな判別しにくさが出ないか確認すること。ただし帯は塗りつぶしの面、境界線は輪郭という性質の違いがあるため、通常は大きな問題にはならない想定
- 基準戦略を切り替えるたびに帯の色がちらつかず滑らかに切り替わるか(アニメーション/トランジションの有無)も軽く確認する

## 動作確認したいポイント

- 比例取崩・現金優先・課税優先のそれぞれを基準に選んだ状態で、帯の色が対応する戦略色(青系/水色系/グレー系)に変わること
- 3戦略同時表示時、太線(基準戦略の中央値線)と帯の色が同系色で視覚的に結びついて見えること
- 課税優先を基準にした際の帯の視認性(薄すぎて見えにくくないか)
- モバイル幅でも色の違いが判別できること

## 完了報告時にお願いしたいこと

- 3戦略それぞれを基準にしたスクリーンショット(Before/After、可能なら3パターンとも)
- KPIスナップショット比較・回帰確認(6-A/6-B)で数値に変化がないことの確認(見た目のみの変更のはずだが念のため)
