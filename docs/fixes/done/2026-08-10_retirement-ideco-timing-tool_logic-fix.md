## 背景(必ず読むこと)

`calcRetirementIdecoTiming`(第9弾ツール)の現行実装は、退職金とiDeCoの受給タイミングが異なる年(19年ルール・10年ルール対象)の場合にも、**同一年に複数受け取る場合の計算方式(法30条5項・国税庁タックスアンサーNo.2735の「合算方式」)をそのまま流用してしまっている**ことが判明した。

しかし実際には、日本の税制上、この2つのケースは根拠となる条文も計算方式もまったく別物である。

| ケース | 根拠 | 計算方式 |
|---|---|---|
| 同一年に2以上受け取る(パターンA相当) | 法30条5項・国税庁No.2735 | 収入・勤続年数を合算して1本で計算(**現行実装のまま変更不要**) |
| 異なる年・19年/10年ルール対象内(パターンB・C相当) | **所得税法施行令第70条第1項第2号・第2項** | 先に受け取った方の税額は完全固定。後に受け取った方だけ、控除額を減額計算する(**現行実装は誤り。本ファイルで修正する**) |

以下、施行令第70条の条文(法令のため著作権の対象外。原文をそのまま引用する)を根拠として、正しいロジックを設計する。

## 施行令第70条の該当部分(原文)

> 一　（省略。同一の使用者以外の他の者から前に退職手当等の支払を受けている場合の規定。今回は非該当）
>
> 二　その年の前年以前4年内（その年に第72条第3項第7号に掲げる一時金の支払を受ける場合には、19年内。以下この号において同じ。）に退職手当等（前号に規定する前に支払を受けた退職手当等を除く。）の支払を受け、かつ、その年に退職手当等の支払を受けた場合において、その年に支払を受けた退職手当等につき第69条第1項各号の規定により計算した期間の基礎となつた勤続期間等（同項第3号に規定する勤続期間等をいう。以下この条において同じ。）の一部がその年の前年以前4年内に支払を受けた退職手当等（次項において「前の退職手当等」という。）に係る勤続期間等（次項において「前の勤続期間等」という。）と重複している場合　その重複している部分の期間を法第30条第3項の勤続年数とみなして同項の規定を適用して計算した金額
>
> 2　前項第2号の場合において、前の退職手当等の収入金額が前の退職手当等について同号の規定を適用しないで計算した法第30条第3項の規定による退職所得控除額に満たないときは、前の退職手当等の支払金額の計算の基礎となつた勤続期間等のうち、前の退職手当等に係る就職の日又は第69条第1項第2号に規定する組合員等であつた期間の初日から次の各号に掲げる場合の区分に応じ当該各号に定める数（1に満たない端数を生じたときは、これを切り捨てた数）に相当する年数を経過した日の前日までの期間を前の勤続期間等とみなして、前項第2号に定める金額を計算する。
>
> 一　前の退職手当等の収入金額が800万円以下である場合　当該収入金額を40万円で除して計算した数
>
> 二　前の退職手当等の収入金額が800万円を超える場合　当該収入金額から800万円を控除した金額を70万円で除して計算した数に20を加算した数

(出典:所得税法施行令第70条。上記は改正前の年数表記(4年内/19年内)。2026年1月以降は「4年内」の部分が「9年内」に延長されている点は前回までの調査通り。19年内の部分は変更なし。**この読み替えが正しいかどうかは、本ファイルのタスク1で改めて確認すること**)

**東京国税局の文書回答での解説(参考・要約):** その年に支払を受けた退職手当等(iDeCo一時金)の勤続期間等の一部が、前年以前19年内に支払を受けた退職手当等(前の退職手当等=退職金)の勤続期間等と重複している場合、(イ)その年の退職手当等の勤続年数に基づく通常の控除額 から (ロ)重複している部分の期間を勤続年数とみなして計算した金額 を差し引いた金額が、その年の退職所得控除額となる。

## タスク2:正しい計算ロジックの設計・実装

### 前提の整理

- 「甲」= 先に受け取った方の受給(退職金が先ならパターンB、iDeCoが先ならパターンC)
- 「乙」= 後に受け取った方の受給
- 対象外(受給間隔が19年/9年の窓を超える)の場合は、**現行実装のまま変更不要**(甲・乙とも独立してフル控除計算)
- 対象内の場合、以下の手順で計算し直す

### 対象内の場合の計算手順

**① 甲の税額は完全固定**

```
甲の手取り = calcRetirementIncomeTax(甲の収入額, 甲の勤続年数(実数), false, false)
```
乙の受給内容によって甲の税額が遡って変わることはない。既存関数をそのまま使う。

**② 甲の「前の勤続期間等」を確定する(みなし勤続期間の判定)**

```
甲の満額控除 = calcRetirementDeduction(甲の勤続年数)

if 甲の収入額 < 甲の満額控除:
    # 施行令70条2項の特例が適用される
    if 甲の収入額 <= 800万円:
        みなし勤続年数 = floor(甲の収入額 / 40万円)
    else:
        みなし勤続年数 = floor((甲の収入額 - 800万円) / 70万円 + 20)

    甲の実開始年齢 = 甲の受給年齢 - 甲の勤続年数
    甲の実効期間 = [甲の実開始年齢, 甲の実開始年齢 + みなし勤続年数]   # 終了側が短縮される
else:
    甲の実効期間 = [甲の受給年齢 - 甲の勤続年数, 甲の受給年齢]   # 実際の期間そのまま
```

**③ 重複期間を、②で確定した「甲の実効期間」と「乙の実期間」で計算する**

```
乙の実期間 = [乙の受給年齢 - 乙の期間年数, 乙の受給年齢]

重複期間 = max(0, min(乙の実期間の終了, 甲の実効期間の終了) - max(乙の実期間の開始, 甲の実効期間の開始))
```

**④ 乙の控除額を減額計算する**

```
(イ) = calcRetirementDeduction(乙の期間年数)          # 乙自身の満額控除
(ロ) = calcRetirementDeduction(重複期間)               # 重複期間を勤続年数とみなした控除額
乙の控除額 = max(0, (イ) - (ロ))
```

**⑤ 乙の税額を計算する**

```
乙の課税退職所得 = max(0, 乙の収入額 - 乙の控除額) / 2
乙の税額 = calcProgressiveIncomeTax(乙の課税退職所得) + calcResidentTax(乙の課税退職所得)
乙の手取り = 乙の収入額 - 乙の税額
```

既存の`calcRetirementIncomeTax`は「勤続年数から控除額を自動算出する」設計になっているため、④で計算した「調整済みの控除額」を直接渡して税額計算する経路が必要になる。既存関数のシグネチャを確認し、以下のいずれかで対応すること:
- `calcRetirementIncomeTax`が控除額を直接指定できるオプション引数を持っていないか確認する
- なければ、`calcProgressiveIncomeTax`・`calcResidentTax`を個別に呼び出す薄いヘルパー関数を`retirementIdecoTiming.ts`内に追加する(**`retirement.ts`本体は変更しないこと**。既存の厳守事項通り)

**⑥ 合計**

```
合計手取り = 甲の手取り(①) + 乙の手取り(⑤)
```

### テストケース①:B-2相当(みなし勤続期間の特例が適用されるケース)

**入力:**
- 甲(先)=退職金:収入1,500万円、勤続35年、受給60歳
- 乙(後)=iDeCo:収入1,000万円、加入20年、受給70歳(受給間隔10年)

**期待される中間値:**
- 甲の満額控除:1,850万円 → 甲の収入1,500万円 < 1,850万円 → みなし勤続期間の特例が**適用される**
- みなし勤続年数:30年(= (1,500万円−800万円)÷70万円+20)
- 甲の実開始年齢:25歳、甲の実効期間:[25歳, 55歳](実際の受給60歳より短縮)
- 乙の実期間:[50歳, 70歳]
- 重複期間:5年(実際のカレンダー上の重複10年ではなく、みなし調整後は5年になる点が最重要確認ポイント)
- (イ)乙の満額控除:800万円、(ロ)重複期間5年分の控除額:200万円
- 乙の控除額:600万円
- 乙の課税退職所得:200万円

**期待される最終値(概算・端数は本番関数の丸め方式に従う):**
- 甲の手取り:1,500万円(変更なし)
- 乙の税額:約30.5万円(所得税+復興税 約10.5万円、住民税20万円)
- 乙の手取り:約969.5万円
- **合計手取り:約2,469〜2,470万円**

(参考:誤った旧ロジックでは、このケースは「合算控除2,550万円が合算収入2,500万円を上回るため非課税」として合計手取り2,500万円と算出されていた。この誤差が今回の修正で解消されることを確認する。)

### テストケース②:みなし勤続期間の特例が適用されないケース(既存のC-1相当)

**期待される最終値(概算):**

- 乙の手取り:約1,464.5万円
- **合計手取り:約2,449〜2,450万円**

(参考:旧ロジックでの合計手取りは2,444万円だった。近い値だが一致しない点に注意。旧ロジックの数値をそのまま正解として扱わないこと。)
