# 修正指示: split-ratio-feedback-and-help-icons

UIバグ修正2件(即実装可)。

## 修正1: 一時金割合の内訳フィードバックテキスト

**症状:** iDeCo受取方式で「併用」選択時に表示される「一時金 50% ／ 年金 50%」が左寄り(ラベル列の下)に表示され、入力欄と視覚的に紐づかない。モバイルでは折り返しも発生する。

**修正:**
1. テキストを「**年金受取分 {100-x}%**」に短縮する(一時金側はユーザー自身の入力値なので表示不要。補数の年金側だけ示す)
2. 表示位置を入力欄クラスタの直下にする。**起点(左端)を入力ボックスの左端(`INPUT_WIDTH_CLASS`開始位置)に一致させる**(右揃えではなく左揃え。現状は右寄りに配置されており入力ボックスと視覚的に紐づいていないため修正)
3. 動的計算(100 − 一時金割合)の挙動は現状維持
4. モバイル375pxで折り返しが発生しないことを実測確認

## 修正2: 利回り設定・MC設定の?アイコン位置と吹き出しの画面外切れ

**症状:** セクション見出し行の?アイコンが右端(アコーディオン矢印の隣)にあり、クリックすると吹き出しが右方向に開いて画面外に切れ、内容が読めない。今回のレイアウト変更以前からの既存バグ。

**修正:**
1. ?アイコンを見出しテキスト(「利回り設定」「MC設定」)の**直後**に移動する。Field系ラベルの?(年間生活費 等)と同じ配置パターンに揃える
2. 吹き出しがビューポート外に切れないよう配置制御を入れる。**横方向**: 右端に近い場合は左寄りに開く。**縦方向**: 下にスペースが足りない場合(MC設定など末尾に近いセクション)は下向きではなく上向きに開く。両方向とも共通のポップオーバー/ツールチップコンポーネント側に入れて全?アイコンに効かせる
3. モバイルでタップ操作で開閉できることを確認する(ホバー依存のままなら、クリック/タップでのトグル開閉に対応させる)。既にタップ対応済みなら現状維持でよい
