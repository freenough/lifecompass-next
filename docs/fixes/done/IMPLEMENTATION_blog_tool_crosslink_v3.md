## 変更内容

対象コンポーネント(v2で作成済み):
- `src/components/tools/RelatedArticles.tsx`
- `IdecoWithdrawalCta.tsx`・`RetirementTaxCta.tsx`・`PensionTimingCta.tsx`

### 1. CTAエリアを箱で囲む

各`{Tool}Cta.tsx`内、既存の「注記文→シミュレーターボタン→`[PR]`アフィリエイト
リンク」の3要素をまとめて、薄い青グレー背景の角丸ボックスで囲む。

- 背景色:`#EEF2F6`(または既存のTailwind設定にある近似色があればそれを使う。
  新規に近い色を追加する場合はグローバルなカラー変数として定義すること)
- 角丸:12px程度(既存の`/tools`カードの角丸と統一)
- 内側の余白:上下1.5rem・左右1.5rem程度
- 3要素の内部の見た目(文言・ボタンスタイル・アフィリエイトリンクの文字サイズ等)
  は一切変更しない。箱で囲むだけ

### 2. 「あわせて読みたい」ブロックを別の箱に分離

CTAボックスの下に、**独立した白背景+薄いボーダーの箱**として配置する。

- 見出し「あわせて読みたい」(既存のまま)
- 白背景(`var(--surface-2)`相当)・薄いボーダー・角丸12px
- CTAボックスとの間に十分なマージン(1.25rem程度)を空け、明確に別ブロックだと
  わかるようにする

### 3. カードのレイアウトを縦積みに統一

**2カラムグリッドを廃止し、カード数(1枚・2枚)によらず常に縦に1列で並べる。**
各カードは「アイコン+ラベル(次に読む)+タイトル」を横並びにした行レイアウトに
統一する(以前検討した「1枚のときだけ全幅にする」という条件分岐は不要になった
ため、実装しないこと)。

```
[本アイコン] 次に読む
             記事タイトル(太字)
```

- アイコン:Tabler Icons `IconBook2`、サイズ20px程度、色`#334155`系
- カード:白背景・薄いボーダー・角丸12px、内側余白は上下0.75〜1rem・
  左右1〜1.25rem程度
- カード間の間隔:8〜10px程度
- モバイル幅(375px)では、フォントサイズ・アイコンサイズ・内側余白を少し
  詰める(本文13px→スマホ時に微調整可、既存の他コンポーネントのモバイル
  対応パターンに合わせること)。ただしレイアウト構造(横並び行×縦積み)自体は
  変えない
