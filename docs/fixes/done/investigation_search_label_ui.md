# 調査指示書(追加):検索結果のtype別ラベル表記

作成日: 2026-08-04
種別: **調査専用**(実装・コード変更は一切行わないこと。ファイルの読み取り・grep・構造確認のみ)
関連: `investigation_site_search.md`(サイト内検索機能・調査済み)の追加調査

---

## 背景・目的

検索モーダルの結果表示は、type(ツール/ブログ/ページ)ごとに見出しを分けてグルーピング
表示する方針が決定済み。この見出し・ラベルのデザインを、絵文字ではなく既存のUI言語に
揃えたテキストラベル(またはバッジ)にしたい。

そのために、サイト内に既存の「カテゴリ・タグ的なバッジ表示」のコンポーネントやパターンが
既にあるかどうかを確認したい。あるなら流用し、ないなら新規デザインが必要という判断になる。

---

## 調査してほしい項目

### 1. ブログのcategoryバッジの実装

- ブログ一覧・記事詳細ページで表示されている`category`バッジ(「FIRE基礎知識」
  「シミュレーター活用」)を描画しているコンポーネントのファイルパス
- 色分け・背景色・角丸・フォントサイズ等のスタイリング方法(Tailwindのクラス構成、
  または専用CSSか)
- このコンポーネントが汎用化されている(propsでラベル文言・色を渡せば別用途にも
  使い回せる)か、ブログ専用にハードコードされているかを報告

### 2. 他の箇所で使われているタグ/バッジ/ラベルパターン

- ツール一覧ページ・お悩み一覧ページ(`concerns.ts`関連)・ブログの`topics`/`stages`
  フィルターUI等で、バッジ・タグ的な見た目(pill形状の背景色付きラベル等)が
  他に使われていないか確認
- 使われている場合、それぞれのファイルパスとスタイリング方法を報告
- 複数箇所で似たパターンが独立実装されている場合(コンポーネント化されていない場合)、
  その旨も報告(将来的な共通化の要否判断材料にしたいため)

### 3. アイコンライブラリの使用状況

- サイト全体でアイコン表示に使っているライブラリ(lucide-react等)とその使用パターン
  (虫眼鏡アイコン自体もこのライブラリから調達する想定のため、既存の import パターンを
  把握したい)
- ツール一覧のカードで各ツールに紐づくアイコン表示がある場合、その実装方法も報告
  (type: 'tool'の結果にアイコンを添えるかどうかの判断材料)

---

## 報告フォーマット

上記1〜3の各項目について、
- 確認できた事実(ファイルパス・該当コード抜粋・スタイリングの要点)
- 既存パターンが流用できそうか、新規デザインが必要そうか、調査担当としての所感

を箇条書きで整理し、**このチャットに報告**すること。
この段階ではコードの変更・新規ファイル作成は一切行わないこと。

---

## 完了後のアクション

この調査結果を受けて、このチャット側で検索結果のtype別ラベルのデザイン方針
(既存バッジコンポーネントの流用 or 新規デザイン、色分けの有無、テキスト文言)を確定する。

その後、`investigation_site_search.md`の調査結果と合わせて、検索機能全体の
「実装指示書」を作成し、`docs/fixes/active/`に配置する。
