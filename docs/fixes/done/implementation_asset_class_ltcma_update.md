## コメントの追記

ASSET_CLASSES定義の直前に、以下の内容のコメントを追記してください(文言はコードの慣習に合わせて調整して構わないが、以下の内容は必ず含めること):

1. 出典:JPモルガン・アセット・マネジメント「2026 Long-Term Capital Market Assumptions」円ベースマトリクス(データは2025年9月30日時点)
2. 各項目のμは同資料の「算術平均」列の値を採用している(このシミュレーターは各年の期待リターンとして単純比率で加算する設計のため、幾何平均ではなく算術平均が実装と整合する)
3. 以下の値は上記LTCMA資料に対応項目がない、または一致する項目が特定できなかったため、別根拠を採用している旨を明記:
   - 先進国債券:LTCMA「先進国国債(為替ヘッジなし)」の値を採用(参考:先進国債券インデックスファンドの一般的な連動対象と整合)
   - 先進国REIT:LTCMA「グローバルREIT除く米国(為替ヘッジなし)」の値を採用
   - 日本REIT:LTCMA非対象資産のため暫定値。μは東証REIT指数の過去実績(約23年間・年率約7%)を踏まえた保守的な想定(要再検証)。σは日本株σ(17.10%)に、米国・先進国のREIT/株式ボラティリティ比率(平均約0.945)を乗じた推定値
4. 名目値(インフレ調整前)として扱っており、インフレの影響は生活費側(SimParams.inflR)にのみ反映される設計である旨(前回セッションで合意済みの注記)
5. 前提値は年次更新が必要である旨(LTCMAは毎年12月頃に改訂されるため)

## 影響範囲の確認と対応

1. この変更はデフォルトプリセットのμ・σにのみ影響し、既存の公開済みブログ記事(`pfManualFlags`で個別のパラメータを手動設定しているもの)には影響しないことを確認してください。念のため、`pfManualFlags`を使用している既存記事・プロファイルが本当にASSET_CLASSESのデフォルト値を参照していないか、コードを確認して報告してください。
2. `scripts/full-verify.js`の既存フィクスチャ(期待値)は、今回の変更により再計算結果が変わるため、変更後の実測値で期待値を更新してください。更新前後の差分(破綻確率・p10/p50/p90等)を報告に含めてください。
3. `src/app/methodology/page.tsx`内でLTCMAの参照年・出典に言及している箇所があれば、上記のコメント内容と矛盾しないよう文言を確認・必要に応じて更新してください(大きな書き直しは不要、事実関係の整合性確認のみ)。
