# 実装指示書:`/tools`一覧ページへの教育費シミュレーター追加(新グループ新設)

## 前提

教育費シミュレーターがまだ`/tools`一覧ページに掲載されていない。以前の設計判断(`NEXT_CHAT_PROMPT_Tools_09.md`関連のセッション)で、「資産を増やす」「資産を受け取る」の機能軸2分類に収まらないツール(教育費試算・ふるさと納税上限額・住宅ローン繰上げ返済)は、将来3つ目のグループ「税金・家計を最適化する」を新設して収める、という設計にしてあった。

教育費シミュレーターはまさにこの3分類目に該当する最初のツールのため、**本指示書で「税金・家計を最適化する」グループを新設し、教育費シミュレーターをそこに配置する。**

---

## 1. `ToolGroup`型の拡張

既存の`ToolGroup`型(または同等の分類用の型)に新しい値を1つ追加する。

- 想定される既存の値:「資産を増やす」「資産を受け取る」に相当する識別子
- 追加する値:「税金・家計を最適化する」に相当する識別子

型定義のファイルパスは、`/tools`一覧ページの実装(`src/app/tools/page.tsx`またはグルーピングを管理する共通ファイル)から特定すること。

## 2. `/tools`一覧ページへのグループ追加

- 既存2グループ(資産を増やす/資産を受け取る)の後に、3つ目のグループ「税金・家計を最適化する」を追加
- グループの見出しスタイル・カードのレイアウトは既存2グループと統一する(新規デザインは不要)
- 教育費シミュレーターを、このグループ内の唯一のツールとして掲載する

## 3. 教育費シミュレーターのツールカード

既存6ツールのカードと同じ構造(アイコン・ツール名・一言説明・リンク)で追加する。

- ツール名:「教育費シミュレーター」
- 一言説明(案):「教育費が積み重なる時期をシミュレーション」または「お子さんの教育費、いつ・いくらかかるか試算」(既存ツールの説明文トーンに合わせて調整可)
- リンク先:`/tools/education-cost`

## 4. LP側(「かんたん計算ツール」ブロック)への掲載可否

以前の設計判断で、LP本体の「かんたん計算ツール」ブロックには6ツール中4つ(積立・積立額逆算・目標資産到達年齢・年金繰上げ繰下げ)のみを厳選掲載し、退職金手取り計算ツール・iDeCo/DC出口戦略シミュレーターは`/tools`一覧ページ経由のみとしていた(「より専門的な内容のため」という理由)。

教育費シミュレーターも同様に、**LP本体には追加せず`/tools`一覧ページ経由のみとする**のが一貫性がある。子供がいる世帯限定のツールであり、LPの汎用的な訴求対象(裾野の広さ)とは性質が異なるため。

**この判断で問題なければLP側の変更は不要。** 異なる判断をしたい場合はKENZOに確認すること。

- 教育費シミュレーターへのリンクが正しく機能するか
