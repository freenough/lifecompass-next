# 調査指示:給与所得控除テーブルの令和8年度税制改正対応(調査のみ・実装しない・緊急)

## 背景・緊急度
resident-tax-timingツールの`calcSalaryIncomeDeduction()`(給与所得控除の速算表、令和7年度改正版
=最低保障額65万円ベース)が、既に令和8年度税制改正により一部の年度で古くなっている可能性が
判明した(前回セッションの副次的発見、財務省一次情報で裏付け済み)。

確認済みの適用時期(財務省「令和8年度税制改正の大綱」より):
> 給与所得控除の最低保障額を5万円引き上げる特例を創設する
> (所得税:令和8年分及び令和9年分、個人住民税:**令和9年度分及び令和10年度分**)
出典:https://www.mof.go.jp/tax_policy/tax_reform/outline/fy2026/08taikou_01.htm

これを住民税年度と所得年(暦年)の対応で整理すると、以下の想定になる(要検証):

| 所得を得た暦年 | 該当する住民税年度 | 想定される給与所得控除の最低保障額 |
|---|---|---|
| 令和7年(2025年) | 令和8年度分 | 65万円(既存実装のまま) |
| 令和8年(2026年) | 令和9年度分 | 74万円(69万円+特例5万円) |
| 令和9年(2027年) | 令和10年度分 | 74万円(同上) |
| 令和10年(2028年)以降 | 令和11年度分以降 | 69万円(特例終了後の恒久額) |

**今日時点(2026年8月)でこのツールを使う大多数のユーザーは、退職年の所得が令和8年または
令和9年に該当する可能性が高く、現状の実装(65万円ベース)は該当ユーザーに対して
控除を過小に見積もり、税額を過大表示している可能性が高い。緊急度は高い。**

**本指示は調査のみを目的とする。コードの変更・新規実装は一切行わないこと。**

## 調査対象

### 1. 法的状態の確認(最優先)
- 「令和8年度税制改正の大綱」(令和7年12月26日閣議決定)が、その後の通常国会で
  法案として可決・成立しているかを確認すること
- 成立している場合、施行日・適用開始時期を条文または財務省・国税庁の一次情報で再確認すること
- 成立時期・施行状況によって、本ツールでこの改正をどう扱うべきか(既に確定した制度として
  実装するか、法案段階として注記に留めるか)の判断材料を報告すること

### 2. 給与所得控除の完全なテーブル(全区分)の確認
現状把握している情報は「最低保障額(190万円以下の区分)」のみである。以下を必ず確認すること:
- 令和9年度分・令和10年度分(74万円ベース)の給与所得控除テーブルの**全区分**
  (190万円以下だけでなく、190万円超〜360万円、360万円超〜660万円、660万円超〜850万円、
  850万円超、それぞれの区分の閾値・計算式が令和7年度版から変わっているか)
- 令和11年度分以降(69万円ベース、特例終了後)の給与所得控除テーブルの全区分
- 出典は財務省の大綱本文だけでなく、国税庁のタックスアンサー(No.1410相当)の更新版が
  既に公開されていればそちらを優先すること。まだ公開されていない場合は、大綱本文・
  法律案要綱等、可能な限り一次に近い情報源から数値を確認すること

### 3. 住民税の基礎控除(43万円)への影響の有無
- 令和8年度改正で、住民税の基礎控除額(現行43万円、`RESIDENT_TAX_BASIC_DEDUCTION`)自体に
  変更があるかを確認すること(前回確認済みの資料では「個人住民税の基礎控除額(43万円)の
  引き上げは実施されない」との記載があったが、令和8年度大綱でも変更がないか再確認すること)

### 4. 非課税限度額(45万円)への影響の有無
- `NON_TAXABLE_SALARY_INCOME_THRESHOLD`(45万円、単身・扶養なし・1級地基準)についても、
  令和8年度改正で基本額等(45万円)自体に変更がないかを確認すること
  (前回確認した資料では「基本額等45万円」は令和7年度改正で「変更なし」とされていたが、
  令和8年度改正での扱いも確認すること)

### 5. 実装方針への示唆(所見の提示のみ、実装はしない)
- `calcSalaryIncomeDeduction()`を、現状の「一律の速算表」から「所得年(または住民税年度)に
  応じて異なるテーブルを参照する」設計に変更する必要があるか、その場合の関数シグネチャの
  変更案(例:第2引数に年を取る等)について所見を述べること
- 波1(前々年・前年所得基準)と波2(退職年所得基準)で、それぞれ異なる年度のテーブルを
  参照する必要が生じる可能性が高いため、この点についても整理すること
- 現在の対象年収帯(400〜800万円)において、65万円ベースと74万円ベースの控除額の差
  (9万円)が、最終的な住民税額にどの程度影響するか(概算でよい)を示すこと

## 成果物
1. 令和8年度税制改正大綱の法的成立状況(法案か、成立済みの法律か)
2. 令和9年度分・令和10年度分・令和11年度分以降、それぞれの給与所得控除テーブル全区分
3. 住民税基礎控除(43万円)・非課税限度額(45万円)への影響の有無
4. 実装方針への所見(年度対応のための設計変更案、影響額の試算)
5. 参照した一次情報のURL一覧(論点ごとに対応関係を明記)
