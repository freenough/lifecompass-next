# 実装指示:`/tools`一覧ページのグルーピング

## 背景

6ツールがフラットな1リストのままだと、初見ユーザーが自分に関係あるツールを
探しにくい。今後さらにツール(教育費試算・ふるさと納税上限額・住宅ローン繰上げ
返済など)が増える前提で、「FIRE人生のフェーズ」ではなく「**何を計算するツールか**」
という機能軸で分類する。

将来的には3分類(資産を増やす/資産を受け取る/税金・家計を最適化する)を想定しているが、
3つ目に該当するツールがまだ存在しないため、**今回は2分類のみ実装**し、3つ目の
グループ枠は作らない(該当ツールが追加されたタイミングで新設する)。

対象リポジトリ:`lifecompass-next`

---

## 変更内容

対象:`src/app/tools/page.tsx`

### グループ分け(確定)

**グループ1見出し:「資産を増やす」**
- 積立(複利)計算機(`compound`)
- 積立額逆算ツール(`monthly-investment`)
- 目標資産到達年齢シミュレーター(`fire-age`)

**グループ2見出し:「資産を受け取る」**
- 年金繰上げ・繰下げ比較シミュレーター(`pension-timing`)
- 退職金手取り計算ツール(`severance`または実際のスラッグ)
- iDeCo/DC出口戦略シミュレーター(`ideco-withdrawal`)

### 実装方針

- 現在`TOOLS`配列がフラットな1配列になっている場合、各ツールオブジェクトに
  `group`フィールド(`'accumulate'` | `'receive'`)を追加し、ページ側で
  `group`ごとにセクション分けして描画する構造にする
  (将来3つ目のグループ`'optimize'`を追加する際、配列に`group: 'optimize'`の
  ツールを足すだけで済む設計にすること)
- 各グループの前にH2見出しを配置(既存の「かんたん計算ツール」ページ全体の
  H1見出しとは別に、グループごとの中見出しとして)
- カードのデザイン・アイコン・説明文は現状から変更しない
- グループの表示順は「資産を増やす」→「資産を受け取る」

### 確認事項

- ページ全体の見出し(H1「かんたん計算ツール」)・サブコピーは変更しない
  (今回のタスク範囲外)
- LP側の「かんたん計算ツール」ブロック(4カード)は今回変更不要
  (LPは既に厳選済みの4ツールをフラット表示する設計のまま)
