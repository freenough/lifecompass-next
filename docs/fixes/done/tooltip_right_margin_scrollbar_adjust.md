# InfoTooltip.tsx:右端マージンをスクロールバー分わずかに広げる

## 背景

`kpi_tooltip_overflow_scrollbar_gap_fix.md`の対応により、ツールチップのテキストが画面右端で切れる問題は解消した。ただし、実際のブラウザ(Windows Chrome/Edge)でスクロールバーの帯にツールチップの右端が数px重なって見える、という軽微な見た目の問題が残っている。機能上の実害はないが、見た目を整えたい。

## 実装したい変更

`InfoTooltip.tsx`の横方向クランプ計算の右端マージンを、現在の`8px`から**`14px`程度**に増やす。

```
// 変更前
const left = Math.min(Math.max(8, b.left), viewportWidth - TOOLTIP_WIDTH - 8);
// 変更後(イメージ)
const left = Math.min(Math.max(8, b.left), viewportWidth - TOOLTIP_WIDTH - 14);
```

- 左端のマージン(`Math.max(8, b.left)`の`8`)は変更不要。あくまで右端のマージンのみ調整する
- `14px`は目安。実装後、見た目を確認して微調整してよい(スクロールバー幅は環境により異なるため、完璧に一致させる必要はなく、視覚的に重ならなければ十分)

## 動作確認したいポイント

- 詳細指標アコーディオンの一番右のカード(「年金開始までの年数」)や、トップKPIの一番右のカード(「最終資産」)でツールチップを開き、右端がスクロールバーの帯に重ならないことを確認する(Playwrightでの確認に加え、可能であれば実ブラウザでの確認も推奨。ただし今回は軽微な調整のため、Playwrightでの位置確認(right値がスクロールバー幅を考慮した値になっているか)で十分)
- 画面が広い場合(1920px等)に、ツールチップが不自然に左寄りに見えすぎないことも軽く確認する
