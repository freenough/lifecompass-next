# LifeCompass シミュレーター FIRE達成KPI「達成率」統一表示 追加指示書

## 位置づけ

`FIX_fire_achievement_kpi_display.md` で実装済みの「FIRE未達成時に
支出比率を表示する」対応を、さらに改善する追加指示。**本指示書は
支出比率表示、および達成時の「資産≥支出×25」という静的な文言表示の
両方を置き換えるものである。**

## 背景・問題意識

現在の実装では、FIRE達成KPIカードの補足情報が状態によって性質の異なる
情報になっている。

- 達成時:「資産≧支出×25」(判定条件の説明。計算値ではなく固定文言)
- 未達成時:「支出比率 ◯◯%」(生活費 ÷ 手取り収入の割合)

この2つは全く別の指標であり、達成/未達成で表示される情報の種類が
入れ替わるのは不自然である。**達成・未達成どちらの状態でも同じ物差しで
状況を示せる「FIRE達成率」を共通の指標として導入し、これに統一する。**

## 修正仕様

### 達成率の計算式(状態によって基準年齢が異なる点に注意)

達成率は「ある時点の資産 ÷ (その時点の年間支出 × 25) × 100」という
共通の考え方だが、**「ある時点」として使う年齢が、達成時と未達成時で異なる**。

```
達成時:   達成率 = fA時点の資産 ÷ (fA時点の年間支出 × 25) × 100
未達成時: 達成率 = retAge時点の資産 ÷ (retAge時点の年間支出 × 25) × 100
```

- `fA`:FIRE達成年齢(資産が支出×25倍を初めて超える最速の年齢)
- `retAge`:`p.retAge`。ライフプランで設定された、実際の退職予定年齢

**なぜ基準年齢を分けるのか**:`fA`(FIRE達成年齢)と`retAge`(実際の退職予定年齢)は
別の概念である。通常`retAge`は`fA`より遅いタイミングになる
(FIRE条件を満たしてからも実際にはしばらく働き続ける想定のケースが多い)。
もし達成時の達成率を`retAge`時点で計算してしまうと、退職予定がまだ先の場合、
資産がさらに積み上がった状態を見ることになり、「基準を初めて満たした瞬間」
という本来伝えたい情報にならない。`fA`時点で計算することで、
「まさに基準を満たした瞬間の達成率」を示すことができる。
一方、未達成の場合は`fA`自体が存在しない(算出されない)ため、
必然的に`retAge`時点を基準にする。

- 「退職時点」「fA時点」いずれのスナップショット取得も、既存の
  「初年度取崩率」の計算で使われている`retSnap`
  (`snaps.find(s => s.age === p.retAge)`に相当)と同様のパターンで、
  `age`の参照先を`p.retAge`または`a.fA`に差し替える形で取得すること
- 「年間支出」はインフレ調整後の名目値(該当スナップショットが
  保持している支出額)を使うこと
- 小数点以下は四捨五入して整数表示(例:「128%」「78%」)
- **ゼロ除算のガード**:基準時点の年間支出が0の場合、達成率は計算できないため
  「—」等にフォールバックする(具体的な文言は他のKPIカードの
  「算出不可」表現と統一すること)
- 達成時の達成率は理論上100%付近になることが多いが、シミュレーションが
  年次刻みであるため厳密に100.0%にはならず、100〜110%程度の幅で
  表示されることが想定内である。これは仕様であり、バグではない

### 表示仕様

```
達成時(FIRE達成年齢が算出できる場合):
  色: 緑(変更なし)
  値: 「{達成年齢}歳」(変更なし)
  補足: 「達成率 ◯◯%」(fA時点で計算。「資産≥支出×25」という
        固定文言から変更する)

未達成時:
  色: 黄色(変更なし)
  値: 「未達成」(変更なし)
  補足: 「達成率 ◯◯%」(retAge時点で計算。既存の「支出比率 ◯◯%」
        から変更する。「支出比率」の計算ロジック
        (`baseExp / baseInc * 100`)は削除すること)
```

### ?マークの説明文(既存文言に追記)

現在?マークをクリックすると表示される説明文:

> 取崩期を通じて資産が「年間支出×25」を下回らない最速の退職年齢。達成できない場合は「未達成」を表示します。

これに以下の一文を**追記**する(既存の説明文は削除・変更しない)。
達成時と未達成時で達成率の計算基準となる年齢が異なるため、
その点が正確に伝わる文言にすること。

> FIRE達成率は、達成時はFIRE達成年齢時点、未達成時は退職予定年齢時点の資産が、「年間支出×25」の何%に達しているかを表します。

修正後の全文(参考):

> 取崩期を通じて資産が「年間支出×25」を下回らない最速の退職年齢。達成できない場合は「未達成」を表示します。FIRE達成率は、達成時はFIRE達成年齢時点、未達成時は退職予定年齢時点の資産が、「年間支出×25」の何%に達しているかを表します。

## 確認事項(完了報告に含めること)

1. FIRE未達成の入力値で固定モードを実行し、補足テキストが
   「支出比率」ではなく「達成率 ◯◯%」(retAge時点で計算)になっていることを確認する
2. FIRE達成済みの入力値で固定モードを実行し、補足テキストが
   「資産≥支出×25」ではなく「達成率 ◯◯%」(fA時点で計算)になっていることを確認する
3. 達成時・未達成時それぞれの達成率の計算結果を、
   手計算(該当スナップショットの資産・支出を使った検算)と突き合わせ、
   一致することを確認する(サンプル値での検算結果を報告に含める)
4. 基準時点の年間支出が0になるような極端な入力値で、
   ゼロ除算エラーが発生せず正しくフォールバックすることを確認する
5. ?マークをクリックし、既存の説明文に「達成時はFIRE達成年齢時点、
   未達成時は退職予定年齢時点」という基準の違いを明記した一文が
   追記された状態になっていることをスクリーンショットで確認する
6. 本修正はKPI表示ロジックのみの変更であり、他のKPIの計算結果に
   影響しないことを確認する
