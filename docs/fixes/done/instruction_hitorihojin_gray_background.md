# 実装指示書: 一人法人LPの背景色をグレーに統一

## 背景

`/hitori-hojin` トップページの「一人法人を知る」「一人法人を考える」セクション、および最終CTA(「一人法人を考える前に、まずは自分の必要資産額を確認してみてください」〜「資産シミュレーターで試算する→」)の背景色について、現状は白背景、CTA部分のみ薄い水色になっている。

資産シミュレーター側の対応するセクション(使い方・最終CTA「まず、自分の数字を入れてみる。」)を確認したところ、白背景と薄いグレー背景を切り替える構成になっており、行動喚起の役割は背景色ではなく**ボタン自体の濃紺色**が担っている。この構成に、一人法人側も合わせる。

## 差し戻し安全性の方針

- 引き続き `feature/lp-visual-refresh` ブランチ上で作業する。mainには直接pushしない。

## やること

1. 「一人法人を知る」「一人法人を考える」の2セクションをまとめて囲む背景を、**白から薄いグレー**に変更する(資産シミュレーター側の「使い方」セクションの背景色と合わせる)。
2. 最終CTAボックス(「一人法人を考える前に...」〜「資産シミュレーターで試算する→」)の背景色を、**薄い水色から薄いグレー**に変更する(資産シミュレーター側の最終CTA「まず、自分の数字を入れてみる。」の背景色と合わせる)。
3. **ボタン(「資産シミュレーターで試算する→」)自体の濃紺色は変更しない。** 行動喚起の役割はこのボタンの色が引き続き担う。
4. 変更後、ページ全体で「白→グレー→白→グレー」のようにセクションの背景が意味のある単位で切り替わっていることを確認する(白背景とグレー背景の隣接が不自然にならないか)。

## 検証(証跡必須)

- 変更後のページ全体のスクリーンショット(PC・モバイル)を報告する。
- 「一人法人を知る/考える」セクション、最終CTAボックスがともにグレー背景になっていること、ボタンの濃紺色は変わっていないことを確認する。
- 資産シミュレーター側の対応箇所の色と一致していることを確認する。
- Vercel Preview URLを報告する。

## やってはいけないこと

- ボタン自体の色を変更すること。
- 資産シミュレーター側の実装を変更すること(一人法人側のみが対象)。
- mainへの直接push。
- 証跡なしの完了報告をしないこと。
