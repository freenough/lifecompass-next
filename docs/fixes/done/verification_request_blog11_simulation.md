# 検証依頼:ブログ記事11本目「教育費はFIREの足かせになるのか」用の実機シミュレーション(再検証)

## 重要な修正指示(前回検証への訂正)

前回の検証で、「年間200万円が無運用のcashに滞留していた」ことを問題とみなし、この200万円を特定口座に振り分ける補正を行った上でA/B/C試算が行われた。**この補正は取り消すこと。**

**注記:** 参照元のnote小説(`nakamura_all_episodes_revised.md`)はこのチャットにアップロードされたファイルであり、リポジトリ内には存在しない可能性がある。Claude Code側で該当ファイルにアクセスできない場合、以下に転記した第2話の数値を正とすること。

中村夫婦シリーズのソースであるnote小説第2話の要約ボックスに、口座別の積立額が明記されている:

- 翔太:NISA年70万円+特定口座年35万円=105万円/年
- 美咲:NISA年75万円=75万円/年
- 合計180万円/年(第1話の要約とも一致)

世帯の年間余剰CF(約316.75万円/年)のうち、実際に投資へ回るのは180万円/年のみで、**残りは意図的に無運用のキャッシュとして滞留する設計になっている。** これは小説のテーマ(「積み立てているのに、ゴールを決めていなかった」)そのものであり、設定漏れではない。**この積立額(翔太105万円/年・美咲75万円/年)を、そのままの数値で使用すること。**

## 評価指標の変更(前回検証への訂正)

前回は「FIRE達成年齢(fA)」を比較指標として使用したが、これは中村シリーズ本編が使っている指標と異なる。本編(第8話〜第10話)は以下の指標で意思決定している:

- 58歳退職時資産額(固定利回り)
- 90歳時点資産額(固定利回り)
- MC破綻率(1,000試算)

**本記事でも、FIRE達成年齢ではなく、上記の指標(特に58歳時点資産額とMC破綻率)を主軸に比較すること。** 「FIRE達成/未達成」という二値ではなく、「教育費パターンによって資産額・破綻率にどれだけの差が生まれるか」を見せる。

## 前提方針(確定)

- ベース:中村夫婦シリーズ、note小説第10話の最終確定設定(翔太58歳退職・美咲56歳退職、退職金翔太1,500万円・美咲1,000万円、68歳以降生活費240万円/年)を出発点とする
- 積立配分は上記の通り、翔太105万円/年・美咲75万円/年で固定(補正しない)
- 元の教育費ライフイベント(子1:49〜52歳250万円/年、子2:52〜55歳250万円/年)を、今回の3パターンに置き換える
- 子供2人・3歳差という構造は元のプロファイルの想定を踏襲する

## ライフイベントの表現方法(確定・前回と同じ)

ライフイベント編集UIは「開始年齢・期間(年)・金額(万円/年、固定)」の構造のみのため、教育費シミュレーターの年次計算結果を、ステージごとに複数のライフイベントへ分割して積み上げる。子供1人あたり、幼稚園(3年)・小学校(6年)・中学校(3年)・高校(3年)・大学(4年)の5イベントに分割する。子供2人分で、パターンごとに最大10個程度のライフイベントになる想定。

## 1. 比較する進路パターン(3パターン)

- **パターンA(オール公立中心):** 幼稚園〜大学まで公立中心、大学は国公立
- **パターンB(私立中心):** 幼稚園〜大学まで私立中心、大学は私立文系
- **パターンC(大学のみ私立、要因分解用):** 幼稚園〜高校は公立、大学のみ私立文系

子供2人とも同じ進路パターンを選択した場合の試算とする(混在パターンは今回は扱わない)。

## 2. 出力してほしい数値

パターンA/B/Cそれぞれについて:

- **58歳退職時資産額(固定利回り)**
- **90歳時点資産額(固定利回り)**
- **MC破綻率(1,000試算)**
- 参考値としてFIRE達成年齢・資産寿命も出しておいてよいが、記事の主軸にはしない

比較として:
- パターンA→Bで58歳時点資産・破綻率がどれだけ変わるか
- パターンA→Cで同上(大学だけの影響)
- パターンC→Bで同上(小中高の影響)

## 3. 実行方法

- 教育費シミュレーターの年次計算は`calcChildYearlyCosts()`等の本番関数を直接呼び出して取得する
- 資産シミュレーター側は本番の`simulate()`/`analyze()`/`runMC()`を直接importして実行するか、実際のブラウザ操作でCSVエクスポートを行う
- 完了報告には、使用した関数・実行方法(実機/本番関数経由)を明記すること
- **今回、積立額・評価指標いずれも小説本編の設定・見せ方から逸脱しないこと。** 逸脱が必要と判断した場合は、必ず先に報告し、KENZOの確認を得てから進めること
