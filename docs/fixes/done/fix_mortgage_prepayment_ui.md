# 指示書:繰上返済(単発)対応 — モーダルUI実装(LifeEventTimeline.tsx)

**このセッションの役割:** 実装。今回はロックファイル(`simulate.ts`/`analyze.ts`)には触れない、通常のフロントエンド変更。

**前提:** `src/lib/helpers.ts`に`calcMortgageBalance`・`calcMortgageTermFromPayment`が実装済み、`simulate.ts`は`prepayAge`/`prepayAmount`/`prepayType`(optional)を受け取れる状態になっている(commit ca4ba51で完了済み)。本指示書はこれらを使い、住宅ローンイベントのモーダルUIに繰上返済の入力・試算表示を追加する。

## 対象画面

`LifeEventTimeline.tsx`のEventFormコンポーネント、住宅ローンイベント種別選択時のフォーム(現状のスクリーンショット:開始年齢・借入額・金利・返済年数の下に試算表示、その下に注記文がある画面)。

## 実装要件

### 1. 繰上返済セクション(トグル)の追加

「返済年数」入力欄の下に、チェックボックスで開閉するセクションを追加する。

```
返済年数        [30]  年

☐ 繰上返済を設定する          ← デフォルトOFF

  （チェックONで以下が展開）
  繰上返済年齢    [    ] 歳
  繰上返済額      [    ] 万円
  方式  [期間短縮型 / 返済額軽減型]（セレクタ、デフォルトは期間短縮型）
```

- チェックOFF時は`prepayAge`/`prepayAmount`/`prepayType`をすべて`undefined`にしてイベントを保存すること(既存の後方互換ガード`hasPrepay`が確実に`false`になるようにする)
- `NumberField`(前回セッションで新設済みの共有コンポーネント)を繰上返済年齢・繰上返済額にも使用し、前0バグの再発を防ぐこと

### 2. 入力バリデーション

- 繰上返済年齢は「開始年齢 < 繰上返済年齢 < 開始年齢+返済年数」の範囲に制限すること(範囲外はエラー表示または入力を受け付けない)
- 繰上返済額は借入額を超えないこと、かつ0より大きいこと
- 期間短縮型で`calcMortgageTermFromPayment`が`null`を返すケース(解なし)を検知した場合、「この条件では期間短縮の効果がありません」等のメッセージを試算エリアに表示し、フォーム送信自体はブロックしない(返済額軽減型への切り替えを促す、または繰上返済額を見直すよう示唆する文言が望ましい)

### 3. 試算表示の拡張

既存の試算ブロック(「試算(元利均等返済)」月次/年次/総返済)の下に、繰上返済セクションがONのときのみ追加ブロックを表示する。

```
試算(元利均等返済)
月次 9.6万  年次 115.8万
総返済 3,474万
─────────────────────────────
繰上返済後(62歳・300万円・期間短縮型)
完済年齢: 85歳 → 79歳(6年短縮)
```

- 期間短縮型:`calcMortgageBalance`で繰上返済時点の残高を求め、`calcMortgageTermFromPayment`で新しい完済年齢を算出して表示
- 返済額軽減型:`calcMortgageBalance`で残高を求め、`calcMortgage`(残存期間そのまま)で新しい月次/年次返済額を算出して表示
- 表示に使う計算は全て`helpers.ts`からimportした関数を使うこと(独自再計算・重複実装を新設しないこと)

### 4. 注記文の修正

現在の注記文「元利均等返済のみ対応。**繰上返済・ボーナス払いは非対応**。返済額は名目固定額です。金利変動リスクは別途イベントで登録してください。」を、以下のように修正する。

> 元利均等返済のみ対応。繰上返済(単発)に対応。ボーナス払いは非対応。返済額は名目固定額です。金利変動リスクは別途イベントで登録してください。

正確な文言は実装者の判断で微調整して構わないが、「繰上返済は非対応」という誤った表記を残さないこと。

### 5. 既存イベントの編集時の互換性

既存の(繰上返済フィールドを持たない)住宅ローンイベントを編集モーダルで開いたとき、チェックボックスはOFF・関連入力欄は空の状態で正しく表示されること(エラーや`undefined`起因の表示崩れがないこと)を確認する。

## 検証

- `tsc`クリーン
- `full-verify.js`が既存件数を維持すること(UI変更のみのため、ロジック側のテスト件数に変化がないことを確認)
- 手動確認項目(Claude Code側で実機確認できる範囲):
  1. 繰上返済チェックOFFのまま新規住宅ローンイベントを追加 → 従来と同じ試算・保存結果になること
  2. チェックONで期間短縮型を選択 → 完済年齢の短縮が正しく表示されること
  3. チェックONで返済額軽減型を選択 → 新しい月次/年次返済額が正しく表示されること
  4. 解なしケース(例:借入額少・金利高・繰上返済額小)で期間短縮型を選んだ場合、警告メッセージが表示されること
  5. 既存の(繰上返済なし)住宅ローンイベントを編集で開いた際、表示崩れがないこと
  6. 前0バグが繰上返済年齢・繰上返済額の入力欄でも発生しないこと(`NumberField`使用の確認)
