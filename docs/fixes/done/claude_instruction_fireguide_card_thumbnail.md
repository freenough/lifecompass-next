# 指示書: LP「FIREガイド」カードをサムネイル型に作り直す

## 種別

実装指示。前回の指示書 `claude_instruction_fireguide_card_simplify.md`（画面幅によってテキストのタイトルを出し分ける案）は、**方針変更により破棄**する。この指示書がそれに代わる。

## 方針変更の理由

前回の案は「アイキャッチ画像を縦横比どおりに全部見せ、画像内のタイトルを読ませる」前提だった。しかし、画像内の文字サイズがどの幅でも足りず、幅ごとの出し分けが必要になっていた。

今回は考え方を変える。

- **画像は雰囲気を伝えるサムネイルと割り切り、横長の枠で切り抜く**（画像内の文字は読めなくてよい）
- **タイトルは、すべての幅でテキストで読ませる**

一般的なブログ一覧のサムネイルと同じ作りにする。

## 作業ブランチと前回の実装の扱い

- `feature/fireguide-card-simplify` で作業すること
- このブランチには、前回の案の未commitの変更（`FireGuideCarousel`）が入っている
  - まず `git diff --stat` で内容を報告すること
  - そのうえで、**`FireGuideCarousel` の変更を破棄して `main` と同じ状態に戻してから**作り直すこと（`git checkout -- <該当ファイル>`）
  - 該当ファイル以外に未commitの変更があれば、触らずに報告すること

## 変更内容（`FireGuideCarousel` のカード）

### 完成形

```
┌──────────────────┐
│  アイキャッチ（16:9で切り抜き） │
├──────────────────┤
│ 記事タイトル（2行まで）        │
│ 2026-07-01                 │
└──────────────────┘
```

### 1. 画像

- 画像の枠を、**16:9 の横長**にする（`aspect-video` 等）
- 画像は枠いっぱいに `object-cover`、位置は `object-center` で表示する。上下が切れてよい
- `next/image` の `sizes` は、実際のカードの表示幅に合わせて見直すこと
  - DPR 2 の端末で画像が引き伸ばされて粗くならないことを、読み込まれた画像の実際の幅（`currentSrc`・`naturalWidth`）で確認すること
- **画像の `alt` は空（`alt=""`）にする**
  - カードのリンクの中にテキストのタイトルが常にあるため、`alt` にもタイトルを入れると、読み上げソフトで同じタイトルが2回読まれてしまうため
  - リンクのアクセシブルな名前が、テキストのタイトルになっていることを確認すること

### 2. テキスト

- **バッジ（カテゴリ）を削除する**。このセクションの記事はすべて同じカテゴリのため、情報になっていない
- **excerpt を削除する**
  - 記事データ側の excerpt は、サイト内検索で使われているため**一切触らないこと**
  - カードでの表示をやめるだけとする
- **タイトルはすべての幅で表示する**。`line-clamp-2` と `[line-break:strict]` を付ける
- **日付はタイトルの下に置く**。小さめ（`text-xs` から `text-sm`）の `text-slate-500` 程度にする
- カードの高さがそろうこと。タイトルが1行の記事と2行の記事で、日付の位置がずれて見えないように調整すること

### 3. 変えないもの

- カードの幅
- カルーセルの動き（矢印・ドラッグ・スクロールスナップ）
- リンクの範囲
- ホバーの挙動

カードの角丸が4px（サイト共通値）でない場合は、4pxにそろえてよい。その場合は変更前後の値を報告すること。

## 比率の比較（commit前に行う）

- 16:9で実装したうえで、ブラウザ上の一時的なスタイル書き換えで **2:1** にした場合も撮影すること
- 撮影対象：375px と 1440px の、FIREガイドのセクション
- 撮ったスクリーンショットを、16:9 と並べて比較できる形で提示すること
- commitするのは16:9の実装とする。比率の最終判断はKENZOがPreviewを見て行う（2:1にする場合は後で1行の変更で対応する）
