# 実装依頼：田中誠プロファイルの勤続年数を5年→13年に変更、fixture更新

## 背景

一連の退職金・iDeCo関連のバグ修正(dcYears混入修正・iDeCo年金ロック漏れ修正・短期退職手当等ルール追加)により、田中誠プロファイル(sevYrs=5)の退職金手取りが739万円→709万円まで変動する状態になっている。

調べたところ、**旧HTML版のバグ(dcYears混入)は常に`max(dcYears=13, sevYrs=5)=13`を使っていた**ため、実際の入力値がsevYrs=5であっても、これまで公開してきた数値(退職金772万円・税28万円)は実質的に「13年」ベースで計算されたものだった。

そこで、田中誠プロファイルの勤続年数(`sevYrs`)を実態に合わせて**5年→13年に変更**する。これにより、修正後の正しいロジックでも退職金側の数値が772万円/28万円(元の公開数値と一致)に戻り、短期退職手当等ルール(5年以下)の対象からも外れる。

## 実装内容

1. 田中誠プロファイルの`sevYrs`を5から13に変更する(プロファイル定義ファイル、および`reference/simulation_fixtures.md`の初期条件記載の両方)
2. 変更後、以下を実機で再計算し、`reference/simulation_fixtures.md`・`scripts/full-verify.js`のTANAKA_EXPECTED系の値を更新する
   - 退職金(手取り):772万円、退職所得税(退職金分):28万円 (想定通りの値になることを確認)
   - iDeCo一時金受取:1,494万円/110万円(変更なしのはず、確認のみ)
   - iDeCo年金受取(15年):1,707万円/433万円(前回のロック漏れ修正で確定済みの値。改めてsevYrs=13の状態でも一致することを確認)
   - 田中誠シリーズの固定利回り資産推移表(完全FIRE・セミリタイア・インフレ2%の3シナリオ、55/60/65/70/80/83/90歳)を再取得し、以前(sevYrs=5・ロック漏れバグ修正後)の値と比較。**退職金側の影響で数値が変わっている場合はその新しい値を、変わっていない場合はその旨を報告すること**
3. MC(モンテカルロ)結果も再実行し、大きな変化がないか確認(前回までの「30万円程度は許容誤差」という運用ルールに従って良い)

## 依頼の範囲

実装+fixture更新+確認。
