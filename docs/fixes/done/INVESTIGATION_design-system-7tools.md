# 調査専用指示書: 全7ツール共通デザインシステムの展開に向けた現状調査

## 位置づけ

このファイルは**調査のみ**を目的とした指示書です。実装は行わず、以下の項目を調査してKENZOに報告してください。設計判断が必要な箇所は独自に決定せず、選択肢を提示して停止してください。

## 背景

新規ツール「繰上返済vs投資比較」の見た目(細い罫線・白背景中心で境界が弱い)を改善したいという話から、これを全7ツール(`monthly-investment`/`fire-age`/`compound`/`pension-timing`/`retirement-tax`/`ideco-withdrawal`/`education-cost`/`prepay-vs-invest`)共通のデザインシステムとして展開する方針になった。

プランニングチャットで以下のデザイントークン案を作成済み(参考・確定ではない):

- **カード:** 枠線を強化(`border-slate-300`程度)、`shadow-sm`追加
- **比較表:** 列ごとの薄いティント背景(繰上返済/CTAアクセント`#334155`系、投資/グレー`#888780`系)、最重要行の強調背景
- **数字強調:** 主要数値をアクセントカラーで太字
- **アイコン:** 各行に小アイコン追加

これを実装する前に、既存7ツールのコンポーネント構造がどこまで共通化されているか、どこが各ツール独自に重複しているかを調査する必要がある。

## 調査項目

### 0. 既存カラーの網羅的な洗い出し(最優先)

上記のデザイントークン案に挙げた5色(NISA緑`#1D9E75`・iDeCo青`#0C447C`・特定青`#378ADD`・現金グレー`#888780`・CTAアクセント`#334155`)は、過去セッションの記録に基づくものであり、**現在のリポジトリを網羅的に確認した結果ではありません**。実際、`retirement-tax`ツールの「一時金」結果カードで使われている青系の枠線・背景色(スクリーンショットで確認、薄い青の枠線+背景)が、この5色のどれにも該当しないことが判明しています。

このため、実装前に以下を必ず確認してください:

- `src/components/tools/`配下の全ツールコンポーネント、および共通レイアウトコンポーネントから、使用されている色(Tailwindのカラークラス`text-blue-XXX`/`bg-blue-XXX`等、およびインラインスタイルのhex値)を`grep`等で網羅的に洗い出す
- 特に`retirement-tax`の結果カード(「一時金」等の数値強調カード)で使われている具体的な色(Tailwindクラス名 or hex値)を報告する
- 洗い出した色を一覧表にして報告し、「サイト全体で一貫した意図的な色分けなのか」「単に各ツール実装時にその場で選ばれた色なのか」を可能な範囲で判別する(gitのcommit履歴やコメントがあれば参考にする)

この結果次第で、デザイントークン案(5色のみ流用)を修正する可能性があります。

### 1. 既存の共有UIコンポーネントの有無

`src/components/`配下(特に`src/components/tools/`の外、共通レイヤーがあれば)に、カード・テーブル等の汎用UIコンポーネントが既に存在するか確認してください。具体的には:

- `Card`、`ComparisonTable`、`Panel`等の汎用コンポーネントが存在するか
- 存在する場合、7ツールのうちどれが実際に使っているか(全ツールが使っているか、一部だけか)
- 存在しない場合、各ツールが独自に(重複して)カード・テーブルのマークアップを書いているか

### 2. 各ツールの比較表・結果表示コンポーネントの構造比較

7ツールのうち、比較表形式の出力を持つツール(`pension-timing`/`retirement-tax`/`prepay-vs-invest`、他にあれば含める)について、各ツールの`XxxComparisonTable.tsx`(または相当のコンポーネント)のJSX構造・Tailwindクラスの使い方を比較し、以下を報告してください:

- 構造(テーブル行数・列数のパターン)がどこまで似ているか
- スタイリング(枠線・背景色・余白)の実装方法が各ツールでどの程度重複しているか、あるいは既に統一されているか
- 単純な出力形式のツール(`monthly-investment`/`fire-age`/`compound`等、比較表を持たないもの)は、カード自体のスタイリングがどう実装されているか

### 3. 共通化の実現可能性の評価

上記1・2の結果を踏まえ、以下2つのアプローチのどちらが現実的か、所見を報告してください(実装はしない):

- **アプローチA:** 新規に汎用共有コンポーネント(例: `src/components/ui/ComparisonTable.tsx`、`src/components/ui/ToolCard.tsx`)を作成し、7ツール全てをこれに移行する
- **アプローチB:** 共有コンポーネント化はせず、Tailwindのユーティリティクラス・カラートークンを各ツールファイルに一貫したルールで手動適用する(将来のdriftリスクは残るが、既存構造への変更は最小)

移行対象ファイル数、既存の各ツール実装がどれだけ酷似/乖離しているかを踏まえて判断材料を提示してください。

### 4. 既存カラートークンの定義場所確認

`#1D9E75`(NISA緑)・`#0C447C`(iDeCo青)・`#378ADD`(特定青)・`#888780`(現金グレー)・`#334155`(CTAアクセント)が、Tailwind設定(`tailwind.config.ts`等)でカスタムカラーとして定義済みか、それとも各コンポーネントにハードコードされているか確認してください。デザインシステム展開時にこれらを新規トークン(例: `bg-prepay-tint`等)として整理すべきかどうかの判断材料にするためです。

### 5. アイコンライブラリの使用状況確認

`@tabler/icons-react`が既存7ツールでどう使われているか(アイコン選定の一貫した方針があるか)を確認してください。前回`prepay-vs-invest`実装時に`IconScale`が「行為の性質を表す」方針で選定された経緯があるため、この方針が他ツールでも一貫しているか確認してください。
