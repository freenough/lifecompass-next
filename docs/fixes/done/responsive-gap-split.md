# 修正指示: responsive-gap-split

## 背景

タブレット幅(640〜1024px、縦積みレイアウト)で「入力を編集」ボタンと「固定モード/MCモード」の間の余白が気になっていた件。調査の結果、バグではなく、以下の要素が積み重なった素直な計算結果と判明した:

- 入力ボタン(fixed配置)の場所取り用スペーサー(33px)
- 左右パネルを包む最上位コンテナの `gap-6`(24px、1024px未満では縦方向の隙間として働く)
- ボタン自体のpadding

このうち `gap-6` は、1024px以上では左右パネル(入力パラメータ⇄KPI側)の**横方向の間隔**としても使われている、共有された値である。単純に小さくすると、PC版の左右の間隔まで一緒に狭くなってしまうため、幅ごとに値を分離する。

## 修正内容

page.tsx内の最上位コンテナ(`<div class="flex flex-col gap-6 lg:flex-row lg:items-start">`)のクラスを以下のように変更する:

- `gap-6` → `gap-2 lg:gap-6`

意図:
- 1024px未満(縦積みレイアウト): gap-2(8px)。タブレット幅での縦の隙間を詰める
- 1024px以上(横並びレイアウト): gap-6(24px)、従来通り。PC版の左右の間隔は変更しない

## 確認事項

- 768px・975px前後(タブレット幅)で、閉じた状態の余白が縮まっていることを実測・スクリーンショットで確認
- 1024px以上(PC横並びレイアウト)で、入力パラメータとKPI側の間隔が**従来通り変わっていない**ことを実測・スクリーンショットで確認(ここが変わってしまうと副作用になるため必須)
- モバイル375pxで回帰がないことを確認
- 6-A/6-B再検証結果
