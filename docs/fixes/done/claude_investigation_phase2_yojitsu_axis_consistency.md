# 調査指示：personalOnly/combined軸と資産管理ツール「個人のみ/合算」表示の整合性確認

作成日：2026-08-31

関連：`NEXT_CHAT_PROMPT_phase2_yojitsu.md`（引き継ぎ）／`claude_investigation_phase2_yojitsu_snapshot.md`（実績記録・表示機能の調査）／`claude_investigation_phase2_yojitsu_simulate_breakdown.md`（simulate()/analyze()の内訳調査）

## 背景

予実比較機能（計画保存 vs 実績）を設計する前提として、シミュレーター側の表示軸と資産管理ツール側の表示軸が同じ定義かどうかを確認する必要がある。

シミュレーター側は以下の2軸で確定している（`simulatorStore.ts`等、既存の設計原則）：
- **personalOnly**：個人口座資産（NISA/iDeCo/特定/現金）。法人からの取崩・移転効果が収入として反映された結果を含む
- **combined**：personalOnly ＋ 残存法人資産（補助バッジ的な表示）

資産管理ツール側にも「表示：個人のみ／合算」トグル（`displayScope`）が存在することは前回調査で確認済みだが、この2つの定義が**本当に同じ計算方法か**は未確認。ここがズレていると、予実比較のグラフを重ねた時点で意味のない比較になる。**このタスクは、両者の定義の一致・不一致を事実確認することのみを目的とする。推測・設計判断・実装は一切行わないこと。**

---

## 調査1：シミュレーター側 combined の「残存法人資産」の算出方法

**確認したいこと**
- シミュレーター側の`combined`表示（personalOnly＋残存法人資産）における「残存法人資産」は、どの時点のどの値を指しているか（CompanyStateの現在残高、シミュレーション実行時点の法人側予測残高、等）
- 何らかの控除（税金・個人化想定比率等）が適用された後の値か、額面通りの残高か

**対象ファイル**
- `simulatorStore.ts`（ロックファイル、読み取りのみ）
- CompanyState関連のcombined計算ロジック（`hojinCompanyState/`配下）

**報告フォーマット**
- 該当コードを抜粋し、「残存法人資産」が何を指すか一文で明記

---

## 調査2：資産管理ツール側「合算」表示の法人資産合計の算出方法

**確認したいこと**
- 「表示：個人のみ／合算」の「合算」時、法人資産合計はどう計算されているか（法人保有資産の額面合計そのままか、何らかの控除が入るか）
- 前回調査で報告された「個人化想定比率」（スクリーンショットに表示されていた設定値）は、資産推移グラフの`totalAmount`自体の計算に影響しているか、それとも別のKPI表示（「個人化想定額」等）だけに使われる別軸の値か

**対象ファイル**
- 資産管理ツール側の合算表示ロジック（`AssetManagementPage.tsx`および関連lib）

**報告フォーマット**
- 該当コードを抜粋し、「合算」時のtotalAmount計算式を明記
- 個人化想定比率が影響する範囲（totalAmount自体か、別表示のみか）を明記

## 調査3：personalOnlyと「個人のみ」表示の整合性（資産移転の扱い）

**確認したいこと**
- シミュレーター側`personalOnly`は「法人からの取崩・移転効果を収入として年次で反映した結果」を含む定義。資産管理ツール側「個人のみ」表示の実績値（`holdings`のうちowner:personalの合計）は、既に資産移転ヘルパーで法人から個人へ移転済みの分をどう扱っているか
- 具体的には：ユーザーが資産移転ヘルパーで法人から個人へ資産を移した場合、その移転額は資産管理ツール側の「個人のみ」の`holdings`合計に加算される実装になっているか（＝実績側の個人のみは、移転後の個人保有資産の実額を指しているか）

**対象ファイル**
- 資産移転ヘルパー関連のコード（前回セッションで設計・実装されたもの）
- `AssetSnapshot`のholdings構造とowner区分

**報告フォーマット**
- 資産移転が実行された場合、個人側`holdings`にどう反映されるかをコードで確認し明記
- シミュレーター側`personalOnly`の「移転効果を収入として反映」という定義と、実績側の「移転後の実額を保有資産として計上」という扱いが、同じ現象を指しているか、それとも計算のタイミングや性質が異なるか（例：計画側は将来の移転を年次収入として積算するのに対し、実績側は移転が起きた瞬間の残高スナップショットである、等の性質の違いがあれば明記）を整理する
