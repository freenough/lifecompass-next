# 実装指示書: 一人法人Hero見出しの幅修正(不自然な改行の解消)

## 背景

`/hitori-hojin` トップページのHero見出し「一人法人を、FIREの選択肢に。」が、本文(その下の説明文・「一人法人を知る」セクション等)より狭いコンテナに入っており、結果として「選択」「肢に。」という**単語の途中で改行**されてしまっている。見た目上かなり不自然。

## 差し戻し安全性の方針

- 引き続き `feature/lp-visual-refresh` ブランチ上で作業する。mainには直接pushしない。

## やること

1. Hero見出しを囲んでいるコンテナの幅(max-width)を確認し、その下に続く本文・セクション群と同じ幅になるよう広げる。
2. 幅を広げた結果の改行位置を確認する。**理想は1行に収まること。** 1行に収まらない場合でも、単語(「選択肢」等)の途中で割れないよう、意味の区切りの良い位置(例:「一人法人を、」の後、「FIREの選択肢に。」の前)で改行されるようにする。手動での改行指定(`<br>`等)を使ってもよい。
3. 資産シミュレーター側のHero見出し(「あなたのFIREは、何歳?」)の改行の扱われ方も参考にし、大きな崩れ方をしていないか一貫性を確認する。

## 検証(証跡必須)

- 修正後のスクリーンショット(PC・モバイル)を報告する。見出しが1行に収まっているか、複数行になる場合は単語の途中で割れていないことを確認する。
- モバイル幅でも同様に不自然な改行がないことを確認する。
- Vercel Preview URLを報告する。

## やってはいけないこと

- 見出しの文言自体を変更すること。
- mainへの直接push。
- 証跡なしの完了報告をしないこと。
