# 指示書:9記事目(nisa-monthly-investment)用の数値算出(改訂版)

## 背景・方針転換

前回の指示書(田中さんフィクスチャ+FIRE達成基準を目標にする案)は、目標のスケール
(全財産でのFIRE達成基準)とNISA単体の積立額の話がかみ合わず、収入の壁にぶつかる
という想定外の脱線が起きたため、方針を変更する。

**特定のキャラクター(田中さん等)は使わない。** 代わりに、既に実装済みの積立額
逆算ツール(`/asset-simulator/tools/monthly-investment`)のデフォルト例
(`MonthlyInvestmentTool.tsx`の`DEFAULT_VALUES`)をそのまま記事の題材にする。

- 現在35歳→目標達成年齢55歳(20年間)
- 現在資産100万円→目標資産3,000万円
- 想定利回り5%(基準ケース)

この方針により、「記事で見た数字が、そのままツールで再現できる」という一貫性が
生まれ、CTAへの導線も自然になる。

## 数値の出所についての整理(重要)

- **利回り別の必要積立額(下記1)** は、`financeCore.ts`の`calcRequiredMonthlyContribution()`
  を実際に呼び出して算出する。これは「ツール自体の実出力」であり、コンテンツルール
  (独自の手計算・再実装スクリプト禁止)には抵触しない(このツール自体が本番稼働中の
  製品機能であるため)
- **モンテカルロでの目標到達率(下記2)** は、`financeCore.ts`には市場変動を扱う機能が
  ないため、**本番の`runMC()`を直接呼び出して算出する**こと。ここは`financeCore.ts`
  では代替できない

---

## 1. 利回り別の必要積立額(3%/5%/7%)

`src/lib/financeCore.ts`の`calcRequiredMonthlyContribution()`を、以下の共通条件で
呼び出し、3パターンの結果を報告すること:

```
currentAssets = 100
targetAssets = 3000
years = 20  // 55 - 35
```

- `annualRatePct`を3・5・7と変えて、それぞれの結果(必要月額積立額)を報告する
- 計算はスクリプトから直接importして呼び出すこと(手計算・別途の複利式の
  再実装は禁止)

## 2. モンテカルロでの目標到達率(想定利回り5%のケース)

1で求めた「年率5%時の必要積立額」を使い、本番の`runMC()`(1,000試行)を実行し、
20年後(現在35歳→55歳時点)に目標資産3,000万円に到達できた試行の割合を算出する。

### 2-1. プロファイル設計

`scripts/verify-finance-core.js`の`buildDummyProfileForVerification()`と同様に、
NISA単体・他ロジックが発火しない条件で組み立てること。ただし、**今回は市場変動
そのものを見たいので、`mcStd`/`mcStdR`は0にせず、実際のボラティリティを設定する
こと**(検証スクリプトでは意図的に0にしていたが、今回はその逆)。

- `curAge = 35`, `retAge`は十分先(例:`curAge + years + 50`)に設定し、20年間は
  積立期のまま推移するようにする
- `acct.nisa.bal = 100`, `acct.nisa.con = (1で求めた5%時の年間積立額)`,
  `acct.nisa.rW = 5`
- `mcStd`/`mcStdR`(ボラティリティ):**新規に数値を考案しないこと。** 既存の
  `SIGMA-AUTO`機能やmethodologyページ、または他の記事・フィクスチャで既に
  使われている「一般的な株式インデックスを想定したボラティリティ」の値を
  探して、それをそのまま使うこと。見つからない場合は、その旨を報告し、
  KENZOに数値を確認すること(新規に考案した値を使わない)
- iDeCo・退職金・年金・配偶者・イベントは無効化(検証スクリプトと同様の
  ダミー設定)

### 2-2. 報告してほしい数値

- 1,000試行中、20年後に資産3,000万円以上を維持できた試行の割合(%)
- 参考として、資産の分布(中央値・25パーセンタイル・75パーセンタイル程度)も
  出せれば記事の資産推移グラフに使えるため、あわせて報告してほしい(必須ではない)

もし追加で実施可能であれば、1で求めた「年率5%時の必要積立額」を固定した上で、

## 報告フォーマット

- 1の結果(3%/5%/7%それぞれの必要積立額)
- 2の結果(モンテカルロでの到達率、使用したボラティリティの値とその出所)
- (あれば)3の資産推移データ
- **算出方法の明記**:`financeCore.ts`経由か、本番`runMC()`経由かを、数値ごとに
  明記すること
- 使用したスクリプトの内容も貼ること(独自の財務計算式を含んでいないか、
  こちらでも確認したいため)
