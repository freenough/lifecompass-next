# 指示書: GA4を本番ドメインでだけ読み込むようにする（両リポジトリ）

## 種別

実装指示。前回の調査報告（GA4・FIREガイド調査のA）と、KENZOの判断に基づく。

## 対象

- `lifecompass-next`
- `freenough-main`

**両方に同じ方針で入れること**（同じ測定IDを使っているため、片方だけでは効果がない）。各リポジトリで `main` から `feature/ga-production-only` を作成して作業すること。

## 方針

### GA4（gtag）

次の**両方を満たすときだけ**読み込む。

1. `NEXT_PUBLIC_VERCEL_ENV === 'production'`（ビルド時に判定。ローカル・Previewを除外する）
2. ブラウザの `window.location.hostname` が、本番ドメインの許可リストに含まれる（`freenough-lifecompass.vercel.app` などのVercelドメインから直接開いた場合を除外する）

- 許可リストは定数として1か所にまとめること（例：`ANALYTICS_ALLOWED_HOSTS`）
- 中身は、実際に読者がアクセスする本番ドメインにすること（例：`www.freenough.com`、必要なら `freenough.com`）
  - `NEXT_PUBLIC_SITE_URL`・canonical・`freenough-main` のリライト設定などから、**実際に配信されているホスト名を確認して決めること**
  - 判断がつかない場合は、実装を止めて報告すること
- ホスト名の判定はクライアント側で行うため、GA4のスクリプトはクライアントコンポーネントの中で、判定を通過したときだけ出力する形にすること（例：`AnalyticsScripts`）
- 測定IDの直書きは、定数1か所にまとめる程度の整理にとどめてよい（環境変数化は今回は不要）
- `trackEvent` は、`window.gtag` がないときに何もせず終わる現在の挙動のままでよい。変更しないこと

### AdSense

- **`NEXT_PUBLIC_VERCEL_ENV === 'production'` のときだけ読み込む**（ホスト名の判定は入れない）
- 審査への影響を避けるため、これまでどおり**サーバーが返すHTMLにスクリプトが含まれる**形を維持すること（クライアント側で後から差し込む形にしない）
- `google-adsense-account` などの確認用 `<meta>` や `ads.txt` がある場合は、**条件を付けず、常に出力したまま**にすること。現状どうなっているかを報告すること

## 検証（GA4・AdSenseへの通信は、Playwrightで遮断したうえで「リクエストが発生しようとしたか」で判定すること）

以下のそれぞれで、`gtag/js`・GA4への送信・`adsbygoogle.js` のリクエストが発生しようとしたかを記録し、表にまとめること。

| ケース | 作り方 | 期待：GA4 | 期待：AdSense |
|---|---|---|---|
| ① ローカル dev | `next dev` | 出ない | 出ない |
| ② 本番ビルド・localhostで表示 | `NEXT_PUBLIC_VERCEL_ENV=production` で build → start し、`localhost` で開く | 出ない | 出る |
| ③ 本番ビルド・本番ドメインとして表示 | ②と同じサーバーを、Chromiumの `--host-resolver-rules` 等で本番ドメイン名に向けて開く | 出る | 出る |
| ④ 環境変数なしのビルド | `NEXT_PUBLIC_VERCEL_ENV` なしで build → start | 出ない | 出ない |

- ③の確認方法が環境の都合でできない場合は、代わりの方法と、その理由を報告すること
- 両リポジトリで、上の4ケースを確認すること
- サーバーが返すHTML（`curl` 等で取得）に、ケース②③でAdSenseのスクリプトタグが含まれていることを示すこと
- `trackEvent` が呼ばれるUI操作（例：ブログ一覧のフィルター）をケース①で行い、エラーが出ないことを確認すること
- `npm run build` と `tsc --noEmit` がエラーなしで通ること。書き換わった `tsconfig.tsbuildinfo` は元に戻すこと

## 本番反映後の確認（マージ後に行う）

マージ・本番デプロイの後に、次のそれぞれでGA4のリクエストが「発生しようとしたか」を確認し、報告すること（通信は遮断したまま）。

- 本番ドメイン：発生する
- `freenough-lifecompass.vercel.app`：発生しない

## コミット

## 安全ルール（必ず守ること）

- 検証中は、GA4・AdSenseへの通信を必ず遮断すること
- `localStorage.clear()` などの破壊的操作は行わないこと
- devサーバーを停止するときは、ポートからPIDを特定し、そのPIDだけを個別に停止すること。`taskkill /F /IM node.exe` は**使用禁止**
- `docs/fixes/active/` フォルダ自体は削除しないこと
