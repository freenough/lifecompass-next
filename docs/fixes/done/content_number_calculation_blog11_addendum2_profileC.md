# 数値算出指示書 追記2:プロファイルC追加(要因分解用)

対象:`content_number_calculation_blog11.md`のH2-5、要因分解のための
プロファイルC追加算出

---

## 背景

現状のA(65歳受給・トグルOFF) vs B(60歳受給・トグルON)の比較だけでは、
Bが優位な理由が「繰上げ受給の効果」なのか「黒字運用の効果」なのか、
両方が混ざっていて分解できない。これを切り分けるため、プロファイルC
(65歳受給・トグルON)を追加する。

## プロファイルC(新規追加)

- 年金受給開始:65歳
- 年金受給額:198万円/年(基礎78万+厚生120万、`penAmtVal`欄)
- 退職後収支黒字運用トグル:**ON**
- その他条件はA・Bと完全に同一(単身・退職年齢60歳・生活費120万円/年・
  特定口座初期残高3,000万円のみ・想定利回り年4%[NISA・iDeCo・特定口座
  すべて、積立期・取崩期共通]・MCオフの決定論的パス)

## 算出・報告する項目

1. Cの60〜90歳の年次総資産推移(グラフ用CSV形式。A・Bと同じ形式で、
   年齢,A,B,Cの4列にまとめて提供すること)
2. Cの90歳時点総資産額
3. **要因分解**:
   - A(65歳・OFF) vs C(65歳・ON)の90歳時点差額 → 「黒字運用のみ」の効果
   - B(60歳・ON) vs C(65歳・ON)の90歳時点差額 → 「繰上げタイミングのみ」の効果
   - 参考として、A vs Bの差額(前回報告済み:+873万円)が、上記2つの効果の
     単純合計とどの程度一致するか(非線形性がある場合はその旨も報告)
4. Cについても、60〜64歳の年金未受給期間に取り崩しが発生しているか
   (Aと同様に発生するはずだが、念のため確認)
5. Cについて黒字が発生する年齢範囲(Bの60〜71歳と同様の情報。Cは65歳受給
   のため、黒字開始年齢はBと異なるはずなので確認すること)

## 算出方法

`simulate()`/`analyze()`を直接importして算出すること。独自の再実装・
手計算は一切行わないこと。既存の`scripts/blog11-pension-timing-numbers.js`
にプロファイルCを追加する形で対応してよい。

実装は行わない。数値算出・報告のみ。
