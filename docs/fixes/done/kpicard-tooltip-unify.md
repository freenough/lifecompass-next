# 修正指示: kpicard-tooltip-unify

## 症状

iPhone SE(375px)で、KPIカード(資産寿命・FIRE達成・初年度取崩率など)の「?」ボタンをタップすると出る吹き出しの、左端の文字が数文字切れて見える(例:「退職初年度の実質引出額」→「初年度の実質引出額」のように先頭が欠ける)。

## 背景

以前の`lp-hero-responsive-issues`対応時の報告で、以下が明記されている:

> KpiCard.tsxは独自の別実装のツールチップ(right-0で右端アンカー済み)を持っており、今回の共有化対象には含めていません

つまりKpiCard.tsxの「?」ツールチップは、MC設定等で使っている共有コンポーネント`InfoTooltip.tsx`(Portal化・横縦両方向の画面外クランプ機能を実装済み)とは**別の独自実装**で、常に右端(right-0)基準で開く簡易な仕組みのまま。狭い画面で左寄りのカードの吹き出しが開くと、右端基準のまま位置がずれ、左側が画面外にはみ出して欠ける。

## 修正方針

KpiCard.tsx独自のツールチップ実装を廃止し、`InfoTooltip.tsx`(共有コンポーネント)に置き換えて統一する。

1. KpiCard.tsx内の独自ツールチップ(right-0アンカー等)を特定する
2. 同じ見た目・同じ挙動になるよう`InfoTooltip.tsx`に置き換える(表示するテキスト内容は変更しない)
3. 置き換えにより、KpiCard.tsxが使われている両方の画面(シミュレーター本体のKpiGrid、LPのHeroDemo)双方に効果が及ぶことを認識した上で、両方で確認する

## 確認事項

- iPhone SE相当(375px)で、KPIカードの吹き出しが画面内に収まり、文字が欠けないことを実測・スクリーンショットで確認(特に画面左寄りのカードと右寄りのカード両方で確認すること)
- 320px幅でも同様に確認
- MC設定等、既存のInfoTooltip利用箇所に回帰がないことを確認
- シミュレーター本体・LPヒーロー双方のKPIカードで、吹き出し以外の見た目(カード本体のレイアウト)に変化がないことを確認
- 6-A/6-B再検証結果
