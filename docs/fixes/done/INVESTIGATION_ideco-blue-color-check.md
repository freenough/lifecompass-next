# 調査専用指示書: iDeCo出口戦略ツールの薄いブルー配色の確認

## 位置づけ

このファイルは**調査のみ**を目的とした指示書です。実装は行わず、以下を確認して報告してください。

## 背景

`prepay-vs-invest`ツールのメイン数値強調に、`ideco-withdrawal`(iDeCo出口戦略シミュレーター)の選択カードで使われている薄いブルーを流用したい。プランニングチャットでのモックアップでは、Tailwindデフォルトの`bg-blue-50`(#EFF6FF)+`text-blue-800`(#0C447C相当)を暫定的に使ったが、これは前回調査報告の「border-accent bg-blue-50」という記述からの推測であり、実際の正確な値を確認できていない。

## 調査項目

`IdecoWithdrawalResult.tsx`(または該当する選択カードコンポーネント、`一時金/年金/併用`選択カード)を確認し、以下を報告してください:

1. **背景色:** 選択状態の背景に使われているクラス名(`bg-blue-50`等)と、それが指す実際の値(Tailwindデフォルトのままか、`globals.css`の`@theme`でカスタムオーバーライドされているか)
2. **枠線色:** `border-accent`が指す実際の値(既に`--color-accent: #334155`と判明済みのはずだが念のため確認)
3. **数値のテキスト色:** カード内の数値・強調テキストに使われている色クラス(存在すれば)
4. **同じ薄いブルーが他のツールでも使われていないか:** `grep`で`bg-blue-50`の全出現箇所を確認し、使用ツール一覧を報告

## 報告フォーマット

該当コードを引用しつつ、上記4項目に回答してください。
