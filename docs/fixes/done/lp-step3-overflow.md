# 修正指示: lp-step3-overflow

## 症状

LPページ下部の「3ステップ紹介」セクション内、「Step 3 FIRE年齢・資産寿命を確認」のli要素が、640px幅でページ幅から約13pxはみ出している(横スクロールが発生する)。

前回のlp-hero-responsive-issues対応時に、作業範囲外の箇所として発見・報告されたもの。

## 調査手順

1. 640px幅で該当のliを含む3ステップ紹介セクションのDOM構造を確認する
2. どの要素が13pxオーバーしているか、DevToolsのscrollWidth/clientWidth比較で特定する
3. 原因(固定幅のテキストが折り返さない、アイコン+テキストのgapが要因、padding計算等)を報告する

## 修正方針

- 原因箇所を特定した上で、640px幅ではみ出しが発生しないよう修正する(テキストの折り返しを許容する、幅指定を可変にする等、原因に応じて対応する)
- 他のStep(Step 1, Step 2)や他の幅で見た目が崩れないことを確認する

## 確認事項

- 640px幅で横スクロールが発生しないことを実測(scrollWidth === clientWidth)で確認
- モバイル375px・PC幅で3ステップ紹介セクションの見た目に回帰がないことをスクリーンショットで確認

## 完了後

このファイルを docs/fixes/done/ へ移動すること。
