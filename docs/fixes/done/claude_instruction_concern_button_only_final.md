## やること：カードの枠線・背景は一切変更せず、ボタンにのみ背景色をのせる

`ConcernCard.tsx`（お悩みカード）について：

1. **カードの枠線（`border`関連のクラス・プロパティ）は一切変更しない**。太さ・色ともに、`main`の現在のコードのままにすること
2. **カード自体の背景色も一切変更しない**（`main`の現在のコードのままにすること。白であれば白のまま）
3. **ボタン（「60秒で試算する」「詳しく試算する」）にのみ、背景色をのせる**。のせる色は、`concerns`関連の実装で以前使用した`bg-sub`（globals.css定義済みの薄いグレー背景トークン）を使うこと
   - `bg-sub`が既にプロジェクト内のどこかで定義・使用されているか確認し、あればそれをそのまま再利用する（新しい色を追加で定義しない）
   - もし`main`の現在のコードにこのトークンが存在しない、または見当たらない場合は、作業を止めて「`bg-sub`相当のトークンが見当たらない」旨を報告すること（推測で新しい色を作らないこと）
4. ボタンの文字色は`--color-accent`（#334155）、枠線は既存の`border`トークンを使う（ボタン自体にうっすら枠を付ける場合）。ボタンがホバー時だけでなく常時visibleな状態で、カードの白背景の上ではっきり見分けられることを確認する

**diffとして正しい状態**：`ConcernCard.tsx`内で変更されるのは、ボタン要素の`className`（背景色を追加する部分）のみ。カードのルート要素の`className`（背景色・枠線を含む）には一切差分が出ないこと。
