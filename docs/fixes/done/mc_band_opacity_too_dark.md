# MCモード:p10〜p90帯の不透明度が濃すぎる/課税優先の線が帯に同化する問題を改善する

## 背景・問題

前回、基準戦略に応じて帯(p10〜p90)の色を`STRATEGY_STYLE`の色に連動させる対応を行った際、彩度の低いグレー(課税優先)は薄く見えやすいという判断から`fillOpacity`を他より高め(0.5)に設定した。

実装後の3パターン(比例取崩/現金優先/課税優先それぞれ基準)のスクリーンショットを確認したところ、以下の問題が見つかった。

1. **課税優先基準時**:帯の色(グレー `#94a3b8`, opacity 0.5)が濃く、グラフ全体が曇って見える。さらに、帯の中を通る「課税優先」の中央値線(グレードット `STRATEGY_STYLE`)が帯の色とほぼ同化し、ほとんど視認できなくなっている。これは基準戦略の線を目立たせるという当初の目的(基準戦略ハイライト対応)と矛盾する状態
2. **比例取崩・現金優先基準時**:opacity 0.35〜0.4だが、帯はグラフの大部分を占める面積の広い要素のため、数値以上に「濃い」「主張が強い」印象を与えている。KPIカード等の他のUI要素(淡い緑・黄色)と比べても彩度・明度のコントラストが強すぎる

## 調査してほしいこと

1. `src/components/simulator/AssetChart.tsx` 内の `BAND_FILL_OPACITY` の定義箇所(前回実装分)を確認する
2. 課税優先の中央値線(`STRATEGY_STYLE`のグレードット、dasharray "2 3")の色コード・太さ・不透明度を確認し、帯の色(グレー)とどの程度近いか比較する

## 実装したい変更

### 1. 帯の不透明度を全体的に下げる

現在の値(比例取崩0.35 / 現金優先0.4 / 課税優先0.5)を、目安として全体的に半分程度(比例取崩0.15 / 現金優先0.18 / 課税優先0.2程度)まで下げる。数値は目安なので、実際にレンダリングして「帯は背景として存在は分かるが、その上の線がはっきり主役として見える」状態になるよう調整すること。課税優先だけ他よりわずかに高めというバランス自体は維持してよいが、絶対値としては大きく下げる。

### 2. 課税優先の線と帯の同化を解消する

不透明度を下げれば大部分は解消される見込みだが、それでも線が視認しにくい場合は以下を検討する。

- 課税優先の中央値線の太さを基準時(3px)でさらに強調する、または線の色を帯の色よりわずかに濃く/暗くする(例:帯は`#94a3b8`のままでも、線は`#64748b`のようにワントーン暗くする)
- 線に薄い縁取り(ストローク)や、SVGの`paint-order`を使った視認性向上策があれば検討してよい(実装コストが高くなる場合は不要)

### 3. 色相自体は変更しない

引き続き、比例取崩=青系、現金優先=水色系、課税優先=グレー系という色相の対応関係は維持すること。今回はあくまで「濃度」の調整であり、配色の枠組みは変えない。

## 動作確認したいポイント

- 3戦略それぞれを基準にした状態で、帯が「背景として存在は分かるが主張しすぎない」濃さになっていること
- 課税優先基準時に、課税優先の中央値線(グレードット)が帯からはっきり判別できること
- 3戦略同時表示時、KPIカードなど他のUI要素と並べても違和感のない落ち着いた印象になっていること
- モバイル幅でも同様に確認すること
