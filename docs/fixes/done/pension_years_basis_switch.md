# 実装：「年金開始までの年数」の基準切り替え(退職済みユーザー対応)

## 背景

詳細アコーディオンの「年金開始までの年数」は、現在`penAge - retAge`(退職年齢基準)で固定計算している。既に退職済み(`curAge ≥ retAge`)のユーザーにとっては、この数字は「もう過ぎた退職年齢」を基準にしたもので、実際に知りたい「あと何年で年金がもらえるか」とズレる。

## 確定仕様(3分岐)

| 状態 | 条件 | 計算式 |
|---|---|---|
| まだ退職前 | `curAge < retAge` | `penAge - retAge`(現状のまま) |
| 退職済みだが年金はまだ | `retAge ≤ curAge < penAge` | `penAge - curAge`に切り替え |
| 年金も既に受給中 | `curAge ≥ penAge` | 数値ではなく「受給中」と表示(マイナスの年数を出さない) |

## 実行内容

1. 該当のKPI計算箇所(詳細アコーディオンの「年金開始までの年数」)を、上記3分岐のロジックに変更する
2. 計算はKPIカード表示コンポーネント側(またはそれに準ずる箇所)で行い、`analyze.ts`・`simulate.ts`は変更しないこと(この値は`curAge`・`retAge`・`penAge`という入力値だけで計算できるため、コア計算ロジックに変更は不要なはず)
3. 「受給中」表示時は、既存の他のKPIカードの「該当なし」的表示(例:MC破綻確率カードの「—」等)のスタイルに準じること
4. ガイドページ(`/guide`)の「年金開始までの年数」の説明があれば、この3分岐について簡潔に追記すること(前回セッションで新規追加した説明文があるはずなので、そこに追記する形でよい)

## 検証

- 田中誠プロファイル(現状`curAge=44 < retAge=55`程度、まだ退職前)で、既存表示(現状のまま)と変わらないことを確認
- `curAge`を`retAge`以上、`penAge`未満に仮に変更した場合の表示を確認(`penAge - curAge`になっているか)
- `curAge`を`penAge`以上に仮に変更した場合、「受給中」と表示され、マイナスの年数が出ないことを確認
