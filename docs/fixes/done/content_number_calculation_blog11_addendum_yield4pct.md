# 数値算出指示書 追記:利回り前提の修正(4%への変更)

対象:`content_number_calculation_blog11.md`のH2-5(比較グラフ)の再計算

---

## 背景

前回の算出結果で、特定口座の取崩期期待リターン(`rRTax`)が1%になっていた。
利回りはシステム全体で固定されているのではなく、ユーザーが画面上で入力
する仕様であることを確認した。1%という値がどこから来たのか(デフォルト
プロファイルの設定値なのか、別の理由か)を確認した上で、記事用の想定利回り
を明示的に4%に指定して再計算すること。

## 確認事項

- なぜ前回の算出で`rRTax=1%`(および関連する`rWTax`等)になったのかを報告する
  (使用したプロファイル・関数のデフォルト値の出どころを specifics に)

## 再計算条件(確定)

- **想定利回り:NISA・iDeCo・特定口座すべて年4%(積立期・取崩期共通)**に
  明示的に設定する
- 標準偏差(σ)・MC設定については、H2-5は引き続きMCオフ(決定論的パス)の
  ため影響しない。念のため、この4%指定がMCオフの決定論的計算に正しく
  反映されることを確認すること
- その他の条件(単身・退職年齢60歳・生活費120万円/年・特定口座初期残高
  3,000万円のみ)は変更なし
- プロファイルA(65歳受給・198万円・トグルOFF)・プロファイルB(60歳受給・
  150万円・トグルON)の構成も変更なし

## 記事への反映方針(確認のみ・作業不要)

想定利回り4%は、本体シミュレーターの一律デフォルト値ではなく、この記事の
検証のために明示的に設定した前提条件であることを、記事本文(H2-5)に
明記する。生活費120万円・初期資産3,000万円と同様、「便宜的に設定した
前提条件」として扱う。

## 再計算して報告する項目

- H2-5:プロファイルA・Bの90歳時点総資産・差額(±◯◯万円、±◯◯%)
- 60〜90歳の年次総資産推移(グラフ用CSV形式)
- A・Bの逆転が発生する年齢(発生する場合)
- プロファイルAの60〜64歳(年金未受給期間)の取り崩し発生有無(参考情報)

H2-3(年金タイミングツール側の数値、pensionCore経由)は利回りと無関係の
ため再計算不要。

実装は行わない。数値算出・報告のみ。
