# 調査専用指示書：個人シミュレーター本体への法人イベント注入ポイントの調査

作成日：2026-08-20

---

## 1. 背景・目的

一人法人ユーザー向けに、「個人＋法人 統合シミュレーション」を、**既存の個人シミュレーター本体（フル機能：固定計算・MC・インパクト比較・シナリオ比較を含む）**でそのまま利用できるようにしたい。

これを実現するには、法人側（`hojinCompanyState`）で計算した「法人からの取崩額を税引き後に変換した年次収入」を、個人シミュレーターが`simulate()`を呼び出す際に、ユーザーが本来入力した`profile.events`と**マージした状態で**渡す必要がある。

この処理は現状、`simulatorStore.ts`（ロック対象ファイル）の内部で完結していると想定される。本調査の目的は、**この一点にだけ、最小限の「外部からイベントを注入できる差し込み口」を追加することが現実的かどうか**を判断するための事実確認である。

**重要**：この調査は「差し込み口を追加してよいかどうか」の実装可否判断のための事前調査であり、実装の可否自体・実装するかどうかはこのチャットで判断する。調査結果を見て、①最小限の拡張で対応する、②別画面で機能を絞って複製する、③法人側だけ独立エンジンを複製する、のいずれかを選ぶ。

---

## 2. 絶対にやってはいけないこと

- **実装・修正は一切行わないこと**。本指示書は調査専用。`simulatorStore.ts`を含め、いかなるファイルも変更しないこと
- ロックファイル（`simulate.ts`/`analyze.ts`/`types.ts`/`profile.ts`/`PortfolioPanel.tsx`/`simulatorStore.ts`/`blog.ts`/`blogTopics.ts`/`concerns.ts`）は**読むだけ**
- 独自に再実装したスクリプトで検証しないこと。既存のコードを読んで報告すること
- 「こう実装すべき」という提案・推奨は書かないこと。事実の報告に徹すること（実装方針はこのチャットで判断する）

---

## 3. 調査対象・確認事項

### 3.1 `simulatorStore.ts`が`simulate()`を呼び出す箇所の特定

1. `simulatorStore.ts`内で`simulate()`（および`analyze()`）を呼び出している箇所を全て特定し、該当行を引用しながら報告する（固定計算モード・MCモードの両方、呼び出し箇所が複数ある場合は全て）
2. `simulate()`の第2引数（`LifeEvent[]`）に渡されている値が、どの状態（store内のどのフィールド）から来ているか、生成・変換の経路を追跡して報告する
3. `profile.events`（ユーザー入力のイベント一覧）から、`simulate()`に渡す直前の配列までの間に、何らかの変換・フィルタリング処理が存在するか確認する（あれば内容を報告）

### 3.2 最小拡張ポイントの技術的実現可能性

1. Zustandストアの設計として、`simulate()`呼び出し部分の直前に「外部から追加イベント配列を受け取り、`profile.events`とマージしてから`simulate()`に渡す」という差し込み口を作る場合、変更が必要になる箇所（関数・行数）を具体的に列挙する。実装イメージの提示ではなく、**「触れる必要がある既存コードの範囲」を事実として報告すること**
2. この差し込み口となる値（追加イベント配列）を、ストアの外部（法人側のReactコンポーネントやフック）からどう渡せるか、既存のZustandストアのAPI設計（他のsetter関数の実装パターン等）を踏まえて、技術的に可能な受け渡し方法の選択肢を列挙する（推奨は不要、選択肢の列挙のみ）
3. MCモード（モンテカルロ実行）と固定計算モードの両方で、この差し込み口が同じように機能するか、それとも一方にしか適用できない構造上の制約があるか確認する
4. インパクト比較機能・シナリオ比較機能が、`simulate()`を複数回（改善案ごと、シナリオごとに）呼び出している場合、追加イベント配列は毎回同じものが使われるべきだが、この点で技術的な障害がないか確認する

### 3.3 変更規模の見積もり

1. 3.2で洗い出した変更箇所について、**行数ベースでの変更規模**（新規追加◯行、既存コード変更◯行、というレベル感）を報告する
2. `full-verify.js`の既存テストケースのうち、`simulatorStore.ts`の変更によって影響を受ける可能性があるものがあれば、件数の目安を報告する
