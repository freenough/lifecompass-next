# 実装指示書: デザインシステム第3弾(多列レイアウトの数値サイズ調整)

## 位置づけ

前回の指示書(`IMPLEMENTATION_design-system-phase2.md`)の「1.5 多列レイアウトの数値サイズ調整」が、完了報告で一切触れられておらず未対応のまま残っています。この項目のみを切り出して再指示します。

## 背景

`compound`・`monthly-investment`・`fire-age`・`pension-timing`・`retirement-tax`の主役数値に青い強調ボックス(`border-accent bg-blue-50`)を適用したところ、単一結果型の数値は`text-4xl sm:text-5xl`という大きなフォントで表示されています。一方、`ideco-withdrawal`(3列カード)は`text-lg sm:text-xl`と大幅に小さく、青ボックスの強調に対して数字が小さすぎ、アンバランスに見える懸念があります。`education-cost`(教育費総額カード、2列)についても、青ボックス自体は既に適用済みですが、フォントサイズの妥当性が未確認のままです。

## 実施内容

### 1. `IdecoWithdrawalResult.tsx`(3列カード)のフォントサイズ引き上げ

現状`text-lg sm:text-xl font-bold`となっている数値サイズを、1〜2段階引き上げてください(目安: `text-xl sm:text-2xl`程度)。

**実機確認必須:** 3列を横並びにするレイアウトのため、引き上げた結果テキストが折り返す・カードからはみ出す等の崩れが起きないか、実際のブラウザで確認すること。数値の桁数(万円単位で4桁になりうる、例: 1,935万円)を考慮すること。崩れが発生する場合は、無理に指定サイズまで引き上げず、崩れない範囲の現実的なサイズに調整し、その判断と理由を完了報告に含めること。

### 2. `EducationCostResult.tsx`(2列カード)のフォントサイズ確認・調整

「教育費総額」「ピーク時の年間負担額」カードの現状のフォントサイズクラスを確認し、完了報告に明記した上で、単一結果型ツール(`text-4xl sm:text-5xl`)に近づける方向で1〜2段階引き上げてください。`ideco-withdrawal`ほど列数が多くない(2列)ため、より大きくできる余地があります。

**実機確認必須:** 2カード分の横幅に収まることを確認すること。崩れる場合は同様に現実的なサイズに調整すること。

## 判断基準

「青い強調ボックス」の視覚的な強さと、数字自体の大きさが釣り合っている状態を目指します。列数による物理的な制約(横幅)は尊重しつつ、可能な範囲で単一結果型ツールとの見た目の差を縮めてください。
