# LifeCompass NISA・iDeCo制度上限の入力警告 確認・実装 指示書

## 背景

レガシー版(`STEP29〜35_simulator.html`)には、NISA・iDeCoの積立額入力時に、
制度上の上限を超えていないかをチェックし、超えている場合に入力欄の
ハイライト表示とトースト通知で警告する機能があった。この機能が
現在のNext.js版の入力フォームに移植されているか不明なため、
まず確認し、実装されていなければ追加する。

**注意**:これは計算結果(`simulate.ts`)を変える機能ではなく、
**入力フォーム側のバリデーション(警告表示のみ、計算のブロックはしない)**である。
警告が出ていても、ユーザーが入力した値はそのままシミュレーションに使われる。

## レガシー版の仕様(参考実装)

`STEP35_simulator.html` には、NISA・iDeCoに関する3つの警告機能があったが、
精査の結果、**数値による閾値判定として実装するのはiDeCo年間上限・NISA年間上限の
2つのみ**とする。NISA生涯枠については、後述の理由により数値判定を行わず、
注意書きのみとする。

**表示形式について**:旧版ではNISA年間上限のみ赤ハイライト、
iDeCoは黄ハイライトと、警告の強さに差があった。
しかし今回の実装はどちらも「計算をブロックしない、あくまで入力時の
目安表示」という同じ性質のものであるため、**色による強弱をつけず、
2つとも同じ形式(黄色ハイライト+トースト警告)に統一する**こと。
以下の閾値・判定式・文言の趣旨はレガシー版のまま踏襲するが、
色(赤/黄)の区別は踏襲しないこと。

### 1. iDeCo年間積立上限(2601〜2615行目付近、`validateIdecoInput`関数)

```
IDECO_ANNUAL_MAX = 27.6万円/年(会社員の上限。月2.3万円)

if (iDeCo年間積立額 > 27.6) {
  入力欄を黄色ハイライト
  トースト表示:「⚠ iDeCo年間積立 {入力額}万円は会社員の場合の上限27.6万円を
  超えています(自営業の場合は上限が異なります)」
}
```

### 2. NISA年間積立上限(4435〜4462行目、`checkNisaLimits`関数)

```
NISA_ANNUAL_MAX = 360万円/年(成長投資枠240万+つみたて120万)

if (NISA年間積立額 > 360) {
  入力欄を黄色ハイライト
  トースト表示:「⚠ NISA年間積立 {入力額}万円は年間上限360万円を超えています」
  (この場合、下記3のチェックは行わずreturnする)
}
```

### 3. NISA生涯枠上限について(数値判定は行わない・注意書きのみ)

**旧版のロジックは不採用とする。** 旧版は「今後の積立見込み額
(積立額×残り年数)のみ」で1,800万円を超えるか判定していたが、
これは既存の残高(=含み益込みの時価)を一切考慮しない不正確なロジックである。

かといって「現在の残高+今後の積立見込み」で判定する案も採用しない。
理由は、NISAの残高は含み益込みの時価であり、生涯枠1,800万円の判定基準
となる投資元本(簿価)とは異なるため。本シミュレーターはNISAの簿価
(投資元本)を追跡するデータ構造を持っていない
(`types.ts`の`AccountConfig`に`costBasis`相当の項目がない。
特定口座の`TaxAccountConfig`のみ`costBasis`を持つ)。
簿価を追跡しない限り、生涯枠の残り枠を正確に判定することは
原理的にできないため、無理に数値判定を行わない。

**対応**:数値による超過判定・警告は行わず、NISAの積立額入力欄の近くに、
制度の存在を伝える注意書きを常時表示する(?マークのポップオーバー、
または入力欄下の小さな注記等、既存のUIパターンに合わせてよい)。

**注意書きの文言(案)**:
> NISAには生涯非課税投資枠1,800万円の上限があります。本シミュレーターは投資元本(簿価)を追跡していないため、この上限に近づいているかどうかの自動チェックは行いません。ご自身の利用状況は証券会社のマイページ等でご確認ください。

## 対応内容

1. Next.js版の入力フォーム(NISA・iDeCoの積立額入力欄があるコンポーネント。
   おそらく「資産」カテゴリの「保有資産」ブロック)に、iDeCo年間上限・
   NISA年間上限の数値チェック、およびNISA生涯枠の注意書きが
   実装されているか確認する
2. 実装されていない場合、上記の仕様通りに追加する。警告表示の実装方法
   (トースト通知・インライン警告文など)は、既存のUIコンポーネント
   (?マークのポップオーバーや、既存のトースト通知があればそれ)に
   合わせて自然な形で実装してよい。レガシー版と全く同じUI(トースト)で
   ある必要はないが、**警告の発生条件・閾値・文言の趣旨は一致させ、
   数値チェック2つの入力欄のハイライト色は黄色で統一する**こと
   (赤ハイライトは使わない)
3. 既に同等の実装がある場合は、そのままでよい(重複実装しない)
4. これらは**入力時の警告・注意書きのみ**であり、計算結果(`simulate.ts`)や
   保存されるデータには一切影響しないこと

## methodologyページの更新

`page.tsx`の「資産運用モデル」セクション、または「税金の扱い」セクションに、
NISA・iDeCoの制度上限警告に関する説明を追加する。追加位置は既存の
セクション構成に合わせて自然な箇所でよい。

**追加する文言(案)**:

> NISA・iDeCoにはそれぞれ制度上の拠出・投資上限があります。本シミュレーターでは、NISAの年間積立が360万円(成長投資枠240万円+つみたて投資枠120万円)を超える場合、およびiDeCoの年間積立が会社員の一般的な上限(27.6万円、自営業等は上限が異なります)を超える場合に、入力欄で警告を表示します。いずれも入力時の目安表示であり、計算上は入力された値がそのまま使用されます。なお、NISAには生涯非課税投資枠1,800万円の上限もありますが、本シミュレーターは投資元本(簿価)を追跡していないため、この上限に対する自動チェックは行っていません。実際の上限・ご自身の利用状況は、勤務先・国民年金の加入区分や証券会社のマイページ等でご確認ください。

## 確認事項(完了報告に含めること)

1. Next.js版の入力フォームで、iDeCo年間積立を27.6万円超に設定した場合に
   警告が表示されることをスクリーンショットで確認する
2. NISA年間積立を360万円超に設定した場合に警告が表示されることを確認する
3. NISA生涯枠に関する注意書きが、積立額に関わらず常時表示されている
   (数値による超過判定を行っていない)ことを確認する
4. 上記1〜3が、計算結果(KPI・グラフの数値)に影響しないことを確認する
5. methodologyページに追加した文言のスクリーンショットを添付する
