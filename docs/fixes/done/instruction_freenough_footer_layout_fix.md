# 実装指示書: フッター2カラム部分の横幅崩れ修正

## 背景

`instruction_freenough_footer_unification.md` で実装したフッターについて、本番実機のスクリーンショットで不具合が確認された。

「FIREを考える / 一人法人を考える」の2カラムブロックだけが、フッター内の他の行(「シミュレーター / 資産管理ツール / …」の共有機能行、「Freenoughについて / 広告開示 / …」のポリシー行)と横幅が揃っておらず、画面の端から端まで広がってしまっている。他の行は中央寄せでコンテンツ幅が制限されているのに対し、2カラム部分だけがビューポート全幅に近い状態で、左右の列が不自然に離れて表示されている。

これは意匠の好みの問題ではなく、レイアウト崩れとして扱う。

## Phase 0: 調査(必須、報告してから次へ)

1. lifecompass-next側 `Footer.tsx`(またはfreenough-main側の対応コンポーネント)で、2カラムブロックのCSS/クラス設定を確認する。
2. フッター全体を包んでいるコンテナ(共有機能行・ポリシー行が使っている中央寄せ・max-width設定)のクラス/構造を確認する。
3. 2カラムブロックが、そのコンテナの**外側**に配置されているのか、**内側だが別のwidth/justify設定で上書きされている**のかを特定する。
4. freenough-main側・lifecompass-next側の両方で同じ現象が起きているか確認する(実装を別々に行っているため、片方だけの可能性もある)。

## Phase 1: 修正

- Phase 0で特定した原因に応じて、2カラムブロックを他の行と同じコンテナ幅(max-width、中央寄せ)に収める。
- 2カラム間の間隔は、余白を持たせつつ画面全幅に広がらない適度な間隔にする(具体的な数値は既存のフッター内の他要素の間隔感に合わせてよい)。
- モバイル幅での2カラム表示(前回のA案:2カラム維持・圧縮)にも同様の崩れがないか確認し、あれば同時に修正する。

## Phase 2: 検証(証跡必須)

- PC幅で、フッターの4段(2カラム/共有機能行/ポリシー行/コピーライト)すべてが**同じ横幅**で中央に揃って表示されていることをスクリーンショットで確認。
- モバイル幅(640px未満)でも2カラム部分が崩れていないことを確認。
- freenough-main・lifecompass-next両方のページで確認する。
- 今回の修正が、前回確認済みのリンク先(特に「一人法人トップ」「一人法人ブログ」の絶対URL化)に影響していないことを確認する。

## やってはいけないこと

- Phase 0の報告なしにPhase 1へ進まないこと。
- リンク先URLやhref実装(前回対応済みのbasePath対応)を変更しないこと。今回はレイアウト(幅・整列)のみの修正。
- 証跡なしの完了報告をしないこと。

## 実施結果(2026-09-07・完了)

### Phase 0調査結果
- 2カラムブロックはコンテナ(`max-w-7xl mx-auto px-4`)の**外側には出ていない**。全て同じ`<div>`の内側。
- 原因は幅の決まり方の違い：②③行(`flex flex-wrap justify-center`)はコンテンツ本来の幅だけ
  占有して中央寄せされるのに対し、①行(`grid grid-cols-2`)はコンテナ幅を2等分し各列を
  引き伸ばすため、テキスト自体は短くても列の区画が画面幅いっぱいに広がって見えていた。
- freenough-main・lifecompass-nextはFooter.tsxのクラス文字列が完全一致しているため、
  **両方で同一の不具合が再現することを確認**。

### 修正内容
- ①2カラムブロックを`grid grid-cols-2`から`flex justify-center`に変更。
- ユーザー指摘により、②③がそのまま使っている`flex-wrap`は流用せず、`flex-nowrap`を
  明示指定（`flex-wrap`のままだと狭い画面で「一人法人を考える」列が下に折り返され
  縦積みになり、モバイルA案「2カラム横並び維持」の仕様に反するため）。
- 両リポジトリで同一修正（クラス文字列完全一致を維持）。
- リンク先(`href`)は一切変更していない。

### Phase 2検証結果（本番実機、全てスクリーンショット取得済み）
- **PC幅**：TOP・資産シミュレーター側・一人法人側（クリーンURL`/hitori-hojin`）の3ページ全てで
  4段（2カラム/共有機能行/ポリシー行/コピーライト）が同じ横幅で中央に揃って表示されることを確認。
- **モバイル幅**（546px、Tailwindの`sm`ブレークポイント640px未満）：一人法人側ページで
  2カラムが横並びのまま崩れず、`document.documentElement.scrollWidth > window.innerWidth`が
  `false`（横スクロール発生なし）であることを確認。
- **リンク先の非破壊確認**：資産シミュレーター側・一人法人側それぞれの本番ページで
  フッター内全リンクの`href`を取得し、前回対応（`instruction_freenough_footer_unification.md`）
  から一切変わっていないことを確認（「一人法人トップ」「一人法人ブログ」の絶対URL化を含む）。
