**今回新たに見つかった問題**：

### 0.1 肝心の「読込後」の証跡が1枚も含まれていない

提出された8枚の内訳は、1節-A・1節-B・手順1（データ入力）・手順3関連（保存前後、3枚）・手順5（未保存編集、2枚）で全てであり、**本調査で最も重要な「同一プロファイルを読込→保存時点の値に戻るかどうか」を示す画像が1枚も提出されていない**。これがなければ、症状が再現したか否かの判断ができない。

### 0.2 「手順5」とラベル付けされた2枚の画像の内容が食い違っている

- 1枚（「手順5(やり直し)」）：法人①現在PFの現金分が111万円に変更された状態で表示されており、結果カード（資産寿命・FIRE達成等）は「未達成」だが「枯渇なし」という、比較的平常な数値
- もう1枚（「手順5」、「やり直し」の記載なし）：現金分の表示は500万円（元の値）に戻っているにもかかわらず、結果カードは「37歳で枯渇」「MC破綻確率：枯渇」という、著しく悪化した数値になっている

**この2枚目は、入力欄の表示（500万円）と、裏側の計算に使われている値（結果から見て111万円相当のシナリオ）が食い違っている可能性を示している。** これは、これまでKENZOが懸念してきた「画面表示と実際の状態が一致しない」症状そのものに近い挙動であり、見過ごせない。単に「同じ手順を2回撮っただけ」なのか、「表示とstateが実際にズレる瞬間を偶然捉えたもの」なのかを、次の報告で明確にすること。
