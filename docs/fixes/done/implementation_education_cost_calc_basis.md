# 実装指示書:教育費シミュレーターに「計算根拠を見る」セクションを追加

## 前提

iDeCo/DC出口戦略シミュレーターには「計算根拠を見る」という折りたたみ式の詳細説明セクションがあるが、教育費シミュレーターには注記1行(「文部科学省...に基づく概算です。実際の費用は学年・時期により変動します。インフレ・学費改定は考慮していません。」)しかなく、情報量に差がある。iDeCo側と同じUIパターンで、教育費シミュレーター用の詳細説明を追加する。

---

## 1. UIパターン(iDeCo側と統一)

- 折りたたみボタン:「計算根拠を見る」+ 開閉アイコン(iDeCo側と同じコンポーネント・スタイルを流用)
- 展開時、結果カード・グラフの下、既存の1行注記の位置に配置(1行注記はこのセクション内に統合し、単独表示は削除してよい)
- 実装は、iDeCo/DC出口戦略シミュレーターの該当コンポーネント(折りたたみ部分)をそのまま流用・共通化できないか確認すること。ツールごとに同じUIを再実装するのではなく、共通コンポーネント化できる場合はそちらを優先する

## 2. 掲載内容(文言案)

冒頭(何を計算しているかの説明):

```
本ツールは、文部科学省「令和5年度子供の学習費調査」(幼稚園・小学校・中学校・高校)
および日本政策金融公庫「令和3年度教育費負担の実態調査結果」(大学)の統計データに基づき、
学校教育費と学校外活動費(塾・習い事等)の合計額を、選択いただいた学年・進路パターンに
沿って積み上げ計算しています。
```

反映していない事項(箇条書き、iDeCo側の「以下は反映していません」パターンを踏襲):

```
ただし、以下は反映していません:

- 学校給食費(公立・私立を問わず発生する食費に近い性質のため、教育の選択による
  追加費用という本ツールの趣旨から除外しています)
- 学年ごとの費用差(受験費用・入学一時金等の一時的な支出)。各ステージの年額は
  均等に按分して表示しています(大学の入学費用のみ、初年度に一括計上しています)
- 留年・浪人等による就学期間の延長(標準的な就学年齢を前提としています)
- 世帯年収・地域による費用差(統計データは全国平均です)
- 物価上昇(インフレ)・将来の学費改定
```

仕送りに関する注記:

```
「一人暮らし」をONにした場合の仕送り額は、日本政策金融公庫の同調査における
自宅外通学者への平均仕送り額(年間約95.8万円)を初期値としています。実際の
仕送り額は各家庭の判断によるものであり、金額は自由に編集できます。
```

締めの一文(iDeCo側の「実際の受取可否・税額は...ご確認ください」に相当する免責):

```
実際の教育費は、進学先・地域・世帯の状況により大きく異なります。本ツールは
大まかな傾向を把握するための目安としてご利用ください。
```

## 3. 文言の調整

- 上記は案であり、既存ツールのトーン(KENZOの「シミュレーションすると〜という結果になることがあります」という語り口)に合わせて、実装時に文言を最終調整してよい
- 「学校外活動費」「学校教育費」等の専門用語は、既に結果画面の出典表記で使われているものと表記を揃えること

## 4. 確認事項

- iDeCo側の折りたたみコンポーネントと見た目・挙動(開閉アニメーション含む)が統一されているか
- 既存の1行注記との重複がないか(統合後、同じ内容が2箇所に表示されていないか)
- iPhone SE幅で箇条書きが読みやすく折り返されているか
- 完了報告時は、変更・新規作成したコンポーネント名を明記すること(行番号は使用しない)
