# 実装指示書:教育費シミュレーター フェーズ1(データ定義+計算エンジン)

## 前提

Product Spec(`product_spec_education_cost_tool.md`)確定版に基づく実装。本フェーズはUIを含まず、**データ定義と計算ロジックのみ**を対象とする。フェーズ2(UI)・フェーズ3(CTA・UTM・GA4)は別指示書で扱う(積立額逆算ツール以降の既存パターンを踏襲した3フェーズ構成)。

---

## 1. 新規ファイル:`src/lib/educationCostData.ts`

以下の統計データを定数として定義する。

### 幼稚園〜高校(文部科学省「令和5年度子供の学習費調査」、学校教育費+学校外活動費の合計、学校給食費除外、年額・円):

```
幼稚園: 公立 169,411 / 私立 311,597
小学校: 公立 297,860 / 私立 1,774,511
中学校: 公立 506,808 / 私立 1,551,042
高校:   公立 597,752 / 私立 1,030,283
```

### 大学(日本政策金融公庫「令和3年度教育費負担の実態調査結果」、4年間合計・円):

```
国公立:   入学費用 672,000 + 在学費用 1,035,000×4年 = 合計 4,812,000
私立文系: 入学費用 818,000 + 在学費用 1,520,000×4年 = 合計 6,898,000
私立理系: 入学費用 888,000 + 在学費用 1,832,000×4年 = 合計 8,216,000
```

**入学費用は初年度に一括計上、在学費用は4年間で均等按分(=年額をそのまま4年間繰り返す)** という構造でデータを持つこと(Spec 6章の按分方針に対応)。

### 仕送り(一人暮らし時、オプトイン、年額・円):

```
プリセット初期値: 958,000(月換算 約8万円)
```

出典:日本政策金融公庫「令和3年度教育費負担の実態調査結果」自宅外通学者データ

### データ構造の設計方針

- ステージ:幼稚園・小学校・中学校・高校・大学の5種類
- 大学のみ、公立/私立の2択ではなく「国公立・私立文系・私立理系」の3択
- 各ステージの年数(標準的な就学年数)も併せて定数化する(幼稚園3年・小学校6年・中学校3年・高校3年・大学4年)
- 型定義は`src/lib/types.ts`の既存パターンに合わせる

## 2. 新規ファイル:計算ロジック(`src/lib/educationCostCalc.ts`、ファイル名は既存の命名慣習に合わせて調整可)

### 主要関数(`calc`プレフィックス規則に従う)

**`calcChildYearlyCosts(child)`**
- 入力:子供1人分のデータ(現在の学年、各ステージの公立/私立選択、大学の場合は国公立/私立文系/私立理系、仕送りの有無・月額)
- 出力:現在〜大学卒業までの年次費用配列(年ごとの金額)
- ロジック:
  - 現在の学年から、各ステージの残り年数・開始年齢を機械的に算出(標準就学年齢前提)
  - 幼稚園〜高校の各ステージ:選択(公立/私立)に応じた年額を、そのステージの残り年数分並べる(均等按分、スパイクなし)
  - 大学:入学費用を初年度に一括計上+在学費用(年額)を4年分均等に並べる。仕送りがONの場合、在学費用の年額に仕送り年額を加算する

**`calcTotalEducationCost(children)`**
- 入力:子供の配列(1〜3人)
- 出力:全員分の教育費総額
- ロジック:各子供の`calcChildYearlyCosts()`結果を合計

**`calcPeakYear(children)`**
- 入力:子供の配列
- 出力:年ごとの合算費用の中で最大となる年(ピーク)とその金額
- ロジック:子供ごとの年次配列を、現在からの経過年数を軸に合算し、最大値とそのタイミングを検出

### 戻り値の設計

- 既存の`financeCore.ts`の`number | null`規約を踏襲するかは本ツールの性質上必須ではない(入力が常に有効な学年・ステージ選択である前提のため、`null`が発生するケースは基本的にない)。ただし子供が1人も入力されていない場合の扱い(0を返すか、UIで防ぐか)は実装時に判断すること

## 3. 検証スクリプト:`scripts/verify-education-cost.js`

既存の`scripts/verify-finance-core.js`と同じ形式で新規作成する。

- 境界値ケース:子供1人・最年少(未就学児)/最年長(大学4年)、子供3人(年齢差なし・年齢差大)
- 代表ケース:オール公立、オール私立、混在パターン(幼稚園私立+それ以降公立など)、仕送りON/OFF
- 手計算またはExcel等での事前検算値と突き合わせてPASS/FAILを出力する
- 既存の`scripts/full-verify.js`との統合が必要かは、既存スクリプトの構成を確認した上で判断すること

## 4. 確認事項

- 実装前に、日本政策金融公庫「教育費負担の実態調査」の令和3年度より新しい調査が公表されていないか、Web検索で再確認すること。新しい調査が見つかった場合は、その数値に差し替えてから実装する
- `financeCore.ts`・`simulate.ts`・`analyze.ts`には一切手を加えないこと(本フェーズは完全に独立した新規ファイルのみを扱う)
- 完了報告時は、変更・新規作成したファイル名と関数名を明記すること(行番号は使用しない)
