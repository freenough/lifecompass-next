# 実装指示：ケーススタディセクション モバイルレイアウト修正

作成日：2026-09-21
種別：**実装（既存実装の改修）**
関連：`claude_investigation_casestudy_mobile_layout.md`（調査指示・完了済み）／`handoff_lp_grid_to_story_layouts.md`（前回セッション、ケーススタディの人物イラスト化・ストーリー形式レイアウト化）

## 背景

前回セッションでケーススタディセクションを「2×2グリッド」から「縦に積む横長の帯（左右交互配置）」に変更し本番マージ済みだが、KENZOがiPhone SE実機で確認したところ、モバイル表示のみレイアウトが崩れていた（タイトルが5〜7行に折り返され、アバターとバッジが本文テキストに重なって浮く）。

### 調査で確認された原因（要約）

- レイアウト自体にモバイル用ブレークポイントが一切存在しない。`sm:`（640px）はバッジ内部の方向にのみ影響しており、外側の行（`flex ${i%2===1 ? 'flex-row-reverse' : 'flex-row'} items-center gap-4 sm:gap-6 py-6`）は375pxでもデスクトップでも常に横一列のまま
- アバター（72px、`shrink-0`）とバッジ塊（約128px、`shrink-0`）はどちらも縮まず、`min-w-0`が付いているテキスト列だけが押し縮められる。375px幅では本文列が79px幅まで潰れる
- その結果、引用文が7行に折り返され、行全体の高さが357pxまで膨らむ
- 行全体に`items-center`が効いているため、本来1行分の高さ（72〜90px程度）を想定して配置されているアバターとバッジが、357pxに膨らんだ行の**縦中央**に再配置され、折り返された引用文の途中に重なって見える
- バッジの左右が田中さん／山本さんで入れ替わっているのは独立したロジックではなく、アバター＋テキスト＋バッジを含む行全体を丸ごと反転させている同一の`i % 2`が原因
- 山本さんの属性テキストが画面下端で見切れているのも同じ原因（本文列が同様に潰れて3行に折り返し、カード高さが382pxまで膨らんで見切れている）

### 今回の修正方針（KENZOとの設計チャットで確定）

1. **モバイルでは左右交互配置をやめ、全カード同じ並び順に統一する**（PC/デスクトップ側の交互配置ロジック自体は変更しない。ブレークポイントより上でのみ有効にする）
2. **モバイルでは横並び（`flex-row`）をやめ、縦積み（`flex-col`）に変更する**
3. **「公開中／近日公開」＋「noteで読む→」のバッジは、モバイルではカード最下部に横並びで固定表示する**（本文の長さに関わらず常に同じ位置に収まるようにするため）

## 1. モバイルレイアウトを縦積み・統一並びに変更する

**対象**：調査で特定されたケーススタディセクションのコンポーネントファイル（`i % 2`で行の向きを反転させている箇所）

**変更内容**：
- モバイル（`sm:`未満、640px未満）では、外側の行を `flex-col` にする。**`i % 2`による`flex-row-reverse`/`flex-row`の出し分けは、モバイル幅では効かせない**（＝全カード同じ並び順で表示する）
- `sm:`以上（デスクトップ）では、現状どおり `sm:flex-row` / `sm:flex-row-reverse` を`i % 2`で出し分ける、既存の交互配置ロジックを維持する
- 実装イメージ（クラス名は既存コードの命名に合わせて調整してよい）：
  `flex flex-col ${i % 2 === 1 ? 'sm:flex-row-reverse' : 'sm:flex-row'} items-start sm:items-center gap-4 sm:gap-6 py-6`
  のように、モバイルでは常に`flex-col`、`sm:`以上でのみ`i % 2`の反転クラスが効くようにする
- `items-center`は、テキスト量によって高さが可変になる現在の構造と相性が悪いことが崩れの直接原因だったため、**モバイルでは`items-start`（またはそれに準ずる、内容量に依らない配置）にする**。デスクトップ側の`items-center`は変更しなくてよい（PC版は現状問題が出ていないため）

## 2. カード内部の要素順序をモバイル用に整理する

- モバイル幅では、カード内の要素を縦に以下の順で並べる：
  1. アバター（人物イラスト）＋名前・属性を横並びにした小さめのヘッダー行（アバターサイズはPC版の72pxより縮小してよい。ヘッダー行1つ分に収まる高さを目安にする）
  2. タイトル（「」で囲まれた引用文・見出し）
  3. 本文の説明文（現状「貯めてきた。でも、いつ辞められる？」等にあたる部分）
  4. バッジ（「公開中／近日公開」＋「noteで読む→」）を、カード最下部に横並びで固定表示。左右どちらかに寄せる場合は右寄せを基本とする
- デスクトップ側（`sm:`以上）の要素順序・見た目は変更しない
- `PersonaAvatar.tsx`自体（viewBoxやprops）は変更不要と想定している。あくまでモバイルでのアバターの表示サイズ・配置位置をラップ側のクラスで調整する想定。もしモバイル対応のために`PersonaAvatar.tsx`側の変更が必要だと判断した場合は、変更前に一度報告すること

## 3. リンク挙動・公開状態表示は維持する

- 田中さん・山本さん・中村夫婦はリンクあり、佐々木さんはリンクなしdiv、という前回実装済みの挙動は変更しない
- 「公開中」「近日公開」の状態表示ロジックも変更しない
