# 実装指示書：資産シミュレーターLP 背景色の交互パターン修正

作成日：2026-08-18
対象リポジトリ：`lifecompass-next`
対象ファイル：`src/app/page.tsx`（前回指示書でセクション挿入した同一ファイル）

---

## 0. 背景

前回の指示（資産管理ツール導線セクションの追加）により、新セクションが「かんたん計算ツール」と「あなたはどのタイプ」の間に白背景で挿入された。これにより、それ以降のセクションの背景色の交互パターンが1つずつズレている。今回はこのズレを修正する。

新セクション自体（資産管理ツール導線）の背景は白のままで変更不要。それ以降のセクションの背景色をすべて反転させる。

---

## 1. 現状 → 修正後

| セクション | 現状 | 修正後 |
|---|---|---|
| こんな悩みはありませんか | 背景色あり | 変更なし（背景色あり） |
| FIREガイド | 背景色なし（白） | 変更なし（背景色なし） |
| かんたん計算ツール | 背景色あり | 変更なし（背景色あり） |
| 【新規】資産管理ツール導線 | 背景色なし（白） | 変更なし（背景色なし） |
| あなたはどのタイプ | 背景色なし（白） | **背景色あり に変更** |
| 使い方（3ステップ） | 背景色あり | **背景色なし（白）に変更** |
| 最終CTA | 背景色なし（白） | **背景色あり に変更** |

修正後、悩み〜最終CTAまで「あり／なし」が一貫して交互になることを確認すること。

---

## 2. 実装方針

- 各セクションの背景色は既存で使われているクラス／トークンをそのまま使い回すこと（新しい色や値を追加しない）。「背景色あり」セクションと「背景色なし」セクションで使っているクラス名をそれぞれ確認し、対象3セクションのクラスを入れ替える形で対応する。
- Tailwindクラスの直接指定であれば該当クラス名を入れ替え、共通コンポーネント（例：`<Section variant="tinted">`のようなラッパー）を使っている場合はpropsの値を入れ替える。
- 新セクション（資産管理ツール導線）や、悩み・FIREガイド・ツールのマークアップ自体には触れない。

---

## 3. 対象外

- ロックファイルへの変更なし（対象外ファイルにも触れない）
- セクションの順序変更なし（今回は背景色のみ）
- 資産管理ツール導線セクションの内部デザイン（テキスト・イラスト）は今回のスコープ外

---

## 4. 検証

- `tsc` / `build` / `full-verify.js` がクリーンであること
- デスクトップ・モバイル両方で、悩み〜最終CTAまでの背景色が一貫して交互になっていることをスクリーンショットで確認
- ロックファイルへの差分ゼロ
