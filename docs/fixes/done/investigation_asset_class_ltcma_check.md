## 背景

`src/lib/profile.ts`のASSET_CLASSES(μ・σ)は「JPモルガンLTCMA 2026年版を参考に設定」とコメントされているが、出典の個別数値との照合が行われていなかった。プランニングチャット側でJPモルガンの円ベースLTCMA 2026年版(公式PDF:`ltcma-2026-jp-matrix_jpy.pdf`)の該当項目を手動で拾い出し、以下の参照値を確定させた。この参照値とコード上の値を機械的に突き合わせてほしい。

**重要な前提**:このシミュレーターはモンテカルロで「毎年ランダムにリターンを引く」設計(`simulate.ts`でμを各年の期待値として使用)であるため、比較すべきはLTCMAの**算術平均**(その年その年の平均値)であり、**幾何平均**(複利成長率、ボラティリティの影響で算術平均より低くなる)ではない。両方を併記するので、コードの実際の使われ方(算術平均としての用途か、他の用途か)を踏まえて、どちらとの整合性を見るべきか含めて判断・報告してほしい。

## 調査項目

1. **`profile.ts`のASSET_CLASSES全項目を、上記参照値の算術平均列およびσ列と突き合わせ、差分を一覧化してください**(全世界株・先進国株・新興国株・日本株・先進国債券・日本債券・先進国REIT・日本REIT・ゴールド・短期債・MMFの10項目)
   - 差分が±1.0pt以内:「一致」
   - 差分が±1.0〜2.0pt:「軽微な乖離」
   - 差分が±2.0pt超:「要確認」
   の3段階で分類してください

2. **日本REITの参照値が見つからない件**:コード上の日本REIT(μ=4.0%・σ=15.0%)がどの指数・出典を想定しているか、`profile.ts`や関連ドキュメントにヒントがないか確認してください

3. **債券項目の出典不明瞭な件**:先進国債券(コードμ=4.0%・σ=10.0%)は、上記のどの候補(先進国国債ヘッジあり/なし・グローバル債券・米国総合債券)とも大きく乖離しています。コード上のコメントや過去のコミットメッセージに、この数値の設定根拠が残っていないか確認してください(`git log`・`git blame`でprofile.tsの該当行の変更履歴を確認)

4. **`simulate.ts`内でのμの実際の使われ方を再確認してください**:各年の期待リターンとして単純に加算されているか(算術平均として扱うのが妥当)、それとも別の統計的な使われ方(例:対数正規分布のパラメータとして幾何平均寄りの扱いになっている等)がないか、コードを読んで報告してください。これによって「算術平均と比較すべき」という前提が正しいかどうかが決まります
