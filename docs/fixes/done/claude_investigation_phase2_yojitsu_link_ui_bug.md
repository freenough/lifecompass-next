# 調査指示：計画保存ボタンの有効化不具合／プロファイル連携UIの実態確認

作成日：2026-08-31
種別：**調査のみ（実装・修正は一切行わない。ただし調査1で明確な不具合と断定できた場合のみ、そのバグ修正は許可する。UI導線の再設計は別途指示するため今回は行わない）**
関連：`claude_instruction_phase2_yojitsu_v1_plan_and_compare.md`（V1実装指示、完了報告済み）／`instruction_phase2_profile_linking.md`（連携機能の実装指示、完了済みのはず）

---

## 背景

V1完了後、KENZOが実機で「計画を保存」ボタンを操作しようとしたところ、連携が必要という案内文が出た。この場でKENZOに操作方法を案内したが、**2回連続で誤った案内をした**（1回目：法人資産セクションのプルダウンだと案内→実際は別のインポート機能だった。2回目：黒枠の空白ボックスを指したが正体不明）。これ以上推測で案内せず、実機・実コードで確定させる。

添付スクリーンショットでは、「法人資産（一人法人）」の見出し右に**何も表示されていない黒枠の空白ボックス**があり、これが本来の連携セレクター（`instruction_phase2_profile_linking.md`3節で実装されたはずのもの）の描画不具合である可能性が高い。

**このタスクは調査を主目的とする。推測は一切禁止。実際に該当画面をブラウザで開き、DOM・コンソールエラー・該当コードを確認した上で報告すること。**

---

## 調査1：法人資産セクションの空白ボックスの正体

**確認したいこと**
- スクリーンショット中の「法人資産（一人法人）」見出し右の黒枠の空白ボックス（本文で説明した「連携セレクター」の位置）が、実際に何のコンポーネントか
- `instruction_phase2_profile_linking.md`3節で実装されたはずの「資産管理ツールプロファイルを選択できるセレクター」がこれに該当するか
- 該当する場合、なぜ選択肢が空、または表示が壊れているのか（データ取得先の不一致、条件分岐のバグ、CSSの表示崩れ等）。ブラウザの開発者ツールでDOM構造・コンソールエラーを確認し、実際の原因を特定すること
- 該当しない場合、このセレクター自体が現在どこにも存在しない（実装が失われた、または別の変更で消えた）可能性を確認すること

**対象ファイル**
- シミュレーター側「法人資産（一人法人）」セクションのコンポーネント（`src/app/app/page.tsx`関連、`CorporateSettingsSection.tsx`等）

**報告フォーマット**
- 実機スクリーンショット（開発者ツールでDOM構造を確認したもの含む）
- 該当コードの抜粋
- 不具合の場合、原因を明記（推測ではなく、実際に再現・特定したもの）

---

## 調査2：「計画を保存」ボタンが有効化されない原因

**確認したいこと**
- `PlanManagerPanel.tsx`の「計画を保存」ボタンの有効化条件（`linkedSimulatorProfileId`の判定ロジック）を確認する
- 実際に、シミュレーター側で何らかの操作をした場合に、資産管理ツール側プロファイルの`linkedSimulatorProfileId`が正しく設定される経路が**現状のコードに実在するか**を確認する（調査1の結果次第では、そもそも設定する手段自体が機能していない可能性がある）
- 安全なテストデータで実際に連携を成立させてみて（可能であれば）、「計画を保存」ボタンが有効化されることを確認する。成立させられなかった場合は、どこで詰まったかを具体的に報告する

**対象ファイル**
- `PlanManagerPanel.tsx`
- 資産管理ツール側プロファイルのstore・型定義（`linkedSimulatorProfileId`関連）

**報告フォーマット**
- ボタン有効化条件の該当コード抜粋
- 実際にテストデータで連携を試みた結果（成功した場合は手順とスクリーンショット、失敗した場合はどの段階で失敗したかを明記）

---

## 調査3：導線の実態整理（個人のみの機能なのに法人セクション経由になっている点）

**確認したいこと**
- 現在、資産管理ツールプロファイルとシミュレータープロファイルを連携させる手段が、UI上どこに（もしあるなら）存在するか、実機で操作可能な箇所をすべて洗い出す
- V1（個人のみの計画保存機能）にとって、法人設定を一切扱わないユーザーが連携を行うための導線が、現状のUIに存在するかどうかを明確にする

**報告フォーマット**
- 現状、連携を成立させる手段としてUI上に実在する箇所を列挙（無ければ「無い」と明記）
- 個人のみのユーザーが迷わず連携できる導線が現状あるかどうかの結論
