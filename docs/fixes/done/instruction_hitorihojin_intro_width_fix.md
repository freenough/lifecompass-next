# 実装指示書: 一人法人Hero直下の説明文の横幅を本文と揃える

## 背景

`/hitori-hojin` トップページで、Hero見出し直下の説明文(「これから法人化を考える人にも...」)と、その下に続く本文(「FIREというと...」)の**両方**が、さらにその下の「一人法人を知る」セクションのカード群(横幅の一番広い要素)より狭いコンテナに入っており、左右の余白が大きく空いている。結果として、説明文・本文それぞれの左端と、カード群の左端が縦のラインで揃わず、ガタついて見える。

**訂正:** 当初「説明文の幅を本文に合わせる」という指示を出したが、これは誤りだった。本文(「FIREというと...」)自体もカード群より狭いコンテナに入っているため、説明文を本文に合わせても根本解決にならない。**基準にすべきはカード群の幅(ページ内で最も広い要素)であり、説明文・本文の両方をそこに合わせる必要がある。**

## 差し戻し安全性の方針

- 引き続き `feature/lp-visual-refresh` ブランチ上で作業する。mainには直接pushしない。

## やること

- Hero見出し直下の説明文、および本文(「FIREというと...」)、**両方**のコンテナ幅を、「一人法人を知る」セクションのカード群と同じ幅に揃える。
- 中央揃え・左揃えといった、現状のテキストの揃え方自体は変更しなくてよい。あくまで**コンテナの横幅**をカード群に合わせることが目的。
- 資産シミュレーター側についても、Hero直下の説明文や本文がカード群・セクション全体の幅より狭くなっていないか確認し、同様の問題があれば修正する。

## 検証(証跡必須)

- 修正後のスクリーンショット(PC・モバイル)を報告する。説明文・本文・カード群、すべての左右の端が縦のラインで揃っていることを確認する。
- 資産シミュレーター側も同様に確認する。
- Vercel Preview URLを報告する。

## やってはいけないこと

- テキストの揃え方(中央揃え)自体を変更すること(幅の問題のみを対象とする)。
- mainへの直接push。
- 証跡なしの完了報告をしないこと。
