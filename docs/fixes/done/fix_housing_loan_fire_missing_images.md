# 修正指示書:housing-loan-fire.md 本文中の画像埋め込み漏れ

作成日: 2026-08-05
種別: 実装(コミット・pushはこのチャットの明示判断を待つこと)
対象リポジトリ: lifecompass-next

---

## 問題

`src/content/blog/housing-loan-fire.md`には、アイキャッチ(frontmatterの`eyecatch`)
以外に、本文中2枚の図版(資産推移グラフ・モンテカルロ枯渇確率グラフ)を埋め込む
markdown記法が入っていない。テンプレートルール上、本文中に2〜4枚の図版を配置する
想定だったが、実装時に反映漏れが発生していた。

## 手順

### 1. 既存記法の確認

本文中に図版を持つ既存記事(例:`dual-income-couple-fire.md`、または他に該当する
記事があれば)のソースを確認し、画像埋め込みの正確なmarkdown記法・キャプションの
付け方(`remarkImageCaption()`がどう機能するか)を把握すること。単純な
`![alt](path)`なのか、alt textやtitle属性がキャプションとして扱われるのか、
実際の記法をそのまま踏襲すること。

### 2. 画像ファイル名(このチャットでの決定)

- 資産推移グラフ:`/images/blog/housing-loan-fire-chart-assets.png`
- モンテカルロ枯渇確率グラフ:`/images/blog/housing-loan-fire-chart-montecarlo.png`

(アイキャッチの命名規則`{slug}-eyecatch.png`に倣った命名。既存記事の本文中画像の
命名慣習と大きく異なる場合は、その慣習に合わせて調整してよい。その場合はこのチャットに
報告すること)

### 3. 挿入位置

**資産推移グラフ:**
H2-3「3パターンで実際にシミュレーションしてみた」内、以下の段落の直後に挿入:

```

```
(この表の直後)

キャプション例:「35〜90歳の資産推移。パターン1(賃貸)は82歳で資産が尽きる」

**モンテカルロ枯渇確率グラフ:**

(この段落の直前)

キャプション例:「モンテカルロ・シミュレーション(1,000試行)による資産枯渇確率」
