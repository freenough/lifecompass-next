前回の指示書(`FIX_mc_mode_strategy_radio_selection.md`、MCモードの戦略選択をラジオボタン化する案)は**撤回します。実装はまだ着手していないはずなので、そのまま破棄してください。**

調査の過程で、旧HTML版(`STEP35_simulator.html`)に、複数戦略選択を活かしたまま破綻しない表示方法が既に実装済みであることが判明しました。Next.js移植の過程でこの仕様が簡略化され、`activeStrategies[0]`だけを見る実装になっていたことが、今回の問題の実態でした。今回は「制限する(ラジオ化)」のではなく、**旧版の設計をそのまま復元する**方針に変更します。

## 復元・再設計する仕様

**重要な方針転換:** 旧版では「KPIの基準戦略(先頭にチェックした戦略)」と「グラフの帯表示戦略(ドロップダウンで選択)」が別々の変数(`_primary`と`bandStrategy`)として存在していましたが、これは概念として本来同じもの(「今どの戦略を見ているか」)であるにもかかわらず別管理になっており、両者が食い違うと分かりにくいという指摘があった。今回はこの2つを**「表示戦略(displayStrategy)」という1つの状態に統合する**形で再設計する。

### 状態設計

- `activeStrategies`(既存):比較対象に含める戦略の集合。チェックボックスで複数選択
- `displayStrategy`(新規、`baseStrategy`と旧`bandStrategy`を置き換える):現在「表示」している単一の戦略。**`activeStrategies`に含まれる戦略の中からのみ選択可能**

責務の分離:
- **比較対象(複数・チェックボックス)** → 破綻確率カードのリスト表示、資産推移グラフの中央値折れ線(戦略ごとに色分けして全部描画)など、「戦略を横並びで比較する」系の表示すべてに使う
- **表示戦略(単一・ラジオ)** → 資産寿命・最終資産・収支転換点・初年度取崩率などの単一値KPIカード、資産推移グラフの帯(p10〜p90)、破綻確率カード内のp10/中央値/p90の補足行など、「1つの戦略の値を代表として見せる」系の表示すべてに使う

### 1. 戦略選択UIの変更

チェックボックスの各行に、比較対象へ含めるかどうかとは別に、「表示戦略」を選ぶラジオボタン(またはそれに準ずるUI)を追加する。

```
☑ 現金優先     ○ 表示
☑ 課税優先     ● 表示
☑ 比例取崩     ○ 表示
```

- ラジオは`activeStrategies`に含まれる(チェックされた)戦略にのみ選択可能とする(チェックされていない戦略のラジオは無効化するか非表示にする)
- チェックが1件しかない場合、ラジオは実質その1件に固定される(選択の必要がないため、非表示または無効表示でよい)
- 表示戦略として選択中の戦略のチェックを外した場合、`activeStrategies`に残っている先頭の戦略に自動的にフォールバックする

### 2. 戦略比較インフォバー(複数選択時のみ表示)

複数戦略が選択されている場合、以下のようなバナーをKPIエリア上部に表示する。文言は「表示戦略」という言葉を使い、KPIとグラフの帯の両方がこれに連動することを示す。

```
[アイコン] 戦略比較モード　単一値のKPI・グラフの帯は「{表示戦略名}」基準。破綻確率はチェック中の全戦略を表示。
```

(旧版参考:`STEP35_simulator.html` 1029-1034行目、`kStratRow`/`kStratPrimary`。ただし文言・変数の意味は上記の通り再設計する)

### 3. 資産推移グラフ(AssetChart、MCモード)

- `activeStrategies`(比較対象)それぞれについて、中央値の折れ線を戦略ごとに色分けして描画する(帯は描画しない)
- p10〜p90の帯(塗りつぶし)は、`displayStrategy`(表示戦略)の1つ分のみ描画する
- グラフ上部のドロップダウン(旧版の「バンド:」)は廃止し、表示戦略の選択はチェックボックス横のラジオ(上記1)に一本化する。グラフ側に重複した選択UIを置かない
- グラフ下の注記は「確率的モード・中央値{n}本+{表示戦略名}のバンド({試行数}試行)」のような文言にする

(参考:旧版 2915-2942行目のロジックは流用可。ただし`bandStrategy`という変数名・独立ドロップダウンUIは`displayStrategy`に統合し、グラフ側の専用ドロップダウンは作らないこと)

### 4. MC破綻確率カード

- **単一戦略選択時**:現状通り、単一の破綻確率・枯渇年齢情報を表示
- **複数戦略選択時**:カードの中身を、`activeStrategies`ごとに1行ずつのリスト表示に切り替える。各行は「色ドット・戦略名・破綻確率(%)・枯渇時の平均/最短年齢(または"全試行で資産維持")」を含む(この部分は比較対象=全戦略を見せる表示なので、表示戦略の影響を受けない)
- p10・中央値・p90の表示は、**表示戦略(displayStrategy)** の値を表示し、「(戦略名)」という注記を添える。表示戦略はラジオで明示的に選ばれているため、旧版で懸念していた「基準がどれか分かりにくい」という問題は解消される想定

(参考:旧版 2632-2680行目、`kBRlist`・`kBRpct`・`kBRpctNote`)

### 5. 将来の拡張性(今回の実装スコープ外・設計メモとして記載)

将来、ファンチャート・年間キャッシュフロー・資産内訳などの機能を追加する場合も、単一戦略の値を表示するものは`displayStrategy`を参照し、複数戦略を横並びで比較するものは`activeStrategies`を参照する、という同じ責務分離のルールに従うこと。今回の実装で、この2つの状態(`activeStrategies`と`displayStrategy`)の管理方法(Zustand store内での置き方)を、他の機能からも参照しやすい形にしておくこと。
