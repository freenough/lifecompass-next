# 中村夫婦:NOTE全話数値の作り直し + ブログ記事用シナリオ出力

## 背景

中村夫婦シリーズはまだ未公開のため、以下3点をこの機会に反映してから新版の数値で作り直す。

1. 口座を翔太・美咲それぞれに分割(合算のまま→個別に)
2. 翔太のNISA積立をNISA生涯枠(1,800万円)内に収まるよう調整
3. 第4話「繰上げ返済」は現行版に未実装のため、「30年ローン vs 20年ローンを選ぶ」という設定に差し替え

ベースプロファイルは添付 `lifecompass_中村夫婦①_split.json`(口座分割・NISA調整済み、第10話=最終確定状態に相当)。ここから**話数を遡って必要なイベントを間引いた状態**を都度作り、各話の数値を出力する。

---

## 先に1点だけ調査・確認してほしいこと(実装前に報告)

**美咲のパート収入の表現方法**(第6話パターンC・ブログのシナリオCで共通して必要)

美咲は`spRetAge`=56で退職済みだが、56〜64歳(65歳の年金開始まで)の間、手取り120万円/年のパート収入がある、という状態を作りたい。現在のイベント体系(`inc_change`に`owner:"spouse"`を指定する等)で表現可能か調査し、**採用する方式をコード上の根拠(該当ファイル・関数名)とともに実装前に報告してください**。これは新しいシナリオの表現方法を決める設計判断のため、二段階(調査→実装)で進めてください。

## パートA:NOTE記事 全話分の再出力

### 共通の基本パラメータ(全話共通)

`lifecompass_中村夫婦①_split.json`の`params`のうち、以下は全話で共通:

- curAge38, spCurAge36, baseInc480, spInc355, baseExp360, inflR2
- retAge58, penAge65, penAmtVal170
- spPenAge65, spPenAmt120
- 口座残高・積立(NISA/iDeco/特定/現金):分割・NISA調整済みの値をそのまま使用
- rWNisa/rWIdeco/rWTax=7、rRNisa/rRIdeco/rRTax=4、mcStd16、mcStdR8

話ごとに変わるのは「**イベントの有無**」と「**spRetAge(美咲の退職年齢)**」のみ。以下、話数ごとに差分を示す。

---

### 第2話:イベントなし

- `events`: `[]`(空)
- `spRetAge`: **65**(まだ変更前のデフォルト)
- 出力:58歳時点の総資産(固定計算)

### 第3話:+教育費

- `events`: 教育費2件のみ(子1:49〜52歳250万円/年、子2:52〜55歳250万円/年)
- `spRetAge`: 65(まだ変更前)
- 出力:49歳・52歳・58歳時点の総資産(固定計算)

### 第4話:+住宅ローン(30年 vs 20年の比較に差し替え)

- `events`: 教育費2件 + 住宅ローン
- `spRetAge`: 65(まだ変更前)
- **2パターン出力**:
  - **4A(30年ローン)**:principal4100, rate1, termYears30, age38〜67(現行の`bTax`調整版と同じ計算式)。年間返済額は既知の158.25万円のはずだが、`calcMortgage()`で改めて算出し確認。
  - **4B(20年ローン)**:principal4100, rate1, termYears20, age38〜57。年間返済額を`calcMortgage()`で新規算出。
- 出力:各パターンの58歳時点総資産
- **注記**:物語上は「20年か30年か悩んだ末、30年ローンを選んで投資を続ける」という結末にするため、第6話以降は4A(30年ローン)の設定を引き継ぐ。4Bは比較のためだけに1回計算すればよい。

### 第5話:美咲の退職年齢を変更(数値確認のみ)

- `events`: 教育費2件 + 住宅ローン(30年・4Aの設定)
- `spRetAge`: 65→**56**に変更
- 出力:90歳時点の総資産が枯渇していないことのみ確認(具体的な数字は本文に不要だが、念のため90歳時点資産を報告)

### 第6話:A/B/Cパターン比較(教育費+ローンのみ、介護費・退職金・生活費見直しはまだ反映しない)

- `events`: 教育費2件 + 住宅ローン(30年)
- `spRetAge`: 56
- **3パターン出力**(いずれも58歳・90歳時点の総資産、固定計算):
  - A:retAge58・spRetAge56、ともに完全退職
  - B:retAge**60**(翔太2年延長)・spRetAge56
  - C:retAge58・spRetAge56、ただし美咲に56〜64歳の間パート収入120万円/年(冒頭の調査結果に基づき実装)

### 第7話:+介護費

- `events`: 教育費2件 + 住宅ローン(30年) + 介護費(55〜57歳、100万円/年)
- `spRetAge`: 56、retAge58(Aパターンのみ)
- 出力:58歳時点の総資産(固定計算)

### 第8話:固定計算+MC(退職金・生活費見直しはまだ)

- `events`: 第7話と同じ(教育費+ローン+介護費)
- 出力:58歳時点総資産(固定計算)、資産枯渇率(MC・1,000試行、90歳時点)

### 第9話:+退職金→+68歳生活費見直し(2段階で出力)

- **ステップ1**:第8話の設定 + 退職金2件(翔太58歳1,500万円、美咲56歳1,000万円)
  - 出力:資産枯渇率(MC)、90歳時点中央値
- **ステップ2**:ステップ1 + 68歳以降生活費を240万円に変更(`base_change`イベント)
  - 出力:資産枯渇率(MC)、90歳時点中央値

### 第10話:最終確定(=ブログ記事のシナリオAと同一)

- `events`: 全イベント込み(教育費2件+住宅ローン30年+介護費+退職金2件+68歳生活費見直し) = 添付JSONそのまま
- 出力:58歳時点総資産(固定)、90歳時点総資産(固定)、資産枯渇率(MC)、90歳時点中央値
- **これはパートBのシナリオAと同じ計算なので、1回実行すれば両方に使い回せます**
