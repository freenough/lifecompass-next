# 指示書: LP「FIREガイド」カードの二重表示解消

## 種別

実装指示。前回の調査報告（GA4・FIREガイド調査のB）と、KENZOの判断に基づく。

## ブランチ

- `lifecompass-next` で、`main` から `feature/fireguide-card-simplify` を作成して作業すること
- **GA4の本番限定化（別の指示書）が終わってから着手すること**

## 背景

`FireGuideCarousel` のカードは、アイキャッチ画像の中に記事タイトルとカテゴリが入っている。そのため、カード下のテキストのタイトル・バッジ・excerptと二重になっている。

実測では、375px幅での画像内のメインタイトルは10.7〜13.9px相当で、目安の14pxに届かない。そのためスマホでは、テキストのタイトルを残す。

## 変更内容

| 要素 | lg（1024px）以上 | lg未満 |
|---|---|---|
| 画像 | 表示 | 表示 |
| 日付 | 表示 | 表示 |
| テキストのタイトル | **非表示** | 表示 |
| バッジ（カテゴリ） | **削除** | **削除** |
| excerpt | **削除** | **削除** |

- テキストのタイトルは `lg:hidden` 等で、lg以上では表示しない
  - lg未満では `line-clamp-2` と `[line-break:strict]` を付ける
  - 既存の見た目（文字サイズ・色）は維持してよい
- 画像の `alt` は、現在どおり記事タイトルの全文のままにすること（lg以上ではこれがリンクの名前になる）
- カードのリンク範囲・カルーセルの動き（矢印・ドラッグ・スクロールスナップ）・カード幅は変更しないこと
- 記事データの excerpt はサイト内検索のインデックスで使われているため、**データ側には一切触れないこと**。カードでの表示をやめるだけとする
- `FireGuideCarousel` がLP以外で使われている場合は、その場所への影響を報告すること

## 検証

### 画像内タイトルの文字サイズ（最重要）

- 1024px・1280px・1440px で、LPの6件すべてについて、画像内のメインタイトルの文字サイズ換算（px相当）を、前回と同じ方法で実測すること
- **1024pxで14px相当に届かない記事があった場合は、実装を完了扱いにせず報告すること。** 切り替え幅（lg）を独断で変えず、代わりの案（例：xlへの変更）を実測値つきで提案すること

### スクリーンショット（変更前後）

- LPのFIREガイドのセクション：375px・768px・1024px・1440px

### 実測値

- カードの高さ（変更前→変更後）：375px・1024px・1440px

### ビルド

- `npm run build` と `tsc --noEmit` がエラーなしで通ること
- 書き換わった `tsconfig.tsbuildinfo` は元に戻すこと

### ロックファイル

- 差分ゼロであることを `git diff --stat` で示すこと

## コミット

- commit・pushはKENZOの指示があるまで行わないこと
- 完了報告にコミット計画を入れること（ファイルを個別に列挙する。`git add -A`・`git add .` は使わない）
- LPの見た目の変更なので、KENZOがVercel Preview URLで確認してから、KENZO自身がmainへのマージを実行する

## 安全ルール（必ず守ること）

- 検証中は、GA4・AdSenseへの通信を必ず遮断すること
- `localStorage.clear()` などの破壊的操作は行わないこと
- devサーバーを停止するときは、ポートからPIDを特定し、そのPIDだけを個別に停止すること。`taskkill /F /IM node.exe` は**使用禁止**
- `docs/fixes/active/` フォルダ自体は削除しないこと
