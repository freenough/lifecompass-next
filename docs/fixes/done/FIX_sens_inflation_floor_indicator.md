# 実装依頼：感度分析パネル「インフレ率Δ」クランプ時の実効値表示

## 背景

`AUDIT_sensitivity_inflation_floor.md`での調査により、以下が判明済み：

- `SensitivityPanel.tsx`内で `inflR: Math.max(0, baseP.inflR + deltas.dI)` というクランプが存在する（旧HTML版からの忠実な移植・仕様として正しい）
- ベースラインのインフレ率が低いプロファイル（例：1%）では、Δスライダーの下側1〜3ポジションが「動かしても結果が変わらない無反応域」になる
- この無反応域はユーザーにとって分かりにくいため、クランプが実際に効いているときだけ実効値を表示するUIを追加する

## 実装内容

### 表示条件

`baseP.inflR + deltas.dI < 0` のときのみ表示する。常時表示はしない（このプロファイルの大半のケースでは無意味な情報になるため）。

### 配置

`SensitivityPanel.tsx`内、インフレ率Δのスライダー行（`<SliderRow id="dI" .../>`）の直下。他の4パラメータ（利回りΔ×2・退職年齢Δ・開始を遅らせた場合）には同様の注記は不要（無反応域の問題がないため、追加しない）。

### 表示文言（固定文言・動的値は不要）

```
適用インフレ率：0%（0%未満にはなりません）
```

クランプが効いている場合、実際に使われる値は常に0%になるため、動的に計算した値を表示する必要はない。固定文言でよい。

### スタイル

新規CSSは追加せず、既存の注記スタイル（infoアイコン＋グレー文字。旧HTML版の`.inp-note`相当、または現行コードベースで同等の役割を持つ既存クラス）を流用すること。もし現行コードベースに`.inp-note`相当のクラス・コンポーネントが存在しない場合は、実装前にKENZOに確認すること（新規スタイル定義が必要になるため）。

### モバイル配慮

文言は上記の短い1文で確定済み。折り返しが発生しないか、モバイル幅（〜480px）での見え方も確認すること。
