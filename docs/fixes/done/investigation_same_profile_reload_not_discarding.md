# 追加調査指示：同一プロファイルの再読込で未保存編集が破棄されない不具合

作成日：2026-09-05
種別：**調査のみ（実装は行わない）**
関連：`investigation_companystate_load_not_switching.md`（前回の調査指示書。A/B間のプロファイル切替・ブラウザリロードは再現せず「異常なし」と判定された）／`instruction_phase2_companystate_rearchitecture.md`（CompanyState専用の下書き保護(`isDirty`/`saveDraft`/`discardDraft`)を撤去し、シミュレーター本体の保存操作に一本化した指示書）

## 0. 背景・前回調査との違い

前回の調査（`investigation_companystate_load_not_switching.md`）では、「プロファイルA⇄B間の切替」「ブラウザリロード」の2パターンで検証し、いずれも正常だった。

今回KENZOから改めて報告された再現手順は、**上記いずれとも異なる、より具体的なシナリオ**：

1. あるプロファイル（例：法人設定を含むプロファイル）で「事業タイムライン」（取崩・事業利益イベント）・「法人ポートフォリオ①現在」（投資分・現金分の残高等）を編集し、**「上書き保存」を押す**
2. 保存後、**同じ画面上でさらに値を変更する**（保存はしない）
3. プロファイル一覧から、**（切替先を別のプロファイルにするのではなく）今アクティブになっているのと同じプロファイルを再度「読込」する**
4. 期待動作：手順2の未保存の編集が破棄され、手順1で保存した値に画面が戻る
5. 実際の動作：画面の値が手順2の編集内容のまま変わらない（保存時点の値に戻らない）

**この「同一プロファイルの再読込」パターンは、前回の調査（A→B→A、B単体の切替）ではテストされていなかった。** 本調査ではここに絞って確認する。

## 1. 調査対象データ（KENZO提供のスクリーンショットの再現用参考値）

- 事業タイムライン：取崩イベント（60〜79歳／50万）、事業利益イベント（40〜49歳／100万）の2件
- 法人ポートフォリオ①現在：投資分（残高）333万円、現金分（残高）500万円

これに準じたテストデータで、1.の手順を再現すること。

## 2. 調査項目

### 2.1 `ProfileDrawer.tsx`（ロックファイル、読み取りのみ）の「読込」ボタンの挙動確認

- 一覧内の「読込」ボタンをクリックした際のハンドラを確認する
- **クリック対象のプロファイルIDが、現在アクティブなプロファイルID（`currentProfileId`）と一致する場合に、処理が早期returnされる、あるいは何らかの理由で`loadProfile()`の呼び出し自体がスキップされる分岐がないか**を重点的に確認する（同一IDだから「変化なし」とみなして何もしない、という実装になっていないか）
- 上記のような分岐がある場合、それがどこに実装されているか（`ProfileDrawer.tsx`内か、それとも呼び出し元か）を特定する。**`ProfileDrawer.tsx`はロックファイルのため、修正はせず、事実確認のみ行うこと**

### 2.2 `simulatorStore.ts`の`loadProfile()`自体の冪等性確認

- 同一プロファイルIDに対して`loadProfile()`が複数回呼ばれた場合、正しくstorageから再取得して現在のstateを上書きするか（何らかのメモ化・キャッシュにより2回目以降は処理がスキップされる実装になっていないか）を確認する
- 前回の調査で確認済みの`loadProfile()`のコード（`useCompanyStateStore.getState().loadForProfile(profile.id)`を呼ぶ箇所）は、`profile.id`が現在の`currentProfileId`と同じ場合でも問題なく再実行されるかを確認する

### 2.3 「上書き保存」ボタン押下後の内部状態確認

- 「上書き保存」を押した後、`currentProfileId`や関連するstateが、次回の同一プロファイル読込判定に影響するような形で変化していないか確認する（例：保存後にIDが不整合になる、保存操作自体が誤って「読込」と同じ扱いをされてしまっている等）

### 2.4 再現テストの実施

以下の手順を、安全なテスト用データで実施し、それぞれの結果を報告する：

1. プロファイルCを新規作成し、1節のデータで事業タイムライン・法人ポートフォリオ①現在を入力
2. 「上書き保存」を押す
3. 事業タイムラインのイベントを1件追加、または法人ポートフォリオの残高を変更する（保存しない）
4. プロファイル一覧で、**現在アクティブなプロファイルC自身**の「読込」をクリックする
5. 画面の値が、手順2で保存した値に戻るか、それとも手順3の未保存の編集のままかを確認する
6. 上記4の際、確認ダイアログ（上書き確認等）が表示されるかどうかも合わせて記録する
7. 比較のため、手順3の後に**別プロファイルDを新規作成してから、改めてプロファイルCを読込む**（＝直接同一プロファイルを選ぶのではなく、一度別プロファイルを経由する）パターンも試し、結果が変わるかを確認する
