# 実装指示:resident-tax-timing 前提条件のUI明示(フェーズ0・文言追加のみ、計算ロジック変更なし)

## 重要な確認事項(着手前に必ず確認すること)
本指示は「フェーズ0」であり、**文言(UIコピー)の追加のみ**を対象とする。
`residentTaxTiming.ts` 内の計算式・型定義・数値は一切変更しないこと。
社会保険料控除・調整控除の追加は別途「フェーズ1(調査)」「フェーズ2(実装)」で扱うため、
**本指示では絶対に着手しないこと**(スコープ外)。

着手前に、直近のP0/P1修正(`impl_resident_tax_timing_final_fixes.md`)およびUIコピー改善
(`impl_resident_tax_timing_ui_copy.md`)がいずれも実装済みであることを、現在のソースコードを
確認した上で前提とすること。もし未実装の箇所があれば、作業前に報告すること。

## 背景
本ツールの現在の計算モデルは「給与所得のみ・独身・扶養家族なし」を暗黙の前提としており、
社会保険料控除・扶養控除等の人的控除・給与以外の所得を考慮していない。この前提が
どこにも明示されていなかったため、ユーザーが誤解する可能性がある(特に「年収」の
定義や、非課税の給付を収入欄に入力してしまうリスク)。フェーズ1・2で計算精度を
改善する前に、まず現状の前提を正直に開示する。

- 「退職前年の年収」ラベルを「退職前年の年収(額面・税込)」に変更

  ふるさと納税・住宅ローン控除等を利用している場合は、実際の税額と異なります。」
