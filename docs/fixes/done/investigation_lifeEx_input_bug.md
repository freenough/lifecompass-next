# 調査専用指示書:余命(lifeEx)入力欄がBackspace/Deleteで削除できないバグ

**ロックファイル(`simulate.ts`・`analyze.ts`・`montecarlo.ts`)は変更禁止・読むだけ。**
今回は調査のみ。原因が明確かつ軽微な修正で直せる場合は、その場で修正しても
構わないが、修正した場合は必ずdiffを完了報告に含めること。判断に迷う場合は
修正せず、原因の報告のみに留めること。

## 背景

MC設定またはプロフィール設定画面の「余命」(lifeEx)入力欄で、既存の値(90)を
Backspace/Deleteキーで削除しようとしても消えず、新しい値(95等)を手入力
できない不具合が発生している。他の数値入力欄(PF画面の金額・%入力等)は
`stripLeadingZero`・`clearZeroOrSelect`(`src/lib/numberInput.ts`)という
共通ヘルパーを使っており、フォーカス時に値を選択状態にする・先頭ゼロを
除去する、といった処理が入っている。lifeEx入力欄がこれと同じパターンを
使っているか、それとも別の実装(例:`valueAsNumber`がNaNになった際に
即座に前の値へフォールバックしてしまう等)になっていないか確認してほしい。

## 再現条件(KENZOさんが特定済み・重要な手がかり)

- **現在年齢(curAge)と退職年齢(retAge)が両方0のとき**:lifeEx欄は正常に
  動作する(95を入力できる、Backspace/Deleteで削除できる)
- **現在年齢・退職年齢に値が設定されているとき**:lifeEx欄の値(例:90)を
  手入力で更新できなくなる

この条件から、**lifeExの入力ハンドラ自体よりも、curAge/retAgeの値を参照して
lifeExを自動補正・クランプする副作用(useEffect等)が存在し、それが
curAge/retAgeが非ゼロのときにだけ発動して、ユーザーの入力中の値を
勝手に元へ戻している**可能性が高いです。調査項目2・3に加えて、この
「curAge/retAge依存の自動補正ロジック」の有無を最優先で確認してください。

## 調査項目

1. **lifeEx入力欄のコンポーネント・イベントハンドラを特定してください。**
   (おそらく`SimulatorForm.tsx`または類似のフォームコンポーネント内)
   あわせて、同じコンポーネント・親コンポーネント内に、curAge/retAgeの
   変更を検知してlifeExの値を書き換える`useEffect`・バリデーション関数・
   `Math.max(lifeEx, retAge)`のようなクランプ処理がないか、必ず確認して
   ください。

2. **`onChange`ハンドラの実装を確認してください。** 特に、入力欄が空文字に
   なった瞬間(`e.target.valueAsNumber`が`NaN`になる瞬間)に、どう処理して
   いるか:
   - `isNaN(n) ? 90 : n`のように、NaNのときに即座に固定値やstate上の
     直前の値へフォールバックしていないか(この場合、空にした瞬間に
     Reactが値を90に戻してしまい、ユーザーからは「消せない」ように
     見える)
   - 他の数値入力欄(`clearZeroOrSelect`・`stripLeadingZero`を使っている
     箇所)との実装の違いを比較してください

3. **`onFocus`/`onClick`ハンドラの有無を確認してください。** 他の入力欄と
   同様に、フォーカス時に値を全選択状態にする処理(`clearZeroOrSelect`)が
   lifeEx欄に適用されているか、されていない場合それが原因になりうるか
   確認してください

4. **原因が特定でき、他の数値入力欄と同じ共通ヘルパー(`stripLeadingZero`・
   `clearZeroOrSelect`)を適用するだけで直る軽微な修正であれば、その場で
   修正して構いません。** その場合、他の入力欄と挙動を統一する形にして
   ください。原因がより複雑(例:バリデーション処理と密結合している等)な
   場合は、修正せず原因のみ報告してください。

## 影響範囲の確認(修正した場合)

- `full-verify.js`を実行し、全PASSを確認すること
- `tsc --noEmit`がクリーンであることを確認すること
- 他のUI項目(lifeEx以外の数値入力欄)の挙動に影響を与えていないか、
  該当コンポーネントの他のprops・他の入力欄への波及がないか確認すること
