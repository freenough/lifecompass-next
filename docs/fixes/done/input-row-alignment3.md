# 修正指示: input-row-alignment2(前回修正の残課題)

前回 input-row-alignment1 完了後のスクリーンショット確認で、以下3件の残課題が見つかった。
いずれもバグ修正扱い(即実装可)。

## 前提

- `src/components/simulator/formLayout.ts` の `UNIT_WIDTH_CLASS` は維持する
- タイムライン(LifeEventTimeline)とField系の26pxオフセットは**修正対象外**(前回GOで確定済みの構造による意図的な差)

---

## 修正1: 集計行(年間支出合計・年間余剰CF・総資産合計)の単位spanに固定幅が効いていない

**症状:** この3行だけ、ボックス幅は他行と同じだが、クラスタ全体(ボックス+単位)が右にずれて凸凹に見える。単位の右端が他行より右に出ている。

**原因(仮説):** 前回「DisplayFieldの単位spanをUNIT_WIDTH_CLASS化した」と報告されたが、レンダリング結果には反映されていない。この3行は集計行のため、**DisplayFieldコンポーネントを経由せず別の場所で直書きされている**可能性が高い。単位spanが固定幅なし(文字幅そのまま)のため、右寄せレイアウトでクラスタごと右に詰まっている。

**修正:**
1. まずブラウザのDevToolsで実際のDOMを確認し、この3行がどのコンポーネント/マークアップからレンダリングされているか特定して報告に含める
2. 該当箇所の単位spanをField系と完全に同一のクラス(`UNIT_WIDTH_CLASS` + `shrink-0` + `text-left`)にする。直書き箇所が複数あるなら、可能であればDisplayField(または共通の行コンポーネント)に寄せて一本化する
3. 修正後、**ソースコードではなくレンダリング結果(computed style / 実測px)**で単位spanの幅=56pxと右端位置の一致を確認する

---

## 修正2: RateField/MC設定のトグルはみ出し解消(トグルを入力欄の左に移動)

**症状:** 利回り設定・MC設定の行で、トグルがカードの右枠線からはみ出している(デスクトップ・モバイル両方)。

**原因:** クラスタ末尾にトグル(32px)を追加したため、右端が単位列より32px外側になり、ネストしたカードのパディング内に収まっていない。

**修正:**
1. RateField系の行構成を `[ラベル][トグル][入力欄][%単位]` の順に変更する(トグルをラベルと入力欄の間に置く)
2. これにより全行の不変条件を「**右端は常に単位列(UNIT_WIDTH_CLASS)で終わる**」に統一する
3. 入力欄幅はField系の入力欄と同じ幅に統一する(w-[60px]は廃止)。あわせて `formLayout.ts` に `INPUT_WIDTH_CLASS` を定数化し、Field/RateField双方で共有する
4. トグルOFF時の入力欄グレーアウト挙動は維持
5. 「取崩期は積立期と同じ〜を使う」チェックボックス行のレイアウトは変更しない

**注意:** トグル移動後、ラベルが長い行(積立期σ等)でトグルと重ならないか、モバイル375pxで確認すること。重なる場合は報告して指示を仰ぐ(勝手にラベルを省略しない)。
