# 実装指示書: デザインシステム第2弾(青ハイライト拡大・比較表縦線修正)

## 位置づけ

前回の第1弾実装後、実機スクリーンショットを8ツール分並べて確認した結果、2つの見た目の問題が見つかった。この指示書に従って修正してください。

## 背景・方針転換

前回の指示書(`IMPLEMENTATION_design-system-7tools-phase1.md`)では「青ハイライトは比較表を持つツール(pension-timing・prepay-vs-invest)のメイン数値のみに適用し、単純な結果表示ツールへの適用はスコープ外」としていました。しかし8ツールのスクリーンショットを並べて見た結果、実際には`prepay-vs-invest`と`ideco-withdrawal`だけが青く、残り6ツールは素のテキストのままで、一貫性のなさの方が問題になっていました。この方針を転換し、**全8ツールの主役数値に青ハイライトを統一適用します。**

## 1. 青ハイライトの全ツール適用

以下の各ツールのResultコンポーネントで、「そのツールの一番見てほしい数値」を、既存の`ideco-withdrawal`/`education-cost`/`prepay-vs-invest`と同一の配色で囲んでください:

```
border: border-accent (#334155)
background: bg-blue-50 (Tailwindデフォルト #eff6ff、globals.cssオーバーライドなし)
数値テキスト: text-slate-800 (青ではなくグレー、太字)
```

**対象ファイルと数値:**

| ファイル | 対象数値 |
|---|---|
| `CompoundInterestResult.tsx` | 「20年後の資産(概算)」の金額(スクリーンショット例: 3,968万円) |
| `MonthlyInvestmentResult.tsx` | 「毎月の積立額(概算)」の金額(例: 6.9万円) |
| `FireAgeResult.tsx` | 「目標資産到達年齢」の年齢(例: 47歳) |
| `PensionTimingResult.tsx` | 「{targetAge}歳受給での年額」の金額(例: 281万円/年) |
| `RetirementTaxResult.tsx` | 「手取り額」の金額(例: 2,676万円) |
| `EducationCostResult.tsx` | 「教育費総額」の金額(例: 991万円)。隣の「ピーク時の年間負担額」カードは補助数値のため対象外、現状の`bg-slate-50`系スタイルのまま変更しない |

**変更しないもの:**
- 各ツール下部の「利回り別の将来評価額」「受給開始年齢別の比較」等のテーブル(選択行のaccentハイライトはそのまま維持)
- `ideco-withdrawal`(既に実装済み)・`prepay-vs-invest`(既に実装済み)は変更不要
- `pension-timing`の受給開始年齢別テーブルの選択行ハイライト(前回`PensionTimingComparisonTable.tsx`で「構造的に不一致のため変更しない」と判断済みの箇所)は今回も変更しない

**注意:** 新規の色・トークンは追加しない。既存3ツールと完全に同じクラスの組み合わせを流用するだけの機械的な適用とすること。

## 2. `PrepayVsInvestComparisonTable.tsx`の縦線の非対称を修正

前回実装で、比較表の`投資`列にのみ`border-l border-border`が付き、`繰上返済`列(1列目)には付いていなかったため、投資列だけが縦線で区切られ、繰上返済列がラベル列と地続きに見える非対称な見た目になっています。

**修正内容:** `繰上返済`列(ヘッダー`<th>`および全ての`<tbody>`データセル)にも、`投資`列と同じ`border-l border-border`を追加してください。これにより「ラベル列 | 繰上返済列 | 投資列」の3列が均等な縦線で区切られます。

ヘッダー行・データ行の両方に漏れなく適用すること(ヘッダーだけ直してデータ行が非対称のまま、という状態にならないよう確認)。
