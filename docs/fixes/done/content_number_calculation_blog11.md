# 数値算出指示書:11本目ブログ記事(年金繰上げ・繰下げ)

対象:H2-3(検証パート)・H2-5(比較グラフ)で使用する数値の算出

**厳守事項:すべての数値は、`pensionCore.ts`の`calcPensionAmountAtAge()`・
`calcBreakEvenAge()`・`calcCumulativeAmount()`、および本体シミュレーターの
`simulate()`/`analyze()`を直接importして算出すること。独自の再実装・
手計算は一切行わないこと。完了報告には、各数値についてどちらの経路
(pensionCore経由/simulate・analyze経由)で算出したかを明記すること。**

---

## 1. H2-3(検証パート):年金タイミングツールでの試算

### 入力パラメータ(共通)

- 老齢基礎年金:78万円/年
- 老齢厚生年金:120万円/年
- 生年月日区分:新率(1962年4月2日以降生まれ)
- 比較終了年齢:90歳

### 算出する受給開始年齢パターン

60歳・65歳(基準)・70歳・75歳の4パターンそれぞれについて:

- `calcPensionAmountAtAge()`による年額
- 65歳受給との差額(±◯◯万円/年)・差額率(±◯◯%)
- `calcBreakEvenAge()`による65歳受給との損益分岐年齢
  (60歳・70歳・75歳のそれぞれについて、65歳との比較で算出。
  比較終了年齢90歳以内に損益分岐が見つからない場合は、その旨を報告すること)
- `calcCumulativeAmount()`による、比較終了年齢(90歳)時点の累計受給額

## 2. H2-5(比較グラフ):本体シミュレーターでの資産推移比較

### 目的

「65歳受給(標準)」と「60歳繰上げ受給+退職後収支黒字運用トグルON」の
資産推移を比較するグラフを記事に掲載するための数値を取得する。

### 世帯設定(共通・両プロファイル同一)

- 単身(配偶者なし。按分ロジックの説明を記事に持ち込まないため、
  あえてシンプルな単身世帯とする)
- 退職年齢:60歳
- 年間生活費:**120万円/年**(確定値。この額は現実の生活費としてはやや
  低めだが、Bプロファイル[60歳繰上げ受給、年金額約150万円/年]で黒字を
  発生させ、再投資トグルの効果を検証可能にするための便宜的な設定である
  旨を、記事本文に明記すること。「実際の生活費とは異なる、検証用の設定」
  という注記を、H2-5冒頭またはグラフ直下に必ず入れる)
- 初期資産:退職時点(60歳)で特定口座**3,000万円**のみ保有(NISA・iDeCoは
  簡略化のため0円とする。この機能がNISA/iDeCoに触れない設計であることを
  記事内でも示しやすくするため。生活費120万円/年に対し、両プロファイルとも
  年金額[A:198万円、B:約150万円]がこれを上回るため枯渇の懸念はほぼないが、
  Aプロファイルの60〜64歳の年金空白期間[5年分、約600万円の取り崩しが
  発生しうる]をカバーできる水準として3,000万円とする)
- 想定運用利回り:シミュレーターの標準期待リターン設定をそのまま使用
  (記事独自の利回り設定はしない)
- モンテカルロ:MCオフ(固定利回りによる決定論的な1本のパス)を使用

### 想定される挙動(参考・実測で確認すること)

- Bプロファイル(60歳受給、年金額約150万円/年)は当初、生活費120万円/年
  との差額(黒字約30万円/年)が再投資トグルにより特定口座で運用される
- インフレにより生活費が徐々に上昇するため、数年後には黒字が赤字に転じ、
  その時点で再投資は自動的に停止し、通常の取り崩しに移行するはずである
  (これは仕様上の想定であり、実測値で実際にそうなるかを確認すること)
- 記事本文では、この「初期数年間だけ再投資が発動し、その後は通常の取り崩しに
  移行する」という挙動を正直に書く(「ずっと黒字が続く」かのような
  誤解を与える書き方は避ける)

### プロファイルA(基準:65歳受給)

- 年金受給開始:65歳
- 年金受給額:198万円/年(基礎78万+厚生120万、`penAmtVal`欄への入力値)
- 退職後収支黒字運用トグル:OFF

### プロファイルB(繰上げ+運用:60歳受給)

- 年金受給開始:60歳
- 年金受給額:H2-3で算出した「60歳受給時の年額」(`calcPensionAmountAtAge()`
  の結果をそのまま`penAmtVal`欄へ転記した値。記事の手順(方式B)と完全に
  一致させること)
- 退職後収支黒字運用トグル:ON

### 取得するデータ

- 両プロファイルについて、60歳〜90歳の年次総資産額(グラフ用の時系列データ)
- 90歳時点の総資産の差額(±◯◯万円、±◯◯%)
- プロファイルAで60〜64歳の間(年金未受給期間)に取り崩しが発生しているか
  どうか(記事内で「繰上げ受給は空白期間の取り崩しを避けられる」という
  補足に使えるかもしれないため、参考情報として取得)
