## Phase 2-0:調査(実装前に必ず実施)

### 既存ツールの配色コードを確認

iDeCo/DC出口戦略シミュレーターの「選択中ボタン」「結果カードの枠線強調」で使われている正確な色コードを確認する(これまでのモック検討では画像からの目視推定で`#1E293B`前後のスレート系濃紺を使っていたが、実際のTailwindクラス名・CSS変数を確認して正確な値に置き換えること)。

```bash
grep -rn "bg-slate\|bg-\[#\|border-slate" src/app/asset-simulator/tools/ideco-withdrawal --include="*.tsx"
```

該当箇所が見つからない場合、共通コンポーネント(`src/components/tools/`配下等、ボタン・カードが共通化されている可能性)も確認すること。

**報告してほしい内容:**
- 選択中ボタンの背景色(Tailwindクラス名 or 実際のカラーコード)
- 強調カードの枠線色・太さ
- 上記が独自のCSS変数として定義されている場合、その変数名(今後の全ツール展開時の一貫性のため、変数を使い回せるなら使い回す)

**この値が確定するまで、2-2(ボタン)・2-4(結果カード)の色指定は着手しないこと。**

## Phase 2-1:入力UI全体構成

### タブ形式(子供1〜3人)

- 初期表示は「子供1」タブのみ。「+子供を追加」ボタン(タブ列の右端、破線ボーダー)で子供2・3のタブを追加(最大3人)
- 未入力のタブには「未入力」バッジ(warning系の色、既存の`--bg-warning`/`--text-warning`トークンを使用)を表示
- 入力済みタブには金額のミニプレビューを表示(例:タブ内に小さく「約1,200万円」等)
- 結果表示エリア上部に「現在◯人分で計算中」の一文を常時表示する

### 子供1人あたりの入力ブロック

1. **現在の学年**:セレクトボックス(未就学児・幼稚園年少〜年長・小1〜小6・中1〜中3・高1〜高3・大学1〜4年)
2. **ステージ別 公立/私立トグル**:幼稚園・小学校・中学校・高校の4ステージは「公立/私立」の2択トグルボタン(横並び、選択中を塗り、非選択を白背景+ボーダーのみ)
3. **大学**:セレクトボックス(国公立/私立文系/私立理系の3択)
4. **仕送り(一人暮らし)のオプトイン**:大学ステージの選択欄の下に「一人暮らしになる予定ですか?」のトグルスイッチ(デフォルトOFF)。ONにすると月額仕送り入力欄(プリセット8万円/月、編集可能)が表示される

## Phase 2-2:ステージ別トグルボタンのスタイル

- 2択ボタンを1つの角丸コンテナで囲み、内部で左右に分割(境界線のみ、外枠は`0.5px solid var(--border)`)
- **選択中:Phase 2-0で確認した既存ツールの色をそのまま適用**(暫定値:背景`#1E293B`系、文字色白)
- 非選択:背景は`var(--surface-2)`(白)、文字色`var(--text-secondary)`
- ボタンの角丸は左端・右端のみ(中央の境界線部分は角丸なし)

## Phase 2-3:結果表示エリア

- 2カラムのメトリックカード:「教育費総額」「ピーク時の年間負担額(◯年後)」
- **注目カード(総額、または一番伝えたい数値)のみ、Phase 2-0で確認した既存ツールの強調枠線色を適用**(暫定値:`1.5px solid #1E293B`系)。もう一方のカードは通常の`0.5px solid var(--border)`
- カード背景は`var(--surface-2)`(白)で統一。既存ツールがカード背景に別の色(グレー系など)を使っている場合はPhase 2-0の調査結果に合わせる

## Phase 2-4:年次推移グラフ

**使用ライブラリ:Recharts**(プロジェクト既存のグラフライブラリ。フェーズ2-0のモック検討ではChart.jsを使ったが、これは検討用の簡易モックであり、本番実装は既存スタックに合わせてRechartsで統一すること)。

- 積み上げ棒グラフ(`BarChart`+`Bar stackId`)、子供ごとに1系列
- 系列カラー:子供1=`#5DA9E0`(青)、子供2=`#173F5F`(紺)、子供3が存在する場合は薄いグレー系を追加(既存ツールのグラフ配色との整合は不要。こちらはFREENOUGHブランドの青・紺・薄いグレー系でまとめる方針。Phase 2-0で確認した「ボタン・カードの配色」とは別軸の決定であり、混同しないこと)
- **複数の子供の年次費用が重複する期間を、`ReferenceArea`で背景に薄いグレー〜紺系の帯として動的にハイライトする**
  - 重複期間はハードコードせず、各子供の年次配列を比較し「2人以上の子供で費用が発生している年」を実データから動的に検出するロジックを`educationCostCalc.ts`側に追加するか、UI側で算出するかは実装しやすい方で判断すること
  - 帯の色:`rgba(23,63,95,0.10)`程度(紺の10%程度の半透明)
- Y軸ラベルは「◯万円」表記
- 凡例はグラフ下に小さいカラースウォッチ+ラベルで独自実装(Rechartsのデフォルト凡例ではなく、既存ツールのグラフ凡例スタイルがあればそれに合わせる)

## Phase 2-5:入力項目数・原則の遵守

- 「30秒で完結」「1画面完結・リアルタイム計算」の既存Tools共通原則を守ること(送信ボタンなし、入力変更のたびに即座に再計算)
- 4人目以降の子供は非対応。3人目のタブの下に軽い注記(「4人目以降のお子さんがいる場合は、本格シミュレーターのライフイベント機能で個別に追加できます」)+本格シミュレーターへのリンクを表示

## 実装後の確認事項

- iPhone SE幅(375px)でタブ・トグルボタン・グラフが崩れずに表示されるか
- 子供2・3を追加した際、未入力バッジ・ミニプレビューが正しく機能するか
- グラフの重複期間ハイライトが、実際に複数パターンの入力(子供の年齢差を変えるなど)で正しく動的に追従するか
- 既存ツールの配色(ボタン・カード)と実際に並べて見比べ、統一感があるか
- 完了報告時は、変更・新規作成したコンポーネント名を明記すること(行番号は使用しない)
