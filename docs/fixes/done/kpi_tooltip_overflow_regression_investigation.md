# 【調査のみ】KPIカードのツールチップが画面右端ではみ出す問題の再発調査

## 背景

KPIカードの「?」アイコンにマウスオーバー(またはタップ)すると表示されるツールチップの吹き出しが、画面右端に近いカードで右側が切れてしまう問題が再発している。過去に一度修正されたはずだが、直近のKPIカード再設計(トップ4枚+詳細アコーディオン4枚への再構成)以降、再び発生している。

添付スクリーンショットでは、詳細指標アコーディオンの一番右のカード(「年金開始までの年数」)のツールチップが、画面右端で切れて表示されている。

## 調査してほしいこと

1. **過去の修正内容の確認**: 以前このツールチップのはみ出しを修正した際のコード(git履歴・コミットログ等から遡れれば)を確認し、どのようなロジック(画面端検出・位置反転など)で対応していたかを特定する
2. **再発の原因**: 直近のKPIカード再設計(`KpiGrid.tsx`の構造変更、詳細アコーディオンの新設)によって、以下のいずれかが起きていないか確認する
   - ツールチップの位置計算が、変更前のDOM構造・親要素のサイズを前提にしたロジックのままになっていて、新しいグリッド構造(特に4列グリッドで一番右端に来るカード)に対応できていない
   - 親要素に`overflow: hidden`などが新たに追加され、ツールチップがクリップされている
   - ツールチップのコンポーネント自体は変わっていないが、呼び出し側(KPIカードの配置)が変わったことで、画面端検出の基準(ビューポート幅、親要素の位置)がズレている
3. **該当コードの特定**: ツールチップ表示ロジックのコンポーネント名・ファイルパスを特定する(共通コンポーネントであれば、通常のKPIカードと詳細アコーディオンの両方で同じコンポーネントを使っているはずなので、なぜ詳細アコーディオンの右端カードでのみ問題が起きるのかも合わせて確認する)

## 期待するレポート形式

- ツールチップのはみ出し防止ロジックが元々どのように実装されていたか
- 再発の具体的な原因(構造変更のどの部分が影響したか)
- 修正方針の選択肢(概要レベルで良い。実装はまだ不要)

コード変更は不要です。レポートのみお願いします。
