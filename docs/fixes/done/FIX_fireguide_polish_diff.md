## 差分2:LP全体の背景色(交互配置)の調整

FIREガイドセクションを挟んだことで、既存の白/薄いグレーの交互配置が崩れている。
**「FIREガイド」と「あなたはどのタイプ?」の背景色クラスを入れ替える**(それ以外のセクションは変更不要)。

| セクション | 現状 | 変更後 |

| FIREガイド | 白 | **薄いグレー**(「あなたはどのタイプ?」で使っているクラスを流用) |

以降のセクション(使い方・シミュレーターを試すブロック・フッター)は元々交互になっているはずなので、この2つの入れ替えだけで全体の整合性が取れる想定。

## 差分3:CTAのビジュアル統一(NOTE誘導ボタン)

「あなたはどのタイプ?」セクション最下部の「→ それぞれのシミュレーション結果をnoteで読む」が、現状Hero部分の「今すぐシミュレーションする→」と同じ**濃紺の背景色ボタン**になっている。

これを、FIREガイドセクションの「記事一覧を見る→」と同じ**太字テキストリンク(背景色なし)**に変更する。

```css
/* 変更前(想定) */
.note-cta-button {
  background: #334155;
  color: white;
  padding: 12px 24px;
  border-radius: 8px;
}

/* 変更後 */
.note-cta-link {
  color: #334155;
  font-weight: 500;
  background: none;
  padding: 0;
}
```

**理由:** 「今すぐシミュレーションする→」をLP上で唯一のプライマリCTAとして視覚的に際立たせるため。NOTE誘導・ブログ一覧誘導はどちらも二次的な導線として同格に扱う。
