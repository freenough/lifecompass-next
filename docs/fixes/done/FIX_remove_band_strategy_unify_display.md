# FIX: bandStrategyを廃止し、グラフの帯をdisplayStrategyに一本化する

## 経緯(重要)

前回の指示書(`FIX_mc_analysis_multi_strategy_layout.md`)で、グラフの帯(p10〜p90)を選ぶための`bandStrategy`という独立した状態と、モンテカルロ分析欄の「グラフのバンド」プルダウンを新設した。

しかし実際の使い方を検討した結果、「バンドだけ表示戦略と別の戦略を見る」という状況自体が、ユーザーにとって積極的に欲しい状態ではないと判断した。バンドだけ別の戦略を見たい場合は、表示戦略(displayStrategy)のラジオ自体をその戦略に切り替えればよく、単一値KPIカードも含めて一貫した状態になるほうが自然である。

そのため、**`bandStrategy`という独立した概念を廃止し、グラフの帯も`displayStrategy`を直接参照する形に戻す。**

## 修正方針(確定・GO)

### 1. AssetChart.tsx

- MCモードの帯(p10〜p90)の参照を、`bandStrategy`から`displayStrategy`に戻す
- グラフ下の注記(「確率的モード・中央値{n}本+{戦略名}のバンド({試行数}試行)」)も`displayStrategy`を参照する

### 2. MonteCarloPanel.tsx

- 「グラフのバンド」プルダウンを削除する
- 戦略ごとの積み上げブロック表示(破綻確率・枯渇年齢・p10/中央値/p90を全戦略分並べる部分)はそのまま維持する(今回削除するのはプルダウンのみ)

### 3. simulatorStore.ts

- `bandStrategy`・`setBandStrategy`、および`setActiveStrategies`内の`bandStrategy`用フォールバックロジックを削除する
- `displayStrategy`側のロジックには影響を与えないこと

### 4. page.tsx(インフォバー文言)

- 「単一値のKPIは『{displayStrategy}』基準。グラフの帯はモンテカルロ分析欄で選択できます。」という文言を、バンドがdisplayStrategyに統合されたことを反映した文言に戻す。例:「単一値のKPI・グラフの帯は『{displayStrategy}』基準。破綻確率の詳細はモンテカルロ分析欄で全戦略を確認できます。」
