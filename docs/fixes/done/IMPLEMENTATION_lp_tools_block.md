# 実装指示:LP「かんたん計算ツール」ブロック追加 + ヘッダーナビ + `/tools`文言修正

## 背景

FREENOUGH Toolsが6個(積立額逆算・目標資産到達年齢・積立複利・年金繰上げ繰下げ・
退職金手取り・iDeCo/DC出口戦略)まで揃ったため、これまでフッターリンクのみだった
ツールへの導線を、LP本体・ヘッダーナビにも追加する。

対象リポジトリ:`lifecompass-next`(本番パス`/asset-simulator`)

---

## タスク1:LPに「かんたん計算ツール」ブロックを新設

### 配置位置

`src/app/page.tsx`(LP本体)内、**「FIREガイド」セクションの直後、「あなたはどのタイプ？」
セクションの直前**に新セクションとして挿入する。

理由:ブログ(FIREガイド)・ツール・note(あなたはどのタイプ)はいずれも
「コンテンツ資産→本格シミュレーターへの誘導」という同じ役割を持つブロック群のため、
連続して配置し一直線のストーリーにする。

### デザイン方針

既存の「FIREガイド」セクションと同じ構造・スタイルを踏襲する:
- 見出し(H2)+ サブコピー(1行)という構成
- カードグリッド(2カラム、レスポンシブでモバイル1カラム)
- セクション末尾に「一覧を見る→」形式のリンク
- カードのアイコンは`/tools`一覧ページで使用しているTabler Iconsをそのまま流用
  (新規アイコンは不要。各ツールで既に使っているものと同一にする)
- 色は既存のブランドカラー(`#334155`系)に統一

### 見出し・サブコピー(確定文言)

```
見出し: かんたん計算ツール
サブコピー: シミュレーターの前に、気になる数字だけサクッと試せます
```

### 掲載する4ツール(確定・この順序で表示)

| # | タイトル | 説明文 | リンク先 |
|---|---|---|---|
| 1 | 積立(複利)計算機 | 毎月の積立額と利回りから、将来の資産額を試算します | `/tools/compound` |
| 2 | 積立額逆算ツール | 目標資産額から、毎月の積立額を逆算します | `/tools/monthly-investment` |
| 3 | 目標資産到達年齢シミュレーター | 今の積立を続けたら、何歳で目標資産に届くかがわかります | `/tools/fire-age` |
| 4 | 年金繰上げ・繰下げ比較シミュレーター | 年金を何歳から受け取るとお得か、損益分岐年齢で比較します | `/tools/pension-timing` |

※ 退職金手取り計算ツール・iDeCo/DC出口戦略シミュレーターの2つはLPには掲載しない
(より専門的な内容のため、`/tools`一覧ページ経由でのみ到達する導線とする)。

### セクション末尾のリンク

```
文言: ツール一覧を見る →
リンク先: /tools
```

(「FIREガイド」セクションの「記事一覧を見る→」と同じスタイル)

### UTM・GA4について

LP内の同一サイト内遷移のため、UTMパラメータは付与不要(ブログ→`/blog`一覧リンクと
同じ扱い)。GA4の新規イベントも不要(各ツール個別ページ側のGA4計測は既存のまま)。
