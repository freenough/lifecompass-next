# LifeCompass 配偶者機能の説明文 追加指示書(methodology・使い方ガイド)

## 背景

配偶者情報(NISA/iDeCo/特定口座/現金の残高・積立、収入・年金、退職年齢等)を
入力できる機能は、今回のUI再編成より前から`simulate.ts`に実装済みだった。
しかし、その挙動がmethodologyページ・使い方ガイドのどちらにも
十分に説明されていない、または説明が不正確なため、両ページに追記する。

**注意**:本指示は文言追加のみであり、`simulate.ts`等の計算ロジックには
一切手を加えない。

---

## 1. methodologyページ(`src/app/methodology/page.tsx`)の修正

### 1-1. 既存の「配偶者口座との合算」段落を差し替え

現在、「資産運用モデル」セクション内に以下の段落がある。

**現状の文言(差し替え対象)**:
> 現在ポートフォリオの金額入力は本人・配偶者の合算値をベースに期待リターン・標準偏差を計算します。配偶者の口座残高はシミュレーション上、本人口座と合算して運用・取崩計算されます。

**差し替え後の文言**:
> 配偶者のNISA・iDeCo・特定口座・現金の残高は、本人の同じ種類の口座と合算した上で、本人が設定したポートフォリオ(期待リターン・標準偏差)で運用されます。配偶者専用の運用方針を別途設定することはできません。取り崩し時も合算後の残高から選択した戦略(比例取崩・現金優先・課税優先)で引き出し、その後は元の残高比率で本人・配偶者に配分し直されます。モンテカルロモードの市場変動も、本人・配偶者で共通の1つの変動として適用されます(口座間の相関を1とみなす設計のため)。
>
> 配偶者の現在年齢・退職年齢・iDeCo受取開始年齢を入力しない場合は、本人と同じ値として計算されます。

### 1-2. 「税金の扱い」セクションへの追記

「退職金」の小見出しの後(または末尾)に、以下を追記する。

> 配偶者の退職金・iDeCo一時金についても、本人と同様に退職所得控除等を適用した手取り額を自動計算します。

## 2. 使い方ガイド(`/guide`ページ)の修正

前回渡した改訂版ガイド内容(`usage_guide_revised.md`)の「② 家計」
セクション末尾、または「③ 資産」セクション末尾に、以下を追記する。
(どちらのカテゴリに追記するのが自然かはページの実装に合わせて判断してよい。
分かりにくければ両方に軽く触れてもよい)

**追記する文言**:
> 配偶者の資産(NISA・iDeCo・特定口座・現金)は、本人の同じ種類の口座と合算され、本人と同じ運用方針で計算されます。配偶者の年齢や退職年齢を入力しない場合は、本人と同じ値として扱われます。

平易な言葉で、細かい計算式(ρ=1、残高比率での配分等)には触れず、
「合算される」「未入力なら本人と同じ扱いになる」という2点が伝われば十分。
