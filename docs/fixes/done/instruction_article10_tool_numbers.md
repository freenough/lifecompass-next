# 指示書:ブログ記事10本目 数値算出(目標資産到達年齢シミュレーター題材)

## 目的

ブログ記事10本目「新NISA、今のペースで積み立てたら何歳で3,000万円に届く?」で
使用する確定数値を、本番ロジックから直接算出する。

**重要:数値は独自再実装スクリプトで算出してはいけない。**
必ず本番の`financeCore.ts`内の関数、および本番の`runMC()`を直接importして
呼び出すこと。実装をコピー・再現・簡略化した別スクリプトでの算出は禁止。

---

## 前提条件(フィクスチャ)

| 項目 | 値 |
|---|---|
| 現在の年齢 | 35歳 |
| 現在の資産額 | 100万円 |
| 毎月の積立額 | 6.89万円 |
| 目標資産額 | 3,000万円 |
| 想定利回り | 3% / 5% / 7%(メインは5%) |

---

## 算出タスク

### タスク1:メイン結果(到達年齢・5%運用)

- 呼び出し関数:`calcAchievementAge()`(`src/lib/financeCore.ts`)
- 引数:現在年齢35、現在資産100万円、毎月積立6.89万円、`annualRatePct=5`、
  目標資産3,000万円
- 出力:到達年齢(floor切り捨て後の値)、到達までの年数
- 呼び出し方法:`fire-age`ツールが実際に呼んでいるのと同じ関数・同じ引数の
  渡し方(`annualRatePct`は%表記のまま渡すこと。0.05のような小数変換は
  Claude Code側で行わない)

### タスク2:感度テーブル(3% / 5% / 7%)

- タスク1と同じ関数を`annualRatePct`=3, 5, 7の3通りで実行
- 各利回りについて「到達年齢」「あと何年で到達するか」を出力
- 記事本文中の感度テーブルにそのまま転記できる形式(表形式)でまとめる

### タスク3:モンテカルロでの到達確率・分布

- 呼び出し関数:本番`runMC()`(9記事目で使用したものと同一の呼び出し経路)
- 同じ前提条件(35歳・100万円・毎月6.89万円・5%運用)で試行
- 出力:
  - 到達年齢時点(タスク1で求めた年齢)での資産分布の目安
    (中央値・25パーセンタイル・75パーセンタイル程度)
  - その年齢時点で目標資産に到達している試行の割合(到達確率)
- 9記事目で同種の数値を出した際の呼び出しコード・パラメータ設定を流用できる
  場合はそれに合わせること(数値の算出条件を記事間で不用意にブラすと
  読者から見た整合性が崩れるため)

---

## 出力形式

以下のいずれかで提出:

1. 実機ブラウザでの`fire-age`ツール実行結果のスクリーンショット・CSVエクスポート、
   および同ツールを使ったモンテカルロ結果のエクスポート
2. 本番関数を直接importするNode/ts-nodeスクリプトの実行結果(スクリプト自体は
   本番コードをimportするだけの薄いラッパーであり、ロジックを一切含まないこと)

いずれの方法でも構わないが、**どちらの方法で算出したかを完了報告に明記**すること。
