# 実装指示書:積立(複利)計算機 フェーズ3(CTA文言・UTM・GA4)

## 前提

フェーズ1(finance-core)・フェーズ2(UI実装)完了済み。本フェーズでCTA文言・
UTM・GA4計測を実装し、公開可能な状態に仕上げる。

## 対応1:CTA文言・構成(訂正版)

**訂正:** 当初この指示書では「本格シミュレーター」「NISA関連コンテンツ」の
2種類のCTAブロックを設置する想定で記述していたが、これは誤りだった。
実際のfire-age・monthly-investmentの本番画面を確認したところ、構成は
以下の通り(画像で確認済み):

- **主CTAは1つのみ**:本格シミュレーターへの誘導ボタン
- その直下に、既存の`AffiliateLink.tsx`による**[PR]アフィリエイトリンクを
  1行で設置**(fire-ageでは「[PR] NISA口座開設先の一例として、松井証券の
  情報はこちら」)
- 「NISA関連コンテンツへのCTA」という独立したブロックや、ブログ記事への
  内部リンクは存在しない。`tool_to_nisa_cta_click`イベントは、この
  **アフィリエイトリンク自体のクリック**に紐づいている

本ツールも**fire-age・monthly-investmentと完全に同一の構成**とする。
ブログ記事リンクへの置き換え・3つ目のCTAの追加はいずれも不要。

**本格シミュレーターへのCTA文言:**
> 「この試算はシンプルな複利計算のみです。税金・NISA枠上限・取り崩し後の
> 資産寿命まで含めて確認したい方は本格シミュレーターへ」

**アフィリエイトリンク:**
- `AffiliateLink.tsx`を第1弾・第2弾と同一の形でそのまま再利用し、
  本格シミュレーターCTAボタンの直下に設置する
- リンク先・文言(松井証券のNISA口座開設)は既存2ツールと同一のものを流用する

## 対応2:UTM

- `utm_source=tools&utm_medium=referral&utm_campaign=compound_interest_tool`
- 第1弾(`monthly_investment_tool`)・第2弾(`fire_age_tool`)と同じ命名規則
  (`{tool_name}_tool`)に統一

## 対応3:GA4イベント

第1弾・第2弾と**完全同一のパラメータ構造**で実装する(イベント設計を分岐
させない方針を踏襲。ChatGPTが第2弾時に提案した`result`パラメータ統合案は
不採用とした経緯があるため、本ツールでも同様の統合・簡略化提案は採用しない):

- `tool_calculate`
- `tool_to_simulator_cta_click`
- `tool_to_nisa_cta_click`

## 対応4:疎通確認

- UTM付きURLへの実遷移確認
