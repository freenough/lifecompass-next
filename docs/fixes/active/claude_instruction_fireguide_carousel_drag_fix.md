# 実装指示：FIREガイドカルーセルのドラッグスクロール — ネイティブ画像ドラッグとの競合修正

作成日：2026-09-21
種別：**実装（バグ修正）**
関連：`claude_instruction_fireguide_carousel_arrows_drag.md`（今回のバグ修正対象。同じ`feature/lp-visual-refresh`ブランチ上での作業）

---

## 背景

矢印ボタン＋ドラッグスクロールの実装後、実機（PC）で確認したところ、カード列をクリック&ドラッグしようとすると、**ブラウザ標準の画像ドラッグ機能（サムネイル画像が半透明の状態でカーソルについてくる挙動）が同時に発生し**、操作感が悪くなっている。

原因：`<img>`要素（`next/image`が出力するものを含む）はブラウザのデフォルトで`draggable`が有効になっており、`mousedown`→`mousemove`で実装した独自のドラッグスクロールと、ブラウザ標準の画像ドラッグ（`dragstart`イベント）が同時に発生してしまっている。前回の指示書では`mousemove`ハンドラ内でのみ`preventDefault()`していたが、`dragstart`イベント自体を止める処理が漏れていた。

---

## 1. ネイティブ画像ドラッグの無効化

以下のいずれか、または両方を実装すること（両方実装する方が確実）：

**① CSSでの無効化**（カルーセル内のサムネイル画像に適用）：
```css
.fireguide-card img {
  -webkit-user-drag: none;
  user-drag: none;
  user-select: none;
}
```

**② `dragstart`イベントを明示的に止める**（カルーセルのトラック要素に対して）：
```js
track.addEventListener('dragstart', (e) => {
  e.preventDefault();
});
```

- 既存の`next/image`（`<Image>`コンポーネント）に`draggable={false}`propを渡せる場合は、それも合わせて設定してよい（CSSでの無効化と併用で問題ない）
- カード全体のテキスト選択（ドラッグ中に文字が青く選択されてしまう挙動）も併せて防ぐため、トラック要素またはカード全体に`user-select: none`を適用すること

---

## 2. 修正後の確認事項

- カード列をクリック&ドラッグした際に、画像の半透明ゴーストが一切表示されないこと
- ドラッグ中のスクロールが滑らかに追従すること（ネイティブドラッグとの競合が解消されたことでカクつきが無くなっているか）
- ドラッグ中にカード内のテキストが選択状態（青ハイライト）にならないこと
- 前回指示書で実装済みの「クリックとドラッグの区別」（5px閾値判定）が今回の修正後も正しく機能していること（誤遷移・通常クリックの遷移、双方を再確認）
- 矢印ボタンのクリック動作、モバイルでのスワイプ動作に影響が出ていないこと
