## 2. `react-peeps`導入の実現可能性確認

- `npm install react-peeps`を検証環境で試し、依存関係の衝突がないか確認すること(peer dependencyの警告等があれば報告に含める)
- react-peepsは`Peep`コンポーネントを`body`・`hair`・`face`・`facialHair`・`accessory`・`strokeColor`・`backgroundColor`・`viewBox`のpropsで描画する。Next.jsのServer Component内では使えない可能性がある(React hooksを使用しているため)ため、Client Componentとして切り出す必要があるかを確認すること
- ビルド時に静的SVG/PNGとして生成しリポジトリに配置する方式と、実行時にコンポーネントとして描画する方式の両方が考えられる。どちらが実装・保守コストの観点で妥当か、所感を報告に含めること(判断はこの調査結果を見てから別途行う)

## 3. 円形フレームでのクロップ位置の実機検証(重要)

上記のパーツ組み合わせ(田中さんの組み合わせ)を実際にレンダリングし、72px程度の円形フレームに収めた際に**頭部から肩までが正しく収まり、下半分が不自然に見切れないこと**を、実機のスクリーンショットで確認すること。

- `Peep`コンポーネントの`viewBox`をデフォルト(`{x:0, y:0, width:850, height:1200}`)のまま使うと全身が描画され、顔が小さくなりすぎる可能性が高い。`viewBox`の`height`を絞る、または`overflow`+`transform`で調整するなど、複数のアプローチを試し、実際にブラウザでレンダリングした結果をスクリーンショットで比較すること
- 最終的に「これなら崩れない」という具体的な数値(`viewBox`の値、CSSの`object-position`/`transform: scale`の値など)を報告に含めること。この数値は次の実装指示でそのまま使う想定
