# 調査指示:e-Gov所得税法XMLからの別表第五抽出可否検証(調査のみ・実装しない)

## 背景
「退職後の住民税キャッシュフロー試算ツール」(resident-tax-timing)第1段階の完了報告で、
給与所得控除の計算に速算表による近似(660万円未満)を用いていることが判明した。
国税庁No.1410によれば、給与収入660万円未満の場合は速算表ではなく「所得税法別表第五
(年末調整等のための給与所得控除後の給与等の金額の表)」を用いるのが正式ルールである。

e-Gov法令検索の現行「所得税法」ページにXML形式のダウンロードが用意されており、
別表第五も同法の収録範囲に含まれることを確認済み。
本指示は、このXMLから別表第五を機械的に抽出し、静的なテーブルデータとして
実装利用できるかを検証するための調査タスクである。

**本指示は調査のみを目的とする。ツール本体のコード変更・新規実装は一切行わないこと。
ただし、抽出検証用の一時スクリプト・データファイルの作成は許可する(下記「作業場所」参照)。**

## 作業場所
- 検証用スクリプト・中間データは `docs/fixes/active/betsuhyo5-extraction/` 配下に作成すること
  (このディレクトリ自体は今回新規作成してよい。`docs/fixes/active/` 直下は削除しないこと)
- ツール本体のソースコード(`src/`配下)には一切手を加えないこと

## 調査対象

### 1. XML取得・構造確認
- e-Gov法令検索「所得税法(現行)」ページ(https://laws.e-gov.go.jp/law/340AC0000000033)からXMLを取得する
- 取得したXML内で「別表第五」に該当するノードを特定し、その構造(タグ構成、表形式かテキスト形式か、セル結合の有無)を報告すること

### 2. 施行日バージョンの確認(最重要)
- XML内に、別表第五の**複数の施行日バージョンが併存していないか**を確認すること
  (令和7年12月1日施行の改正により、給与所得控除の最低保障額が55万円→65万円に変更されているため、
  新旧どちらの版が収録されているか、あるいは新版のみかを必ず確認する)
- 併存している場合、**令和7年12月1日以降施行版のみ**を対象として抽出できるかを確認し、
  新旧の見分け方(施行日属性・附則の記載等)を報告すること
- 併存していない(現行版=最新版のみ)場合は、その旨と根拠を報告すること

### 3. 全行抽出の可否
- 別表第五の全行(収入金額の区分ごとの給与所得金額)をプログラムで抽出できるかを検証すること
- 抽出した行数を報告すること(概算ではなく実際の行数)
- 抽出データの先頭数行・末尾数行をサンプルとして報告書に含めること

### 4. 抽出データの精度照合
- 抽出したテーブルの中から、以下の代表的な収入額における給与所得金額を、
  国税庁No.1410ページの記載内容および公知の給与所得早見表と突き合わせて一致を確認すること:
  - 190万円、300万円、360万円、400万円、500万円、600万円、660万円付近の境界値(最低5点以上)
- 一致しない場合、原因(旧版参照・パース誤り等)を特定して報告すること

### 5. 実装方針への反映(調査結果に基づく判断材料の提示のみ、実装はしない)
- 抽出が安全に行えると判断できる場合:
  - 抽出結果を静的なJSON/TSデータとして固定する方針(自動再生成パイプラインは今回作らず、
    抽出スクリプト自体は `reference/` 配下相当の場所に保存し、次回税制改正時に再利用する
    運用でよいか)についての所見を報告すること
- 抽出が困難・リスクが高いと判断できる場合:
  - どの工程で困難があったか(構造の複雑さ、施行日バージョンの混在、データ量等)を具体的に報告し、
    代替案(速算表近似の継続+誤差の明記、部分的な範囲のみ別表第五を使う、等)の選択肢を提示すること

## 成果物
1. XML取得方法・別表第五ノードの構造サマリー
2. 施行日バージョンの調査結果(併存の有無、令和7年12月以降施行版の特定方法)
3. 抽出した全行データ(件数・先頭/末尾サンプル)
4. 代表収入額・境界値5点以上での照合結果(一致/不一致とその理由)
5. 実装方針への所見(抽出可能と判断した場合の運用案、または困難だった場合の代替案)
6. 参照した一次情報のURL一覧
