# 実装指示書: ヘッダーロゴをテキストロックアップ化(コンパスアイコン撤去)

## 背景

現状、資産シミュレーター側・一人法人側のヘッダーロゴは「コンパスアイコン+セクション名(資産シミュレーター/一人法人)」という構成になっている。これを、**「FREENOUGH」という親ブランド名を常に示しつつ、コンパスアイコンは使わない**構成に変更する。

これまでの検討経緯:
- 2段組(FREENOUGH上段+セクション名下段)は高さが増える、クリック領域が曖昧になるという理由で不採用。
- テキストのみの1行ロックアップ(「FREENOUGH ｜ セクション名」)を採用する。
- コンパスアイコンはヘッダーから撤去し、favicon用途としてのみ残す。一人法人側に対応するアイコンが存在しないため、資産シミュレーター側だけアイコンを残すと左右で扱いが不揃いになるための判断。
- ブログ記事のアイキャッチテンプレート(コンパス+資産シミュレーターのロゴが入った既存デザイン)は今回の変更対象外。従来通り継続する。

## 差し戻し安全性の方針

- 引き続き `feature/lp-visual-refresh` ブランチ上で作業する。mainには直接pushしない。
- 既存のロゴコンポーネントは直接改変せず、新規コンポーネントとして追加し呼び出し側を差し替えるか、変更前の実装をコメント等で分かる形にして、切り戻しやすくする。

## 変更内容

対象:lifecompass-next側の資産シミュレーター・一人法人、両方のヘッダー(既存の`usePathname()`分岐ロジックを使っている`Header.tsx`)。

1. **コンパスアイコンをヘッダーから削除する。**
2. ロゴ表示を、**「FREENOUGH」+区切り(縦棒「｜」または細い縦線)+セクション名**のテキストのみの構成に変更する。
   - 資産シミュレーター側:「FREENOUGH ｜ 資産シミュレーター」
   - 一人法人側:「FREENOUGH ｜ 一人法人」
3. **この表示全体(「FREENOUGH」部分も含めて)を1つのリンクとして扱い、クリック先は従来通りそのセクションのハブページのまま**にする(資産シミュレーター側は`/asset-simulator`、一人法人側は`/hitori-hojin`)。FREENOUGH TOPへは飛ばさない。
4. フォント・太さは、FREENOUGH TOP側のロゴ(`FREENOUGH`の表記、太字・レタースペーシングのある見た目)を参考にしつつ、セクション名部分は現状のヘッダーの文字と同程度のウェイトでよい。「FREENOUGH」部分をやや強調(太字)し、セクション名部分をやや軽いウェイトにするなど、親子関係が視覚的にも伝わる程度の差をつけてよい。
5. **favicon(ブラウザタブに表示されるアイコン)を、全ページに一貫して設定する。** 現状、ページによってfaviconが設定されていない箇所があるため、この機会に洗い出して統一する。
   - FREENOUGH TOP(freenough-main)、資産シミュレーター側の各ページ、一人法人側の各ページ、それぞれでfaviconの設定有無を確認する。
   - コンパスのモチーフを、全ページ共通のfaviconとして設定する(セクションごとに変える必要はない、全て同じfaviconでよい)。
   - 既に一部のページで別のfaviconや正しいコンパスが設定されている場合は、それを壊さないよう配慮しつつ、未設定のページに同じものを適用する。
6. FREENOUGH TOP側(freenough-main)のヘッダーロゴは今回の変更対象外(既に「FREENOUGH」単独表記のため変更不要)。念のため現状を確認し、変更が不要であることを確認する。
7. ブログ記事のアイキャッチテンプレート(コンパス+資産シミュレーターのロゴが入ったデザイン)は変更しない。

## Phase 0: 調査(必須、報告してから次へ)

1. 現在のヘッダーロゴ実装(コンパスアイコンのコンポーネント、テキスト部分の構造)を確認する。
2. 現在のfaviconの設定状況を、FREENOUGH TOP・資産シミュレーター側・一人法人側それぞれについて確認する。どのページに設定があり、どのページに設定がないかを一覧化して報告する。
3. ブログ記事のアイキャッチテンプレートが、今回変更するヘッダーロゴのコンポーネントを共有していないか(誤って影響が及ばないか)確認する。

## Phase 1: 実装

- 上記1〜7を実装する。

## Phase 2: 検証(証跡必須)

- 資産シミュレーター側・一人法人側それぞれのヘッダーのスクリーンショット(PC・モバイル)を報告する。コンパスアイコンが消え、「FREENOUGH ｜ セクション名」のテキスト表記になっていることを確認する。
- ロゴ全体をクリックして、それぞれ正しいハブページ(`/asset-simulator`、`/hitori-hojin`)に遷移することを確認する(FREENOUGH TOPに飛ばないこと)。
- FREENOUGH TOP側のヘッダーに変更がないことを確認する。
- ブログ記事のアイキャッチテンプレートに影響が出ていないことを確認する。
- favicon設定について、Phase 0で洗い出した「設定なしだったページ」全てに、修正後は正しく表示されていることをスクリーンショットまたはブラウザタブの表示で確認し、報告する。
- Vercel Preview URLを報告する。

## やってはいけないこと

- Phase 0の報告なしにPhase 1へ進まないこと。
- ロゴ全体のリンク先をFREENOUGH TOPに変更すること(従来通り各セクションのハブページのまま)。
- ブログ記事のアイキャッチテンプレートを変更すること。
- mainへの直接push。
- 証跡なしの完了報告をしないこと。
