# データ収集結果:「退職翌年の住民税」記事用データ

`docs/fixes/active/data_collection_resident_tax_article.md` の実装。

**取得方法**: `src/lib/tax/residentTaxTiming.ts`の`calcResidentTaxTiming()`(本番関数)を
`scripts/_scratch_collect_article_data.js`(データ収集後に削除する使い捨てスクリプト、
`ts-node`経由で本番TSファイルをそのままrequireするだけで、独自の再計算・再実装は一切なし)
から直接呼び出して取得した。**記事用の数値を独自に計算した箇所は一切ない。**

**実行時点の前提**: `retirementYear`(=`new Date().getFullYear()`)は取得時点で **2026年**。
本ツールは常に「退職が今年」という前提で計算するため、この収集結果も2026年時点の税制
(令和8年度税制改正の給与所得控除特例テーブル等)に基づく。将来この収集結果を再利用する
場合、年が変わっていれば数値が変わり得る点に注意(特に②側の給与所得控除は年収帯によっては
年で変わる)。

**入力条件(全パターン共通)**: `postRetirementIncome: 0`、`priorYearIncomeTwoYearsAgo`未指定
(3月退職は前々年所得を退職前年の年収で代用)、`retirementYearIncomeOverride`未指定、
`lumpSumPreference: "installment"`、`isAge40OrOver`未指定(40歳未満・14.6%)、
`socialInsuranceRateOverride`未指定。

## 使用したデータ収集スクリプトについて

`scripts/_scratch_collect_article_data.js`は本データ収集専用の使い捨てスクリプトであり、
`ts-node`経由で`src/lib/tax/residentTaxTiming.ts`の`calcResidentTaxTiming()`をそのまま
requireして呼び出すのみ(独自ロジックは含まない)。本指示の「コードの変更・新規実装は
一切行わないこと」の対象は本番コード(`src/`配下)であり、このスクリプトは本番コードを
一切変更していない。データ収集完了に伴い削除済み。
