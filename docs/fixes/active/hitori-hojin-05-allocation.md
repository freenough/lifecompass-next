# 法人に資産を残すべきか、個人に移すべきか

前回の記事では、役員報酬の設定が「法人に残す資金」と「個人に移す資金」の配分を決めることでもある、という話をしました。この記事では、法人から個人へお金を移す方法にはどんな選択肢があるのか、そして法人に資産を残しておくことにはどんな意味があるのかを整理します。

## この記事の結論

- 法人から個人へお金を移す主な方法には、役員報酬・配当・役員退職金の3つがあります
- 配当は法人税を払った後の利益から支払われるため、法人税と個人の配当課税という二段階の負担がかかります
- 役員退職金には退職所得控除や税負担を軽くする仕組みがありますが、金額の妥当性には専門的な判断が必要です
- 「法人に残すか、個人に移すか」に一律の正解はなく、そのお金をいつ、何のために使うのかによって考え方が変わります

## 法人から個人へお金を移す3つの方法

法人から個人へお金を移す方法には、役員報酬・配当・役員退職金があります。一方で、そもそも今は個人へ移さず、法人に資産を残しておくという選択肢もあります。それぞれ税金のかかり方や性質が異なるため、順番に見ていきます。

- **役員報酬**:毎月同額を支給する、法人の経費として扱われる方法(前回詳しく扱いました)
- **配当**:法人の利益を株主(一人法人の場合は代表者自身であることが多い)に分配する方法
- **役員退職金**:代表者が役員を退任する際に、まとまった金額を支給する方法

## 配当という選択肢

配当は、法人税等を差し引いた後の税引後利益から支払われます。つまり、法人段階で一度法人税がかかった後のお金に対して、さらに受け取った個人側にも配当所得として所得税がかかる、という二段階の負担が発生します。

これに対して役員報酬は、一定の要件を満たせば法人の損金として扱われ、個人側では給与所得として課税されます。個人が受け取る配当には、配当控除という税負担を調整する仕組みもありますが、配当は法人税等を負担した後の利益から支払われるため、法人と個人を通算した税負担は、役員報酬と比べて重くなりやすいとされることが多いです。こうした理由から、一人法人では配当よりも役員報酬や役員退職金が選ばれることが多い傾向があります。ただし、これも個々の所得水準や状況によって変わるため、一律に「配当は不利」と言い切れるわけではありません。

## 役員退職金という選択肢

役員退職金は、代表者が役員を退任する際にまとまった金額を受け取る方法です。退職金には、給与所得とは異なる税負担の仕組みが適用されます。

具体的には、勤続年数に応じて計算される「退職所得控除」という控除があります。目安として、勤続20年以下では「40万円×勤続年数」、20年を超える部分については「800万円+70万円×(勤続年数-20年)」という式で計算されます。さらに、退職金からこの控除額を差し引いた残りの金額は、原則としてその2分の1だけが課税対象になります(ただし、役員としての勤続年数が5年以下の場合は、この2分の1課税は適用されません)。

このように、退職金は給与所得と比べて税負担が軽くなるように設計された仕組みですが、注意点もあります。役員退職金の金額には法律上の上限があるわけではありませんが、勤続年数や最終的な役員報酬の水準などから算出される「適正な金額」を大きく超える部分は、税務上不相当に高額と判断され、法人の損金として認められない可能性があります。適正額の算定には専門的な判断が必要になるため、実際に検討する場合は税理士に相談することをおすすめします。

FIREに伴って役員を退任する場合には、役員退職金はそのタイミングと関連づけて検討できる選択肢になります。ただし、FIREすることと役員を退任することは必ずしも同じタイミングとは限りません。法人を維持したままFIREし、役員としては引き続き名前を置いておく、というケースもあり得るため、この2つを混同しないように注意が必要です。

## 法人に資産を残す、という選択肢

ここまで見た配当・役員退職金はいずれも、法人から個人へお金を移す方法でした。一方で、あえて法人に資産を残しておく、という選択肢もあります。

法人に資産を残すことは、それ自体で税負担を軽くする方法ではありません。法人に残った利益には、これまで見てきた法人税等の負担が生じています。それでもなお個人に移さず法人に残しておく理由は、法人として事業を継続したり、将来の支出や役員退職金の原資として使ったりできるという「選択肢」を保っておけることにあります。前回触れた通り、法人に資産を残す意味には、事業の運転資金の確保、将来の投資への備え、将来の役員退職金の原資とすることなどがあります。

ただし、法人に資産を残している間は、そのお金を個人の生活費やFIRE後の資産として直接使うことはできません。法人に残すか、個人に移すかを考えることは、「今の自分の生活のために使うお金」と「法人としての選択肢を保つために置いておくお金」のどちらを優先するか、という判断でもあります。

## どう考えればいいか

配当・役員退職金・法人に残す、という3つの選択肢を並べると、「結局どれが一番得なのか」を知りたくなりますが、これも前回の役員報酬と同じく、一律の正解はありません。

考え方の軸になるのは、そのお金を「いつ」「何のために」使うのかです。生活費として今使うお金は役員報酬で、法人を退任するタイミングでまとめて受け取りたいお金は役員退職金で、当面使う予定がなく事業や将来のために備えておきたいお金は法人に残す、というように、時間軸に応じて役割を分けて考えることができます。

税負担の大小だけで判断するのではなく、自分のFIRE計画の中で、そのお金がいつ必要になるのかを起点に考えることが、このシリーズを通じて大切にしている視点です。

## まずは、自分の生活費と必要資産額を確認してみてください

法人に残すか個人に移すかを考える前提として、まず自分の生活費や、完全リタイアを前提にした場合に必要な資産額を把握しておくと、「いつ、どれくらいのお金が必要になるか」を考える土台になります。[資産シミュレーターで試算する](/asset-simulator?utm_source=blog&utm_medium=referral&utm_campaign=hitori_hojin_asset_allocation_blog)

## よくある質問

**Q. 配当と役員報酬、どちらが税金上有利ですか?**
役員報酬は一定の要件を満たせば法人の損金として扱われ、個人側では給与所得として課税されます。配当は法人税等を負担した後の利益から支払われ、個人側でも課税されるため、法人と個人を通算した税負担で見ると、一般的には役員報酬の方が選ばれやすい傾向があります。ただし所得水準や個別の状況によって結果は変わるため、一律には言えません。

**Q. 役員退職金はいくらまで出せますか?**
法律上の金額の上限はありませんが、勤続年数や役員報酬の水準などから算出される「適正な金額」を大きく超える部分は、税務上不相当に高額と判断され、法人の損金として認められない可能性があります。具体的な金額の算定は専門的な判断が必要なため、税理士への相談をおすすめします。

**Q. 法人を畳む予定がなくても、役員退職金を受け取れますか?**
役員を退任するタイミングであれば、必ずしも法人を畳む(解散する)タイミングと一致している必要はありません。ただし、代表取締役から会長・非常勤役員などへ肩書を変更するだけで、実質的な職務内容や関与の度合いが変わっていない場合は、税務上「退職した」とは認められないことがあります。その場合、支給した金額は退職金ではなく役員賞与として扱われ、法人の損金として認められない可能性があります。一人法人で「代表は退くが実務には引き続き関わる」といった形を検討する場合は特に、実際に検討する際は専門家に確認することをおすすめします。

**Q. 結局、法人に残すのと個人に移すの、どちらがいいですか?**
一律の答えはありません。生活費として今必要なお金、将来まとめて受け取りたいお金、当面使う予定のないお金など、そのお金をいつ・何のために使うのかによって、適した方法は変わります。

## まとめ

- 法人から個人へお金を移す主な方法には、役員報酬・配当・役員退職金の3つがあり、法人に資産を残すという選択肢もあります
- 配当は法人税と個人の配当課税が二段階でかかるため、税負担の面では役員報酬や役員退職金と比べて選ばれにくい傾向があります
- 役員退職金には退職所得控除や2分の1課税といった優遇がありますが、金額の妥当性や「実質的な退職」の要件には専門的な判断が必要です
- 法人に資産を残すこと自体は税負担を軽くする方法ではなく、法人としての選択肢を保つ判断です
- 法人に残すか個人に移すかは、そのお金をいつ、何のために使うのかを起点に考えると整理しやすくなります
