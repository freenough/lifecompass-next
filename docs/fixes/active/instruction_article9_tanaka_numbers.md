# 指示書:9記事目(nisa-monthly-investment)用の数値算出

## 背景・目的

ブログ9記事目「新NISAは毎月いくら積み立てればいい?」の執筆に必要な数値を、
田中さん(42歳・既婚会社員)の既存フィクスチャをベースに算出する。

**重要:本タスクで使う数値は、`financeCore.ts`(積立額逆算ツール用の簡易エンジン)
ではなく、本番の`simulate()`/`analyze()`/`runMC()`を直接importして呼び出す方法
でのみ算出すること。** 独自の再計算スクリプト・簡易式は一切使わないこと
(`financeCore.ts`は積立額逆算ツールという別の機能のために作った簡略版であり、
コンテンツの数値根拠としては使わない)。

## 前提:田中さんフィクスチャの再利用ルール

田中さんの既存フィクスチャ(`full-verify.js`等の回帰テストで使われているJSON)を
そのまま使うこと。既存記事(`ideco-nisa`等)で使われている田中さんの基本パラメータ
(年齢・収入・支出・退職金・年金・既存資産配分等)を**一切変更しない**こと。

**動かす変数は「想定利回り(NISA口座の`rW`)」と「NISA口座の毎月積立額
(`acct.nisa.con`)」の2つのみ**とする。それ以外のパラメータ(iDeCo・退職金・
年金・支出等)は田中さんの既存フィクスチャの値をそのまま固定して使うこと。

この制約により、「利回りが変わると必要な積立額がどう変わるか」「その積立額で
本当に目標を達成できるか」という比較の中で、変化の要因を積立額・利回り以外に
求めずに済むようにする(既存の複数記事データ再利用ルールと同じ考え方)。

## 算出してほしいもの

### 1. 目標の確認(最初にこれを報告すること)

田中さんの既存フィクスチャに、既に「目標資産額」「FIRE達成年齢」に相当する
設定(または`ideco-nisa`記事等で言及されている目標)が含まれているはずなので、
まずそれを特定し、報告すること。具体的には以下を明示すること:

- 田中さんの現在年齢・現在のNISA口座残高
- 想定しているFIRE達成年齢(または目標とする年数)
- 目標資産額(このプロジェクトの「FIRE達成」の定義:総資産が生涯を通じて
  年間支出×25を下回らない、という基準に基づくものであれば、その金額)

もしフィクスチャ内に明確な「目標資産額」が定義されていない場合は、既存記事で
使われている田中さんの年間支出額から`年間支出×25`を計算し、これを目標資産額
として使うこと(このプロジェクトのFIRE達成の定義と整合させるため)。

### 2. 利回り別の必要積立額(年率3%/5%/7%)

田中さんの現在のNISA残高・目標資産額・目標年数を固定した上で、**NISA口座の
毎月積立額(`acct.nisa.con`)を変数として二分探索し、本番`simulate()`+
`analyze()`を実際に繰り返し呼び出すことで**、各利回り(3%/5%/7%)ごとに
「目標資産額に到達するために必要な毎月積立額」を求めること。

- 二分探索のロジックはスクリプト側で書いて構わないが、**計算エンジン自体
  (資産推移の計算)は必ず本番の`simulate()`を呼び出すこと**。二分探索の
  「探索」部分はオーケストレーションであり、财务計算の再実装ではないため、
  本番関数経由というルールには抵触しない
- 収束条件・探索範囲は妥当な精度(例:必要積立額の誤差0.1万円程度)で構わない

### 3. モンテカルロでの目標到達率(想定利回り5%のケース)

2で求めた「年率5%時の必要積立額」を実際に田中さんのプロファイルに設定し、
本番の`runMC()`(1,000試行)を実行して、以下を報告すること:

- 1,000試行中、実際に生涯資産が枯渇せず目標を達成できた試行の割合(%)
- 破綻確率(このプロジェクトのKPI定義に沿った、既存の指標をそのまま使うこと)

### 4. (参考・任意)積立額を固定して利回りが変動した場合の資産推移比較

もし追加で実施可能であれば、「年率5%時点の必要積立額」を固定した上で、
実際の利回りが3%/5%/7%だった場合の資産推移(グラフ用データ)も出力しておくと、
H2-2の「資産推移を比較」セクションでそのまま使えるため、あわせて出力して
ほしい(必須ではない、時間があれば)。

## 報告フォーマット

- 田中さんフィクスチャの基本パラメータ(1で確認した内容)
- 利回り3%/5%/7%それぞれの必要積立額(2の結果)
- モンテカルロでの目標到達率・破綻確率(3の結果)
- (あれば)4の資産推移データ
- **算出方法の明記**:実機ブラウザのCSVエクスポートか、本番関数を直接importして
  呼び出したスクリプト経由か、を明記すること。後者の場合は、呼び出したファイル名・
  関数名(`simulate`/`analyze`/`runMC`)を報告に含めること
- 使用したTypeScript/JavaScriptスクリプトがあれば、その内容も貼ること(独自の
  財務計算式を含んでいないか、こちらでも確認したいため)
