## 背景(判断根拠)

`category`は`blogTopics.ts`のテーマ軸(NISA・積立投資/iDeCo・退職金/年金・
老後の資産計画/教育費/シミュレーションの考え方/住宅・ローン)とは独立した、
記事カードの表示バッジ(ワッペン)です。判定基準は以下の通りです。

- 記事の核となる数値が本番`simulate()`/`runMC()`/ツール実出力に由来する
  → **シミュレーター活用**
- 記事の核となる数値・説明が公式計算式の独自再現・制度解説ベースで構成
  されている(本番シミュレーターを経由しない)
  → **FIRE基礎知識**

この記事は在職老齢年金の公式計算式を独自実装・Decimal型で検算したもので、
資産シミュレーター本体は使用していないため、"FIRE基礎知識"が正しい分類です。

新規category("税金・社会保険"等)の新設は不要と判断しました。今後、
制度・税金系の記事が増えても、この2軸(方法=category / テーマ=topic group)
で運用できます。
