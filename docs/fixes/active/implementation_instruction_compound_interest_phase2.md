# 実装指示書:積立(複利)計算機 フェーズ2(UI実装)

## 前提

フェーズ1(finance-core拡張)完了済み。`calcFutureValue()`が
`src/lib/financeCore.ts`にexport済み。本フェーズではこれを呼び出すUIを実装する。

## 対応1:ページ・コンポーネント一式の新規実装

- `src/app/tools/compound/page.tsx`
- `src/components/`(第1弾・第2弾と同じ配置規則に合わせること)配下に:
  - `CompoundInterestTool.tsx`(親コンポーネント、状態管理)
  - `CompoundInterestForm.tsx`(入力フォーム)
  - `CompoundInterestResult.tsx`(メイン結果+法務注記)
  - `CompoundInterestSensitivityTable.tsx`(感度テーブル)
  - `CompoundInterestCta.tsx`(CTA文言・ボタン)
- `AffiliateLink.tsx`は第1弾のものをそのまま再利用(新規実装不要)

## 対応2:入力仕様(4項目)

Product Spec 5章の通り、以下4項目のみ(年齢は含まない):

1. 現在の資産額(万円・0以上、初期値0円も許容)
2. 毎月の積立額(万円・0より大きい)
3. 想定利回り(年率・%・3/5/7のプリセット+自由入力。第1弾・第2弾と同一UI部品を流用)
4. 積立期間(年・1〜60程度)

`calcFutureValue(currentAssets, monthlyContribution, years, annualRatePct)`を
そのまま呼び出す形でよい(単位変換は関数内部で完結しているため、UI側での
%↔小数の変換処理は不要)。

## 対応3:出力仕様

**メイン結果:**
- 「◯年後、資産は◯◯◯万円になります」という中立的な表現
- 内訳表示:元本合計(積立額×期間+現在資産)・運用益(将来評価額−元本合計)
  - 元本合計はUI側で`monthlyContribution * 12 * years + currentAssets`として算出
  - 運用益は`将来評価額 - 元本合計`として算出

**感度テーブル:**
- 利回り3%/5%/7%それぞれの将来評価額を並べて表示(第1弾・第2弾と同一パターンの
  テーブルコンポーネントを流用・改修)

**表示丸め:**
- 万円単位・四捨五入(`Math.round()`)。状態変数自体は丸めず、最終表示フィールドの
  みで丸める(第1弾で確立した規則を踏襲)

## 対応4:法務注記(固定文言、3点)

1. 税金・手数料は考慮しない旨
2. NISA等の非課税制度の枠上限は考慮しない旨(本ツール固有:汎用ツールのため
   「NISA口座前提ではない」ことを明示)
3. インフレ非考慮の注記(第1弾・第2弾で確定した修正後の文言をそのまま使用):
   > 「本ツールはインフレ(物価上昇)を考慮しません。入力した利回りをそのまま
   > 複利計算するだけの試算です。入力する利回りが名目か実質かによって、
   > 将来の金額の意味合いが変わります。」
4. 将来の成果を保証するものではない旨
