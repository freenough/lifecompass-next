# 実装指示：「毎月の資産を、記録する。」カード 微調整（カード幅・前回比表示）

作成日：2026-09-21
種別：**実装（小規模な見た目調整）**
関連：`claude_instruction_asset_card_redesign_unified.md`（完了報告への追加対応）

---

## 背景

前回の完了報告（ブランチ`feature/lp-asset-allocation-demo`、未コミット）をKENZOが実機スクリーンショットでレビューし、以下2点の追加調整が必要と判断した。

1. カード右側（KPI3枠＋ドーナツ）の**箱の横幅が狭く**、「目標資産」の値（例：11,122万円）と「前回比」の万円（例：+100万円）が2行に段落ちしてしまっている。カード（箱）自体の幅を広げて、段落ちしないようにする
2. 「前回比」の下にある小さい「+7.1%（2026-08比）」の行は情報として細かすぎるため、**表示しない**（絶対額「+100万円」のみを表示する形にする）

---

## 1. カードの幅を広げる

- `AssetManagementPromoSection.tsx`（またはKPI3枠＋ドーナツを含むカード全体を囲っているラッパー要素）の幅制約を確認し、KPI3枠のうち値が長くなりうるもの（目標資産・前回比）が2行に折り返さない程度まで広げること
- 左側（見出し・説明文・箇条書き・CTAボタン）とのバランスを見ながら調整すること（左右どちらかに極端に偏らないようにする。既存のグリッド比率がある場合はその範囲内で右側の比率を増やす、全体の最大幅を広げる、のいずれか適切な方法でよい）
- デスクトップ幅・モバイル幅の両方で、値が折り返さずに収まることを確認すること

## 2. 「前回比」の詳細行を削除する

- `AssetProgressBadges.tsx`内で「+7.1%（2026-08比）」のような、パーセンテージ＋比較月を表示している小さいテキスト行を削除する
- 「前回比」の値としては、絶対額（例：「+100万円」）のみを表示する形にする
- 裏側で保持している`PREV_DIFF_PCT`等のパーセンテージ計算・定数自体は、削除せず残しておいてよい（将来的に使う可能性があるため）。あくまで画面上の表示から外すだけでよい

---

## 遵守事項

- ロックファイル（`types.ts`/`profile.ts`/`PortfolioPanel.tsx`/`simulate.ts`/`analyze.ts`/`montecarlo.ts`/`blog.ts`/`blogTopics.ts`/`concerns.ts`/`ConcernCard.tsx`）への依存・変更は一切ゼロを維持すること
- ドーナツ・KPI3枠の内容（数値・ロジック）自体は変更しない（今回はレイアウト・表示項目の調整のみ）
- 既存の`feature/lp-asset-allocation-demo`ブランチで作業を継続してよい
- コミット・push・Vercel Preview作成は、KENZOの確認・指示を受けるまで行わないこと
- 完了報告には、デスクトップ幅・モバイル幅（可能な範囲の実測幅）でのスクリーンショットを添付すること
