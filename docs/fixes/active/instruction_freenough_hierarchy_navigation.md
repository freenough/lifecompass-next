# 情報設計確定書 兼 実装指示書: FREENOUGH / 資産シミュレーター / 一人法人の階層整理

## 背景・目的

現状、FREENOUGH TOP・資産シミュレーター・一人法人の3ページ(2リポジトリ: freenough-main, lifecompass-next)は、ヘッダー・フッターの項目がそれぞれ独自にバラバラに実装されており、以下の問題があった。

- 一人法人ページのヘッダーが資産シミュレーターのものをそのまま流用しており、「ブログ」等をクリックすると一人法人の記事ではなく資産シミュレーター本体のブログに飛んでしまう。
- TOPページから一人法人への導線がヘッダー・本文ともに存在せず、一人法人は事実上サイト内で孤立している。
- フッターが3ページで完全にバラバラ。
- 一人法人ページのロゴが常に `/asset-simulator` に飛ぶ実装になっており、一人法人セクション内で自分のハブに戻れない(バグ)。

以下、この一連のチャットで議論・確定した仕様を記す。**これは調査を伴う実装指示書であり、Phase 0の報告なしにPhase 1へ進まないこと。**

## 確定した全体構造

```
FREENOUGH(親ブランド、TOP)
├── 資産シミュレーター(ハブLP: /asset-simulator)
│     └── シミュレーター本体アプリ(/asset-simulator/app)
└── 一人法人(ハブLP: /hitori-hojin)

共有機能(両方から使われる):
- シミュレーター本体アプリ
- 資産管理ツール(個人+法人合算対応)
```

「資産シミュレーター」(ハブLP)と「シミュレーター」(計算アプリ本体、`/asset-simulator/app`)は別物として扱う。この区別は既存実装(資産シミュレーターヘッダーの「シミュレーター」リンクが既に`/asset-simulator/app`を指している)を踏襲する。

## 詳細仕様

### ヘッダー(資産シミュレーター側、lifecompass-next)

現状の6項目に「資産管理ツール」を追加し7項目にする。

```
シミュレーター / ツール / お悩み / ブログ / 使い方ガイド / 資産管理ツール / Note
```

- 既存5項目のリンク先は変更しない。
- 追加する「資産管理ツール」は、既存の資産管理ツールページ(個人+法人合算対応)への直接リンク。

### ヘッダー(一人法人側、lifecompass-next)

現状の資産シミュレーターと同一の6項目を廃止し、以下の3項目に差し替える。

```
シミュレーター / 資産管理ツール / 一人法人ブログ
```

- 「シミュレーター」:資産シミュレーター側と同じ行き先(`/asset-simulator/app`)。
- 「資産管理ツール」:資産シミュレーター側と同じ行き先(同一ページ、法人トグルで個人/法人を切り替えられるもの)。**新規に別ページを作らないこと。**
- 「一人法人ブログ」:`/hitori-hojin/blog`。
- 「一人法人トップ」は含めない(ロゴが同じ行き先を持つため冗長)。

### ヘッダー(FREENOUGH TOP側、freenough-main)

現状の4項目(シミュレーター / ブログ / ツール / Note)に「一人法人」を追加し5項目にする。挿入位置は「シミュレーター」の直後。

```
シミュレーター / 一人法人 / ブログ / ツール / Note
```

- 既存4項目のリンク先は変更しない。
- 「一人法人」は `/hitori-hojin` へのリンク。

### ロゴのリンク先(修正必須)

各ページのロゴは、そのセクション自身のハブLPへリンクする。

- FREENOUGH TOP:`/`(現状通り)
- 資産シミュレーター側:`/asset-simulator`(現状通りのはず、Phase 0で確認)
- **一人法人側:`/hitori-hojin`(現状 `/asset-simulator` になっているバグ。修正必須)**

### TOPページ本文への一人法人カード追加

現状、TOPページ本文には資産シミュレーターの単独カード(アイコン+説明文+CTAボタン)のみが存在する。この隣(または直下)に、同じ見た目・同じ構造で一人法人カードを新設する。

```
資産シミュレーター                一人法人
[コンパスアイコン]                [新規アイコン、要デザイン検討]
あなたの「足りる」を、            完全リタイアだけがFIREじゃない。
数字で確かめる。
[資産シミュレーターを見る→]        [一人法人という選択肢を見る→]
```

- 一人法人カードのコピーは上記を仮置きとし、最終文言はコンテンツ制作側(このチャット)で別途詰める。今回のスコープはカードの構造・配置のみ。
- アイコンは既存のコンパスアイコンとは別のものを用意する(既存アイコン流用はしない)。具体的なアイコン案は本指示書のスコープ外、別途相談。

### フッター(全ページ共通、3ページとも完全一致させる)

```
FIREを考える              一人法人を考える
├ 資産シミュレーター        ├ 一人法人トップ
├ ツール                    └ 一人法人ブログ
├ お悩み
└ ブログ

シミュレーター / 資産管理ツール / 使い方ガイド / 計算ロジック / Note

Freenoughについて / 広告開示 / プライバシーポリシー / 免責事項 / 運営者情報

© 2026 FREENOUGH
```

- 「資産シミュレーター」(ハブLP)と「シミュレーター」(アプリ本体)の表記揺れに注意。上段列は「資産シミュレーター」(ハブLPへのリンク)、下段共有行は「シミュレーター」(アプリ本体へのリンク)。
- この構成を3ページ(TOP・資産シミュレーター・一人法人)全てに同一実装する。

## Phase 0: 調査(必須、ここで止まって報告)

1. freenough-main・lifecompass-nextそれぞれで、ヘッダー・フッターを実装しているコンポーネントファイルを特定する(共通コンポーネント化されているか、ページごとに個別実装されているかを含めて報告)。
2. 現状のTOPページヘッダー4項目(シミュレーター/ブログ/ツール/Note)それぞれの実際のリンク先(href)を確認する。
3. 現状の資産シミュレーターヘッダーの「シミュレーター」の実際のリンク先が `/asset-simulator/app` であることを確認する(想定と異なる場合は報告)。
4. 現状の資産管理ツールページの実際のパスを確認する(個人+法人合算対応の実体ページ)。
5. 一人法人側のロゴのリンク先が実際に `/asset-simulator` になっている(バグ)ことを再確認する。
6. 上記いずれかがロックファイル(`types.ts`/`profile.ts`/`PortfolioPanel.tsx`/`simulate.ts`/`analyze.ts`/`montecarlo.ts`/`blog.ts`/`blogTopics.ts`/`concerns.ts`/`ProfileDrawer.tsx`)に該当・依存していないか確認する。

## Phase 1: 実装

Phase 0の報告内容を踏まえ、以下を実装する。

1. 資産シミュレーターヘッダーに「資産管理ツール」項目を追加。
2. 一人法人ヘッダーを3項目(シミュレーター/資産管理ツール/一人法人ブログ)に差し替え。
3. TOPヘッダーに「一人法人」項目を追加。
4. 一人法人ページのロゴのリンク先を `/hitori-hojin` に修正。

- 一人法人ページでロゴをクリックし、`/hitori-hojin` に遷移すること(`/asset-simulator` に飛ばないこと)を確認。
- 3ページのフッターが完全に一致していることを確認。
- TOPページに一人法人カードが表示され、クリックで `/hitori-hojin` に遷移することを確認。
- 既存ページ(特にロックファイルに関連する機能)に意図しない影響が出ていないことを確認。

## 実施状況(2026-09-06〜07)

Phase 0報告後、ユーザー判断により**ヘッダー・ロゴ・TOPカードのみ先行実装**（フッターの4段構成化は
別途相談・未着手のまま）。

### Phase 0調査で判明した、指示書の想定との相違点
- lifecompass-next: Header/Footerは共通コンポーネントだが完全にパス非依存の静的実装で、
  hitori-hojin専用の分岐は最初から存在しなかった（「流用」ではなく「未実装」）。
- freenough-main: フッターは共通コンポーネント化されておらずpage.tsxにベタ書き。しかも
  現状の内容は指示書が想定する4段構成とは別物（About/広告開示/プライバシー/免責/X/Noteの1行のみ）。
- freenough-mainのTOPロゴは現状`<span>`のプレーンテキストで、リンクにすらなっていなかった
  （「現状通り」という指示書の前提と異なる）。
- ロックファイルへの依存: なし（安全に変更可能と確認）。

### 実装内容(ヘッダー・ロゴ・TOPカードのみ)
- lifecompass-next `Header.tsx`: `usePathname()`で`/hitori-hojin`配下かを判定し、ナビ項目と
  ロゴ行き先を分岐。資産シミュレーター側に「資産管理ツール」を追加、一人法人側は
  「シミュレーター/資産管理ツール/一人法人ブログ」の3項目に差し替え。
- freenough-main `Header.tsx`: 「一人法人」を「シミュレーター」の直後に追加、ロゴを`<a href="/">`化。
- freenough-main `page.tsx`: 既存の資産シミュレーターカードを2カラムgridに変更し、同一構造で
  一人法人カードを新設(アイコンは`IconBuilding`、コピーは指示書記載の仮置き文言)。

### 本番デプロイ後に発覚した追加バグとその場での修正
Phase 2検証中、一人法人側ヘッダーの「ロゴ」と「一人法人ブログ」がnext/linkのままだったため、
`https://www.freenough.com/hitori-hojin`のクリーンURL表示中でもクリック1回で
`/asset-simulator/hitori-hojin/...`にURLが巻き戻る不具合を発見した
（implementation_hitorihojin_url_cleanup.mdで対処した記事リンクの問題と同一原理。
今回のヘッダー実装時に見落としていた）。この2箇所のみ`HITORI_HOJIN_SITE_URL`ベースの
絶対URL付き`<a>`に修正（「シミュレーター」「資産管理ツール」は`/asset-simulator`配下への
遷移が正しい仕様のためnext/linkのまま維持）。追加コミットで本番デプロイ・再検証済み。

### Phase 2検証結果(本番実機、スクリーンショット・DOM確認済み)

  の7項目が表示され、既存5項目のリンク先は変更なし。
