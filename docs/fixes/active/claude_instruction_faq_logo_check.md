## 調査項目

### 1. 「よくある質問」セクションを持つ記事の洗い出し

- `src/content/blog/`配下（通常ブログ）と、hitori-hojin側の記事コンテンツ配下（該当ディレクトリを確認の上）で、`## よくある質問`という見出し（表記ゆれがあれば併せて報告）を含むファイルを一覧化してください
- 該当ファイルが何件あるか、ファイル名一覧を報告してください

### 2. Q&Aの記法パターンの確認

- 上記で見つかった各ファイルについて、「よくある質問」セクション内のMarkdown記法をそのまま抜粋して報告してください（例: `**Q. ...**`の次の行に`A. ...`が続く、という形式が全ファイルで統一されているか、それとも表記ゆれがあるか）
- 質問文・回答文それぞれの改行・強調記法（`**`等）の使われ方に一貫性があるか確認してください
- 1ファイルあたりのQ&A数（最小〜最大）も報告してください

### 3. データの流れの確認（実装方式の判断材料）

- `src/lib/blog.ts`（**読み取りのみ**）で、Markdownファイルの内容が`content`フィールドとしてページ側にどう渡っているか（生Markdown文字列のままか、`remark-html`等で変換済みのHTML文字列になった状態で渡されるか）を確認して報告してください
- `src/app/blog/[slug]/page.tsx`で、`post.content`（またはそれに相当するフィールド）を実際にどう受け取って表示しているかも報告してください
- hitori-hojin側（`hitoriHojinBlog.ts`・対応するpage.tsx）についても同様に確認してください

### 4. Organization logo画像の候補調査

- `freenough-main`・`lifecompass-next`両リポジトリの`public/images/`配下に、正方形に近い比率のロゴ画像（サイト全体で使われているブランドロゴ）が存在するか確認してください
- 存在する場合、ファイルパス・実際の画像サイズ（幅×高さ、ファイルサイズ）を報告してください
- Googleの推奨（正方形、最小112×112px程度）に対して現状のファイルがそのまま使えそうか、リサイズ・新規作成が必要そうかを報告してください（判断は不要、事実の報告のみ）
- 参考: 過去の調査で`freenough-main/public/images/compass_logo.png`（668KB）が存在することが分かっています。この画像の実際の用途（サイト内のどこでどう使われているか）と正確な寸法も確認してください
