# 実装指示書: 3特徴セクション(モンテカルロ対応/日本制度対応/データ保護)のカード撤去

## 位置づけ

LP再設計の一部。今回は**この3つのカードの見た目変更のみ**が対象。Hero・ダークセクション・その他のセクションは今回のスコープ外、一切変更しない。

## 差し戻し安全性の方針(これまで通り)

- `feature/lp-visual-refresh` ブランチ(既存)上で作業する。mainには直接pushしない。
- Vercel Preview URLを報告し、確認・GO判断が出るまでmainにマージしない。
- 既存コンポーネントは直接改変せず、新規コンポーネント追加+呼び出し側の差し替えを基本とする。

## 変更内容

対象:資産シミュレーターLP、「モンテカルロ対応」「日本制度に完全対応」「データは端末の外に出ない」の3枚のカード。

1. **カードの見た目(白背景・枠線・角丸・シャドウ)を撤去する。** 背景色、border、box-shadowを外し、他の要素から独立したカードには見えないようにする。
2. **アイコンは現在使用しているHeroicons/Lucide系のコンポーネントをそのまま使う。** 新しいアイコンを作らない、差し替えない。
3. **アイコンの周りに、円の輪郭線(ストローク、塗りつぶしなし)を追加する。** 円は塗らない(背景色を敷かない)。色は既存のアイコンと同じ単色(現状のダークネイビー系の色)に合わせる。
4. **アイコン自体(円ごと)のサイズを、現状より一回り大きくする。** 具体的な倍率は実装しながら調整してよいが、目安として現状の1.4〜1.6倍程度の直径を想定。
5. タイトル・説明文の文言は変更しない。フォント(Zen Kaku Gothic New等、既に他Phaseで検討したもの)は今回のスコープ外なので、既存のまま変更しない。
6. 3枚の横並びレイアウト自体(左右の配置)は維持してよい。変えるのは各アイテムの中身(カード→円アイコン)のみ。

## 確認してほしいこと(Phase 0扱い)

- 「日本制度に完全対応」の説明文「NISA・iDeCo・退職金・年金を一体で計算」が、実装上も4項目のまま変わっていないことを確認する(内容変更ではなく事実確認のみ)。

## 検証(証跡必須)

- 変更後のセクションのスクリーンショット(PC・モバイル)を報告する。
- カードの枠線・背景・シャドウが完全になくなっていること、アイコンが円の輪郭線で囲まれ、現状より大きく表示されていることを確認する。
- 円は塗りつぶされていない(輪郭線のみ)ことを確認する。
- 他のセクション(Hero、その下に続くセクション)に意図しない影響が出ていないことを確認する。
- Vercel Preview URLを報告する。

## やってはいけないこと

- Hero・ダークセクション・その他のセクションを変更すること(今回のスコープ外)。
- アイコンを新規に作成・差し替えること(既存のHeroicons/Lucideをそのまま使う)。
- 円を塗りつぶすこと(輪郭線のみ)。
- mainへの直接push。
- 証跡なしの完了報告をしないこと。
