## 3. 入力フォーム仕様(`FireAgeForm.tsx`)

5項目、第1弾と同じUI部品を流用:

| 項目 | 型 | 備考 |
|---|---|---|
| 現在の年齢 | 数値(歳) | |
| 現在の資産額 | 数値(万円) | |
| 目標資産額 | 数値(万円) | **ヘルプテキストを添えること**: 「目安:年間支出×25(4%ルール)」 |
| 毎月の積立額 | 数値(万円) | |
| 想定利回り | 3/5/7%のプリセットボタン | `calcAchievementAge()`に渡す際は**%表記の数値そのまま**(例:5)を渡すこと。小数(0.05)に変換しない |

## 4. 計算・結果表示(`FireAgeTool.tsx` / `FireAgeResult.tsx`)

`calcAchievementAge()`の戻り値に応じて3パターンを出し分ける:

- **`null`の場合**:
  > 現在の条件では目標資産への到達は見込めません。積立額を増やす、目標資産を
  > 見直す、運用期間を延ばす、などをご検討ください。

- **`0`の場合**:
  > すでに目標資産に到達しています。

- **正の数値の場合**:
  - **表示前に必ず`Math.floor()`で整数化すること(四捨五入は使わない)**。
    フェーズ1のJSDocに明記された理由(年末積立モデルとの整合性・法務的な
    保守性)に基づく
  - 表示文言: 「目標資産に到達するのは◯歳です(現在から約◯年後)」
    - 「約◯年後」の年数は `floor(到達年齢) - 現在の年齢(入力値)` で計算する
      (端数処理の一貫性のため、到達年齢を先にfloorしてから年数を引き算する)

## 5. 感度テーブル(`SensitivityTable.tsx`)

利回り3パターン(3/5/7%)で、到達年齢に加えて「あと何年」列を併記する:

| 利回り | 到達年齢 | あと何年 |
|---|---|---|
| 3% | ◯歳 | ◯年 |
| 5% | ◯歳 | ◯年 |
| 7% | ◯歳 | ◯年 |

各セルの計算・丸め方針は4章のメイン結果と同一(floor)。

## 7. ツール名・タイトル表記(重要)

- ページタイトル(H1・`<title>`等): 「目標資産到達年齢シミュレーター」
- **「FIRE達成」という断定表現はページ内のどこにも使わないこと**
  (7章のメイン結果表現方針と同一の理由)

    目標資産にいつ到達するかが分かります。FIREを目指す資産形成期間の
    目安としてもご活用いただけます。」
- **grep確認必須**: 実装完了後、`FIRE達成`という文字列がページ内・
