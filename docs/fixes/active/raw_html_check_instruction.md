# 実装指示書:ブログ記事内の生HTML混入チェックスクリプト(再発防止)

## 背景
`fire-inflation-sensitivity.md`で発生した「生HTML(`<div>`・`<a>`等)がビルド時に
警告なく消える」バグ(修正済み)と同種の問題が、今後別の記事で再発した場合に
気づけるようにするための保険。

## やること
`src/content/blog/*.md` 全件を対象に、**`<AffiliateLink ... />` 以外の生HTML
タグ**が本文中に含まれていないかを検出するチェックスクリプトを1つ追加する。

### 実装内容
- 新規スクリプト(例: `scripts/check-raw-html-in-blog.js` または `.ts`)を追加
- 各Markdownファイルのfrontmatterを除いた本文を対象に、`<tagname ...>`形式の
  パターンをgrep/正規表現で検出する
- 検出対象から `<AffiliateLink` は除外する(意図した記法のため)
- 検出した場合、該当ファイル名・行番号・該当タグを標準出力に警告として出す
- 何も検出されなければ「問題なし」を出力する

### ビルドへの組み込み
- `package.json` の `scripts` に追加し、`npm run build` の前段(`prebuild`)
  として自動実行されるようにする
  例:
  ```json
  "prebuild": "node scripts/check-raw-html-in-blog.js",
  "build": "next build"
  ```
- 検出された場合、ビルド自体は止めない(警告のみ・exit code 0)。
  理由: 意図的に生HTMLを使いたいケースが将来出る可能性を完全には排除しない
  ため、いきなりビルドを止める強い仕様にはしない。まずは「気づける」状態を
  作ることが目的。

## 完了報告に含めてほしい内容
- 追加したスクリプトのコード
- 既存9記事に対して実行した結果(問題なしであることの確認)
- 意図的に生HTMLを含む一時テストファイルを作り、正しく警告が出ることを
  確認した結果(確認後にテストファイルは削除)
- `npm run build` が問題なく通ることの確認
