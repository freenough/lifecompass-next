## 修正1: 「見出し+一覧リンク」構成を4セクション全てに統一

前回指示書2-1節では「こんな悩みはありませんか?」セクションのみの例外としていたが、これを**お悩み/FIREガイド/ツール/ケーススタディの4セクション全てに適用する**。

新しい構成(4セクション共通):

```
─── ラベル
見出し本体                                   ○○一覧を見る→ (右寄せ、見出しと同じ高さ)
補足文(見出し直下、左寄せ、全幅)
[カード群]
```

- 見出し本体と「○○一覧を見る→」リンクは、横並びの1行(`display:flex; justify-content:space-between; align-items:baseline;`)に配置する。見出しが左、リンクが右
- 補足文はこの行の**直下**に、**全幅**で左寄せ配置する(前回指示書の「左カラム35%:右カラム65%」という2カラム比率構成は不要になったため、この点は撤回する。補足文がもはや右カラムに収まる短文ではなく、全幅で流れる構成になったため)
- 各セクションの一覧リンク文言(前回指示書2-2節から変更なし、**位置のみ**この構成に統一):
  - お悩み → 「お悩み一覧を見る→」
  - FIREガイド → 「記事一覧を見る→」
  - ツール → 「ツール一覧を見る→」
  - ケーススタディ → 「NOTEを見る→」
- **レスポンシブ**: モバイル幅で見出しとリンクが同じ行に収まらない場合、無理に1行に詰めず、リンクを見出しの下に折り返す(右寄せは維持)
