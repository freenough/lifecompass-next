# 指示書:ブログ記事の画像キャプション自動スタイリング

## 目的

Markdown記事内で、画像の直後に置かれた「キャプション行」を自動的に小さいフォント・
控えめな色で表示できるようにする。今回は記事10本目(`nisa-achievement-age`)の
分布図キャプションで最初に使うが、今後すべての記事で使える共通ルールとして実装する。

## 検出ルール(執筆側の記法)

執筆側は、画像の直後に**イタリック(斜体)のみで構成された1行の段落**を置く。
それ以外の見た目上のマークアップ(HTMLタグ等)は使わない。

```markdown
![55歳時点の資産分布(モンテカルロ法・1,000試行)](/images/blog/nisa-achievement-age/asset-distribution.png)

*本図は分布のイメージを示すものであり、各点の間隔は正確な縮尺ではありません。*
```

## 実装方針

remarkの処理パイプライン(既存の`affiliateLink`カスタムノード実装と同じ場所、
`src/lib/markdown.ts`または該当ファイル)に、以下の変換を追加する。

1. mdast(Markdownの構文木)を走査し、次の条件に一致する`paragraph`ノードを探す:
   - 直前の兄弟ノードが`paragraph`かつ、その中身が`image`ノード1つのみ
     (画像だけの段落、という意味)
   - 対象の`paragraph`自体が、`emphasis`ノード1つのみで構成されている
     (つまり「イタリックだけの1行」)
2. 条件に一致した場合、その段落のhastノード(HTML変換後)に
   `className: ['img-caption']`を付与する
3. 通常の本文イタリック(`*このように*文中で使う場合`)には一切影響しないよう、
   「画像直後」かつ「段落全体がイタリックのみ」という2条件を両方満たす場合のみ
   適用すること(誤検出防止)

## CSS

`globals.css`(または該当のブログ記事用スタイルシート)に追加:

```css
.img-caption {
  font-size: 0.8em;
  color: var(--tx2, #5c5a52); /* サイトの本文セカンダリカラー相当。実際の変数名に合わせて調整 */
  text-align: center;
  margin-top: -0.5rem;
  margin-bottom: 1.5rem;
}
```

`var(--tx2, ...)`の部分は、実際にNext.js版で使われているテキストセカンダリカラーの
CSS変数名/Tailwindクラスに合わせて調整すること(旧HTML版の`--tx2`は参考値)。

## 確認事項

- 通常の本文中のイタリック強調(画像に紐付かないもの)が、誤って小フォント化
  されていないか
- 画像が無い記事、画像の直後がイタリック段落でない記事に影響が出ていないか
  (既存8記事への横断チェック)
- ダークモード対応があるサイトの場合、キャプションの色がダークモードでも
  読める配色になっているか
