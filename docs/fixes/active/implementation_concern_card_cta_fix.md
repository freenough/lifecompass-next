# 実装指示書:sequence-of-returns-riskカードのCTA先を記事に変更

## 対象・制約

**ロックファイル(`simulate.ts`・`analyze.ts`・`montecarlo.ts`)は変更禁止。**
対象は`src/data/concerns.ts`の該当エントリ(`sequence-of-returns-risk`)のみ。

## 背景

`sequence-of-returns-risk`のconcernカードは、ボタン「詳しく試算する」
(`ctaType: 'fullSimulator'`、`ctaUrl: '/app?...'`)でシミュレーター本体に
直接誘導しているが、この記事で検証したB/C(退職1年目の暴落タイミングを
固定した試算)は、シミュレーターの通常操作では再現できない。ユーザーが
「詳しく試算する」を押しても、記事で見た検証そのものは試せずに戸惑う
可能性がある。outcomeの文言(「モンテカルロ試算で確認できます」)も、
この点で正確性を欠く。

## 調査項目(修正前に確認)

1. `ConcernCard`(またはカードを描画しているコンポーネント)の実装を確認し、
   `ctaType`の値(`'fullSimulator'`・`'lightTool'`等)が、ボタンのラベル・
   アイコン・スタイルを自動的に決定する仕組みになっているか、それとも
   `ctaUrl`・`ctaLabel`はエントリごとに自由に指定でき、`ctaType`は分類
   目的(集計・表示ロジックの分岐等)のみに使われているかを確認してください。
2. 他のconcernエントリで、`ctaUrl`が`/app`(シミュレーター)以外(例:
   記事自体や別ページ)を指しているケースが既にあるか確認してください。

## 修正内容

調査の結果、`ctaUrl`を自由に変更してよい設計だと確認できた場合、
`sequence-of-returns-risk`エントリを以下のように変更してください:

- `ctaUrl`:`/app?...`(シミュレーター)から、`articleUrl`と同じ
  `/blog/sequence-of-returns-risk`に変更(記事内で正確な説明とともに
  シミュレーターへのリンクを案内しているため、カードからは記事へ誘導する)
- `ctaLabel`:「詳しく試算する」から「検証結果を見る」等、記事へ誘導する
  文言に変更(具体的な文言は既存の他カードの言い回しを参考に、自然な
  ものにしてください)
- `outcome`:「暴落が来る「タイミング」によって、資産が尽きる確率が
  どれだけ変わるかをモンテカルロ試算で確認できます」を、「確認できます」
  という現在ツール上でできるかのような表現を避け、「確認した記事です」
  のような、記事の内容を指す表現に修正してください

もし`ctaUrl`と`articleUrl`が同じ値になることで表示上の重複(「詳しく読む→」
と新しいボタンが同じ遷移先になり、UI的に冗長)が発生する場合は、実装せず
その旨を報告してください。その場合はプランニングチャット側で別の対応
(ボタン自体を非表示にする設定があるか等)を検討します。

## 完了報告に含めるべき内容

- 調査結果(ctaTypeとURLの関係、他エントリの実例)
- 修正した場合はdiff
- 修正しなかった場合はその理由(UI重複等)
- `full-verify.js`・`tsc`の確認結果(データファイルの変更のみのため
  影響ないと想定されるが念のため)

commit・pushは行わず、報告のみでお願いします。
