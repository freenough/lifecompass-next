# 実装指示書:戦略比較モードのチェックボックス/ラジオボタンのレイアウト改善

**種別:実装含む**
**背景:** 「戦略比較」モードのUIで、左側のチェックボックス群(比例取崩・現金優先・課税優先。比較対象に含めるかどうかのON/OFF)と、右端のラジオボタン群(KPI・グラフの単一値表示の基準にする戦略を選ぶ。「表示」ラベルの2択)が、画面上で大きく離れて配置されており、間に不自然な空白が生じている。両者は本来「同じ戦略に対する2種類の操作」という対応関係にあるが、離れているためその関係性が伝わりにくい。

---

## 修正方針

チェックボックスとラジオボタンを**同じ行の中に隣接配置**し、1つの戦略につき「チェックボックス+ラベル ...... ラジオボタン」が1行で完結する形にする。

### レイアウトイメージ

```
☑ 比例取崩              ◉ 表示
☑ 現金優先              ○ 表示
☐ 課税優先              (ラジオ非表示 or グレーアウト)
```

### 実装内容

1. 現状「チェックボックス群を左カラム、ラジオボタン群を右カラムに分けて配置している」構造(2カラムレイアウト)を、**1行の中で両方を横並びにする**構造に変更する。
2. 各行は「チェックボックス+戦略名ラベル」を左詰め、「ラジオボタン+『表示』ラベル」を右詰めにし、行間の余白を他のチェックボックス行と揃える。
3. **チェックボックスがOFFの戦略(比較対象に含まれていない戦略)は、対応するラジオボタンを非表示にするか、グレーアウトして操作不可にする。**(比較対象に含まれていない戦略をKPI表示の基準にはできないため)
4. 現状「ラジオボタンは比例取崩・現金優先の2つ分しかない」ため行数が揃っていない点も、この変更で自然に解消される想定(課税優先の行にもラジオボタンの位置は確保しつつ、チェックボックスがOFFなら非表示/グレーアウトにする)。

---

## 確認してほしいこと

- レスポンシブ対応:モバイル幅で「チェックボックス+ラベル」と「ラジオボタン+ラベル」が同じ行に収まりきらない場合、折り返し方(2段に分ける等)を既存のモバイルレイアウトの方針に合わせて決めること。
- 既存の`displayStrategy`(単一値表示に使う戦略を選ぶロジック)・比較対象の複数選択ロジック自体には変更を加えず、**見た目の配置のみ**を変更すること。
- チェックボックスをOFFにした際、既にその戦略がラジオボタンで選択されていた場合の挙動(自動的に別の戦略に切り替わるか、エラーになるか)を確認し、既存の挙動を維持すること(今回はレイアウト変更のみで、ロジック変更はしない)。
