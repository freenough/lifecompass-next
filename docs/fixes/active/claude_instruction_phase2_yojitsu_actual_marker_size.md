# 実装指示：予実比較グラフ、実績側マーカーサイズの縮小

作成日：2026-08-31
種別：**実装（スタイル微修正）**
関連：`claude_instruction_phase2_yojitsu_chart_style_planA.md`（案A実装済み）／`claude_instruction_phase2_yojitsu_polish.md`3節（実績を細い実線+小マーカーにした元の指示）

---

## 背景

案A適用後の実機スクリーンショットで、実績側の表示が「細い線に小さなマーカー」ではなく、**マーカーが大きく、丸が連なっているだけ**に見える状態になっている。線ではなく点の集合のように見え、当初「やぼったい」と指摘された見た目の問題が実質的に解消されていない。

## 修正内容

- 実績側のマーカー半径を現状よりさらに縮小する（目安：半径2px前後。線の太さ（`strokeWidth`）との比率で、線が主役でマーカーは控えめな点、という見え方になるようにする）
- 縮小した結果、実際に「線がつながって見える」ことをスクリーンショットで確認すること。数値だけ小さくして確認を怠らないこと
- 計画側（点線＋MC帯）のスタイルは変更しない

## 遵守事項

- ロックファイルへの変更はゼロ
- 検証は安全なテストデータで行うこと
- 完了報告には、修正前後を比較できる実機スクリーンショット（固定モード・MCモード両方）を添付すること
