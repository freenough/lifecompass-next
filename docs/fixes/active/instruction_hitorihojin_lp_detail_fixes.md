# 実装指示書: 一人法人LP 4点の細部修正

## 位置づけ

引き続き `feature/lp-visual-refresh` ブランチ上で作業する(既存の一人法人ブログ一覧・トップページ記事カードの対応と同じ流れ)。それら既存分がまだmainにマージされていない場合は、本指示の変更もその上に積み重ねてよい。

## 差し戻し安全性の方針(これまで通り)

- mainには直接pushしない。Vercel Preview URLを報告し、確認・GO判断が出るまでマージしない。

## 変更内容

### 1. Heroの見出しフォントサイズ

`/hitori-hojin` トップページのHero見出し(「一人法人を、FIREの選択肢に。」)のフォントサイズを、資産シミュレーター側Hero見出し(「あなたのFIREは、何歳?」)と同じ大きさに揃える。

- Phase 0で両方の現在のfont-size値を確認し、一致していない場合は一人法人側を資産シミュレーター側の値に合わせる。
- 資産シミュレーター側のHeroは、以前のタイポグラフィ変更(Phase1)を全面差し戻し済みのため、**現在の本番の値**を基準にする(差し戻し前の実験的な値ではない)。

### 2. 「①から順番に読みたい方はこちら→」の文言変更

- リンクテキストを「①から順番に読みたい方はこちら→」から「すべての記事を見る→」に変更する。
- **URLの扱いは、このチャットでの確認結果に従うこと(A: `series=hitori-hojin-intro`のまま維持 / B: 絞り込みなしの`/hitori-hojin/blog`に変更、いずれかをこのチャットから追って連絡する)。** 決定が届くまでは、リンクテキストの変更のみ実装し、URLはいったん現状のまま(`series=hitori-hojin-intro`)にしておいてよい。

### 3. 最下部の「すべての記事を見る→」リンクを削除

- `/hitori-hojin` トップページ最下部にある、既存の「すべての記事を見る→」(`/hitori-hojin/blog`、絞り込みなし)へのリンクを削除する。
- このリンクの前後の余白・レイアウトが不自然にならないよう調整する。

### 4. 法人資産管理ツールの右側イメージから「個人化想定比率」を削除

- 「法人の資産も、FIREの進捗に。」セクション右側、「個人＋法人合算」の表示パネル内にある「個人化想定比率 70%」の項目を削除する。
- 「目標までの進捗 68%」の項目はそのまま残す。
- Phase 0で、このパネルのデータソース(静的なデモ用データか、実際のツールの値を参照しているか)を確認し、他の箇所(実際の資産管理ツール本体等)に影響が出ないことを確認してから対応する。
- 項目を1つ削除した後のレイアウト(進捗バー・凡例との余白バランス)を整える。

### 5. ヘッダーロゴのテキストをセクションごとに出し分け

- 画面左上のロゴ横のテキストが、現状どのページでも「資産シミュレーター」のまま表示されている。
- `/hitori-hojin` 配下のページでは、このテキストを**「一人法人」**に変更する。資産シミュレーター側のページでは、従来通り「資産シミュレーター」のまま変更しない。
- 既存の`Header.tsx`内、ロゴのリンク先切り替えで使っている`usePathname()`によるパス分岐のロジックを、テキスト表示にも同様に適用する形で実装する。

## Phase 0: 調査(必須、報告してから次へ)

1. 資産シミュレーター側Hero見出しの現在のfont-size(クラス名・値)を確認する。
2. 「法人資産管理ツール」の右側パネルのデータソースを確認する(1で述べた通り)。
3. `Header.tsx`の既存のusePathname分岐ロジックの実装箇所を確認する。

## Phase 1: 実装

- 上記1〜5(2のURL部分を除く)を実装する。

## Phase 2: 検証(証跡必須)

- 変更後の`/hitori-hojin`トップページ全体のスクリーンショット(PC・モバイル)を報告する。
- Hero見出しのフォントサイズが資産シミュレーター側と一致していることを、実際のfont-size値の比較で報告する。
- リンク文言が変更されていること、最下部の重複リンクが削除されていることを確認する。
- 「個人化想定比率」が削除され、「目標までの進捗」は残っていることを確認する。
- `/hitori-hojin`配下でロゴテキストが「一人法人」になっており、資産シミュレーター側ページでは従来通り「資産シミュレーター」のままであることを確認する。
- Vercel Preview URLを報告する。

## やってはいけないこと

- Phase 0の報告なしにPhase 1へ進まないこと。
- 2のリンクURLについて、このチャットからのA/B確定連絡を待たずに変更すること。
- 資産管理ツール本体(実際のツール側)のデータや表示に影響を与えること。
- mainへの直接push。
- 証跡なしの完了報告をしないこと。
