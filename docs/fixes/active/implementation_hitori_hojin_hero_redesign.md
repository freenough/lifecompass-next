   | | body | hair | face | accessory | 背景色／線色 |

3. **ボタン文言**：`SIMULATOR_CTA_LABEL`（一人法人LP下部CTAで使っている定数）を使う。資産シミュレーターLP側の「今すぐシミュレーションする →」とは表記を変える。行き先は`/app`（`next/link`、自動で`/asset-simulator/app`になる想定通り）。
4. **導入文2段落**：新しい導入ブロックに統合する。現在`page.tsx:61-72`にある単独の2段落ブロックは削除する（内容が重複するため）。
5. **Heroの背景**：`#EFF6FF`の帯をやめ、白にする。

## 1. Hero部分

### 構成（PC・スマホ共通のJSX、Tailwindのブレークポイントで出し分け）

- 背景：白
- 左側（テキスト）：見出し・説明文・CTA
- 右側（スマホでは下）：分かれ道の図（線＋3人のイラスト）

**見出し**：現状の`<h1>`のクラスを、資産シミュレーターLPの見出しクラスに差し替える。改行位置（`一人法人を、<wbr />FIREの選択肢に。`）と`[word-break:keep-all]`は維持する。

**説明文**（既存のまま、変更なし）：
```
これから法人化を考える人にも、すでに一人法人を運営している人にも。税金や社会保険だけでなく、法人と個人のお金をどう考えるかを、FIREの視点から整理します。
```

**新設する1行＋CTA＋補足文**（現状のHeroにはCTAがないため新規追加）：
```jsx
<p className="mt-3 text-base font-bold text-[#16202e]">
  法人からの取り崩しも織り込んで、あなたのFIREの時期を試算できます。
</p>
<Link
  href="/app"
  onClick={() => trackEvent('hojin_lp_cta_click', { location: 'hero' })}
  className="/* 資産シミュレーターLPのCTAボタンと同じ見た目のクラス */"
>
  {SIMULATOR_CTA_LABEL}
</Link>
<p className="mt-2 text-sm text-slate-400">{FREE_NO_SIGNUP_NOTE}</p>
```
（`FREE_NO_SIGNUP_NOTE`・`SIMULATOR_CTA_LABEL`は`src/lib/ctaCopy.ts`から import。ボタンの見た目クラスは、資産シミュレーターLP側のCTAボタンの実装をコピーして流用してよい）

**揃え（PC／スマホ）**：PC（xl以上、左右2列）はテキストブロック全体を左揃えのまま。スマホ（xl未満、1列）は見出し・説明文・「法人からの取り崩しも…」の1行を中央揃えにする（背景・判断結果6番を参照。資産シミュレーターLPのスマホHeroに合わせる）。

### 分かれ道の図

デザイン意図：「会社員」と「完全リタイア」を1本の線で結び、途中で2本の点線（別の選択肢）が分岐しつつ、1本だけ実線・強調色で分岐して「一人法人」に至る。

- 実装は、`Flow.dc.html`/`Main.dc.html`のSVGパス（`<line>`・`<path>`・`<circle>`）をそのまま流用してよい。色は`#C9D3DF`（非強調の線）と`#0F2A4A`（強調線、accent）のまま、コードベースの慣例通り直書きでよい（他のブロックも直書きの16進数を使っている）
- SVGは`viewBox="0 0 600 480"`のまま、`width="100%" height="auto"`にして横幅に追従させる（アスペクト比600:480を保つラッパーに入れる）
- 3人の`PersonaAvatar`は、SVGの外に絶対配置のオーバーレイとして重ねる。位置は元のpx値を600×480に対する割合に変換し、パーセント指定にする（コンテナのアスペクト比が保たれるため、幅・高さそれぞれのpxをそのまま600または480で割った値でよい）：

| 人物 | left | top | サイズ（正方形） |
|---|---|---|---|
| 会社員 | 2.3% | 19.6% | 18.7%（幅の割合） |
| 完全リタイア | 79.0% | 19.6% | 18.7% |
| 一人法人 | 49.3% | 57.5% | 21.3% |

ラベル（「会社員」「完全リタイア」「一人法人」の文字）も同様に、元のpx値を600×480に対する割合に変換して配置する。

スマホ版（375px想定、viewBox `0 0 342 290`）も同じ考え方で、`MainMobile.dc.html`のpx値を342×290に対する割合に変換する。

**この図とアバターの正確なピクセル対応はデザインツール上の値であり、実装時は見た目のバランスを優先して微調整してよい。** 大きな崩れがなければ、上の割合に忠実である必要はない。

## 2. Hero直下の導入ブロック

**アイコン・論点一覧は置かない。** 検討の過程で一度「知る／考える」に対応するアイコン一覧を並べる案があったが、最終的に不採用とし、以下の2段落だけを横幅いっぱいに、左揃えで縦に並べる形に確定している。実装もこれに合わせる。

```
[段落1]
FIREというと、「完全に働くのをやめること」だけをイメージしがちです。でも、完全リタイアと会社員の間には、仕事を続けながら働き方や収入の持ち方を変え、資産形成を続けるという選択肢もあります。その選択肢の一つとして、一人法人があります。

[段落2]
このシリーズでは、「法人化すれば得をする」という切り口ではなく、一人法人特有の論点を、自分のFIRE計画の中でどう位置づけるかという視点で整理します。
```

- 2段落とも、Heroと同じコンテナ幅いっぱい（左揃え、中央寄せの文章ブロックにはしない）
- フォントサイズはHeroの本文（説明文・CTA上の1行）と同じにする
- この下に直接`HitoriHojinGuideSection`（知る／考える記事一覧）が続く。論点アイコンやリンクは何も挟まない。
