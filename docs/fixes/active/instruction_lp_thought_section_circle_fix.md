# 実装指示書: 3特徴セクションのアイコン枠、楕円→正円に修正

## 背景

`instruction_lp_thought_section_circle_icons.md` の実装結果をPreviewで確認したところ、アイコンを囲む輪郭線が円ではなく、**横に伸びた楕円(ピル/カプセル型)**になってしまっていた。幅が親要素(カラム)いっぱいに伸びており、高さだけが小さいため、潰れた楕円に見えている。

## やること

- アイコンを囲む輪郭線の要素について、**幅と高さを同じ値の固定サイズ(正方形)にし、border-radiusを50%(または円になる値)にする。** 親要素の幅に追従して伸びないようにする。
- サイズ感は前回指示した「現状より1.4〜1.6倍程度」の直径を維持する(円としてのサイズ自体は変えなくてよい、形だけ直す)。
- 円は横方向中央に配置する(アイコンの下に来るタイトル・説明文と中央揃えになるように)。

## 検証(証跡必須)

- 修正後のスクリーンショット(PC・モバイル)を報告する。3つとも正円(幅=高さ)になっていることを確認する。
- モバイル幅で画面が狭くなっても、円が潰れて楕円にならないことを確認する(レスポンシブでの挙動も見る)。
- Vercel Preview URLを報告する。

## やってはいけないこと

- 今回のスコープ外(Hero、他セクション)を変更しないこと。
- mainへの直接push。
- 証跡なしの完了報告をしないこと。
