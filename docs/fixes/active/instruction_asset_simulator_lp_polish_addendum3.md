## 修正1: 「一覧を見る」リンクの位置をラベル行に変更

これまでの指示では、「○○一覧を見る→」リンクを**見出し本体と同じ行**に右寄せ配置していたが、この方針を撤回し、**ラベル行(「─── ケーススタディ」等)と同じ行に右寄せ配置**する方式に変更する。

新しい構成(4セクション共通):

```
─── ラベル                                   ○○一覧を見る→ (右寄せ、ラベルと同じ行)
見出し本体(全幅)
補足文(全幅)
[カード群]
```

- ラベルとリンクは`display:flex; justify-content:space-between; align-items:center;`で横並び(ラベルが左、リンクが右)
- 見出し本体・補足文は、リンクと競合せずそれぞれ全幅で配置する(見出しが2行に折り返っても、リンクの位置には一切影響しない)
- 変更理由: 見出しの文字数によってリンクの表示位置がぶれる問題が、そもそも解消される。ラベル行は常に短いテキストのため、モバイル幅でも折り返しの心配なくリンクと同じ行に収まる
- これに伴い、これまで指示していた「モバイル幅で見出しとリンクが同じ行に収まらない場合の折り返し対応」は不要になる。実装しないこと
