# 指示書: LP本文コンテナ幅の拡大・「毎月の資産を、記録する。」ブロック外枠削除

作成日: このセッション時点

## 0. 全体方針

- ヘッダー(グローバルナビ)・フッターは今回の変更対象外。触らない
- 本文コンテンツセクション(Hero・お悩み・資産管理ツールブロック等)のコンテナ幅を広げ、左右の余白を詰める
- 「毎月の資産を、記録する。」ブロックは、右カードの外側にある不要な外枠を削除する
- 進め方は2段構成:
  1. まず調査(下記1章)→結果確認
  2. 次に実装(コンテナ幅の実装＋外枠削除＋位置調整)を1本の実装指示書にまとめて着手

基準ブランチ: `main`

## 1. 調査指示書: LP本文コンテンツのコンテナ幅・共有定義の把握

### 背景
Hero・お悩み・資産管理ツールブロック等、本文コンテンツセクションで左右の余白が広く見える問題がある。原因はセクション間で共有されているコンテナ最大幅(`max-w-*`等)にあると想定。ヘッダーとフッターは今回の変更対象外とし、本文コンテンツセクションのみを対象に幅を広げる方針。

### 対象範囲(明確化)
- **対象**: Hero、お悩みセクション、資産管理ツールブロック、その他本文コンテンツセクション
- **対象外**: ヘッダー(グローバルナビゲーションバー)、フッター(いずれも現状のまま変更しない)

### 調査対象・確認事項

1. **共有コンテナの定義箇所の特定**
   - 上記「対象」セクションが共通で使っている`max-w-*`(または相当するCSS値)のクラス名・定義ファイルパスを特定
   - Tailwindのユーティリティクラス直書きか、共通コンポーネント(例: `<Container>`)に集約されているかを明記
   - このコンテナが、ヘッダー・フッターとも共有されているかを確認(共有されている場合、本文だけ広げる実装方法を別途検討する必要があるため重要)

2. **現在の値**
   - 上記コンテナの現在のmax-width値(px換算)
   - 左右パディング(コンテナ自体に`px-*`があるか)の値

3. **影響範囲の洗い出し**
   - 上記コンテナを変更した場合に影響を受けるセクション・コンポーネントの一覧(ファイルパス付き)
   - その中にロックファイル(`ConcernCard.tsx`等)が含まれるか
   - ヘッダー・フッターが意図せず巻き込まれない実装方法があるかどうかも報告する

4. **Heroのグラフカードとの関係**
   - グラフカードの幅が、コンテナ幅に対して固定比率か、コンテナいっぱいに広がる設計か
   - コンテナを広げた場合、グラフも自動的に大きくなるか、それとも別途グラフ自体の幅指定を変える必要があるか

### 期待する成果物
調査結果レポート(各項目についてファイルパス・現状値・依存関係を明記)。この結果を元に「1箇所の変数変更でPreview確認できる」実装指示書を作成する。

## 2. 追加指示: 「毎月の資産を、記録する。」ブロックの外枠削除

### 変更内容(今すぐ着手可、コンテナ幅の調査結果を待たなくてよい)
- 外側の枠(padding・border・rounded-*の外側コンテナ)を削除する
- 内側の右カード(KPIバッジ3枠+ドーナツ)はそのまま維持(削除しない)
- 左のコピー(見出し・本文・箇条書き・CTA・注記)の構造・スタイルは変更しない、あくまで外枠を剥がすのみ

### 左右位置の最終調整(コンテナ幅調査の結果を待って実施)
- 左コピーの左端を、Heroの見出し左端の水平位置に揃える
- 右カードの右端を、Heroのチャートカード右端の水平位置に揃える
- **調整後、左右の間(中央付近)の空白が目立つ場合は、余白をそのまま残さず、右カード内のグラフ(ドーナツ)自体の横幅を広げて埋めることを優先する**(コンテナ幅・マージンの再調整より先に、中身のビジュアル要素を大きくする方向で対応)

### 確認事項
- `AssetBreakdownDonut.tsx`/`AssetProgressBadges.tsx`がロックファイルかどうか(前回セッションでは新規作成扱いだったため、おそらく非ロック)
- 外枠削除後、背景色(白)がHeroや他セクションと同じ地色になるか(このブロックだけ背景色が違う設計になっていないか)

## 3. 次セッションで最初に確認すべきこと

1. 調査結果(1章)を確認し、実装指示書を作成する
2. 外枠削除(2章)を先行着手する場合、実機/Vercel Previewで背景色・左右位置のズレがないか確認
3. コンテナ幅拡大の実装後、左右位置調整とグラフ横幅調整を実機確認
