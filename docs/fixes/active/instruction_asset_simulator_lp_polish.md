# 指示書: 資産シミュレーターLP 細部調整(カード角丸・2カラム化・ヘッダーロゴ・かんたん計算ツール・フッター)

対象ブランチ: `feature/lp-visual-refresh`(既存の一人法人LP作業と同一ブランチで継続)
参考: キオミル株式会社(https://kiomiru.co.jp/)のデザインパターンを部分的に踏襲

---

## 1. カード角丸を4pxに統一

- 対象: 「こんな悩みはありませんか?」「FIREガイド」「あなたはどのタイプ?(ケーススタディ)」の各カード、およびCTAボタン全般
- `border-radius` を **4px** に変更(現状はおそらく `rounded-2xl` 相当でより強い丸み)
- **対象外**: Hero直下の3特徴セクション(モンテカルロ対応/日本制度対応/データ保護)は円アイコン+テキストのみでカード枠自体が存在しないため、**触らない**
- **対象外(別ルール)**: 「かんたん計算ツール」のカードは本指示書5節の通り左右ボーダーなしになるため、角丸を適用すると上下線の端が不自然にぶつ切りになる。**このカードのみ `border-radius: 0` とする**

## 2. 4セクションの2カラム化(お悩み/FIREガイド/ツール/ケーススタディ)

対象: 「こんな悩みはありませんか?」「FIREガイド」「かんたん計算ツール」「あなたはどのタイプ?」の4つのセクション見出し

現状(中央寄せの見出しのみ)を、以下の2カラム構成に変更する。

```
左カラム(目安35%)              右カラム(目安65%)
─── お悩み                     シミュレーターなら、悩みに
こんな悩みはありませんか?        具体的な数字で答えられます
```

- 各セクションの小ラベルは以下の通り(すべて左寄せ、14px・font-weight 500、グレー):
  - こんな悩みはありませんか? → 「お悩み」
  - FIREガイド → 「FIREガイド」
  - かんたん計算ツール → 「ツール」
  - あなたはどのタイプ? → 「ケーススタディ」
- ラベルの上/横に短い横線(20〜24px程度)を添える(キオミルの「─── 課題解決」と同型)
- 見出し本体は左カラムに左寄せ・太字で配置
- 右カラムには補足文のみを左寄せで配置(現状の中央寄せ補足文をそのまま移動)
- 左右カラム間の `gap` は64px程度を目安に、CSS Gridの列幅比率(35:65程度)とgapのみで非対称レイアウトを作る(特殊な装飾技法は不要)
- **レスポンシブ**:
  - タブレット幅(768〜1024px程度)で左カラムの見出しが不自然に折り返さないか要確認。過去に一人法人Heroで同種の折り返し不具合(「選択肢」が単語途中で改行)が発生した実績があるため、同じ確認を行うこと
  - スマホ幅では1カラムに縦積み(ラベル→見出し→補足文の順)

## 3. ヘッダーロゴの主従関係

- 対象: **資産シミュレーター側・一人法人側の両方**のヘッダーロゴ表記
- 「FREENOUGH」を拡大、区切り文字の後のセクション名(「資産シミュレーター」「一人法人」等)を縮小・グレー寄りの色に変更し、主従関係を明確にする
- フォントサイズ比の目安は1.4〜1.6倍程度(「FREENOUGH」側を基準に、セクション名側を1/1.4〜1/1.6のサイズに)
- 「FREENOUGH」の色・2つ目のEの下の緑アンダーラインアクセントは現状のまま変更しない
- ヘッダーは共通コンポーネントから全ルートに一括描画される設計のため、**変更後は資産シミュレーター配下・一人法人配下それぞれの複数ページ(LPトップだけでなく記事ページ・ツールページ等)で反映を確認すること**(過去に「LPトップだけ直って配下ページに反映されない」不具合が発生した実績あり)

## 4. CTAボタンの角丸

- 1節のカード角丸(4px)とサイズ感を揃える
- 対象: Hero直下の主要CTA、各セクションのCTAボタン全般

## 5. かんたん計算ツールのカードをボーダーレス化+4列化

- 説明文(「毎月の積立額と利回りから、将来の資産額を試算します」等)は**削除せずそのまま残す**
- カードの左右ボーダーは削除し、**上下ボーダーのみ**を各カード(グリッドアイテム)に個別設定する(横幅いっぱいの1本線ではなく、グリッドの列間gapがそのまま区切りの余白になる方式。キオミルの「得意なサイトタイプ」セクションと同じ実装)
- `border-radius` は1節の通り `0`
- デスクトップは**4列**、スマホは**2列**(iPhone SE幅まで含めて2列を維持)
- iPhone SE幅など画面が狭い場合、2列表示時にカード内の説明文が窮屈にならないよう、**説明文のフォントサイズを2列時のみ縮小**する(タイトルは縮小不要、本文のみ対応)

## 6. フッター最下部の濃紺化

- 対象: フッター最下部の「© 2026 FREENOUGH」を含むブロックのみ(その他の背景色リズムは現状維持)
- 背景色をCTAボタンと同じ濃紺に変更(キオミルのフッター最下部と同型の締め方)
- フッターも共通コンポーネントのため、全ルートでの反映確認を行うこと

## 7. 実装後の確認チェックリスト

- [ ] 1節: 3特徴セクションに角丸変更が誤って適用されていないか
- [ ] 1節: かんたん計算ツールカードのみ `border-radius: 0` になっているか(他カードは4px)
- [ ] 2節: タブレット幅(768〜1024px)で左カラム見出しが不自然に折り返していないか(4セクション全て)
- [ ] 3節: ヘッダーロゴ変更が資産シミュレーター・一人法人の両方、かつそれぞれ複数ページで反映されているか
- [ ] 5節: iPhone SE幅で2列表示時、説明文が窮屈に見えないか(フォントサイズ縮小が効いているか)
- [ ] 6節: フッター最下部の濃紺化が全ルートに反映されているか
- [ ] Preview環境で全項目を目視確認後、KENZOのGO出しを待ってmainマージ
