## 1. `ResidentTaxTimingTool.tsx` — 導入文の追加

見出し直下の既存説明文の後に、以下を追加:
「住民税は「前の年の所得」をもとに翌年課税される仕組みのため、退職すると、①退職前から進行中
だった住民税の残り と ②退職した年の所得をもとにした翌年の新しい住民税、という2つのタイミング
でお金が必要になります。」

## 2. `ResidentTaxTimingResult.tsx` — セクション見出しの言い換え

**修正前**: 「今の住民税の残り({incomeBasisYearLabel}の所得基準)」/「退職翌年6月からの新規課税」
**修正後**: 「① 退職前から進行中の住民税の残り({incomeBasisYearLabel}の所得基準)」/
「② 退職した年の所得をもとにした、翌年6月からの新しい住民税」

①②はアクセントカラー(`text-accent`)の太字で表示し、ヘッドライン直下の内訳表示
(「退職時に給与・退職金から差し引かれる想定」「自分で納付する想定」、プレーンテキスト・番号なし)
とは視覚的に区別した(税金の発生タイミングの軸 vs お金の出どころの軸)。
