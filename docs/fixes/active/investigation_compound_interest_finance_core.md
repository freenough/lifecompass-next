# 投資調査指示書:積立(複利)計算機 finance-core既存ロジックの所在確認

## 背景

Tools第3弾(積立(複利)計算機)は、現在資産・毎月積立額・想定利回り・積立期間から
将来評価額を試算する「順算」ツール。第1弾`calcRequiredMonthlyContribution()`・
第2弾`calcAchievementAge()`はいずれも「年金終価(ordinary annuity)の閉じた式」の
逆算にあたる関数であり、その内部で順算相当の計算(将来価値を求める処理)を
すでに保持している可能性が高い。

第2弾の検証スクリプトが「順算↔逆算の往復整合性チェック」を行っていたことからも、
順算ロジックに相当する計算式がコードのどこかに存在するはずである。

**本タスクは調査のみ。実装は行わない。**

## 調査してほしいこと

1. `src/lib/financeCore.ts`内に、将来価値(将来評価額)を返す関数が既に
   `export`されているか確認する
   - 例:`calcFutureValue()`のような名前の関数、または`calcRequiredMonthlyContribution()`・
     `calcAchievementAge()`の内部で使われているプライベートなヘルパー関数

2. 上記1で見つからない場合、`scripts/verify-fire-age.js`
   (または`scripts/verify-monthly-investment.js`)の中に、「順算↔逆算の
   往復整合性チェック」で使われている順算ロジックが存在するか確認する
   - スクリプト内だけに存在する場合、それがfinanceCore.ts側の関数を呼んでいるのか、
     スクリプト内で独自に再実装されているのかを明確にする

3. どちらにも見つからない場合、`calcRequiredMonthlyContribution()`・
   `calcAchievementAge()`それぞれの実装(年金終価の式)を確認し、そこから
   将来価値を求める式が数学的にどう導出できるかを示す

## 報告してほしい内容

- 上記1〜3のどのケースに該当したか
- 既存の順算ロジックが見つかった場合、その関数名・シグネチャ(引数・戻り値の型)・
  利回りの単位(%表記か小数表記か)
- 見つからなかった場合、新規に`calcFutureValue()`を実装するとしたら、
  どの既存関数(またはその内部ロジック)をベースに実装するのが最も整合性が
  高いか、実装方針の提案(コードは書かず、方針のみ)

## 遵守事項

- 独自の複利計算式を新規に考案してはいけない。あくまで既存コードベースに
  存在する年金終価の式との整合性を確認・活用する前提で調査すること
- 本タスクでは`financeCore.ts`・`page.tsx`等への変更は一切行わない。
  調査結果の報告のみ
