# 実装指示書：Hitori-Hojin LP「管理する」ブロックの表示切り替え

作成日：2026-08-18
対象リポジトリ：`lifecompass-next`
対象：Hitori-Hojin LP（`/hitori-hojin`）

---

## 0. 背景・スコープ

Hitori-Hojin LPの確定骨格は以下の通りで、「計算する」「管理する」は将来実装として非表示のプレースホルダーになっている。

```
Header → Hero → Intro
→「一人法人を知る」
→「一人法人を考える」
→[非表示]計算する
→[非表示]管理する
→ブログ一覧
→FIRE資産シミュレーターへの接続CTA
→[非表示]NOTE
→Footer
```

法人資産管理ツール（Phase1）の実装が完了したため、**「管理する」ブロックのみを表示状態に切り替える**。「計算する」は`CompanyState`実装待ちのため、引き続き非表示のままにする。この指示書は「管理する」ブロックのみを対象とする。

着手前に、LPの表示/非表示を制御している実装箇所（フラグ、条件分岐、またはコンポーネント自体が未実装でプレースホルダーのみ存在するのか）を確認し、以下の対応方針のどちらに該当するか報告すること：

- (A) 「管理する」ブロック用のコンポーネントの型・枠だけが存在し、表示フラグがfalseになっている → フラグをtrueにし、中身を本指示書の内容で実装
- (B) ブロック自体が未実装（プレースホルダーコメントのみ等） → 新規にコンポーネントを作成し、LPに組み込む

いずれの場合も、**「計算する」ブロックの非表示状態・実装には一切触れない**こと。

---

## 1. コンポーネント方針

- 「知る」「考える」ブロックで使われている`<ContentSection>`とは別の、独立したセクションコンポーネントとして実装する（資産シミュレーター側で作った`AssetManagementPromoSection.tsx`と役割が近いイメージだが、hitori-hojin側の複製方針に従い新規ファイルとして実装すること。import流用はしない）
- 配置先：hitori-hojin関連コンポーネントが置かれているディレクトリ（既存の8記事・LPコンポーネントと同じ場所）
- ファイル名例：`HitoriHojinManageSection.tsx`（既存の命名パターンに合わせて調整してよい）
- CTAのリンク先：法人資産管理ツールのルート（`src/lib/hojinAssetManagement/routes.ts`から取得、URLのハードコード禁止）

---

## 2. レイアウト

- デスクトップ：2カラム（左：テキスト＋CTA、右：イラスト）
- モバイル：1カラムに縦積み
- 外枠のスタイル（角丸・ボーダー・カード背景）は、資産シミュレーター側の導線セクション（`AssetManagementPromoSection.tsx`）と統一感を持たせる。ただし当該ファイルをimportせず、同じ見た目になるようスタイルを複製すること

## 3. コピー（確定文言）

**見出し：**
```
法人の資産も、FIREの進捗に。
```

**サブテキスト：**
```
法人に保有している資産を記録し、個人資産と合わせたFIRE進捗を確認できます。
```

**3つの特徴（アイコン＋テキスト）：**
```
[アイコン: building-bank系]  法人預金・証券口座など、法人特有の資産を記録
[アイコン: chart-donut系]    個人資産と合算して、FIRE進捗をまとめて確認
[アイコン: adjustments系]    将来の手取り目安を、自分で設定して試算
```

**CTAボタン：**
```
法人資産管理ツールを開く →
```

**CTA下部の補足テキスト：**
```
無料・登録不要・データは端末内に保存
```

## 4. 右側イラスト（積み上げバー・静的モック）

資産シミュレーター側の導線セクションで採用したドーナツ型とは差別化し、法人資産管理ツールの一番の特徴である「個人＋法人の積み上げ進捗バー」を模した静的イラストにする。**実データ連携ではなく固定値のモック**（法人資産管理ツール本体の実装が変わってもLP側の修正が不要になるようにするため）。

構成：
- カード内タイトル：「個人＋法人 合算」
- 横棒グラフ（CSS実装。個人資産部分＝濃い塗り、法人保有資産部分＝斜線パターンで右側に積み上げ）
  - 個人資産部分：全体の68%程度の幅、塗り色は法人資産管理ツールのCTAボタンと同じ濃紺
  - 法人保有資産部分：個人資産の右に14%程度の幅で追加、斜線パターン（濃紺の斜線、資産シミュレーター側の積み上げバーモックと同じ配色ルールを使用）
  - 目標ライン：バー右端にグレーの縦線マーカー
- 凡例：個人資産／法人保有資産の2行
- バー下に2つのミニ統計カード（グレー背景の角丸カード）：
  - 「目標までの進捗」→ `68%`
  - 「個人化想定比率」→ `70%`
- 日付表記・具体的な金額は入れない（資産シミュレーター側の対応と同様、モックとしての抽象度を保つ）
