# 調査依頼：法人資産トグルON時に「資産推移」グラフが消える不具合

作成日：2026-09-02
種別：**調査のみ（修正は行わない）**

---

## 0. 現象

資産管理ページ（`/asset-simulator/...` 資産管理ツール、プロファイル「テストB」で確認）にて、以下の再現手順で発生。

1. 「法人資産（一人法人）を含める」トグルがOFFの状態では、「資産推移」グラフ（保有資産の記録履歴9件分）が正常に折れ線で表示されている
2. 同じプロファイル・同じ記録履歴のまま、トグルをONにする
3. 「資産推移」グラフが空状態（「記録を重ねると推移がグラフで確認できます」「記録履歴はまだありません。『記録する』を押すと、今の保有資産が記録されます。」）に変わる

**添付スクリーンショット2枚（KENZOが実際に操作した画面）**
- トグルOFF時：「資産推移」に9件分の記録履歴・折れ線グラフが正常表示
- トグルON時：同じプロファイルなのに「資産推移」が空状態表示に切り替わる。上部に「表示：個人のみ／合算」の切替が新たに現れ、「法人資産が未入力のため『個人のみ』で表示しています」という注記も出ている

**重要な手がかり**：このプロファイルには法人資産（法人保有資産）が一切入力されていない（法人保有資産合計0円）。つまりこのプロファイルには法人スナップショットが1件も存在しない状態でトグルをONにしている。それにもかかわらず、個人側の記録履歴（9件、法人トグルに関係なく存在するはずのデータ）まで巻き込まれて消えている点が不自然。

**予実比較（下部の別グラフ）は影響を受けていない**：トグルON後も「予実比較」グラフ内の実績の点は表示されたままで、計画カーブとの比較も継続している。影響は「資産推移」グラフのみに限定されている。

---

## 1. 調査してほしいこと

推測ではなく実際のコードを確認して報告すること。

1. 「資産推移」グラフ（記録履歴一覧＋折れ線、`予実比較`とは別のセクション）を描画しているコンポーネントのファイルパス・コンポーネント名を特定する
2. そのコンポーネントが「記録履歴が0件かどうか」をどう判定しているか、実コードを引用する。特に、法人トグルON時にどのデータソース（`personalSnapshots`か`hojinSnapshots`か、あるいは両方をマージしたものか）を参照しているかを明確にする
3. 仮説：法人トグルONになると、判定ロジックが「法人スナップショットの有無」または「合算後の何らかの配列」を見てしまっており、個人のみの記録履歴（本来トグルに関係なく存在するはず）が無視されている可能性がある。この仮説が実コード上正しいか、コードを引用して確認・反証する
4. トグルON/OFFの状態管理がどのstore/propで行われているか（`useAssetManagerProfileStore`か別のstoreか）、その値がグラフ側にどう渡っているかを追う
5. 同じ原因パターン（トグル状態によって参照するデータソースを誤って切り替えている箇所）が、このページ内の他の表示（FIRE進捗カード等）にも無いか、ざっと確認する（モグラ叩き防止。V1のハイドレーションエラー修正時と同じ方針）
